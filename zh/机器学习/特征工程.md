# 特征工程

Q1：**特征工程与特征选择之间有什么区别？**

- **特征工程是从已有数据中构造、变换出新特征；特征选择是从所有特征（包括新造的）里挑出对预测最有用的子集。通常先做特征工程，再做特征选择。**
- 特征工程的典型任务：填充缺失值、把类别变量编码成数字、变量变换、构造或提取新特征。
- 特征选择一般需要标签，并根据模型在验证集上的表现来评估选出的子集。

Q2：**无监督学习可以帮助解决哪些常见的机器学习问题？**

- **无监督学习主要能缓解三类问题：标签稀缺、异常值和繁重的人工特征工程。**
- 数据稀缺：用聚类等方法给未标注样本自动打伪标签。
- 异常值：用降维、聚类等方法检测并剔除异常点。
- 特征工程：用表征学习自动学出有用的特征，减少人工设计。

Q3：***说出特征选择*的一些好处**

- **特征选择能降低过拟合、加快训练，并让模型更容易理解。**
- 特征多而样本少时会引入噪声，模型更容易过拟合。
- 特征少了运行更快，省下的算力可以用来尝试更复杂的模型或搜索更多超参数。
- 小特征集更容易解释，便于聚焦主要的预测来源。

Q4：**解释One-Hot encoding和label encoding。应用这些技术后数据集的维度是增加还是减少？**

- **Label encoding 给每个类别分配一个整数，维度不变；One-Hot encoding 把每个类别变成一个只有一位为 1 的 0/1 向量，维度会增加（增加到类别数）。**
- Label encoding 例如"红=0、绿=1、蓝=2"，但会引入本不存在的大小顺序，更适合有序类别或树模型。

**Q5：讲述机器学习算法应该包括哪些主要流程？**

- **一个典型的机器学习流水线依次包括：数据预处理、特征选择、模型训练（分类/回归）和后处理。**
- 例如分类管道：Scaler（标准化到零均值、单位方差）→ 特征选择器（去掉强相关、冗余的特征）→ 模型。

Q6：**可以使用PCA做特征选择吗？**

- **不能算特征选择。特征选择是从原特征中挑出一个子集，而 PCA 得到的主成分是所有原始特征的线性组合，属于特征提取/降维。**

Q7：**如何用F-test方法来选择特征？**

- **F-test 是一种统计检验：比较"只有常数项的模型"和"常数项加某个特征的模型"的最小二乘误差，看加入该特征后误差是否显著下降；显著的特征就保留。**
- 它衡量的是特征与目标之间的线性关系，对非线性关系不敏感。

Q8：**你知道哪些特征选择方法？**

- **分为无监督和有监督两类，有监督方法又分为 Filter、Wrapper 和 Embedded 三种。**
- 无监督：丢掉方差接近 0、缺失值很多或彼此高度相关的特征。
- Filter：用相关系数、互信息等统计量单独给每个特征打分，速度快。
- Wrapper：用模型对不同特征子集训练并在验证集上评分，选最好的子集；效果好但很耗时。
- Embedded：在训练中同时完成选择，如 LASSO 让不重要特征的权重变为 0，或用自编码器的瓶颈层做选择。

Q9：**如何提高随机森林的性能？**

- **主要通过调节节点大小和树的数量：想提高预测能力，可以用更小的 nodesize（让树长得更深）和更多的树。**
- 也可以调节每次分裂随机选取的特征数（mtry / max_features）来平衡树之间的相关性和单棵树的强度。

Q10：**如何对未知特征（不明白特征的真实意义）进行特征工程？**

- **缺乏领域知识而特征又很多时，手工设计意义不大，更适合用自动化的特征工程。**
- 用 PCA、ICA 把数据映射到新的特征空间。
- 用深度特征合成，或借助神经网络中间层学到的表示作为特征。

Q11：**讲述PCA的具体执行流程？**

- **先标准化数据，计算协方差矩阵并做特征分解，按特征值从大到小取前 N 个特征向量作为主成分，再把数据投影到这些方向上。**
- 标准化很重要：PCA 对方差敏感，量纲不同的特征会扭曲主成分。
- 特征值越大，对应主成分解释的方差越多；可按累计解释方差比（如 95%）选 N。
- 投影就是用原始（标准化后的）数据乘以选出的特征向量矩阵。

Q12：**解释PCA（主成分分析）和ICA（独立成分分析）之间的区别？**

- **PCA 找方差最大且互相正交（不相关）的方向，主要用于压缩信息、降维；ICA 找统计上相互独立的成分，主要用于把混合信号分离开（如盲源分离）。**
- PCA 只用到二阶统计量（协方差）；ICA 要求独立，比不相关更强，需要非高斯性等高阶信息。

Q13：**如何将偏态分布转变为正态分布？**

- **常用对数变换或平方根变换把长尾压缩，使分布更接近正态，因为很多模型在变量接近正态时预测更可靠。**
- 对数变换压缩能力最强，适合严重右偏的数据（有 0 值时用 log(1+x)）。
- 平方根变换更温和；更通用的还有 Box-Cox / Yeo-Johnson 变换。

Q14：**你知道哪些数据的插值方法？**

- **按数据类型选择填充值：连续数据用均值或中位数，类别数据用中位数或众数，布尔数据按频率填充。**
- 连续数据：近似正态用均值；偏态或异常值多时用中位数。
- 类别数据：有序类别用中位数，无序类别用众数。

Q15：**多元线性回归中，应该去除高度相关的特征吗？**

- **一般建议只保留其中一个。高度相关的特征（多重共线性）会让 $X^TX$ 接近奇异，导致权重估计的方差很大，模型系数不稳定、难以解释。**
- 共线性主要影响系数的稳定性和可解释性，对整体预测精度的影响相对较小。
- 除了删特征，也可以用岭回归（L2 正则）或 PCA 来缓解。
- 核心公式：权重的方差为 $\mathrm{Var}(w)=\sigma^2(X^TX)^{-1}$

引用：[https://datascience.stackexchange.com/questions/36404/when-to-remove-correlated-variables](https://datascience.stackexchange.com/questions/36404/when-to-remove-correlated-variables)

Q16：**如何在迁移学习中运用特征工程？**

- **把在大规模通用数据集上预训练好的模型当作特征提取器，复用它学到的特征映射，只在上面接一个从头训练的新分类器。**
- 数据少时冻结主干只训新头；数据多时可以进一步微调整个网络。

Q17：**标准化和归一化异同**

- **两者都是线性缩放，不改变数据的大小顺序；归一化（min-max）把数据缩放到 [0,1]，标准化（z-score）把数据变成均值 0、方差 1。**
- 归一化只由最大、最小两个极值决定，对异常值敏感。
- 标准化用到均值和标准差，每个数据点都有影响，更稳健，也更常用。

Q18：**如何理解组合特征？**

- **组合特征就是把两个或多个特征交叉成一个新特征，用来表达单个特征无法表达的交互关系。**
- 例如新闻推荐中，单独用性别或兴趣效果一般，但"性别 × 兴趣"能体现女性偏好娱乐、男性偏好体育财经等模式，效果明显更好。
- 线性模型自己学不到交互，所以特别依赖组合特征。

Q19：**如何处理高维组合特征？比如用户ID和内容ID？**

- **直接交叉会得到维度极高、极其稀疏的特征，常用矩阵分解把用户和内容各自映射成低维向量，用向量内积表示它们的组合。**
- 这样参数量从 $m\times n$ 降到 $(m+n)\times k$，并能泛化到没出现过的组合。
- 常见的矩阵分解有 SVD、QR 分解、LU 分解等；推荐系统里的 FM、矩阵分解都是这个思路。

Q20：**文本特征表示有哪些模型？他们的优缺点都是什么？**

- **主要有词袋、N-gram、主题模型和词嵌入四类，从简单稀疏逐渐走向稠密且有语义。**
- 词袋：简单，但丢失词序和上下文，表示高维稀疏。
- N-gram：把连续 n 个词当一个特征，保留局部词序，但参数空间更大、更稀疏。
- 主题模型（如 LDA）：能得到每篇文档的主题分布，维度低、可解释。
- 词嵌入：把词映射为 K 维稠密向量，能刻画词与词之间的语义关系。

Q21：**Word2vec和LDA两个模型有什么区别和联系？**

- **两者都利用词的共现信息：LDA 基于"文档-单词"共现，把词按主题聚类；Word2vec 基于"上下文-单词"共现，学习每个词的稠密向量，向量相似说明它们常出现在相同上下文中。**
- 模型类型不同：LDA 是基于概率图的生成式模型，有隐变量（主题）需要推断。
- Word2vec 是神经网络模型，通过学习网络权重得到词向量。
- LDA 结果是文档-主题、主题-单词两个概率分布；Word2vec 结果是词向量。

Q22：**怎么检测特征中的异常值？**

- **常用方法有统计规则（3σ、四分位数）、统计检验、基于 PCA 重构误差以及基于距离/聚类的方法。**
- 3σ 原则：假设正态分布，偏离均值超过 3 倍标准差（概率约 0.3%）的点视为异常。
- 四分位数（箱线图）：超出 $[Q1-1.5\,IQR,\ Q3+1.5\,IQR]$ 的点视为异常，不依赖正态假设。
- PCA：分解再重构，重构误差大的点为异常。
- 距离/聚类：用 kmeans、KNN、DBSCAN 等，离簇中心最远或不属于任何簇的点为异常。

Q23：**怎么处理特征中的异常值？**

- **可以直接删除含异常值的记录，或把异常值当作缺失值交给缺失值处理方法，也可以用均值或众数修正。**
- 还可以做截尾（clipping 到某个分位数）或对数变换来降低其影响。

Q24：**如何解决数据不平衡的问题？**

- **主要从数据（重采样、合成样本）、评价指标和算法三方面入手。**
- 采样：上采样复制少数类（容易过拟合，可加轻微扰动）；下采样删减多数类（会丢信息，可多次下采样训练多个模型再集成）。
- 数据合成：如 SMOTE，利用少数类样本在特征空间的相似性生成新样本。
- 评价指标：看 precision、recall 和 PR 曲线，而不是只看准确率或 ROC——ROC/AUC 在极度不平衡时容易显得过于乐观。
- 算法：选择对类别倾斜不太敏感的模型（如树模型），或使用类别加权损失。

引用：[https://blog.csdn.net/](https://blog.csdn.net/)

Q25：**简述线性判别分析LDA的原理**

- **LDA 是有监督的降维方法：寻找一个投影方向，使投影后同类样本尽量靠近（类内方差小）、不同类中心尽量远离（类间方差大）。**
- 与 PCA 的区别：PCA 不用标签，只保留最大方差方向；LDA 利用类别标签，保留最有区分力的方向。
- 对 $C$ 个类别，最多能降到 $C-1$ 维。

## 信号处理特征工程（生理信号与音频）

Q26：**什么是采样定理（Nyquist）和混叠？量化会带来什么影响？**

- **采样定理说：采样率必须大于信号最高频率的两倍，才能无失真重建信号；否则高于 $f_s/2$（Nyquist 频率）的成分会"折叠"到低频，形成无法去除的混叠。**
- 采样或降采样前必须先做抗混叠低通滤波；实际采样率常取最高有用频率的 2.5–5 倍。
- 量化把连续幅值变成有限位数的离散值，会引入量化噪声，每多 1 bit 信噪比约提高 6 dB。
- 位数不足或增益不当时，微弱信号（如 µV 级 EEG）会被淹没，大信号会被削波（clipping）。

Q27：**FIR 与 IIR 滤波器有什么区别？Butterworth 滤波器有什么特点？**

- **FIR 只用当前和过去的输入，总是稳定且可以做到严格线性相位，但要陡峭的过渡带需要很高阶数；IIR 带有输出反馈，用很低阶数就能得到陡峭的响应，但相位非线性、可能不稳定。**
- IIR 实践中常用二阶节（SOS）形式实现以保证数值稳定。
- Butterworth 是最常用的 IIR 滤波器：通带最平坦、无纹波，幅频响应单调下降。
- 它的过渡带不如 Chebyshev / 椭圆滤波器陡，但不引入通带纹波，因此最常用于生理信号预处理；$n$ 阶的阻带衰减约为 $20n$ dB/十倍频程。

Q28：**带通、陷波滤波分别用于什么场景？为什么常用零相位滤波（filtfilt）？**

- **带通滤波保留感兴趣的频段，去掉低频漂移和高频噪声；陷波滤波在极窄频带内强衰减，主要去除 50/60 Hz 工频干扰。filtfilt 正反各滤一次，相位失真相互抵消，波形不会发生时移。**
- 带通常见范围：ECG 0.5–40 Hz、EEG 0.5–45 Hz、sEMG 20–450 Hz、PPG 0.5–8 Hz。
- 零相位能保证 R 峰、ERP 等波形特征的时间位置准确；代价是等效衰减翻倍。
- 局限：filtfilt 需要未来样本，是非因果的，只能离线用；实时系统要用因果滤波并补偿群延迟。

Q29：**什么是频谱泄漏？加窗为什么能缓解它？**

- **对有限长信号做 DFT 相当于加了矩形窗并假设信号周期延拓；如果截取长度不是信号周期的整数倍，边界处的跳变会让能量从真实频率"泄漏"到相邻频点。加窗用两端平滑衰减到 0 的窗函数减小边界跳变，从而降低旁瓣、减轻泄漏。**
- 权衡：主瓣宽度（频率分辨率）与旁瓣高度（泄漏）互相制约。
- 矩形窗主瓣最窄但旁瓣最高（约 −13 dB）；Hann（约 −31 dB）、Hamming（约 −43 dB）、Blackman 旁瓣依次更低，但主瓣更宽。
- 补零只是对频谱插值，让曲线更平滑，不会提高真实的频率分辨率。

Q30：**FFT 和 STFT 有什么区别？如何理解时频分辨率的权衡？**

- **FFT 给出整段信号的全局频谱，不知道频率成分何时出现，只适合平稳信号；STFT 把信号切成加窗、重叠的短帧，每帧做 FFT，得到时频图，适合语音、EEG 等非平稳信号。**
- 频率分辨率约等于 1/窗长：窗越长，频率分辨率越好但时间分辨率越差，反之亦然。
- 受不确定性原理限制，时间和频率分辨率不能同时任意精细。
- STFT 对所有频率使用同一窗长，因此整个时频平面上的分辨率是固定的。

Q31：**小波变换（CWT/DWT）与 STFT 相比有什么优势？**

- **小波变换用母小波的伸缩和平移作为基函数，实现多分辨率分析：高频用短窗（时间分辨率好），低频用长窗（频率分辨率好），特别适合"低频缓慢 + 高频瞬态"的信号，如 QRS 波、EEG 棘波。**
- CWT：尺度连续，冗余大、计算量大，主要用于时频可视化（如 Morlet 小波的 scalogram，可作 2D CNN 输入）。
- DWT：用滤波器组 + 降采样逐层分解出近似（低频）和细节（高频）系数，高效无冗余，常用于去噪、去基线漂移和压缩；各子带的能量、熵等可作特征。
- 缺点：需要选择母小波（如 db4、sym）和分解层数；DWT 不具平移不变性（可用 SWT 缓解）。

Q32：**如何估计功率谱密度（PSD）？Welch 方法的原理是什么？**

- **最直接的是周期图（FFT 取模平方），但它的方差不随数据变长而下降，估计很嘈杂；Welch 方法把信号分成有重叠（常用 50%）的段，每段加窗算周期图后取平均，以牺牲频率分辨率换来更低的方差。**
- 平均 K 段大约能把方差降低 K 倍，是典型的偏差-方差权衡。
- 其他方法：多窗口法（multitaper）、参数化 AR 谱估计（适合短数据）。
- PSD 是 EEG 频段功率、HRV 频域指标、EMG 中值频率等特征的基础。

Q33：**重采样、去趋势和归一化在信号预处理中需要注意什么？**

- **重采样前要先抗混叠滤波；去趋势是为了去掉缓慢漂移，避免低频能量主导频谱；归一化要防止数据泄漏，并注意它会抹掉绝对幅值信息。**
- 重采样：降采样用 `decimate`，有理数倍变换用多相滤波 `resample_poly`；基于 FFT 的 `resample` 假设信号周期，边界可能振铃。
- 去趋势：多项式拟合相减、高通滤波或中值滤波。
- 归一化：z-score 可消除个体间幅值差异，robust scaling（中位数/IQR）对异常值更稳健；统计量只能在训练集或受试者自身校准数据上估计。
- 有些任务（如 EMG 力度估计、EEG 绝对功率）恰恰需要绝对幅值，不宜归一化。

Q34：**长时信号如何分段（滑动窗口）？窗口上常提取哪些统计特征？**

- **用固定长度、带重叠（常用 50%）的滑动窗口切分信号，窗长要匹配目标现象的时间尺度；然后在每个窗口上提取时域统计量和频域特征。**
- 窗长示例：EEG 睡眠分期 30 s、EMG 手势识别 150–250 ms、HRV 分析 5 min；太长增加延迟、混入多种状态，太短特征不稳定。
- 标签：可用窗口内多数投票、窗口末端标签，或丢弃跨状态边界的窗口。
- 时域特征：均值、方差、RMS、峰峰值、百分位数、偏度、峰度、过零率、Hjorth 参数；频域特征：频段功率、谱质心、谱熵、主频。
- 注意：重叠窗口高度相关，先切窗再随机划分训练/测试集会造成严重泄漏。

Q35：**常见的熵特征有哪些？样本熵如何计算？**

- **熵衡量信号的复杂度/不规则程度，常见的有香农熵/谱熵、近似熵、样本熵、排列熵和多尺度熵。样本熵比较长度为 $m$ 和 $m+1$ 的模板在容差 $r$ 内的匹配数，匹配比例越低（熵越大），信号越不规则。**
- 谱熵：对归一化 PSD 求香农熵，越低说明能量越集中在少数频率。
- 近似熵会计入自匹配，有偏差且依赖数据长度；样本熵排除自匹配，偏差更小，常取 $m=2$、$r=0.2\cdot$std，但计算复杂度为 $O(N^2)$。
- 排列熵基于排序模式，快且抗噪；多尺度熵在多个粗粒化尺度上分别算样本熵。
- 核心公式：$SampEn(m,r)=-\ln\dfrac{A}{B}$（$B$、$A$ 分别为长度 $m$、$m+1$ 的匹配对数）

Q36：**ECG 预处理中常见的噪声有哪些？如何去除？**

- **主要有基线漂移、工频干扰、肌电干扰和运动伪迹，分别用高通/中值滤波、陷波、低通/小波去噪处理，严重伪迹则直接剔除。**
- 基线漂移（<0.5 Hz，呼吸和运动引起）：高通滤波（诊断级用 0.05 Hz 以保留 ST 段）、两级中值滤波或小波去除低频分量。
- 工频干扰：50/60 Hz 陷波或自适应滤波。
- 肌电干扰：宽带高频，用低通（如 40 Hz）或小波阈值去噪，与 QRS 频带重叠，难以完全去除。
- 运动伪迹/电极接触不良：用信号质量评估（SQI）剔除低质量片段；离线分析用零相位滤波保持波形形态。

Q37：**简述 Pan-Tompkins R 峰检测算法**

- **Pan-Tompkins 是经典的实时 QRS 检测算法：通过带通、微分、平方和滑动积分把 QRS 波变成明显的能量包络，再用自适应阈值判定 R 峰。**
- 带通（约 5–15 Hz）突出 QRS、抑制 P/T 波和噪声；微分取斜率；平方放大高斜率部分；约 150 ms 窗口积分得到能量包络。
- 自适应双阈值分别跟踪信号峰和噪声峰；200 ms 不应期防止重复检测；长时间未检出则降低阈值回溯搜索。
- 最后回到原始信号中精确定位 R 峰；工程上可直接用 NeuroKit2、BioSPPy 等库。

Q38：**HRV 有哪些时域和频域特征？计算时需要注意什么？**

- **HRV 基于相邻 R 峰间期（RR/NN）序列：时域指标有 SDNN、RMSSD、pNN50，频域指标有 LF、HF 和 LF/HF；计算时要先处理非均匀采样和异位搏动。**
- SDNN 反映总体变异；RMSSD 和 pNN50 反映逐拍变异，主要体现副交感（迷走）活动。
- 频段：LF 0.04–0.15 Hz，HF 0.15–0.4 Hz（与呼吸相关，体现迷走活动）；LF/HF 传统上被视为交感-迷走平衡，但有争议。
- RR 序列非均匀采样，需先插值重采样（如 4 Hz）再做 Welch，或用 Lomb-Scargle 周期图。
- 必须先剔除/校正异位搏动和误检；指标依赖记录时长（短时标准为 5 min），不同长度不可直接比较。

Q39：**EEG 的频段如何划分？如何提取频段功率特征？**

- **常用频段为 delta（0.5–4 Hz）、theta（4–8 Hz）、alpha（8–13 Hz）、beta（13–30 Hz）、gamma（>30 Hz）。频段功率通常用 Welch 估计 PSD，在频段内积分得到绝对功率，再除以总功率得到相对功率，并取对数。**
- 对应状态：delta 深睡眠，theta 困倦，alpha 放松闭眼，beta 警觉/运动，gamma 高级认知但易受肌电污染。
- 相对功率能降低个体间幅值差异；取 log 让分布更接近正态。
- 衍生特征：频段功率比（如 theta/beta）、左右半球不对称性、微分熵（情绪识别常用）、通道间相干性，以及运动想象中的 CSP 空间滤波特征。

Q40：**EEG 中有哪些常见伪迹？如何用 ICA 去除？什么是 epoching？**

- **常见伪迹有眼电（EOG）、肌电（EMG）、心电（ECG）、工频干扰和电极问题。ICA 把多通道 EEG 分解成独立成分，识别出伪迹成分后将其置零再重建信号。Epoching 是以事件为锚点截取固定时间窗，用于 ERP 和事件相关分析。**
- EOG 低频大幅值、在额叶；EMG 高频宽带、在颞区。
- ICA 流程：先高通约 1 Hz、剔除坏导 → 分解 → 根据地形图、频谱或 ICLabel 识别伪迹成分 → 去除后反投影。它要求源独立、线性混合且通道足够，也可能误删神经信号。
- Epoching：截取如 −200 至 800 ms 的窗口，用事件前区间做基线校正，再按幅值阈值（如 ±100 µV）剔除坏试次。

Q41：**PPG 信号处理有什么难点？如何从中估计心率和血氧（SpO2）？**

- **最大难点是运动伪迹：腕戴设备中手臂运动的频率与心率频带重叠，简单带通无法分开。心率通过带通后检测脉搏峰或找 PSD 主频得到；SpO2 利用红光和红外光吸收差异，计算"比值的比值" R，再查校准曲线。**
- PPG 的 AC 分量是心搏引起的脉动，DC 分量是组织等的基础吸收。
- 去运动伪迹：用加速度计做自适应滤波、频谱减法与谱峰跟踪（如 TROIKA）、用 SQI 剔除差片段，或深度学习融合加速度信息。
- 还可提取脉率变异性、脉搏波形态，以及与 ECG 联合的脉搏传导时间（用于无袖带血压估计）。
- 核心公式：$R=\dfrac{AC_{red}/DC_{red}}{AC_{IR}/DC_{IR}}$，SpO2 再由设备校准曲线（常见近似 $110-25R$）得到；测量受运动、低灌注和肤色影响。

Q42：**表面肌电（sEMG）常用哪些特征？**

- **常用时域特征是 MAV、RMS、WL、ZC、SSC（Hudgins 特征集），常用频域特征是平均频率 MNF 和中值频率 MDF；MNF/MDF 下降是经典的肌肉疲劳指标。**
- 预处理：带通 20–450 Hz（采样率 ≥1000 Hz）、陷波去工频；包络用整流后低通。
- MAV、RMS 与肌肉激活程度/肌力相关；WL 反映信号复杂度；ZC、SSC 需配合噪声阈值。
- 疲劳时传导速度下降，频谱向低频移动，所以 MNF/MDF 降低。
- 手势识别常用 150–250 ms 窗口、50% 以上重叠，以满足实时性（总延迟 <300 ms）。

Q43：**生理信号建模中如何避免数据泄漏？如何处理类别不平衡？**

- **关键是按受试者划分数据（如 GroupKFold 或留一受试者交叉验证），并且所有预处理只在训练折内拟合；不平衡则用加权损失、平衡采样和合适的评价指标来处理。**
- 受试者间差异极大，随机划分窗口会让同一人的样本同时进训练和测试集，模型学会"认人"，结果严重虚高。
- 受试者内评估要按时间划分并留间隔；归一化、特征选择、ICA、过采样都放进训练折的 Pipeline 中；明确报告评估方式。
- 不平衡：类别加权损失、Focal Loss、分层/平衡采样；只在训练集上过采样，信号层面的增强通常比特征空间 SMOTE 更合理。
- 评价用 F1、平衡准确率、Cohen's kappa、AUPRC 和事件级指标（如每小时误报数），并按部署时的先验调整阈值。

Q44：**手工特征 + 传统模型与端到端 1D-CNN（原始信号）相比各有什么优劣？**

- **手工特征 + 传统模型在小数据下稳健、可解释、易部署，但依赖领域知识且可能遗漏信息；端到端深度模型能自动学习模式，大数据时通常更强，但需要大量标注、可解释性差、易过拟合到受试者或设备。**
- 手工特征流程容易受某一步误差影响（如 R 峰检测错误）。
- 深度模型对采样率、导联配置变化较敏感。
- 折中：时频图 + 2D CNN、有可解释先验的网络（如 SincNet、EEGNet）、手工特征与深度特征融合、自监督预训练后微调。
- 按数据规模、可解释性要求和部署资源选择；无论哪种都要做受试者独立评估。

Q45：**详细描述 MFCC 的提取流程**

- **MFCC 的流程是：预加重 → 分帧 → 加窗 → FFT 求功率谱 → Mel 滤波器组 → 取对数 → DCT，最后保留前 12–13 个系数。**
- 预加重（系数约 0.97）补偿语音高频衰减；分帧常用 25 ms 帧长、10 ms 帧移；加 Hamming 窗减少泄漏。
- Mel 滤波器组（20–40 个三角滤波器）模拟人耳低频分辨率高、高频分辨率低的特性。
- 取对数压缩动态范围，符合人耳对响度的感知；DCT 去相关，舍去对应精细谐波结构的高阶系数。
- 可选：倒谱均值方差归一化（CMVN）消除信道影响，加一阶/二阶差分得到 39 维特征。
- 核心公式：$m=2595\log_{10}\left(1+\dfrac{f}{700}\right)$

Q46：**log-Mel 频谱与 MFCC 有什么区别？为什么深度模型更偏好 log-Mel？什么是差分特征？**

- **MFCC 就是在 log-Mel 上再做 DCT 并截断，得到去相关的低维特征，适合对角协方差 GMM-HMM 等传统模型；深度模型偏好 log-Mel，因为它保留了频谱的局部结构，CNN 能直接利用，而网络自己就能学会去相关和降维。**
- DCT 混合了所有频带，破坏了相邻频带的局部相关性，截断还丢掉了谐波等信息。
- 现代 ASR、声音事件检测、说话人识别（如 Whisper 用 80/128 维 log-Mel）大多用 log-Mel（Fbank）。
- 差分特征（Δ / ΔΔ）描述特征随时间的变化，用前后若干帧回归得到；13 维 MFCC + Δ + ΔΔ = 39 维。对 RNN/Transformer 等有时间建模能力的模型，差分的增益通常较小。

Q47：**常用的音频手工特征有哪些？**

- **主要有时域特征（过零率、短时能量）、频谱形状特征（谱质心、滚降点、谱通量等）、音乐特征（色度）和音高特征（F0 及其统计量）。**
- 过零率：清音/噪声高、浊音低，用于清浊音判别；短时能量/RMS 反映响度，用于静音检测。
- 谱质心与音色"明亮度"相关；滚降点是累计能量达到 85%/95% 的频率；谱通量衡量相邻帧频谱变化，用于起始点检测；还有谱平坦度、谱带宽、谱对比度。
- 色度（Chroma）把能量折叠到 12 个半音，用于和弦识别、翻唱检测。
- F0 可用自相关、倒谱、YIN/pYIN 或 CREPE 估计；F0、jitter、shimmer、HNR 常用于情感识别和病理嗓音检测；帧级特征再做统计汇总可得片段级向量（如 eGeMAPS）。

Q48：**什么是语音活动检测（VAD）？有哪些实现方法？**

- **VAD 判断每一帧是语音还是非语音，是 ASR、说话人识别、语音编码和降噪的前置步骤，可以减少计算并避免模型学习静音段。实现方法从简单阈值到统计模型再到神经网络。**
- 能量 + 过零率阈值：简单快速，低信噪比下效果差。
- 谱特征：谱熵、谱平坦度等（语音谱结构强、熵低）。
- 统计模型：语音/噪声分别建模做似然比检验（如 WebRTC VAD 用 GMM）；神经网络 VAD（如 Silero、pyannote）在噪声下更鲁棒。
- 后处理加 hangover 和最小时长约束平滑决策；阈值根据下游任务在漏检与虚警之间权衡。

Q49：**音频（及生理信号）有哪些数据增强方法？**

- **音频常用 SpecAugment（在频谱上做时间扭曲、频率掩蔽、时间掩蔽）、波形级增强（变速、变调、加噪、加混响等）和 Mixup；生理信号常用加噪、幅值缩放、时间扭曲、随机裁剪和通道丢弃。**
- SpecAugment 开销低，能显著提升 ASR 鲁棒性。
- 波形级：速度扰动（同时改时长和音高）、time-stretch（只改时长）、pitch-shift（只改音高）、按指定 SNR 加噪、与房间冲激响应卷积、增益变化等。
- Mixup：两条样本及其标签按 Beta 分布采样的比例线性混合，常用于声音事件分类。
- 注意：增强不能改变标签语义（如对 ECG 时间伸缩会改变心率），且只能用在训练集上。

Q50：**wav2vec 2.0 / HuBERT 等自监督表征与手工特征（MFCC/Fbank）相比有什么特点？**

- **自监督模型从海量无标注语音中学到层次化表示，在标注很少时效果远超 MFCC/Fbank；代价是模型大、推理慢，迁移到非语音或不同采样率时存在领域失配，可解释性也差。**
- wav2vec 2.0：CNN 编码原始波形，Transformer 建模上下文；预训练时掩蔽部分帧，用对比损失从干扰项中找出真实的量化表示。
- HuBERT：先用 k-means 聚类生成伪标签（首轮用 MFCC，之后用上一轮模型特征），在掩蔽帧上做掩码预测，训练更稳定；WavLM 再加入去噪和说话人混合。
- 浅层偏声学/说话人信息，中间层偏音素/语义；可冻结模型、对各层加权求和后接轻量头（SUPERB 方式），也可整体微调。
- 实践：数据少的语音任务优先用自监督表征；资源受限、需要实时或可解释时，Fbank/MFCC + 小模型仍是强基线；EEG/ECG 领域也有类似的自监督预训练。
