# 梯度提升树（GBDT / XGBoost / LightGBM / CatBoost）

## Boosting 基础

Q1：***Boosting 和 Bagging 有什么区别？***

| | Bagging（如随机森林） | Boosting（如 AdaBoost、GBDT） |
|---|---|---|
| 训练方式 | **并行**，各基学习器相互独立 | **串行**，后一个学习器依赖前面的结果 |
| 样本使用 | bootstrap 有放回采样 | 全部样本，按权重/梯度关注难样本 |
| 基学习器 | 强学习器（深树，低偏差高方差） | 弱学习器（浅树，高偏差低方差） |
| 主要作用 | **降低方差** | **降低偏差**（也有一定降方差作用） |
| 组合方式 | 等权平均 / 投票 | 加权求和（加法模型） |
| 对噪声 | 鲁棒 | 较敏感，容易拟合噪声/异常值 |

- 直观理解：Bagging 是"多个专家独立投票取平均"，Boosting 是"一个接一个地纠正前面的错误"。

Q2：***简述 AdaBoost 的原理。***

- 二分类 $y\in\{-1,+1\}$，初始化样本权重 $w_i = 1/N$。对 $t=1,\dots,T$：
    1. 用当前权重训练弱分类器 $h_t$，计算加权错误率 $\epsilon_t = \sum_i w_i \mathbb{I}(h_t(x_i)\ne y_i)$；
    2. 计算分类器权重 $\alpha_t = \frac{1}{2}\ln\frac{1-\epsilon_t}{\epsilon_t}$（错误率越低权重越大，$\epsilon_t<0.5$ 时 $\alpha_t>0$）；
    3. 更新样本权重 $w_i \leftarrow w_i \exp(-\alpha_t y_i h_t(x_i))$ 并归一化，**错分样本权重增大**。
- 最终模型 $H(x)=\text{sign}\left(\sum_t \alpha_t h_t(x)\right)$。
- 理论视角：AdaBoost 等价于用**指数损失** $L=\exp(-yF(x))$ 的**前向分步加法模型**。指数损失对误分类样本惩罚呈指数增长，因此 AdaBoost **对噪声和异常值敏感**。GBDT 把这一思想推广到任意可微损失。

## GBDT

Q3：***GBDT 的核心思想是什么？为什么说它是"函数空间的梯度下降"？***

- GBDT 是一个**加法模型**：$F_M(x) = F_0(x) + \sum_{m=1}^{M}\nu\, h_m(x)$，每个 $h_m$ 是一棵回归树，用前向分步算法逐棵训练。
- 第 $m$ 步希望找 $h_m$ 使 $\sum_i L(y_i, F_{m-1}(x_i)+h_m(x_i))$ 最小。把 $F$ 在每个样本处的取值看作"参数"，损失对其的**负梯度**就是最速下降方向：
$$r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$$
- 由于只能在训练点上算梯度，为了泛化到新样本，用一棵回归树去**拟合负梯度** $\{(x_i, r_{im})\}$（称为**伪残差**），相当于把梯度投影到"树函数空间"。因此 GBDT 是在**函数空间做梯度下降**，与参数空间的梯度下降 $\theta \leftarrow \theta - \eta\nabla_\theta L$ 对应。
- 对平方损失 $L=\frac12(y-F)^2$，负梯度正好是残差 $y-F$，所以"拟合残差"只是平方损失下的特例。

Q4：***写出 GBDT 的算法流程。***

1. 初始化 $F_0(x)=\arg\min_\gamma \sum_i L(y_i,\gamma)$（平方损失下为均值，对数损失下为 log-odds）。
2. 对 $m=1,\dots,M$：
    1. 计算伪残差 $r_{im} = -\partial L(y_i,F_{m-1}(x_i))/\partial F_{m-1}(x_i)$；
    2. 用 $\{(x_i, r_{im})\}$ 拟合一棵回归树（按 MSE 分裂），得到叶区域 $R_{jm}, j=1..J$；
    3. 对每个叶子做**线搜索**求最优输出值：$\gamma_{jm} = \arg\min_\gamma \sum_{x_i\in R_{jm}} L(y_i, F_{m-1}(x_i)+\gamma)$；
    4. 更新 $F_m(x)=F_{m-1}(x)+\nu\sum_j \gamma_{jm}\mathbb{I}(x\in R_{jm})$。
3. 输出 $F_M(x)$。

- 注意：树的**结构**由拟合负梯度决定，**叶子值**则按原始损失重新优化（对平方损失两者一致）。

Q5：***GBDT 如何做分类？***

- GBDT 的基学习器始终是**回归树**，分类时拟合的是对数几率（logit）空间中的值。
- **二分类**：$p=\sigma(F(x))$，使用对数损失 $L=-[y\log p + (1-y)\log(1-p)]$，$y\in\{0,1\}$。
    - 负梯度 $r_i = y_i - p_i$（真实标签减预测概率）；
    - 叶子值没有闭式解，通常用一步**牛顿法**近似：$\gamma_j = \frac{\sum_{i\in R_j} r_i}{\sum_{i\in R_j} p_i(1-p_i)}$；
    - 初始化 $F_0 = \log\frac{\bar y}{1-\bar y}$。
- **多分类**（$K$ 类）：每轮训练 **$K$ 棵树**，每类一棵，输出经 softmax 得到概率，第 $k$ 类的负梯度为 $y_{ik}-p_{ik}$。因此多分类的树数量是 $K \times$ 迭代轮数。

Q6：***GBDT 中的 Shrinkage（学习率）和子采样有什么作用？***

- **Shrinkage**：$F_m = F_{m-1} + \nu h_m$，$0<\nu\le1$（常用 0.01–0.1）。每棵树只走"一小步"，不完全信任单棵树，给后续树留出修正空间，相当于正则化。经验上**小学习率 + 多棵树**泛化更好，但训练时间更长；$\nu$ 与树的数量需联合调节（通常配合早停）。
- **行子采样**（Stochastic Gradient Boosting，Friedman 2002）：每轮只用一部分样本（如 50%–80%，无放回）训练树。引入随机性降低方差、减少过拟合，并加速训练；未被采样的样本还可用来做类似 OOB 的估计。
- **列子采样**（XGBoost 引入，借鉴随机森林）：按树/层/节点随机选择部分特征，进一步降低过拟合、加速计算。

Q7：***GBDT 常用哪些损失函数？***

- 回归：
    - **平方损失**（L2）：负梯度为残差，对异常值敏感；
    - **绝对损失**（L1）：负梯度为 $\text{sign}(y-F)$，叶子值取残差中位数，更鲁棒；
    - **Huber 损失**：小误差用 L2、大误差用 L1，兼顾两者；
    - **分位数损失**：用于分位数回归、预测区间；
    - Poisson / Gamma / Tweedie：计数、正值、保险理赔等场景。
- 分类：对数损失（二分类/多分类 softmax）、指数损失（等价 AdaBoost）。
- 排序：LambdaMART（LambdaRank 的梯度 + MART），XGBoost/LightGBM 中的 `rank:ndcg`、`lambdarank`。
- 只要损失**一阶可导**就能用于 GBDT；XGBoost 还需要**二阶导**（自定义损失需提供 grad 和 hess）。

## XGBoost

Q8：***XGBoost 的目标函数是什么？如何用二阶泰勒展开推导？***

- 正则化目标函数（第 $t$ 轮加入树 $f_t$）：
$$\mathcal{L}^{(t)} = \sum_{i=1}^{n} l\left(y_i, \hat y_i^{(t-1)} + f_t(x_i)\right) + \Omega(f_t),\quad \Omega(f) = \gamma T + \frac{1}{2}\lambda\sum_{j=1}^{T} w_j^2$$
其中 $T$ 为叶子数，$w_j$ 为叶子权重（也可加 L1 项 $\alpha\sum|w_j|$）。
- 在 $\hat y^{(t-1)}$ 处二阶泰勒展开，记 $g_i = \partial_{\hat y} l(y_i,\hat y^{(t-1)})$，$h_i = \partial^2_{\hat y} l(y_i,\hat y^{(t-1)})$，去掉常数项：
$$\tilde{\mathcal{L}}^{(t)} = \sum_{i=1}^{n}\left[g_i f_t(x_i) + \frac12 h_i f_t^2(x_i)\right] + \gamma T + \frac12\lambda\sum_j w_j^2$$
- 树把样本映射到叶子 $f_t(x)=w_{q(x)}$，令 $I_j=\{i\mid q(x_i)=j\}$，$G_j=\sum_{i\in I_j} g_i$，$H_j = \sum_{i\in I_j} h_i$，按叶子重组：
$$\tilde{\mathcal{L}}^{(t)} = \sum_{j=1}^{T}\left[G_j w_j + \frac12 (H_j+\lambda) w_j^2\right] + \gamma T$$
每个叶子是独立的一元二次函数。

Q9：***推导 XGBoost 的最优叶子权重和分裂增益公式。***

- 对 $w_j$ 求导令其为 0，得**最优叶子权重**：
$$w_j^* = -\frac{G_j}{H_j+\lambda}$$
- 代回得到给定树结构 $q$ 下的最优目标值（**结构分数**，越小越好）：
$$\tilde{\mathcal{L}}^*(q) = -\frac12\sum_{j=1}^{T}\frac{G_j^2}{H_j+\lambda} + \gamma T$$
- 一个节点分裂成左右子节点后目标值的减少量即**分裂增益**：
$$\text{Gain} = \frac12\left[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right] - \gamma$$
- 精确贪心算法：对每个特征按取值排序，从左到右扫描累加 $G_L,H_L$（$G_R=G-G_L$），一次扫描即可算出所有切分点的增益。
- 与牛顿法的联系：$w^*=-G/(H+\lambda)$ 就是带 L2 正则的**牛顿步**，所以 XGBoost 可看作函数空间的牛顿法，GBDT 是函数空间的梯度下降。

Q10：***XGBoost 中的 $\gamma$、$\lambda$、`min_child_weight` 分别起什么作用？***

- **$\gamma$**（`gamma` / `min_split_loss`）：每增加一个叶子的代价。只有 $\text{Gain}>0$（即括号内的增益大于 $\gamma$）才分裂，相当于**内置的预剪枝**。XGBoost 实际做法是先长到 `max_depth`，再**自底向上剪掉负增益的分裂**，这样可以避免预剪枝"视野短浅"的问题。
- **$\lambda$**（`reg_lambda`）：叶子权重的 L2 正则，缩小 $|w^*|$，让每棵树预测更平滑，同时出现在增益分母中，抑制样本少（$H$ 小）的叶子。**$\alpha$**（`reg_alpha`）是 L1 正则，会把小权重置零。
- **`min_child_weight`**：子节点中 $\sum h_i$ 的最小值。平方损失下 $h_i=1$，即最小样本数；对数损失下 $h_i=p_i(1-p_i)$，在预测已经很确定的区域 $h$ 很小，可防止为极少量"已学好"的样本单独分裂。

Q11：***XGBoost 为什么要用二阶导？有什么好处？***

- **精度与收敛**：二阶信息相当于牛顿法，比只用一阶梯度的 GBDT 更准确地逼近损失，通常收敛更快、需要的树更少。
- **统一框架**：分裂准则和叶子权重都只依赖 $g_i, h_i$，任何**二阶可导**的损失只需提供 grad/hess 就能直接接入，无需为每种损失单独推导线搜索。
- **自然地引入正则**：二次形式让 $\lambda$、$\gamma$ 能以闭式出现在叶子权重和增益中。
- $h_i$ 还是**样本权重**：目标可改写为 $\sum_i \frac12 h_i (f_t(x_i) - (-g_i/h_i))^2 + \Omega$，即以 $h_i$ 为权重、$-g_i/h_i$ 为标签的加权平方损失，这是加权分位数草图的理论基础。
- 要求：损失需二阶可导且 $h_i>0$（如 MAE 二阶导为 0，需要特殊处理）。

Q12：***XGBoost 有哪些工程优化？（稀疏感知、加权分位数草图、块结构）***

- **近似分裂与加权分位数草图（Weighted Quantile Sketch）**：精确贪心需遍历所有切分点，数据量大时代价高。近似算法按分位数提出候选切分点（全局：每棵树前提一次；局部：每次分裂后重新提）。由于目标可看作以 $h_i$ 为权重的加权平方损失，所以按 **$h_i$ 加权的分位数**选切分点，并提出了带理论保证、可合并的加权分位数草图数据结构。
- **稀疏感知分裂（Sparsity-aware Split Finding）**：缺失值、0 值、one-hot 产生的稀疏数据，在每个节点学习一个**默认方向**：分别把缺失样本全放左、全放右计算增益，取较大者。遍历时只扫描非缺失值，复杂度与非缺失元素数量成线性，大幅加速稀疏数据。
- **列块结构（Column Block）**：训练前把数据按列以 **CSC 格式预排序**存储为 block，后续每次分裂都复用这个排序，避免重复排序；不同特征的增益计算可**并行**（XGBoost 的并行是**特征粒度**的，树之间仍是串行的）。
- **缓存感知访问**：按排序后的索引取梯度会导致不连续内存访问、缓存命中率低，XGBoost 为每个线程分配缓冲区，**预取**梯度到连续内存。
- **核外计算（Out-of-core）**：数据放不进内存时，把 block 存到磁盘，配合**块压缩**和**分片**到多块磁盘，用独立线程预读。
- 补充：XGBoost 后来也实现了直方图算法（`tree_method="hist"`，2.0 起为默认）和 GPU 训练（`device="cuda"`），实践中已很少使用精确贪心。

Q13：***XGBoost 相比传统 GBDT 有哪些改进？***

1. **二阶泰勒展开**（函数空间牛顿法）vs GBDT 只用一阶梯度；
2. **目标函数显式加入正则项**（叶子数 $\gamma T$ 和叶子权重 L2/L1），控制模型复杂度；
3. **基学习器**：除 CART 外还支持线性模型（`gblinear`）和 DART（带 dropout 的树）；
4. **列采样**，借鉴随机森林，降低过拟合并加速；
5. **缺失值处理**：稀疏感知，自动学习默认方向；
6. **Shrinkage** 作用在每棵树上（GBDT 也有，但 XGBoost 作为标配）；
7. **分裂查找**：支持精确、近似（加权分位数草图）、直方图算法；
8. **工程优化**：特征级并行、列块预排序、缓存感知、核外计算、分布式、GPU；
9. **剪枝**：先长到最大深度，再按 $\gamma$ 后剪枝；
10. 内置交叉验证、早停，支持自定义损失和评估指标。

## LightGBM

Q14：***LightGBM 的直方图算法是什么？有什么优点？***

- 训练前把每个连续特征离散化为最多 `max_bin`（默认 255）个**桶（bin）**，每个样本只存桶索引（如 uint8）。分裂时遍历数据，在每个桶中累加 $\sum g$、$\sum h$ 和样本数，形成直方图，再在 **桶边界**上寻找最佳切分点。
- 优点：
    - **内存小**：不需存预排序结果和排序索引，特征值用 8 位整数存储，内存约降为预排序的 1/8；
    - **计算快**：切分点从 $O(\#\text{data})$ 降到 $O(\#\text{bin})$，构建直方图 $O(\#\text{data}\times\#\text{feature})$，寻找切分 $O(\#\text{bin}\times\#\text{feature})$；
    - **直方图做差加速**：父节点直方图 = 左子直方图 + 右子直方图，只需构建**样本较少**的子节点的直方图，另一个用减法得到，速度近乎翻倍；
    - **正则化效果**：粗粒度的切分点本身就是一种正则，对噪声不敏感；
    - 通信开销小，利于分布式并行。
- 缺点：切分点不精确，可能损失一点精度（但实际影响通常很小，在 GBDT 框架中常可忽略）。

Q15：***Level-wise 与 Leaf-wise 生长策略有什么区别？***

- **Level-wise（按层生长）**，XGBoost 默认（`grow_policy="depthwise"`）：每次把同一层的所有叶子都分裂。
    - 优点：易并行，树较平衡，不容易过拟合；
    - 缺点：很多增益很低的叶子也被分裂，带来不必要的计算开销。
- **Leaf-wise（按叶子生长）**，LightGBM 默认：每次从当前所有叶子中选择**增益最大**的一个分裂。
    - 优点：在相同叶子数下，能更快降低损失，**精度更高**；
    - 缺点：可能长出很深、很不平衡的树，**在小数据上容易过拟合**，因此需要用 `num_leaves`（主要复杂度参数）、`max_depth`、`min_data_in_leaf` 限制。
- 调参注意：`num_leaves` 应小于 $2^{\text{max\_depth}}$，否则 `max_depth` 约束形同虚设。XGBoost 也可设置 `grow_policy="lossguide"` 实现 leaf-wise。

Q16：***什么是 GOSS（基于梯度的单边采样）？***

- 动机：梯度绝对值小的样本已经被拟合得较好，对信息增益贡献小；直接丢掉它们会改变数据分布。
- 做法：
    1. 按梯度绝对值降序排列，**保留前 $a\times100\%$ 的大梯度样本**；
    2. 从剩下的样本中**随机采样 $b\times100\%$**；
    3. 计算增益时，给小梯度采样样本乘以权重 $\frac{1-a}{b}$，以补偿分布偏移，近似无偏地估计增益。
- 效果：只用 $(a+b)$ 比例的数据就能较准确地估计增益，显著加速训练，论文给出了误差界。
- 新版 LightGBM 中通过 `data_sample_strategy="goss"` 启用，参数 `top_rate`（$a$）和 `other_rate`（$b$）。

Q17：***什么是 EFB（互斥特征捆绑）？***

- 动机：高维稀疏数据中（如 one-hot），很多特征**几乎从不同时取非零值**（互斥），可以把它们合并为一个特征而不损失信息，从而减少特征数量。
- 做法：
    1. **确定捆绑哪些特征**：构造图，节点是特征，边权是两个特征的冲突（同时非零）次数。把"捆绑"建模为**图着色问题**（NP 难），用贪心近似：按度数排序，依次把特征加入冲突不超过阈值 $K$ 的已有 bundle，否则新建 bundle；允许少量冲突以换取更多捆绑。
    2. **合并特征**：给 bundle 中不同特征的取值加上**偏移量**，使它们落在不重叠的桶区间。例如特征 A 取值 [0,10)，B 取值 [0,20)，则 B 加偏移 10 变为 [10,30)，合并后取值 [0,30)。
- 效果：直方图构建复杂度从 $O(\#\text{data}\times\#\text{feature})$ 降为 $O(\#\text{data}\times\#\text{bundle})$，且 $\#\text{bundle}\ll\#\text{feature}$。

Q18：***LightGBM 如何处理类别特征？***

- 原生支持：通过 `categorical_feature` 指定，特征需编码为非负整数，无需 one-hot。
- **many-vs-many** 划分：在每个节点上，按各类别的 $\frac{\sum g}{\sum h + \text{cat\_smooth}}$ **排序**，再在排序后的直方图上像连续特征一样寻找最优切分点，即把类别集合分为两个子集。这是 Fisher (1958) 最优划分思想的应用，复杂度 $O(k\log k)$ 而非 $O(2^k)$。
- 类别数较少（$\le$ `max_cat_to_onehot`，默认 4）时退化为 one-vs-rest。
- 防过拟合参数：`min_data_per_group`、`cat_smooth`、`cat_l2`、`max_cat_threshold`。高基数类别特征仍容易过拟合，此时可考虑目标编码或 CatBoost。
- 为何不 one-hot：one-hot 后每次分裂只能切出一个类别，增益小、树不平衡且很深；原生划分能一次把相似类别归为一组。

Q19：***LightGBM 和 XGBoost 有什么区别？***

| | XGBoost | LightGBM |
|---|---|---|
| 分裂查找 | 经典为预排序精确/加权分位数近似（现默认 hist） | 直方图算法 + 直方图做差 |
| 生长策略 | 默认 level-wise | 默认 leaf-wise |
| 采样 | 行/列随机采样 | 另有 GOSS 梯度单边采样 |
| 稀疏特征 | 稀疏感知分裂 | EFB 互斥特征捆绑 |
| 类别特征 | 早期需手动编码，新版本有实验性/原生支持（`enable_categorical`） | 原生 many-vs-many 划分 |
| 速度/内存 | 较慢、内存较高（经典版本） | 更快、更省内存 |
| 并行 | 特征并行 | 特征并行、数据并行、**投票并行**（降低通信） |
| 过拟合 | 树较平衡，相对稳健 | leaf-wise 在小数据上易过拟合 |

- 实践结论：两者在调参充分时精度通常相近；大数据、高维时 LightGBM 更快；XGBoost 2.x 引入 hist 默认、GPU 和类别支持后，速度差距明显缩小。

## CatBoost

Q20：***CatBoost 的 Ordered Target Statistics 是什么？解决了什么问题？***

- 类别特征常用**目标编码**（用类别对应的标签均值替换类别）。但如果用全部训练数据（包括样本自身）计算，会造成**目标泄漏**：样本 $x_i$ 的编码含有 $y_i$ 的信息，训练时编码与标签强相关，测试时分布不同，导致**条件偏移**和过拟合（极端情况下，每个类别只出现一次时编码就等于标签本身）。
- CatBoost 的做法：对训练样本做随机排列 $\sigma$，样本 $x_i$ 的编码**只使用排在它前面的样本**：
$$\hat x_i^k = \frac{\sum_{j:\sigma(j)<\sigma(i)} \mathbb{I}(x_j^k = x_i^k)\, y_j + a\,P}{\sum_{j:\sigma(j)<\sigma(i)} \mathbb{I}(x_j^k = x_i^k) + a}$$
其中 $P$ 为先验（如全局正类比例），$a>0$ 为平滑权重。类似"在线学习"，每个样本只用"历史"信息编码，避免泄漏。
- 为降低单一排列带来的方差，会使用多个随机排列。测试时用全部训练数据计算统计量。
- 此外 CatBoost 还会**贪心构造类别特征组合**（交叉特征）并同样做 ordered TS。

Q21：***什么是 Ordered Boosting？什么是预测偏移（prediction shift）？***

- **预测偏移**：标准 GBDT 中，第 $t$ 轮计算样本 $x_i$ 的梯度时使用的模型 $F_{t-1}$ 是**用包括 $x_i$ 在内的数据训练的**，所以训练样本上的残差分布与测试样本上的不同（训练残差偏小），即梯度估计有偏，导致过拟合。本质上与目标泄漏是同一类问题。
- **Ordered Boosting**：同样基于随机排列，理论上为每个样本 $i$ 维护一个**只用排列中前 $i-1$ 个样本训练**的模型 $M_{i-1}$，用 $M_{i-1}$ 计算样本 $i$ 的残差，保证残差是"无偏"的。
- 实现上不可能真的维护 $n$ 个模型，CatBoost 只在指数增长的前缀长度（$2^j$）上维护近似模型，共享树结构、仅叶子值不同，开销可接受。
- 在小数据集上效果明显；大数据上可用 `boosting_type="Plain"` 加速。

Q22：***CatBoost 为什么使用对称树（Oblivious Tree）？***

- **对称树**：同一层的所有节点使用**相同的特征和切分阈值**，深度为 $d$ 的树有 $2^d$ 个叶子，每个叶子对应 $d$ 个二值判断构成的索引。
- 优点：
    - **推理极快**：预测时只需计算 $d$ 个比较得到 $d$ 位二进制索引，直接查表，易于向量化/SIMD，CPU 上推理速度显著快于普通树；
    - **正则化效果**：结构约束强，不易过拟合，对参数不太敏感，默认参数表现就不错；
    - 训练时每层只需选一个最优（特征, 阈值），且与 ordered boosting 结合更方便。
- 缺点：表达能力受限，同样深度下需要更多树；CatBoost 也支持 `grow_policy="Depthwise"` / `"Lossguide"`。

## 调参与实战

Q23：***GBDT 类模型有哪些关键超参数？调参顺序是怎样的？***

- 关键超参数（以 XGBoost/LightGBM 为例）：
    - 迭代与步长：`n_estimators`、`learning_rate`；
    - 树复杂度：`max_depth`、`num_leaves`（LightGBM）、`min_child_weight` / `min_data_in_leaf`；
    - 随机性：`subsample` / `bagging_fraction`、`colsample_bytree` / `feature_fraction`；
    - 正则化：`reg_lambda`、`reg_alpha`、`gamma` / `min_split_gain`；
    - LightGBM 专有：`max_bin`、类别相关参数。
- 常用调参顺序：
    1. 先固定较大学习率（如 0.1），用**早停**确定树的数量；
    2. 调树结构：`max_depth` / `num_leaves`、`min_child_weight` / `min_data_in_leaf`（对效果影响最大）；
    3. 调采样：`subsample`、`colsample_bytree`（常在 0.6–0.9）；
    4. 调正则：`lambda`、`alpha`、`gamma`；
    5. **降低学习率**（如 0.01–0.05），增加树数量，再次早停得到最终模型。
- 实践中常用 Optuna 等贝叶斯优化工具对上述参数联合搜索，比网格搜索更高效。

Q24：***GBDT 中如何使用早停（Early Stopping）？要注意什么？***

- 训练时监控**验证集**上的指标，若连续 `early_stopping_rounds` 轮（如 50–200）没有提升就停止，并使用最佳轮次的模型（`best_iteration`）。

```python
import lightgbm as lgb

model = lgb.LGBMClassifier(n_estimators=10000, learning_rate=0.05, num_leaves=63)
model.fit(X_tr, y_tr,
          eval_set=[(X_val, y_val)],
          eval_metric="auc",
          callbacks=[lgb.early_stopping(stopping_rounds=100), lgb.log_evaluation(200)])
print(model.best_iteration_)
```

- 注意事项：
    - 早停使用的验证集本身也被"拟合"了，最终评估要用**独立的测试集**或嵌套交叉验证；
    - 交叉验证时每折早停轮数不同，最终在全量数据上重训时可取平均最佳轮数（或按数据量适当放大）；
    - 监控指标应与业务目标一致（如 AUC、logloss、RMSE），并确保验证集划分方式与线上一致（时间序列需按时间切分）。

Q25：***GBDT 如何处理类别不平衡问题？***

- **样本/类别加权**：XGBoost/LightGBM 的 `scale_pos_weight`（常设为 负样本数/正样本数）、LightGBM 的 `is_unbalance=True`、或通过 `sample_weight` 自定义权重。加权会放大少数类的梯度和 Hessian，影响分裂和叶子值。
- **采样**：对多数类下采样、对少数类上采样（SMOTE 在树模型上收益通常有限）。
- **自定义损失**：如 Focal Loss，需提供一阶和二阶导数。
- **评估与阈值**：用 PR-AUC、F1、Recall@K 等替代准确率；不要用默认 0.5 阈值，应在验证集上**调整分类阈值**。
- 注意：加权或采样会**扭曲预测概率**，需要准确概率时（如 CTR 预估）应做校准（Platt / Isotonic）或对下采样做概率还原 $p = \frac{p'}{p' + (1-p')/w}$（$w$ 为负样本采样率）。

Q26：***GBDT 的特征重要性有哪几种？各有什么问题？SHAP 有什么优势？***

- XGBoost 的 `importance_type`：
    - **weight / split**：特征被用于分裂的**次数**，偏向高基数、连续特征；
    - **gain**：使用该特征分裂带来的**平均增益**（`total_gain` 为总增益），更能反映实际贡献，但仍基于训练集；
    - **cover**：使用该特征分裂时覆盖的平均样本（Hessian 和）。
- LightGBM 提供 `split` 和 `gain` 两种。不同指标排序可能差异很大，且这些全局指标**不一致**：模型更依赖某特征时其重要性不一定上升。
- **SHAP**（TreeSHAP，Lundberg 等）：基于 Shapley 值，满足**局部准确性、一致性、缺失性**；TreeSHAP 在树模型上可在多项式时间内精确计算；能给出**每个样本**每个特征的贡献及方向，聚合 $|\phi|$ 的均值即全局重要性，还可分析交互作用（SHAP interaction values）。
- 补充：相关特征仍会分摊 SHAP 值；评估泛化贡献时可配合验证集上的置换重要性。

Q27：***什么是 GBDT + LR？为什么有效？***

- 来源：Facebook 2014 年广告 CTR 预估论文（*Practical Lessons from Predicting Clicks on Ads at Facebook*）。
- 做法：先训练 GBDT，把每个样本在每棵树中落入的**叶子索引**作为类别特征，one-hot 后拼成高维稀疏向量（可与原始特征一起）输入 **逻辑回归**。

```python
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import OneHotEncoder

gbdt = GradientBoostingClassifier(n_estimators=100, max_depth=3).fit(X_gbdt, y_gbdt)
leaves = gbdt.apply(X_lr)[:, :, 0]            # (n_samples, n_trees) 叶子索引
enc = OneHotEncoder(handle_unknown="ignore").fit(leaves)
lr = LogisticRegression(max_iter=1000).fit(enc.transform(leaves), y_lr)
```

- 为什么有效：每条根到叶的路径相当于一个**自动学习的特征组合**（多特征交叉 + 非线性离散化），解决了 LR 需要大量人工特征工程的问题；LR 部分又可以高频更新、适合大规模稀疏在线学习。
- 注意：GBDT 和 LR 最好用**不同数据**训练，避免 LR 在 GBDT 过拟合的叶子特征上过拟合；高基数 ID 类特征不适合直接放进 GBDT。该方案后来被 FM/FFM、Wide & Deep、DeepFM 等深度 CTR 模型取代，但思路（树模型做特征变换）仍常用。

Q28：***表格数据为什么常用 GBDT 而不是深度学习？随机森林和 GBDT 怎么选？***

- **GBDT 在表格数据上的优势**（参考 Grinsztajn 等 2022 *Why do tree-based models still outperform deep learning on tabular data?*）：
    - 表格特征**异构**、含大量无信息特征，树模型天然做特征选择，对无关特征鲁棒；MLP 对旋转不变，难以利用特征的"轴对齐"含义；
    - 目标函数常**不光滑、存在突变**，树的分段常数结构更容易拟合，而神经网络偏好光滑函数；
    - 中小数据量（几千到几十万行）下树模型更不易过拟合；
    - 对缺失值、异常值、尺度不敏感，预处理少；训练快、调参成本低、可解释性工具（SHAP）成熟、部署简单。
- **何时考虑深度学习**：数据量极大、包含文本/图像/序列等非结构化特征、需要端到端学习表示（embedding）、多任务/多模态、在线增量学习；或者使用表格基础模型（如 TabPFN 系列在小数据集上表现很强）。实践中 GBDT 与 NN 的**集成**往往最好。
- **随机森林 vs GBDT**：

| | 随机森林 | GBDT |
|---|---|---|
| 集成方式 | Bagging，并行 | Boosting，串行 |
| 降低 | 方差 | 偏差 |
| 基树 | 深树，不剪枝 | 浅树（深度 3–8） |
| 调参 | 少，默认参数就很稳 | 多，对学习率/树深敏感 |
| 过拟合 | 树越多越稳定，不易过拟合 | 树太多会过拟合，需早停 |
| 噪声/异常值 | 鲁棒 | 较敏感 |
| 精度 | 好的基线 | 调好后通常更高 |
| 其他 | 有 OOB 估计，训练易并行 | 支持任意可微损失、排序等 |

- 选择建议：需要快速稳健的基线、数据噪声大、调参资源少时用随机森林；追求最高精度、有时间调参时用 GBDT（XGBoost / LightGBM / CatBoost，类别特征多时优先 CatBoost）。
