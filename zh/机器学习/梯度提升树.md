# 梯度提升树（GBDT / XGBoost / LightGBM / CatBoost）

## Boosting 基础

Q1：***Boosting 和 Bagging 有什么区别？***

**Bagging 并行训练多个独立的强学习器再取平均，主要降低方差；Boosting 串行训练多个弱学习器，每个都去纠正前面的错误，主要降低偏差。**

| | Bagging（如随机森林） | Boosting（如 AdaBoost、GBDT） |
|---|---|---|
| 训练方式 | 并行，相互独立 | 串行，依赖前面的结果 |
| 基学习器 | 深树（低偏差高方差） | 浅树（高偏差低方差） |
| 主要作用 | 降低方差 | 降低偏差 |
| 对噪声 | 鲁棒 | 较敏感，容易拟合噪声 |

- 直观理解：Bagging 是"多个专家独立投票"，Boosting 是"一个接一个地改错"。

Q2：***简述 AdaBoost 的原理。***

**AdaBoost 依次训练弱分类器，每轮提高被分错样本的权重，让下一个分类器更关注难样本；最后按各分类器的准确程度加权投票。**

- 错误率越低的分类器，投票权重越大。
- 错分样本权重增大、分对的减小，然后归一化。
- 理论上它等价于用**指数损失**的前向分步加法模型，指数损失对误分样本惩罚很重，所以对噪声和异常值敏感。
- 核心公式（分类器权重）：$\alpha_t = \frac{1}{2}\ln\frac{1-\epsilon_t}{\epsilon_t}$

## GBDT

Q3：***GBDT 的核心思想是什么？为什么说它是"函数空间的梯度下降"？***

**GBDT 是把很多回归树加起来的加法模型，每棵新树去拟合当前模型损失的负梯度；相当于把整个预测函数当作参数，每一步沿负梯度方向走一小步，所以叫函数空间的梯度下降。**

- 负梯度只能在训练点上算，用一棵树去拟合它，才能泛化到新样本。
- 平方损失下负梯度恰好就是残差，所以"拟合残差"只是一个特例。
- 核心公式（伪残差）：$r_{i} = -\partial L(y_i, F(x_i)) / \partial F(x_i)$

Q4：***写出 GBDT 的算法流程。***

**先用一个常数初始化模型，然后每轮：算出每个样本的负梯度，用一棵回归树去拟合它，再给每个叶子求最优输出值，最后乘上学习率加到模型里。**

- 初始化取使损失最小的常数（平方损失下是均值，对数损失下是 log-odds）。
- 树的**结构**由拟合负梯度决定，**叶子值**则按原始损失重新优化（线搜索）。
- 重复 M 轮后输出所有树之和。

Q5：***GBDT 如何做分类？***

**GBDT 的基学习器始终是回归树，分类时在对数几率（logit）空间里做提升，最后用 sigmoid 或 softmax 转成概率。**

- 二分类用对数损失，负梯度就是"真实标签减预测概率" $y - p$。
- 叶子值没有闭式解，一般用一步牛顿法近似。
- 多分类（K 类）每轮训练 K 棵树，每类一棵，输出经 softmax 得到概率。

Q6：***GBDT 中的 Shrinkage（学习率）和子采样有什么作用？***

**两者都是正则化手段：学习率让每棵树只走一小步，给后面的树留修正空间；子采样引入随机性，降低方差、减少过拟合，同时加快训练。**

- 经验上"小学习率 + 多棵树"泛化更好但更慢，学习率和树数要配合早停一起调。
- 行子采样：每轮只用一部分样本训练（Stochastic Gradient Boosting）。
- 列子采样：每棵树/层/节点只用部分特征，借鉴随机森林，XGBoost 引入。

Q7：***GBDT 常用哪些损失函数？***

**只要损失一阶可导就能用于 GBDT：回归常用平方、绝对值、Huber 和分位数损失，分类用对数损失，排序用 LambdaMART。**

- 平方损失对异常值敏感；绝对损失和 Huber 更鲁棒。
- 分位数损失用于预测区间；Poisson / Gamma / Tweedie 用于计数、正值等场景。
- 指数损失对应 AdaBoost。
- XGBoost 还需要二阶导，自定义损失要同时提供 grad 和 hess。

## XGBoost

Q8：***XGBoost 的目标函数是什么？如何用二阶泰勒展开推导？***

**目标函数是"训练损失 + 树的复杂度正则"，复杂度惩罚叶子数和叶子权重的大小。把损失在上一轮预测处做二阶泰勒展开后，每个叶子的目标都变成关于叶子权重的一元二次函数，可以直接求解。**

- 每个样本只需要一阶导 $g_i$ 和二阶导 $h_i$，按叶子汇总成 $G_j$、$H_j$。
- 展开后去掉常数项，各叶子互不影响，可以分别优化。
- 核心公式：$\Omega(f) = \gamma T + \frac{1}{2}\lambda\sum_j w_j^2$

Q9：***推导 XGBoost 的最优叶子权重和分裂增益公式。***

**对每个叶子的二次函数求极值，得到最优叶子权重为"负的梯度和除以（Hessian 和 + λ）"；把它代回去得到每棵树的结构分数，分裂增益就是分裂后左右子节点分数之和减去分裂前的分数，再减去 γ。**

- 每个节点的分数形如 $G^2/(H+\lambda)$，增益 = 左分数 + 右分数 − 父分数（再乘 1/2），减 γ 后大于 0 才分裂。
- 精确贪心：每个特征排序后从左到右累加 $G_L,H_L$，一次扫描算出所有切分点的增益。
- 最优权重就是带 L2 正则的牛顿步，所以 XGBoost 可看作函数空间的牛顿法。
- 核心公式：$w_j^* = -\frac{G_j}{H_j+\lambda}$

Q10：***XGBoost 中的 $\gamma$、$\lambda$、`min_child_weight` 分别起什么作用？***

**γ 是每多一个叶子的代价，增益不够大就不分裂；λ 是叶子权重的 L2 正则，让预测更平滑；`min_child_weight` 要求子节点的 Hessian 之和不能太小，防止为极少量样本单独分裂。**

- γ 相当于内置剪枝：XGBoost 先长到 `max_depth`，再自底向上剪掉增益为负的分裂，避免预剪枝视野短浅。
- λ 同时出现在增益分母里，会抑制样本少的叶子；α 是 L1 正则，会把小权重压成 0。
- 平方损失下 $h_i=1$，`min_child_weight` 就是最小样本数；对数损失下预测很确定的样本 $h_i$ 很小。

Q11：***XGBoost 为什么要用二阶导？有什么好处？***

**二阶导相当于用牛顿法代替梯度下降，对损失的近似更准，通常收敛更快、需要的树更少；同时让任何二阶可导的损失都能套进同一个分裂和叶子权重公式。**

- 统一框架：自定义损失只需提供 grad 和 hess，不用为每种损失单独推导线搜索。
- 正则项 λ、γ 能以闭式出现在叶子权重和增益里。
- $h_i$ 可以看作样本权重，这是加权分位数草图的基础。
- 要求损失二阶可导且 $h_i>0$（如 MAE 二阶导为 0，需要特殊处理）。

Q12：***XGBoost 有哪些工程优化？（稀疏感知、加权分位数草图、块结构）***

**XGBoost 主要在"怎么快速找切分点"上做优化：用加权分位数草图减少候选切分点，用稀疏感知分裂高效处理缺失值，用预排序的列块结构支持特征级并行，再加上缓存优化和核外计算。**

- 加权分位数草图：按 $h_i$ 加权的分位数提出候选切分点，代替遍历所有值。
- 稀疏感知：每个节点为缺失值学习一个默认方向（分别放左、放右，取增益大的），只扫描非缺失值。
- 列块结构：训练前按列预排序存成 block 并反复复用，不同特征可并行计算（树之间仍是串行）。
- 缓存感知预取和核外计算（block 存磁盘、压缩、分片）支持大数据。
- 现在默认用直方图算法（`tree_method="hist"`）并支持 GPU，精确贪心已很少用。

Q13：***XGBoost 相比传统 GBDT 有哪些改进？***

**XGBoost 在算法上用二阶泰勒展开并在目标里显式加入正则，在工程上做了大量加速，是一个更准、更快、更不易过拟合的 GBDT 实现。**

- 算法：二阶导（牛顿法）、叶子数和叶子权重正则、列采样、按 γ 后剪枝。
- 缺失值：稀疏感知，自动学习默认方向。
- 分裂查找：支持精确、加权分位数近似和直方图算法。
- 工程：特征级并行、列块预排序、缓存感知、核外计算、分布式和 GPU。
- 易用性：支持线性基学习器和 DART，内置交叉验证、早停、自定义损失。

## LightGBM

Q14：***LightGBM 的直方图算法是什么？有什么优点？***

**训练前把每个连续特征分成最多 255 个桶，每个样本只存桶编号；分裂时在每个桶里累加梯度做成直方图，只在桶边界上找切分点。这样又省内存又快。**

- 内存小：特征值用 8 位整数存，无需存预排序结果。
- 计算快：候选切分点从样本数级别降到桶数级别。
- 直方图做差：父节点直方图减去一个子节点的直方图就得到另一个，只需构建样本较少的那个子节点。
- 粗粒度切分本身有正则作用；代价是切分点不精确，但精度损失通常很小。

Q15：***Level-wise 与 Leaf-wise 生长策略有什么区别？***

**Level-wise 每次把同一层所有叶子都分裂，树平衡、不易过拟合但有很多无用分裂；Leaf-wise 每次只分裂增益最大的那个叶子，相同叶子数下精度更高，但容易长出很深的树、在小数据上过拟合。**

- XGBoost 默认 level-wise，LightGBM 默认 leaf-wise（XGBoost 也可设 `grow_policy="lossguide"`）。
- Leaf-wise 要用 `num_leaves`（主要复杂度参数）、`max_depth`、`min_data_in_leaf` 来约束。
- `num_leaves` 应小于 $2^{\text{max\_depth}}$，否则深度限制形同虚设。

Q16：***什么是 GOSS（基于梯度的单边采样）？***

**GOSS 保留所有梯度大的样本，只对梯度小的样本随机采样，再给采样到的小梯度样本放大权重来补偿；这样只用一小部分数据就能比较准确地估计分裂增益，从而加速训练。**

- 动机：梯度小的样本已经学得较好，对增益贡献小；但直接丢掉会改变数据分布。
- 做法：保留前 $a$ 比例的大梯度样本，从剩余中采样 $b$ 比例，并乘以权重 $\frac{1-a}{b}$。
- 新版用 `data_sample_strategy="goss"` 开启，参数为 `top_rate`（a）和 `other_rate`（b）。

Q17：***什么是 EFB（互斥特征捆绑）？***

**在高维稀疏数据里，很多特征几乎从不同时非零，EFB 把这些互斥的特征捆绑成一个特征，减少特征数量，从而加速直方图构建，且几乎不损失信息。**

- 选哪些特征捆绑可建模为图着色问题，用贪心近似，并允许少量冲突。
- 合并时给不同特征的取值加上偏移量，使它们落在不重叠的桶区间。
- 直方图构建的代价从与特征数成正比降为与 bundle 数成正比。

Q18：***LightGBM 如何处理类别特征？***

**LightGBM 原生支持类别特征，不需要 one-hot：在每个节点把各类别按"梯度和 / Hessian 和"排序，再像连续特征一样找最优切分，把类别集合一次分成两组。**

- 排序后切分只需 $O(k\log k)$，不必枚举 $2^k$ 种划分。
- 类别很少（默认 ≤4）时退化为 one-vs-rest。
- 不用 one-hot 的原因：one-hot 每次只能切出一个类别，增益小、树又深又不平衡。
- 高基数类别仍易过拟合，可调 `cat_smooth`、`min_data_per_group` 等，或改用目标编码 / CatBoost。

Q19：***LightGBM 和 XGBoost 有什么区别？***

**LightGBM 用直方图、leaf-wise 生长、GOSS 和 EFB，速度更快、内存更省；经典 XGBoost 用预排序和 level-wise 生长，树更平衡、更稳健。调参充分时两者精度通常相近。**

| | XGBoost | LightGBM |
|---|---|---|
| 分裂查找 | 预排序 / 分位数近似（现默认 hist） | 直方图 + 做差 |
| 生长策略 | level-wise | leaf-wise |
| 采样与稀疏 | 行列采样，稀疏感知 | GOSS，EFB |
| 类别特征 | 新版支持 `enable_categorical` | 原生 many-vs-many 划分 |

- XGBoost 2.x 默认 hist 并支持 GPU 和类别特征后，速度差距已明显缩小。

## CatBoost

Q20：***CatBoost 的 Ordered Target Statistics 是什么？解决了什么问题？***

**它是一种防止目标泄漏的目标编码：把样本随机排列，每个样本的类别编码只用排在它前面的样本的标签均值来算，这样编码里不含自己的标签。**

- 普通目标编码用了样本自己的标签，训练时编码和标签强相关、测试时不是，导致条件偏移和过拟合。
- 编码中加入先验和平滑项，避免样本少的类别编码不稳定。
- 用多个随机排列降低方差；测试时用全部训练数据计算统计量。
- CatBoost 还会贪心构造类别特征组合，同样做 ordered TS。

Q21：***什么是 Ordered Boosting？什么是预测偏移（prediction shift）？***

**预测偏移是指标准 GBDT 用"见过该样本"的模型去算它的梯度，训练残差比测试时偏小，梯度估计有偏而导致过拟合；Ordered Boosting 用"只在排列中排在它前面的样本上训练的模型"来算每个样本的残差，消除这种偏差。**

- 本质上和目标泄漏是同一类问题。
- 实现上不维护 n 个模型，只在指数增长的前缀长度上维护近似模型，共享树结构。
- 小数据集上效果明显；大数据可用 `boosting_type="Plain"` 加速。

Q22：***CatBoost 为什么使用对称树（Oblivious Tree）？***

**对称树每一层所有节点都用同一个特征和阈值，预测时只要做 d 次比较得到一个 d 位索引直接查表，推理极快；同时结构约束强，有正则化作用，不易过拟合。**

- 推理易向量化，CPU 上明显快于普通树。
- 对参数不太敏感，默认参数表现就不错。
- 缺点是表达能力受限，同样深度需要更多树；CatBoost 也支持 Depthwise / Lossguide。

## 调参与实战

Q23：***GBDT 类模型有哪些关键超参数？调参顺序是怎样的？***

**关键参数分四类：树数和学习率、树的复杂度、采样比例、正则项。一般先用较大学习率加早停定树数，再调树结构，然后调采样和正则，最后降低学习率增加树数。**

- 树复杂度（影响最大）：`max_depth`、`num_leaves`、`min_child_weight` / `min_data_in_leaf`。
- 采样：`subsample`、`colsample_bytree`，常在 0.6–0.9。
- 正则：`reg_lambda`、`reg_alpha`、`gamma`。
- 实践中常用 Optuna 等贝叶斯优化联合搜索，比网格搜索高效。

Q24：***GBDT 中如何使用早停（Early Stopping）？要注意什么？***

**训练时监控验证集指标，连续若干轮（如 50–200 轮）没有提升就停止，并使用最佳轮次的模型。**

- 早停用的验证集也被"拟合"了，最终评估要用独立测试集或嵌套交叉验证。
- 交叉验证各折最佳轮数不同，全量重训时可取平均（或按数据量适当放大）。
- 监控指标要和业务目标一致，验证集划分要和线上一致（时间序列按时间切）。
- LightGBM 中用 `callbacks=[lgb.early_stopping(100)]`，之后读 `best_iteration_`。

Q25：***GBDT 如何处理类别不平衡问题？***

**最常用的是给少数类加权（如 `scale_pos_weight` = 负样本数 / 正样本数），其次是重采样或自定义损失；同时要换用合适的评估指标并调整分类阈值。**

- 加权会放大少数类的梯度和 Hessian，影响分裂和叶子值。
- 也可以下采样多数类，或用 Focal Loss（需提供一阶、二阶导）。
- 用 PR-AUC、F1 等指标代替准确率，在验证集上调阈值而不是用默认 0.5。
- 加权或采样会扭曲概率，需要准确概率（如 CTR）时要做校准或概率还原。

Q26：***GBDT 的特征重要性有哪几种？各有什么问题？SHAP 有什么优势？***

**内置的重要性有按分裂次数（split/weight）、按增益（gain）和按覆盖样本（cover）几种，都基于训练集、彼此排序可能差很大，而且不满足一致性；SHAP 基于 Shapley 值，有一致性保证，还能给出每个样本、每个特征的贡献和方向。**

- 分裂次数偏向高基数、连续特征；gain 更能反映实际贡献，但仍基于训练集。
- 不一致：模型更依赖某特征时，其重要性不一定上升。
- TreeSHAP 在树模型上可多项式时间精确计算，还能分析交互作用。
- 相关特征仍会分摊 SHAP 值；评估泛化贡献可配合验证集上的置换重要性。

Q27：***什么是 GBDT + LR？为什么有效？***

**这是 Facebook 2014 年 CTR 预估的方案：先训练 GBDT，把样本在每棵树落入的叶子编号 one-hot 成稀疏特征，再喂给逻辑回归。每条根到叶的路径相当于一个自动学到的特征组合，省去大量人工特征工程。**

- GBDT 负责非线性离散化和特征交叉，LR 负责大规模稀疏特征、可高频在线更新。
- GBDT 和 LR 最好用不同数据训练，避免 LR 在过拟合的叶子特征上过拟合。
- 高基数 ID 类特征不适合直接放进 GBDT。
- 后来被 FM、Wide & Deep、DeepFM 等深度模型取代，但"树做特征变换"的思路仍常用。

Q28：***表格数据为什么常用 GBDT 而不是深度学习？随机森林和 GBDT 怎么选？***

**表格特征异构、无关特征多、目标函数常有突变，树模型天然做特征选择、擅长拟合分段函数，在中小数据上更不易过拟合，预处理少、训练快，所以通常比神经网络好。随机森林适合做稳健基线，GBDT 调好后精度通常更高。**

- 神经网络偏好光滑函数，且对特征旋转不变，难以利用特征"轴对齐"的含义（Grinsztajn 等 2022）。
- 数据量极大、有文本/图像等非结构化特征、需要端到端表示学习时考虑深度学习；小数据也可试 TabPFN；GBDT 与 NN 集成往往最好。

| | 随机森林 | GBDT |
|---|---|---|
| 集成方式 | Bagging，并行，降方差 | Boosting，串行，降偏差 |
| 基树 | 深树 | 浅树（深度 3–8） |
| 调参与过拟合 | 参数少，树越多越稳 | 对学习率/树深敏感，需早停 |
| 噪声 | 鲁棒 | 较敏感 |

- 选择：数据噪声大、调参资源少时用随机森林；追求最高精度用 GBDT，类别特征多时优先 CatBoost。
