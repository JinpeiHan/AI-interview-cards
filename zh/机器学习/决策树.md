# 决策树

## 基础与划分准则

Q1：***什么是决策树？它是如何做预测的？***

- 决策树是一种**非参数**的监督学习模型，可用于分类和回归。它把特征空间**递归地划分**成若干互不相交的矩形区域（轴平行划分），每个区域对应一个**叶节点**。
- 内部节点是对某个特征的测试（如 $x_j \le t$ 或 $x_j \in \{a,b\}$），分支是测试结果，叶节点存放预测值：
    - 分类：叶节点内样本的**多数类**（或类别概率分布）；
    - 回归：叶节点内样本标签的**均值**。
- 预测时从根节点出发，按特征测试一路走到叶节点，输出该叶的值。本质上是一组 **if-then 规则**，也可看作对条件概率分布 $P(Y|X)$ 的分段常数近似。

Q2：***决策树的构建流程是怎样的？什么时候停止分裂？***

- 采用**自顶向下、贪心**的递归划分（Hunt 算法）：
    1. 在当前节点上，遍历所有特征及其候选切分点，按划分准则（信息增益、增益率、基尼指数、MSE 等）选出**最优划分**；
    2. 按该划分把样本分到子节点；
    3. 对子节点递归执行，直到满足停止条件。
- 常见停止条件：节点内样本全属于同一类；没有可用特征或所有样本特征取值相同；样本数小于 `min_samples_split`；达到 `max_depth`；划分带来的不纯度下降小于阈值。
- 寻找全局最优决策树是 **NP 完全**问题，所以实践中都用贪心的局部最优策略，这也意味着决策树对数据扰动敏感。

Q3：***信息熵、条件熵、信息增益分别如何定义？***

- 设数据集 $D$ 有 $K$ 类，第 $k$ 类占比 $p_k$，**信息熵**：
$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$
熵越大，不确定性（不纯度）越高；全为一类时 $H=0$，均匀分布时最大为 $\log_2 K$。
- 用特征 $A$（取值 $a_1,\dots,a_V$）把 $D$ 划分为 $D_1,\dots,D_V$，**条件熵**：
$$H(D|A) = \sum_{v=1}^{V} \frac{|D_v|}{|D|} H(D_v)$$
- **信息增益**（即 $D$ 与 $A$ 的互信息）：
$$\text{Gain}(D,A) = H(D) - H(D|A)$$
ID3 选择信息增益最大的特征进行划分。

Q4：***信息增益有什么缺陷？增益率是如何解决的？***

- 信息增益**偏好取值数目多的特征**。极端情况下，用"样本 ID"划分，每个子集只有一个样本，条件熵为 0、信息增益最大，但毫无泛化能力。
- C4.5 使用**增益率**，用特征自身的"固有值"(intrinsic value / split information) 做归一化：
$$\text{GainRatio}(D,A) = \frac{\text{Gain}(D,A)}{IV(A)},\quad IV(A) = -\sum_{v=1}^{V}\frac{|D_v|}{|D|}\log_2\frac{|D_v|}{|D|}$$
取值越多，$IV(A)$ 越大，从而惩罚多值特征。
- 但增益率反过来**偏好取值少的特征**，所以 C4.5 采用启发式：先从候选特征中选出**信息增益高于平均水平**的，再从中选**增益率最高**的。

Q5：***基尼指数是什么？和熵有什么关系？***

- **基尼指数**表示从数据集中随机抽两个样本，其类别不一致的概率：
$$\text{Gini}(D) = \sum_{k=1}^{K} p_k(1-p_k) = 1 - \sum_{k=1}^{K} p_k^2$$
- 按特征 $A$ 的切分点把 $D$ 二分为 $D_1, D_2$ 后：
$$\text{Gini}(D,A) = \frac{|D_1|}{|D|}\text{Gini}(D_1) + \frac{|D_2|}{|D|}\text{Gini}(D_2)$$
CART 选择使划分后基尼指数**最小**的特征和切分点。
- 与熵的关系：对 $-\ln p$ 在 $p=1$ 处一阶泰勒展开得 $-\ln p \approx 1-p$，代入熵即得 $\sum p_k(1-p_k)$，所以**基尼指数可看作熵的一阶近似**。两者曲线形状相近，实践中效果差别通常很小；基尼不需要算对数，**计算更快**；熵对类别分布的变化稍敏感一些。
- 二分类时：$\text{Gini}=2p(1-p)$，误分类率 $=\min(p,1-p)$，熵 $=-p\log p-(1-p)\log(1-p)$；三者都在 $p=0.5$ 取最大。误分类率不可导、对节点纯度变化不敏感，一般不用于生长树，但常用于剪枝评估。

## 三种经典算法

Q6：***ID3、C4.5、CART 有什么区别？***

| | ID3 | C4.5 | CART |
|---|---|---|---|
| 划分准则 | 信息增益 | 增益率（启发式） | 分类：基尼指数；回归：平方误差 |
| 任务 | 分类 | 分类 | 分类 + 回归 |
| 树结构 | 多叉树 | 多叉树 | **二叉树** |
| 连续特征 | 不支持 | 支持（二分离散化） | 支持 |
| 缺失值 | 不支持 | 支持（样本权重分配） | 支持（代理分裂 surrogate split） |
| 剪枝 | 无 | 悲观错误剪枝 (PEP) 等后剪枝 | 代价复杂度剪枝 (CCP) |
| 特征复用 | 离散特征用过即不再用 | 离散特征不复用，连续特征可复用 | 特征可在不同节点重复使用 |

- 补充：sklearn 的 `DecisionTreeClassifier/Regressor` 实现的是**优化版 CART**（二叉树，`criterion` 可选 `gini`/`entropy`/`log_loss`），不是 ID3/C4.5。

Q7：***决策树如何处理连续特征？***

- **二分法离散化**（C4.5 / CART）：把特征 $a$ 在当前节点上的取值排序为 $a^1<a^2<\dots<a^n$，候选切分点取相邻值中点 $t_i = \frac{a^i + a^{i+1}}{2}$（共 $n-1$ 个），对每个切分点计算划分准则，选最优者。
- 优化：只有在**类别发生变化的相邻点之间**才可能出现最优切分点（对熵/基尼成立），可大幅减少候选数；大数据下可用**直方图 / 分位数分桶**近似（GBDT 框架常用）。
- 与离散特征不同，连续特征在后续节点**可以再次被使用**（如先 $x\le 5$，再 $x \le 2$）。
- 复杂度：每个节点每个特征排序 $O(n\log n)$，可通过预排序复用。

Q8：***决策树如何处理缺失值？***

需要解决两个问题：

1. **有缺失值时如何选划分特征？**（C4.5）只用该特征**无缺失的样本子集** $\tilde D$ 计算信息增益，再乘以无缺失样本占比 $\rho$：$\text{Gain}(D,a) = \rho \cdot \text{Gain}(\tilde D, a)$。
2. **选定特征后，缺失样本分到哪个分支？**
    - **C4.5**：让该样本以**不同权重同时进入所有子节点**，权重为各子节点中无缺失样本的占比 $\tilde r_v$；预测时也沿所有分支走，按权重汇总概率。
    - **CART**：使用**代理分裂（surrogate split）**，找与主分裂划分结果最相似的其他特征来决定缺失样本的去向。
    - **XGBoost / LightGBM**：训练时为每个分裂学习一个**默认方向**，把缺失值分别放到左/右，取增益更大的方向。
    - **sklearn**（1.3 起）：树模型原生支持 NaN，分裂时同样会尝试把缺失样本放到左/右子节点中更优的一侧。
- 工程上也可以简单填充（中位数、众数、特殊值如 -999），树模型对"特殊值填充"通常也能学到其含义。

Q9：***回归树是如何构建的？***

- CART 回归树使用**平方误差最小化**准则。对特征 $j$ 和切分点 $s$，划分为 $R_1(j,s)=\{x|x_j\le s\}$ 和 $R_2(j,s)=\{x|x_j>s\}$，求解：
$$\min_{j,s}\left[\min_{c_1}\sum_{x_i\in R_1}(y_i-c_1)^2 + \min_{c_2}\sum_{x_i\in R_2}(y_i-c_2)^2\right]$$
内层最优解 $c_m = \text{mean}(y_i \mid x_i \in R_m)$，即叶节点输出该区域样本均值。
- 遍历所有 $(j,s)$ 找最优划分，递归执行，得到的模型是**分段常数函数**：$f(x)=\sum_{m=1}^{M} c_m \mathbb{I}(x\in R_m)$。
- 也可以用 MAE 准则（叶节点取中位数，对异常值更鲁棒）或泊松偏差等。
- 局限：预测值只能是训练集中叶节点均值，**无法外推**到训练标签范围之外，且输出不连续、不光滑。

## 剪枝与过拟合

Q10：***决策树为什么容易过拟合？有哪些应对方法？***

- 原因：决策树是低偏差、**高方差**的模型。如果不加限制，树可以一直分裂直到每个叶子只剩一个样本，训练误差为 0，把噪声也完全拟合了；同时贪心划分对数据扰动非常敏感，换一小部分数据可能得到完全不同的树。
- 应对方法：
    - **预剪枝**：限制 `max_depth`、`min_samples_split`、`min_samples_leaf`、`max_leaf_nodes`、`min_impurity_decrease`；
    - **后剪枝**：REP、PEP、CCP 等；
    - **集成**：Bagging / 随机森林降低方差，Boosting 用浅树降低偏差；
    - 特征选择、增加数据量。

Q11：***预剪枝和后剪枝有什么区别？各有什么优缺点？***

- **预剪枝**：在生长过程中，每次分裂前评估该分裂是否能提升泛化性能（如验证集精度、不纯度下降阈值、深度/样本数限制），不能则停止分裂、把当前节点标记为叶。
    - 优点：训练和测试开销小，实现简单。
    - 缺点：**"视野短浅"**，有欠拟合风险。某些分裂当前看收益不大，但其后续分裂可能带来显著提升（典型例子是 XOR 问题：单独按任一特征划分都没有增益）。
- **后剪枝**：先生成一棵完整的树，再自底向上考察每个内部节点，若把其子树替换成叶节点能提升泛化性能，则剪掉。
    - 优点：保留更多分支，**欠拟合风险小，泛化性能通常优于预剪枝**。
    - 缺点：要先长出完整树，训练开销大。
- 常见后剪枝方法：**REP**（Reduced Error Pruning，用独立验证集）、**PEP**（Pessimistic Error Pruning，C4.5，对训练误差做连续性修正，无需验证集）、**CCP**（Cost-Complexity Pruning，CART）。

Q12：***详细说一下 CART 的代价复杂度剪枝（CCP）。***

- 定义子树 $T$ 的代价复杂度损失：
$$C_\alpha(T) = C(T) + \alpha |T|$$
其中 $C(T)$ 是训练误差（如叶节点的基尼/误分类/平方误差加权和），$|T|$ 为叶节点数，$\alpha\ge0$ 权衡拟合程度与复杂度。$\alpha=0$ 时完整树最优，$\alpha\to\infty$ 时只剩根节点。
- 对内部节点 $t$，比较"剪成单叶"与"保留子树 $T_t$"：当
$$\alpha = g(t) = \frac{C(t) - C(T_t)}{|T_t| - 1}$$
时两者损失相等。$g(t)$ 衡量剪掉该子树后**每减少一个叶节点误差增加多少**。
- 算法（**最弱连接剪枝**，weakest link pruning）：
    1. 对完整树 $T_0$ 计算每个内部节点的 $g(t)$，剪掉 $g(t)$ 最小的节点，得到 $T_1$，记 $\alpha_1 = \min g(t)$；
    2. 重复直到只剩根，得到嵌套子树序列 $T_0 \supset T_1 \supset \dots \supset T_n$，对应 $\alpha$ 区间 $[\alpha_i, \alpha_{i+1})$；
    3. 用**交叉验证**或独立验证集从子树序列中选出最优子树（即选最优 $\alpha$）。
- sklearn 中对应参数 `ccp_alpha`，可用 `cost_complexity_pruning_path()` 获取 $\alpha$ 序列：

```python
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import cross_val_score

path = DecisionTreeClassifier(random_state=0).cost_complexity_pruning_path(X_train, y_train)
scores = [cross_val_score(DecisionTreeClassifier(ccp_alpha=a, random_state=0),
                          X_train, y_train, cv=5).mean() for a in path.ccp_alphas]
best_alpha = path.ccp_alphas[max(range(len(scores)), key=scores.__getitem__)]
```

## 特征重要性与可解释性

Q13：***决策树的特征重要性是怎么计算的？有什么偏差？***

- sklearn 默认的 `feature_importances_` 是 **MDI（Mean Decrease in Impurity，基尼重要性）**：特征 $j$ 的重要性为所有使用 $j$ 分裂的节点上**加权不纯度下降**之和，再归一化：
$$\text{Imp}(j) = \sum_{t:\,v(t)=j} \frac{N_t}{N}\left[I(t) - \frac{N_{t_L}}{N_t} I(t_L) - \frac{N_{t_R}}{N_t} I(t_R)\right]$$
- 偏差与问题：
    - **偏向高基数特征**（连续特征、类别很多的特征、ID 类特征）：它们候选切分点多，更容易"偶然"找到能降低不纯度的切分，即使是随机噪声特征也会得到不低的重要性；
    - **基于训练集计算**，反映的是模型如何拟合训练数据，而非泛化中的真实贡献，过拟合的树会放大这一问题；
    - **相关特征**会分摊/抢占重要性，导致单个特征的重要性被低估；
    - 只给出全局重要性大小，不给出方向和单样本解释。
- 替代方案：**置换重要性**（permutation importance，在验证集上打乱特征看性能下降；但相关特征下也会有问题）、**drop-column importance**、**SHAP**（TreeSHAP，有一致性保证，可给出单样本贡献和方向）。

Q14：***为什么说决策树可解释性好？它的可解释性有什么局限？***

- 优点：
    - 模型就是一组**人类可读的 if-then 规则**，可以可视化，每个预测都能追溯到一条从根到叶的路径；
    - 天然完成**特征选择**，能展示哪些特征在决策中起作用；
    - 是"白盒"模型，便于向业务方、监管方解释（如信贷审批）。
- 局限：
    - 只有**浅树**才真正可解释，深树有成百上千条规则，人类难以理解；
    - **不稳定**：数据小扰动可能导致树结构大变，解释随之改变，降低可信度；
    - 规则反映的是相关性而非因果；
    - 一旦集成为随机森林/GBDT，可解释性大幅下降，需要借助 SHAP 等工具。

Q15：***为什么决策树不需要做特征归一化/标准化？***

- 决策树的分裂只依赖于**特征值的排序**（$x_j \le t$ 把样本分成两组），对特征做任何**单调变换**（缩放、平移、取对数等）都不改变样本的排序，从而不改变划分结果和不纯度，只是切分阈值 $t$ 随之变换。
- 决策树不涉及距离计算，也不使用梯度下降优化参数，因此不存在"量纲大的特征主导距离"或"条件数差导致收敛慢"的问题。
- 同理，决策树对**单调变换下的异常值**也比较鲁棒（特征上的异常值只影响排序位置）。但注意：回归树的**标签**异常值仍会影响 MSE 准则和叶节点均值。

Q16：***决策树如何处理类别特征？***

- ID3/C4.5：多叉分裂，每个取值一个分支（容易碎片化，且偏好多值特征）。
- CART：二叉分裂，需要把 $K$ 个类别划分成两个子集，暴力枚举有 $2^{K-1}-1$ 种。对二分类（或回归）问题有经典结论：按每个类别的**正类比例（或标签均值）排序**后，最优划分一定是排序序列上的某个切分点，只需检查 $K-1$ 种（Fisher 1958 / Breiman 等）。LightGBM 处理类别特征也借鉴了这个思路。
- sklearn 的决策树（截至目前）**不原生支持类别特征**，需要 one-hot、序数编码或目标编码。One-hot 后高基数特征会使树非常不平衡、每次只能切出一个类别，效果常不如原生类别分裂。

## 优缺点与对比

Q17：***决策树有哪些优缺点？***

优点：

- 可解释性强，可视化直观；
- 几乎不需要数据预处理：**无需归一化**，能处理数值和类别特征，能处理缺失值（视实现而定）；
- 能自动捕捉**非线性关系和特征交互**；
- 预测速度快，复杂度为 $O(\text{depth})$；
- 可处理多分类、多输出问题。

缺点：

- 容易**过拟合**，需要剪枝或集成；
- **不稳定**（高方差），数据微小变化可能导致完全不同的树；
- **贪心**构建，只能得到局部最优；
- 轴平行划分，难以高效表达斜线/对角决策边界（需要很多阶梯式划分）；
- 回归时输出分段常数，**无法外推**；
- 类别不平衡时偏向多数类；
- 难以表达 XOR、奇偶校验等需要多特征联合的概念（贪心下单个特征无增益）。

Q18：***决策树和逻辑回归有什么区别？分别适合什么场景？***

- **决策边界**：逻辑回归是线性边界（除非手工构造特征）；决策树是轴平行的分段边界，可表达非线性。
- **特征交互**：树自动学习交互，LR 需要人工构造交叉特征。
- **预处理**：LR 需要标准化、处理缺失值、对类别做 one-hot、对异常值敏感；树基本不需要。
- **输出**：LR 输出平滑、校准较好的概率；树输出的是叶节点频率，概率比较粗糙。
- **稳定性与方差**：LR 方差低、稳定；单棵树方差高。
- **外推**：LR 能外推线性趋势，树不能。
- 场景：特征与目标近似线性、需要稳定概率输出、高维稀疏特征（如文本、广告 ID 类特征）时用 LR；存在复杂非线性和交互、需要规则化解释时用树（实践中多用树的集成）。

Q19：***决策树的时间复杂度是多少？***

- 训练：设 $n$ 个样本、$d$ 个特征。每层需要对所有特征扫描所有样本，借助预排序每层代价约 $O(nd)$，平衡树深度 $O(\log n)$，总体约 $O(nd\log n)$（若每个节点重新排序则为 $O(nd\log^2 n)$ 量级）。sklearn 文档给出的典型值为 $O(n_{\text{features}}\, n_{\text{samples}} \log n_{\text{samples}})$ 量级。
- 预测：单样本 $O(\text{depth})$，平衡树约 $O(\log n)$，最坏 $O(n)$。
- 加速：直方图/分桶近似（把连续特征离散成 $B$ 个桶，代价降到 $O(nd + Bd)$ 每层）、特征采样、并行化。

Q20：***决策树与随机森林、GBDT 的关系是什么？***

- 决策树是这两类集成模型的**基学习器**：
    - **随机森林**（Bagging）：用 bootstrap 样本 + 随机特征子集训练很多**深树**（低偏差、高方差），通过平均**降低方差**；
    - **GBDT**（Boosting）：串行训练很多**浅树**（高偏差、低方差），每棵树拟合当前模型的负梯度，**降低偏差**。
- 选择 CART 作为基学习器的原因：可处理分类和回归、二叉结构便于实现、对特征尺度不敏感、能自动建模交互、训练快。
- GBDT 中的树都是**回归树**，即使做分类任务也是如此，因为拟合的是连续的负梯度。详见随机森林和梯度提升树卡片。
