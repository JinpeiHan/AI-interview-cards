# 决策树

## 基础与划分准则

Q1：***什么是决策树？它是如何做预测的？***

**决策树是一种非参数的监督学习模型，它把特征空间递归地切成若干矩形区域，每个区域对应一个叶子。预测时从根节点开始，按每个节点的特征测试一路走到叶子，输出叶子的值。**

- 内部节点是特征测试（如 $x_j \le t$），叶子存放预测值。
- 分类输出叶子内的多数类（或类别比例），回归输出叶子内标签的均值。
- 本质上是一组 if-then 规则，相当于对 $P(Y|X)$ 的分段常数近似。

Q2：***决策树的构建流程是怎样的？什么时候停止分裂？***

**自顶向下贪心地递归划分：在当前节点遍历所有特征和切分点，选出让不纯度下降最多的划分，把样本分到子节点，再对子节点重复，直到满足停止条件。**

- 停止条件：节点内全是同一类、没有可用特征或特征取值都相同、样本数太少、达到最大深度、不纯度下降小于阈值。
- 找全局最优树是 NP 完全问题，所以只能用贪心的局部最优，这也让树对数据扰动很敏感。

Q3：***信息熵、条件熵、信息增益分别如何定义？***

**信息熵衡量一个数据集类别的不确定性；条件熵是按某个特征划分后各子集熵的加权平均；信息增益就是划分前后熵的减少量，也就是特征和标签的互信息。ID3 选信息增益最大的特征。**

- 全是一类时熵为 0，均匀分布时熵最大（$\log_2 K$）。
- 条件熵的权重是各子集样本占比。
- 核心公式：$H(D) = -\sum_k p_k \log_2 p_k$

Q4：***信息增益有什么缺陷？增益率是如何解决的？***

**信息增益偏好取值多的特征，极端时按"样本 ID"划分增益最大却毫无泛化能力。C4.5 的增益率把信息增益除以特征自身的固有值（取值越多固有值越大），以此惩罚多值特征。**

- 但增益率反过来偏好取值少的特征。
- 所以 C4.5 用启发式：先选出信息增益高于平均的特征，再从中选增益率最高的。
- 核心公式：$\text{GainRatio}(D,A) = \text{Gain}(D,A) / IV(A)$

Q5：***基尼指数是什么？和熵有什么关系？***

**基尼指数是从数据集中随机抽两个样本、类别不一致的概率，越小越纯；CART 选划分后加权基尼指数最小的切分。它可以看作熵的一阶泰勒近似，两者效果通常差不多，但基尼不用算对数，更快。**

- 熵对类别分布的变化稍敏感一些。
- 二分类时基尼、熵、误分类率都在 p=0.5 时最大。
- 误分类率对纯度变化不敏感，一般不用来生长树，但常用于剪枝评估。
- 核心公式：$\text{Gini}(D) = 1 - \sum_k p_k^2$

## 三种经典算法

Q6：***ID3、C4.5、CART 有什么区别？***

**ID3 用信息增益、只做分类、只支持离散特征；C4.5 改用增益率，支持连续特征、缺失值和剪枝；CART 是二叉树，分类用基尼指数、回归用平方误差，既能分类又能回归。**

| | ID3 | C4.5 | CART |
|---|---|---|---|
| 划分准则 | 信息增益 | 增益率 | 基尼 / 平方误差 |
| 任务与树结构 | 分类，多叉 | 分类，多叉 | 分类+回归，二叉 |
| 连续特征 / 缺失值 | 都不支持 | 都支持 | 都支持（代理分裂） |
| 剪枝 | 无 | 悲观错误剪枝 PEP | 代价复杂度剪枝 CCP |

- sklearn 的决策树实现的是优化版 CART，不是 ID3/C4.5。

Q7：***决策树如何处理连续特征？***

**用二分法：把当前节点上该特征的取值排序，取相邻值的中点作为候选切分点，逐个计算划分准则，选最好的那个。**

- 最优切分点只会出现在类别发生变化的相邻点之间，可以大幅减少候选数。
- 大数据下可用直方图 / 分位数分桶近似（GBDT 常用）。
- 和离散特征不同，连续特征在后续节点还可以再次使用。

Q8：***决策树如何处理缺失值？***

**要解决两个问题：选特征时，C4.5 只用该特征无缺失的样本算信息增益，再乘以无缺失样本占比；分配样本时，不同算法做法不同。**

- C4.5：缺失样本按各分支的样本比例，以不同权重同时进入所有子节点。
- CART：用代理分裂，找与主分裂结果最相似的其他特征来决定去向。
- XGBoost / LightGBM / sklearn（1.3 起）：把缺失值分别放左、放右，取增益更大的方向作为默认方向。
- 工程上也可以直接填充（中位数或 -999 等特殊值），树通常也能学到其含义。

Q9：***回归树是如何构建的？***

**CART 回归树按平方误差最小来分裂：对每个特征和切分点，把样本分成两部分，每部分用均值预测，选总平方误差最小的那个切分，递归下去。最终得到一个分段常数函数，叶子输出区域内样本的均值。**

- 也可以用 MAE 准则（叶子取中位数，对异常值更鲁棒）或泊松偏差。
- 局限：无法外推到训练标签范围之外，输出不连续、不光滑。
- 核心公式：$\min_{j,s}\left[\sum_{x_i\in R_1}(y_i-c_1)^2 + \sum_{x_i\in R_2}(y_i-c_2)^2\right]$，$c_m$ 为区域均值

## 剪枝与过拟合

Q10：***决策树为什么容易过拟合？有哪些应对方法？***

**决策树是低偏差、高方差的模型：不加限制时可以一直分裂到每个叶子只剩一个样本，把噪声也学进去；而且贪心划分对数据扰动很敏感。应对方法是剪枝和集成。**

- 预剪枝：限制 `max_depth`、`min_samples_leaf`、`max_leaf_nodes`、`min_impurity_decrease` 等。
- 后剪枝：REP、PEP、CCP。
- 集成：随机森林降低方差，Boosting 用浅树降低偏差。
- 也可以做特征选择、增加数据。

Q11：***预剪枝和后剪枝有什么区别？各有什么优缺点？***

**预剪枝是在生长过程中，每次分裂前判断这个分裂能否提升泛化，不能就停；后剪枝是先长出完整的树，再自底向上把不划算的子树替换成叶子。预剪枝快但容易欠拟合，后剪枝泛化通常更好但更慢。**

- 预剪枝"视野短浅"：某次分裂当下收益小，但后续分裂可能收益很大（如 XOR 问题）。
- 后剪枝保留更多分支，欠拟合风险小，但要先长出完整树，训练开销大。
- 常见后剪枝：REP（用验证集）、PEP（C4.5，无需验证集）、CCP（CART）。

Q12：***详细说一下 CART 的代价复杂度剪枝（CCP）。***

**CCP 在训练误差上加一个"α × 叶子数"的惩罚。从完整树开始，每次剪掉"每减少一个叶子、误差增加最少"的那个子树（最弱连接），得到一串越来越小的嵌套子树，对应一串 α，最后用交叉验证选出最好的那个。**

- α=0 时完整树最优，α 很大时只剩根节点。
- 对每个内部节点，计算剪掉它的子树后平均每少一个叶子误差增加多少，最小的先剪。
- sklearn 中用 `cost_complexity_pruning_path()` 得到 α 序列，再用交叉验证选 `ccp_alpha`。
- 核心公式：$C_\alpha(T) = C(T) + \alpha |T|$

## 特征重要性与可解释性

Q13：***决策树的特征重要性是怎么计算的？有什么偏差？***

**sklearn 默认用 MDI（平均不纯度下降）：把一个特征在所有分裂节点上带来的加权不纯度下降加起来，再归一化。它偏向高基数特征、基于训练集计算，而且相关特征会互相分摊重要性。**

- 高基数特征（连续值、类别多、ID 类）候选切分点多，容易"偶然"降低不纯度，连随机噪声特征也会得分不低。
- 基于训练集，反映的是拟合而非泛化，过拟合的树会放大这一问题。
- 只给全局大小，不给方向和单样本解释。
- 替代方案：验证集上的置换重要性、drop-column 重要性、TreeSHAP。

Q14：***为什么说决策树可解释性好？它的可解释性有什么局限？***

**因为模型就是一组人能读懂的 if-then 规则，可以画出来，每个预测都能追溯到一条从根到叶的路径。但这只对浅树成立，而且树很不稳定。**

- 优点：天然做特征选择，是白盒模型，便于向业务方和监管方解释（如信贷审批）。
- 局限：深树有成百上千条规则，人看不懂。
- 数据稍有扰动树结构就可能大变，解释也随之变化。
- 规则反映相关而非因果；集成成随机森林/GBDT 后需要 SHAP 等工具。

Q15：***为什么决策树不需要做特征归一化/标准化？***

**因为分裂只看特征值的排序，缩放、平移、取对数这类单调变换不改变排序，划分结果和不纯度都不变，只是阈值跟着变。而且树不算距离、也不用梯度下降，不存在量纲影响。**

- 同理，特征上的异常值只影响排序位置，树对此比较鲁棒。
- 但回归树的标签异常值仍会影响平方误差和叶子均值。

Q16：***决策树如何处理类别特征？***

**ID3/C4.5 为每个取值开一个分支；CART 做二叉分裂，要把类别分成两组。对二分类或回归，只需把类别按正类比例（或标签均值）排序，最优划分一定是排序后的某个切分点，所以只要检查 K−1 种而不是指数多种。**

- 多叉分裂容易碎片化，且偏好多值特征。
- 这个排序技巧来自 Fisher 1958 / Breiman 等，LightGBM 也借鉴了它。
- sklearn 的决策树不原生支持类别特征，需要 one-hot、序数编码或目标编码；高基数 one-hot 会让树又深又不平衡。

## 优缺点与对比

Q17：***决策树有哪些优缺点？***

**优点是可解释、几乎不需要预处理、能自动捕捉非线性和特征交互、预测快；缺点是容易过拟合、不稳定、只能贪心求局部最优，而且轴平行划分难以表达斜线边界、回归无法外推。**

- 优点补充：能处理数值和类别特征、缺失值（视实现而定），支持多分类和多输出，预测复杂度为 O(深度)。
- 缺点补充：类别不平衡时偏向多数类；难以学到 XOR、奇偶校验这类需要多特征联合的概念。
- 过拟合和不稳定一般通过剪枝和集成解决。

Q18：***决策树和逻辑回归有什么区别？分别适合什么场景？***

**逻辑回归是线性边界，稳定、概率校准好，但需要人工构造交互特征和较多预处理；决策树是轴平行的分段边界，能自动学非线性和交互、几乎不用预处理，但方差大、概率粗糙、不能外推。**

- LR 需要标准化、处理缺失值、对类别做 one-hot，对异常值敏感；树基本不需要。
- LR 能外推线性趋势，树不能。
- 适合 LR：近似线性关系、需要稳定概率、高维稀疏特征（文本、广告 ID）。
- 适合树：复杂非线性和交互、需要规则化解释（实践中多用树的集成）。

Q19：***决策树的时间复杂度是多少？***

**训练大约是 O(n·d·log n)：每层要对 d 个特征扫描 n 个样本，平衡树大约有 log n 层。预测单个样本是 O(深度)，平衡树约 O(log n)，最坏 O(n)。**

- 每个节点都重新排序时会更慢，用预排序可以复用。
- 加速手段：直方图分桶、特征采样、并行化。

Q20：***决策树与随机森林、GBDT 的关系是什么？***

**决策树是两者的基学习器：随机森林用 bootstrap 样本和随机特征训练很多深树再平均，降低方差；GBDT 串行训练很多浅树，每棵拟合当前模型的负梯度，降低偏差。**

- 常用 CART 做基学习器，因为它能分类也能回归、二叉结构好实现、对尺度不敏感、能自动建模交互、训练快。
- GBDT 里的树都是回归树，即使做分类也一样，因为拟合的是连续的负梯度。详见随机森林和梯度提升树卡片。
