# 统计与A/B测试

## 假设检验基础

Q1：***描述假设检验的一般框架***

- **原假设** $H_0$（通常是"无效应/无差异"）与**备择假设** $H_1$；检验的逻辑是"反证法"：假设 $H_0$ 为真，看观测到的数据有多"罕见"。
- 一般步骤：
    1. 提出 $H_0$、$H_1$，确定单侧还是双侧检验；
    2. 预先设定**显著性水平** $\alpha$（常用 0.05）；
    3. 选择**检验统计量**（如 $z$、$t$、$\chi^2$），并知道它在 $H_0$ 下的分布；
    4. 由样本计算统计量和 p 值（或与临界值比较）；
    5. 若 $p<\alpha$ 则**拒绝** $H_0$，否则**不能拒绝** $H_0$（注意不是"接受 $H_0$"）。
- 追问点：$\alpha$、样本量、检验方法都应在看数据**之前**确定，否则会引入 p-hacking。

Q2：***p 值的正确含义是什么？有哪些常见误读？***

- **定义**：在 $H_0$ 为真的前提下，得到与观测结果**一样极端或更极端**的统计量的概率：$p=P(|T|\ge|t_{obs}|\mid H_0)$。
- 常见误读：
    - "p 值是 $H_0$ 为真的概率"——p 值是 $P(\text{数据}\mid H_0)$，而不是 $P(H_0\mid \text{数据})$，后者需要先验（贝叶斯）。
    - "$1-p$ 是 $H_1$ 为真的概率"。
    - "p 值越小效应越大"——p 值同时受效应大小和样本量影响，样本极大时微小效应也会显著；应同时报告**效应量和置信区间**。
    - "$p>0.05$ 说明没有差异"——可能只是功效不足。
    - "p=0.05 意味着假阳性率 5%"——在所有显著结果中假阳性的比例（FDR）还取决于真实效应的先验比例和功效。
- $H_0$ 为真时，p 值服从 $[0,1]$ 上的**均匀分布**——这是理解 peeking 和多重比较问题的关键。

Q3：***解释第一类错误、第二类错误和统计功效***

| | $H_0$ 为真 | $H_1$ 为真 |
|---|---|---|
| 拒绝 $H_0$ | **第一类错误**（假阳性），概率 $\alpha$ | 正确，概率 $1-\beta$（**功效**） |
| 不拒绝 $H_0$ | 正确，概率 $1-\alpha$ | **第二类错误**（假阴性），概率 $\beta$ |

- **功效（Power）** $=1-\beta$：真实存在效应时检测出来的概率，A/B 测试中通常要求 80%。
- 影响功效的因素：效应量 ↑、样本量 ↑、方差 ↓、$\alpha$ ↑ 都会使功效 ↑。
- 在固定样本量下 $\alpha$ 和 $\beta$ 此消彼长；只有增加样本量或降低方差才能同时降低两者。

Q4：***置信区间如何正确解释？与假设检验有什么关系？***

- 95% 置信区间：如果**重复抽样**很多次，每次都按同样方法构造区间，约 95% 的区间会包含真实参数。
- 误读："真实参数有 95% 的概率落在这个区间内"——在频率学派中参数是固定值，一个具体区间要么包含它要么不包含；这种说法对应的是贝叶斯的**可信区间**。
- 均值差的区间：$(\bar x_B-\bar x_A)\pm z_{1-\alpha/2}\sqrt{\frac{s_A^2}{n_A}+\frac{s_B^2}{n_B}}$。
- **对偶关系**：双侧检验在水平 $\alpha$ 下拒绝 $H_0:\delta=0$ ⇔ $1-\alpha$ 置信区间不包含 0。置信区间比单个 p 值提供更多信息（效应大小与不确定性）。

Q5：***中心极限定理（CLT）是什么？为什么它对 A/B 测试很重要？***

- **CLT**：$X_1,\dots,X_n$ 独立同分布，均值 $\mu$、方差 $\sigma^2<\infty$，则 $\frac{\bar X-\mu}{\sigma/\sqrt n}\xrightarrow{d}\mathcal N(0,1)$。
- 重要性：大多数业务指标（收入、时长）**本身并不正态**，但其**样本均值**近似正态，因此可以对均值差使用 z 检验/t 检验，构造置信区间。
- 注意事项：
    - 重尾分布（如收入、少数"鲸鱼"用户）收敛很慢，需要更大样本，或做**截尾（winsorize/capping）**、对数变换；
    - 要求样本独立——若随机化单位是用户、分析单位是会话/页面浏览，则观测不独立，需要 delta 方法或聚类稳健标准误；
    - 方差无穷（如柯西分布）时 CLT 不成立。

## 常用检验

Q6：***z 检验和 t 检验有什么区别？什么是 Welch t 检验？***

- **z 检验**：总体方差已知或样本量很大（用样本方差近似），统计量服从标准正态。比例指标（转化率）常用两比例 z 检验：
  $$z=\frac{\hat p_B-\hat p_A}{\sqrt{\hat p(1-\hat p)\left(\frac1{n_A}+\frac1{n_B}\right)}}$$
  其中 $\hat p$ 为合并比例。
- **t 检验**：总体方差未知、用样本方差估计，统计量服从 t 分布（自由度相关，尾部比正态更厚）；小样本时更准确，$n$ 大时 t 分布 → 正态。
- **Student t 检验**假设两组**方差相等**；**Welch t 检验**不假设方差相等：
  $$t=\frac{\bar x_B-\bar x_A}{\sqrt{\frac{s_A^2}{n_A}+\frac{s_B^2}{n_B}}},\quad \nu\approx\frac{\left(\frac{s_A^2}{n_A}+\frac{s_B^2}{n_B}\right)^2}{\frac{(s_A^2/n_A)^2}{n_A-1}+\frac{(s_B^2/n_B)^2}{n_B-1}}$$
  （Welch–Satterthwaite 自由度）。实践中**默认用 Welch**，在方差相等时它几乎不损失功效，方差不等时更稳健。
- **配对 t 检验**：同一对象前后两次测量，对差值做单样本 t 检验。

Q7：***卡方检验用于什么场景？***

- **独立性检验**：两个分类变量是否独立（如实验组别 × 是否转化的列联表）。
- **拟合优度检验**：观测频数是否符合期望分布——A/B 测试中的 **SRM 检查**就是这种用法。
- 统计量：$\chi^2=\sum\frac{(O_i-E_i)^2}{E_i}$，自由度 $(r-1)(c-1)$（独立性）或 $k-1$（拟合优度）。
- 条件：期望频数一般不小于 5，否则用 **Fisher 精确检验**。
- 对 2×2 表，卡方检验与双侧两比例 z 检验等价（$\chi^2=z^2$）。

Q8：***什么时候使用 Mann-Whitney U 检验？***

- 非参数检验，比较两个独立样本，**不假设正态性**，基于秩（rank）：把两组数据合并排序，比较各组秩和。
- 检验的原假设是 $P(X>Y)=P(Y>X)$（随机占优），**并不严格等于检验中位数相等**——只有在两分布形状相同仅位移不同时才可解释为中位数差异。
- 适用：小样本、强偏态、有离群点、序数数据。
- 缺点：不能直接给出"均值提升多少"，而业务通常关心均值（如人均收入）；大样本下 t 检验依靠 CLT 已足够稳健。替代方案还有 bootstrap、对数变换后 t 检验。

Q9：***什么是 Bootstrap？什么时候用？***

- 思想：用经验分布近似总体分布，**有放回地**从样本中重复抽取同样大小的样本 $B$ 次（如 1000–10000 次），每次计算统计量，用这些统计量的分布估计标准误和置信区间。
- **百分位区间**：取 bootstrap 统计量的 2.5% 和 97.5% 分位数；更精确的有 BCa 区间。
- 适用：统计量没有简单的解析标准误（中位数、分位数、比率指标、AUC 等），或分布形态复杂。
- 注意：
    - 必须按**随机化单位**重抽样（如按用户而不是按事件），否则低估方差；
    - 对极端分位数、极小样本、重尾分布效果不佳；
    - 计算量大，大规模实验平台通常用 delta 方法代替。

```python
import numpy as np
def bootstrap_ci(a, b, stat=np.mean, B=5000, alpha=0.05, seed=0):
    rng = np.random.default_rng(seed)
    diffs = [stat(rng.choice(b, len(b))) - stat(rng.choice(a, len(a))) for _ in range(B)]
    return np.quantile(diffs, [alpha / 2, 1 - alpha / 2])
```

## A/B 测试设计

Q10：***如何选择 A/B 测试的指标？什么是北极星指标和护栏指标？***

- **北极星指标/OEC（总体评估标准）**：反映产品长期价值的核心指标，例如活跃用户留存、人均有效时长；需要**对业务价值敏感、可在实验周期内移动、不易被操纵**。
- **主要指标（决策指标）**：本次实验直接要改善的指标，通常是北极星的可测代理，如点击率、转化率。
- **护栏指标（Guardrail）**：不能变差的指标，分两类：
    - 业务护栏：收入、留存、投诉率、卸载率；
    - 可信度护栏：**SRM**、页面加载延迟、崩溃率——用来检验实验本身是否可靠。
- 好指标的性质：**敏感性**（能检测到变化）、**方向性**（与长期价值一致）、低方差；可以用历史实验或 A/A 测试评估指标的方差和敏感性。
- 追问：短期指标与长期价值冲突（例如更多广告提高收入但降低留存）时，需要长期holdout或代理指标校准。

Q11：***如何选择随机化单位？***

- 常见单位：**用户**（user id）、设备/cookie、会话、页面浏览、地区/时间片（集群）。
- 原则：
    - **一致的用户体验**：用户可感知的改动（UI、推荐策略）应按用户分流，避免同一用户来回切换；
    - **随机化单位应与分析单位一致或更粗**：若按用户分流却以页面浏览为分析单位（如 CTR = 点击/PV），观测不独立，朴素方差公式低估方差，需用 **delta 方法**或 bootstrap 按用户重抽样；
    - **干扰/网络效应**：存在用户间相互影响时，需更粗粒度的单位（地区、集群、时间片）；
    - 更细的单位样本量更大、功效更高，但可能导致体验不一致和泄漏。
- 未登录用户只能按 cookie/设备，存在一人多设备的问题。

Q12：***A/B 测试的样本量如何计算？MDE 是什么？***

- **MDE（最小可检测效应）**：在给定 $\alpha$、功效下，实验能够可靠检测到的最小效应；应由**业务意义**决定（多大提升值得上线），而不是事后调整。
- 双样本均值比较，每组样本量（双侧）：
  $$n=\frac{(z_{1-\alpha/2}+z_{1-\beta})^2\cdot 2\sigma^2}{\delta^2}$$
- 当 $\alpha=0.05$、功效 80% 时，$(1.96+0.84)^2\approx 7.85$，得到经验公式 $n\approx\frac{16\sigma^2}{\delta^2}$（每组）。
- 比例指标：$\sigma^2=p(1-p)$。例如基线转化率 $p=10\%$，想检测绝对提升 $\delta=0.5\%$：$n\approx 16\times0.09/0.005^2=57600$ 每组。
- 规律：样本量与 $\sigma^2$ 成正比、与 $\delta^2$ 成反比——MDE 减半，样本量变为 **4 倍**。因此降低方差（CUPED）能直接缩短实验时间。

Q13：***实验需要运行多长时间？什么是新奇效应和首因效应？***

- 时长 = 所需样本量 / 每日进入实验的流量，但还需满足：
    - 至少覆盖**完整的周周期**（通常 1–2 周以上），消除星期几效应；
    - 避开节假日、大促等异常时间，或明确结果的外推范围；
    - 足够长以观察**新奇/首因效应**衰减。
- **新奇效应（Novelty effect）**：用户因"新鲜感"而短期内更多使用新功能，效果随时间衰减，导致高估。
- **首因效应/变化厌恶（Primacy effect）**：老用户习惯旧版，短期内表现变差，适应后才回升，导致低估。
- 识别方法：画**处理效应随时间的曲线**；按新/老用户分别分析（新用户不受这两种效应影响）；按用户首次曝光的天数（cohort）分析；必要时设置长期 holdout。

Q14：***什么是"偷看"（peeking）问题？如何用序贯检验解决？***

- **peeking**：实验进行中反复查看 p 值，一旦 $p<0.05$ 就停止。由于 $H_0$ 下 p 值随时间随机游走，多次查看相当于多重比较，**实际第一类错误率远高于 5%**（查看次数越多越高）。
- 解决方案：
    - **固定样本量**：事先计算样本量，到时才看结果；
    - **成组序贯检验（Group Sequential）**：预先设定若干次中期分析，用 **α 消耗函数**（O'Brien-Fleming、Pocock）分配 α——O'Brien-Fleming 早期边界很严格、后期接近常规阈值；
    - **始终有效推断（Always-valid inference）**：如 mSPRT（混合序贯概率比检验）、置信序列（confidence sequences），允许随时查看而保证错误率，代价是固定时间点上功效略低；
    - 贝叶斯方法也会受 optional stopping 影响其频率学性质，不能完全回避该问题。

Q15：***什么是多重比较问题？Bonferroni 和 BH 方法有什么区别？***

- 同时检验 $m$ 个假设（多个指标、多个实验组、多个细分人群）时，至少一个假阳性的概率 $1-(1-\alpha)^m$ 迅速增大（$m=20$ 时约 64%）。
- **FWER（族错误率）控制——Bonferroni**：每个检验用阈值 $\alpha/m$。简单但很保守，$m$ 大时功效损失严重。改进：Holm 逐步法（一致更有功效）。
- **FDR（错误发现率）控制——Benjamini-Hochberg**：FDR = 被拒绝的假设中假阳性的期望比例。步骤：
    1. 将 p 值从小到大排序 $p_{(1)}\le\dots\le p_{(m)}$；
    2. 找最大的 $k$ 使得 $p_{(k)}\le\frac{k}{m}q$；
    3. 拒绝前 $k$ 个假设。
- 选择：关键决策需要严格控制任何假阳性时用 FWER；探索性分析（大量指标/人群筛选）用 FDR 更合适。
- 实践：预先指定**唯一的主要指标**，其他指标作为次要/探索性；细分分析结果需要复现验证。

Q16：***什么是 SRM？如何检查？***

- **SRM（Sample Ratio Mismatch，样本比例不匹配）**：实际各组样本比例显著偏离设计比例（如设计 50/50，观测 50.8/49.2）。
- 检查：卡方拟合优度检验，$\chi^2=\sum\frac{(O_i-E_i)^2}{E_i}$；常用很严格的阈值（如 $p<0.001$）报警。
- SRM 说明**随机化或数据管道有问题**，实验结果不可信，应先排查而不是解读效果。常见原因：
    - 分流 bug、哈希冲突、实验组页面加载更慢导致埋点丢失；
    - 机器人流量过滤在两组中不均衡；
    - 实验组触发条件不同（触发分析时只统计了部分用户）；
    - 实验中途改变流量比例。

Q17：***什么是网络效应/干扰？如何处理？***

- A/B 测试依赖 **SUTVA**（个体处理效应稳定假设）：一个单位的结果不受其他单位分组的影响。以下场景会违反：
    - **社交网络**：实验组用户的新功能影响其好友（对照组）的行为 → 效应被稀释或放大；
    - **双边市场**（打车、外卖、广告竞价）：实验组和对照组共享供给/预算，实验组"抢"走资源，导致效应**高估**；
    - 共享库存、共享模型训练数据（反馈回路）。
- 解决方案：
    - **集群随机化**：按社交图聚类（graph cluster randomization）或按地理区域分流；
    - **切换实验（Switchback）**：按时间片在整个地区交替开关处理，常用于双边市场；
    - **预算/资源分离**：给实验组和对照组分配独立的预算或供给池；
    - 代价：随机化单位变少，方差增大，功效降低。

Q18：***什么是 CUPED？为什么能降低方差？***

- **CUPED**（Controlled-experiment Using Pre-Experiment Data，微软 2013）：利用实验前的协变量 $X$（通常是同一指标在实验前的值）对指标 $Y$ 做调整：
  $$Y_{cuped}=Y-\theta(X-\bar X),\quad \theta=\frac{\mathrm{Cov}(X,Y)}{\mathrm{Var}(X)}$$
- 方差：$\mathrm{Var}(Y_{cuped})=\mathrm{Var}(Y)(1-\rho^2)$，其中 $\rho$ 为 $X,Y$ 相关系数。若 $\rho=0.7$，方差下降约 51%，相当于样本量近乎翻倍。
- **无偏性**：$X$ 是实验前数据，不受处理影响，两组 $X$ 的期望相同，因此调整不改变处理效应的期望。
- 本质上等价于在回归中加入预处理协变量（ANCOVA / 回归调整）；推广：CUPAC 用 ML 模型预测作为协变量。
- 注意：协变量必须**不受处理影响**；新用户没有历史数据时可用其他实验前特征或缺失指示。

Q19：***什么是比率指标？为什么需要 delta 方法？***

- **比率指标**：分子、分母都是随机变量，例如 CTR = 总点击/总曝光，按用户分流时分析单位（曝光）比随机化单位（用户）更细。
- 同一用户的多次曝光相关，直接用二项方差 $p(1-p)/N$ 会**低估方差**，导致假阳性增加。
- **delta 方法**：对 $R=\bar Y/\bar X$（$\bar Y,\bar X$ 为用户级均值）进行一阶泰勒展开：
  $$\mathrm{Var}\left(\frac{\bar Y}{\bar X}\right)\approx\frac{1}{\mu_X^2}\mathrm{Var}(\bar Y)+\frac{\mu_Y^2}{\mu_X^4}\mathrm{Var}(\bar X)-2\frac{\mu_Y}{\mu_X^3}\mathrm{Cov}(\bar Y,\bar X)$$
  其中方差和协方差都在用户级别估计（如 $\mathrm{Var}(\bar Y)=s_Y^2/n$）。
- delta 方法也用于**相对提升**（lift）$\frac{\bar Y_B}{\bar Y_A}-1$ 的置信区间。替代方案：按用户 bootstrap。

Q20：***什么是辛普森悖论？在 A/B 测试中如何出现？***

- **辛普森悖论**：每个子群体中 B 都比 A 好，但合并后 A 比 B 好（或相反）。原因是存在**混杂变量**，且各组在子群体中的**构成比例不同**。
- 经典例子：肾结石治疗——A 疗法在小结石和大结石患者中治愈率都更高，但 A 疗法更多被用于难治的大结石，合并后 A 的治愈率反而更低。
- A/B 测试中的场景：
    - 实验中途**改变流量比例**（例如第一天 1% 第二天 50%），而各天的基线转化率不同；
    - 按触发条件或后处理变量分群（分群依据受处理影响）；
    - 不同平台/国家的流量分配不均衡。
- 对策：保持流量比例不变，或按天/层**分层分析**后加权；只按**实验前**属性做分群分析。

## 因果推断与贝叶斯方法

Q21：***什么是混杂？倾向得分方法如何工作？***

- **混杂变量（Confounder）**：同时影响处理 $T$ 和结果 $Y$ 的变量，使"相关"不等于"因果"。随机化实验通过随机分配切断混杂；观测数据中需要做调整。
- 关键假设：**可忽略性**（给定 $X$ 后 $T$ 与潜在结果独立，即无未观测混杂）、**重叠性**（$0<e(x)<1$）、SUTVA。
- **倾向得分** $e(x)=P(T=1\mid X=x)$（通常用逻辑回归/GBDT 估计）。Rosenbaum & Rubin 证明：给定 $e(x)$ 就足以平衡 $X$。
- 使用方式：
    - **匹配（PSM）**：为每个处理样本匹配倾向得分相近的对照样本；
    - **逆概率加权（IPW）**：处理组权重 $1/e(x)$，对照组 $1/(1-e(x))$，$\widehat{ATE}=\frac1n\sum\left[\frac{T_iY_i}{e(x_i)}-\frac{(1-T_i)Y_i}{1-e(x_i)}\right]$；
    - 分层、或作为回归协变量；**双重稳健（AIPW）**结合结果模型和倾向模型，任一正确即一致。
- 局限：**无法处理未观测混杂**；倾向得分接近 0/1 时权重爆炸，需截断；需检查匹配后的协变量平衡（标准化均值差）。

Q22：***解释双重差分（DiD）***

- 场景：无法随机化，但有处理组和对照组在处理**前后**的数据（如某城市上线新政策）。
- 估计量：
  $$\hat\tau_{DiD}=(\bar Y_{T,post}-\bar Y_{T,pre})-(\bar Y_{C,post}-\bar Y_{C,pre})$$
  第一项差分消除处理组固定差异，第二项消除共同的时间趋势。
- 回归形式：$Y_{it}=\beta_0+\beta_1\text{Treat}_i+\beta_2\text{Post}_t+\tau(\text{Treat}_i\times\text{Post}_t)+\epsilon_{it}$。
- 核心假设：**平行趋势**——没有处理时，两组的趋势相同。可用处理前多期数据做事件研究（event study）检验前趋势。
- 扩展/注意：处理时点交错（staggered adoption）时传统双向固定效应可能有偏，需要用新的估计量（如 Callaway–Sant'Anna）；不满足平行趋势时可考虑**合成控制法**。

Q23：***什么是 Uplift 建模？和普通响应模型有什么区别？***

- **普通响应模型**预测 $P(Y=1\mid X)$——谁会购买；**Uplift 模型**预测**个体处理效应（CATE）**：$\tau(x)=E[Y\mid T=1,X=x]-E[Y\mid T=0,X=x]$——谁会**因为干预而**购买。
- 用户四象限：说服型（干预才买，目标人群）、确定型（总会买，干预浪费）、无望型（总不买）、勿扰型（干预反而流失，要避免）。
- 方法（Meta-learners）：
    - **S-learner**：一个模型，把 $T$ 当作特征，预测 $f(x,1)-f(x,0)$；
    - **T-learner**：处理组、对照组各训练一个模型，作差；
    - **X-learner**：适合处理组/对照组样本不均衡；
    - 以及因果森林、直接优化 uplift 的树（分裂准则基于处理效应差异）、DR-learner。
- 训练数据最好来自**随机实验**；评估不能用普通 AUC（个体真实 uplift 不可观测），用 **Qini 曲线 / uplift 曲线**。

Q24：***贝叶斯 A/B 测试和频率学派 A/B 测试有什么区别？***

| | 频率学派 | 贝叶斯 |
|---|---|---|
| 参数 | 固定未知 | 随机变量，有先验 |
| 输出 | p 值、置信区间 | 后验分布、$P(B>A\mid\text{数据})$、期望损失 |
| 解释 | 间接（关于数据在 $H_0$ 下的罕见程度） | 直观（"B 比 A 好的概率是 95%"） |
| 先验 | 不需要 | 需要，影响结果（小样本时尤甚） |

- 转化率的经典做法：**Beta-Binomial 共轭**，先验 $\text{Beta}(\alpha,\beta)$，观测 $s$ 次成功 $n$ 次试验后，后验为 $\text{Beta}(\alpha+s,\beta+n-s)$；通过蒙特卡罗采样估计 $P(p_B>p_A)$ 和**期望损失** $E[\max(p_A-p_B,0)]$。
- 误区："贝叶斯方法可以随意偷看"——后验本身在 optional stopping 下仍是有效的贝叶斯更新，但其**频率学意义上的错误率**并不受控；若以"$P(B>A)>95\%$ 就停"作为规则，假阳性率同样会膨胀。
- 实践：大流量平台多采用频率学派 + 序贯检验 + 方差缩减；贝叶斯方法在小流量、需要直观决策（期望损失）以及融合历史实验先验时更有优势。

```python
import numpy as np
rng = np.random.default_rng(0)
a = rng.beta(1 + conv_a, 1 + n_a - conv_a, 100_000)
b = rng.beta(1 + conv_b, 1 + n_b - conv_b, 100_000)
prob_b_better = (b > a).mean()
expected_loss_b = np.maximum(a - b, 0).mean()
```
