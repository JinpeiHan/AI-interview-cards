# 机器学习基础

## 学习范式与理论

Q1：***监督学习、无监督学习、自监督学习有什么区别？***

- **区别在于监督信号从哪来：监督学习用人工标签学习 $x\to y$；无监督学习没有标签，只找数据本身的结构；自监督学习从数据自身构造"伪标签"来做监督训练，不需要人工标注。**
- 监督：分类、回归，代价是标注成本高。
- 无监督：聚类（K-means）、降维（PCA）、密度估计、异常检测。
- 自监督：掩码预测（BERT、MAE）、下一个 token 预测（GPT）、对比学习（SimCLR、CLIP）。
- 现代大模型的范式通常是"自监督预训练 + 监督微调 + 偏好对齐（RLHF/DPO）"；此外还有半监督和强化学习。

Q2：***推导偏差-方差分解***

- **模型的期望平方误差可以拆成三部分：偏差的平方（模型平均预测离真实函数多远）、方差（换一份训练集预测会抖动多少）和不可约的噪声。推导思路是在误差里插入"模型的平均预测"再展开平方，由于噪声均值为 0 且与训练集独立，交叉项都为 0。**
- 偏差大：模型太简单，系统性偏离 → 欠拟合。
- 方差大：模型对训练数据的随机性太敏感 → 过拟合。
- 模型越复杂，偏差通常越小、方差越大，需要折中。
- 深度学习中的双下降现象说明经典 U 形曲线不总成立：过参数化模型越过插值点后测试误差会再次下降，隐式正则起了作用。
- 核心公式：$E[(y-\hat f)^2]=\text{Bias}^2+\text{Variance}+\sigma^2$

Q3：***如何用学习曲线诊断欠拟合和过拟合？***

- **把训练误差和验证误差画成随样本量（或训练轮数）变化的曲线：两者都高且很接近是欠拟合（高偏差）；训练误差低、验证误差高、中间有大间隙是过拟合（高方差）。**
- 欠拟合时加数据没用，应加大模型、加特征、减弱正则、训练更久。
- 过拟合时加数据有用，也可加强正则、简化模型、数据增强、早停。
- 和基准误差（人类水平）比较：训练误差与基准的差约等于可避免偏差，验证与训练误差之差约等于方差。
- 验证曲线（横轴是超参数）用来找验证误差最低的超参数。

Q4：***参数模型与非参数模型有什么区别？***

- **参数模型的参数个数固定、与样本量无关，对函数形式有较强假设；非参数模型的复杂度随数据量增长，假设更少。"非参数"不是没有参数，而是参数数量不固定。**
- 参数模型：线性/逻辑回归、朴素贝叶斯、固定结构的神经网络；快、省数据、可解释，但假设错了偏差大。
- 非参数模型：KNN、决策树、核 SVM、高斯过程；灵活，但需要更多数据、预测可能慢、易过拟合、受维度灾难影响大。

Q5：***生成模型和判别模型有什么区别？***

- **判别模型直接学 $P(y\mid x)$ 或决策边界；生成模型学数据是怎么产生的，即联合分布 $P(x,y)$，再用贝叶斯公式得到 $P(y\mid x)$。**
- 判别：逻辑回归、SVM、CRF、大多数神经网络分类器。生成：朴素贝叶斯、高斯混合、HMM，以及 VAE、GAN、扩散模型、语言模型。
- 数据充足时判别模型分类通常更准；数据少时生成模型可能收敛更快（Ng & Jordan 2001）。
- 生成模型能生成样本、处理缺失特征、做异常检测，但需要更强的分布假设。
- 经典配对：朴素贝叶斯 ↔ 逻辑回归，HMM ↔ CRF。

Q6：***什么是"没有免费的午餐"定理？***

- **NFL 定理说：在所有可能的问题上平均，任何学习算法的表现都一样，没有一个算法在所有问题上都最好。算法好不好，取决于它的归纳偏置是否符合具体问题的结构。**
- 所以选模型要靠领域知识和数据特性，并用验证集实验比较。
- 现实问题并不是在"所有可能函数"上均匀分布，而是有平滑性、层级结构等规律，所以 GBDT 在表格数据、Transformer 在序列数据上普遍好用，这和 NFL 不矛盾。

Q7：***MLE 和 MAP 有什么区别？它们与正则化有什么关系？***

- **MLE 只找让数据出现概率最大的参数；MAP 在此基础上乘上参数的先验，相当于在对数似然上加一个正则项。高斯先验对应 L2 正则，拉普拉斯先验对应 L1 正则。**
- 先验越"窄"，对应的正则越强。
- 数据量趋于无穷时似然主导，MAP 趋于 MLE；均匀先验时两者相等。
- MAP 仍是点估计，完整的贝叶斯推断保留整个后验分布。
- 核心公式：$\hat\theta_{MAP}=\arg\max_\theta\left[\sum_i\log p(x_i\mid\theta)+\log p(\theta)\right]$

## 正则化

Q8：***L1 和 L2 正则化有什么区别？为什么 L1 会产生稀疏解？***

- **L1 惩罚权重的绝对值，会把很多权重压到正好为 0，得到稀疏解，可做特征选择；L2 惩罚权重的平方，只把权重整体缩小、几乎不会到 0。**
- 几何解释：L1 的约束区域是菱形，尖角在坐标轴上，损失等高线最容易在尖角处碰到它，于是某些权重为 0；L2 的约束区域是圆，切点一般不在轴上。
- 梯度解释：L2 的梯度随权重变小而变小，推不到 0；L1 在 0 附近仍有恒定大小的"推力"，能把小权重直接推到 0（软阈值）。
- 贝叶斯解释：L1 对应在 0 处有尖峰的拉普拉斯先验，L2 对应平滑的高斯先验。

| | L1 | L2 |
|---|---|---|
| 解 | 稀疏 | 稠密、整体变小 |
| 相关特征 | 随机选一个 | 权重平均分配 |
| 优化 | 0 处不可导，用坐标下降/近端梯度 | 光滑，有闭式解 |

Q9：***什么是弹性网络（Elastic Net）？***

- **Elastic Net 同时加 L1 和 L2 正则，既保留 L1 的稀疏性，又用 L2 弥补 Lasso 的两个缺点。**
- 相关特征：Lasso 只会随机选其中一个，Elastic Net 有"分组效应"，会一起选入或一起剔除。
- 特征数大于样本数时，Lasso 最多选出 $n$ 个特征，Elastic Net 没有这个限制。
- 需要调两个超参数（总强度 $\lambda$ 和 L1 比例 $\alpha$），通常用交叉验证。

## 模型评估与数据

Q10：***交叉验证有哪些变体？各适用于什么场景？***

- **最常用的是 k 折交叉验证（轮流用一份做验证、其余训练，取平均）；再根据数据特点选变体：类别不平衡用分层 k 折，同一实体有多条样本用分组 k 折，时间序列用按时间顺序的切分，调参加评估用嵌套交叉验证。**
- k 折常用 5 或 10；$k=n$ 即留一法，偏差小但方差和计算量大。
- 分组 k 折保证同一用户/患者只出现在训练或验证一侧，防止泄漏。
- 时间序列绝不能打乱，训练集只能用验证集之前的数据，必要时中间留间隔。
- 嵌套交叉验证内层调参、外层评估，避免在同一份数据上既选超参又报性能的乐观偏差。

Q11：***什么是数据泄漏？有哪些常见形式？***

- **数据泄漏是训练时用到了预测时拿不到的信息，导致离线指标虚高、上线后效果差。**
- 目标泄漏：特征由标签派生或在标签之后才产生（如预测流失时用"注销日期"）。
- 预处理泄漏：在划分之前对全量数据做标准化、填充、特征选择、过采样；目标编码没用 out-of-fold。
- 时间泄漏和实体重复：随机划分时间序列；同一用户或近重复样本同时出现在训练集和测试集；大模型里测试集混进预训练语料。
- 防范：先划分再预处理，用 Pipeline 把预处理放进交叉验证内部；按时间/分组划分；对"好得可疑"的特征保持警惕。

Q12：***如何处理类别不平衡问题？***

- **首先换评估指标（不用准确率，用 PR-AUC、F1、各类召回率），然后从数据、算法、决策三个层面处理；其中最简单有效的往往是调整分类阈值。**
- 数据层面：欠采样多数类、过采样少数类、SMOTE 插值合成；只能在训练折内做，否则泄漏。
- 算法层面：类别加权/代价敏感学习、Focal Loss（降低易分样本的权重）、平衡集成方法。
- 决策层面：根据业务代价在 PR 曲线上选阈值。
- 重采样或加权会扭曲预测概率，需要概率时要事后校准；极度不平衡时可当作异常检测处理。

Q13：***哪些模型需要特征缩放？为什么？***

- **依赖距离、梯度下降、正则惩罚或方差的模型需要缩放，因为尺度大的特征会主导结果或让优化变慢；树模型不需要，因为分裂只看特征值的排序。**
- 距离类：KNN、K-means、RBF 核 SVM。
- 梯度下降类：线性/逻辑回归、神经网络（尺度不一使损失面狭长，收敛慢）。
- 正则化：Ridge/Lasso 对所有系数一视同仁，尺度不同惩罚就不公平；PCA 中大方差特征会主导主成分。
- 方法：标准化（最常用）、Min-Max（对离群点敏感）、鲁棒缩放（中位数和 IQR）、对数变换；缩放参数只在训练集上拟合。

Q14：***如何处理缺失值？***

- **先判断缺失机制，再选方法：完全随机缺失可以直接删除或简单填充；依赖其他变量的缺失可以用其他特征建模填充；依赖缺失值本身的缺失（如高收入者不填收入）最难，"是否缺失"本身就是信息，要加缺失指示变量。**
- 删除：缺失很少时删行，缺失比例极高时删列。
- 简单填充：均值/中位数、众数或"Unknown"类别，会低估方差。
- 模型填充：KNN 填充、迭代回归填充（MICE）；时间序列用前向填充或插值。
- XGBoost/LightGBM 能在分裂时自动学习缺失值的走向；填充统计量只能在训练集上算。

Q15：***什么是模型校准？如何校准？***

- **校准是让预测概率和真实频率一致，比如预测 0.8 的样本里约 80% 真是正例。风控、广告出价、模型融合等需要用概率做决策的场景必须校准。做法是在独立的校准集上学一个把分数映射为概率的单调函数。**
- 评估：可靠性图、ECE（期望校准误差）、Brier 分数、对数损失。
- 逻辑回归通常校准较好；朴素贝叶斯偏向 0/1；随机森林远离 0/1；深度网络往往过度自信。
- 方法：Platt Scaling（拟合一个逻辑回归，适合数据少）、Isotonic 回归（更灵活但需更多数据）、Temperature Scaling（神经网络里只学一个温度参数，不改变预测类别）。
- 校准是单调变换，不改变 AUC。

## KNN

Q16：***KNN 的原理是什么？常用的距离度量有哪些？***

- **KNN 对新样本找训练集中最近的 K 个邻居，分类时多数投票、回归时取平均（可按距离加权）。它没有训练过程，预测时才计算，属于惰性学习。**
- 欧氏距离最常用；曼哈顿距离对离群点更鲁棒，高维时区分度更好；二者都是闵可夫斯基距离的特例。
- 余弦距离：文本、嵌入向量，只看方向不看大小。
- 马氏距离考虑特征相关性和尺度；汉明距离用于二值/类别特征，Jaccard 用于集合。
- 必须先做特征缩放，否则大尺度特征主导距离。

Q17：***如何选择 KNN 中的 K？***

- **K 太小模型对噪声敏感、过拟合（低偏差高方差），K 太大边界过于平滑、欠拟合（高偏差低方差）；实际用交叉验证在一组 K 中选验证误差最低的。**
- 经验起点 $K\approx\sqrt n$。
- 二分类取奇数避免平票；类别不平衡时可用距离加权投票。
- 1-NN 的渐近错误率不超过贝叶斯错误率的 2 倍（Cover & Hart）。

Q18：***什么是维度灾难？它为什么影响 KNN？***

- **维度灾难是指维度升高后数据变得极其稀疏，所有点之间的距离趋于相近，"最近邻"就失去了意义，所以 KNN 的预测质量会明显下降。**
- 保持同样采样密度所需的样本量随维度指数增长。
- 邻域不再局部：10 维时要覆盖 10% 的数据，每个维度要取约 80% 的范围。
- 无关特征会严重干扰距离。
- 缓解：降维、特征选择、度量学习、在学到的嵌入空间里做 KNN；真实数据通常位于低维流形上，所以在嵌入空间里 KNN 仍然有效。

Q19：***什么是 KD 树？如何加速 KNN 搜索？***

- **KD 树是一种二叉空间划分树：每层选一个维度、在中位数处把数据一分为二。搜索时先下到查询点所在的叶子得到候选，再回溯，只有当"以当前最近距离为半径的球"与另一侧区域相交时才去搜索，否则剪枝。低维时平均接近 $O(\log n)$。**
- 维度较高（约 20 维以上）时剪枝失效，退化成接近暴力搜索。
- Ball Tree 用超球划分，在较高维和非欧距离下更好。
- 大规模高维向量用近似最近邻（ANN）：LSH、HNSW、IVF + 乘积量化（如 FAISS），这也是向量数据库和 RAG 检索的基础。

## 集成学习

Q20：***Bagging、Boosting 和 Stacking 有什么区别？***

- **Bagging 并行训练多个独立的强模型再平均，主要降方差（如随机森林）；Boosting 串行训练弱模型，每个修正前一个的错误，主要降偏差（如 GBDT、XGBoost）；Stacking 用一个元模型去组合多个异质模型的预测。**

| | Bagging | Boosting | Stacking |
|---|---|---|---|
| 训练 | 并行、独立 | 串行、纠错 | 基模型 + 元模型 |
| 主要降低 | 方差 | 偏差 | 两者 |
| 基模型 | 强（深树） | 弱（浅树） | 异质模型 |
| 代表 | 随机森林 | AdaBoost、GBDT、XGBoost | Kaggle 融合 |

- Bagging 的平均效果受模型间相关性限制，随机森林用特征随机采样降低相关性。
- AdaBoost 提高错分样本权重；GBDT 每轮拟合损失的负梯度；Boosting 对噪声敏感，需要学习率和早停。
- Stacking 必须用 out-of-fold 预测训练元模型，否则泄漏；元模型通常用简单的逻辑回归。Blending 是用留出集代替 K 折的简化版。
