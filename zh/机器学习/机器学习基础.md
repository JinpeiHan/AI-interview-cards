# 机器学习基础

## 学习范式与理论

Q1：***监督学习、无监督学习、自监督学习有什么区别？***

- **监督学习**：训练数据有标签 $(x,y)$，学习映射 $f:x\to y$；分类、回归。代价是标注成本高。
- **无监督学习**：只有 $x$，发现数据结构；聚类（K-means）、降维（PCA）、密度估计、异常检测。
- **自监督学习**：从数据本身构造"伪标签"做监督训练，本质上不需要人工标注：
    - 掩码预测：BERT 的 MLM、MAE 的掩码图像重建；
    - 下一个 token 预测：GPT 类语言模型的预训练；
    - 对比学习：SimCLR、MoCo、CLIP（同一样本的不同视图/图文配对拉近，不同样本推远）。
- 其他：**半监督**（少量标签 + 大量无标签，如伪标签、一致性正则）、**强化学习**（通过与环境交互获得奖励信号）。
- 追问：现代大模型的范式通常是"自监督预训练 + 监督微调 + 偏好对齐（RLHF/DPO）"。

Q2：***推导偏差-方差分解***

- 设 $y=f(x)+\epsilon$，$E[\epsilon]=0$，$\mathrm{Var}(\epsilon)=\sigma^2$；$\hat f$ 是在随机训练集 $D$ 上学到的模型。在某点 $x$ 的期望平方误差：
  $$E_{D,\epsilon}\left[(y-\hat f(x))^2\right]=\underbrace{\left(E_D[\hat f(x)]-f(x)\right)^2}_{\text{Bias}^2}+\underbrace{E_D\left[(\hat f(x)-E_D[\hat f(x)])^2\right]}_{\text{Variance}}+\underbrace{\sigma^2}_{\text{不可约误差}}$$
- 推导要点：令 $\bar f=E_D[\hat f(x)]$，展开 $(f+\epsilon-\hat f)^2=((f-\bar f)+(\bar f-\hat f)+\epsilon)^2$，由于 $\epsilon$ 与 $D$ 独立且均值为 0、$E_D[\bar f-\hat f]=0$，交叉项全部为 0。
- 含义：
    - **偏差**：模型假设过于简单，系统性偏离真实函数 → 欠拟合；
    - **方差**：模型对训练集的随机性过于敏感 → 过拟合；
    - 模型复杂度 ↑ 通常偏差 ↓、方差 ↑，存在折中。
- 追问：深度学习中的**双下降（double descent）**现象——过参数化模型在插值阈值之后测试误差再次下降，说明经典 U 形曲线并不总是成立，隐式正则（SGD、架构）起了作用。

Q3：***如何用学习曲线诊断欠拟合和过拟合？***

- **学习曲线**：横轴为训练样本量（或训练轮数），纵轴为训练误差和验证误差。
- **高偏差（欠拟合）**：训练误差和验证误差都高，且两者很快收敛到接近的水平 → 增加数据**无用**；应增加模型复杂度、添加特征、减少正则化、训练更久。
- **高方差（过拟合）**：训练误差很低，验证误差明显更高，两者之间存在大的**间隙**，随样本量增加间隙缩小 → 增加数据**有用**；也可加强正则化、减少特征、简化模型、数据增强、早停。
- **验证曲线**：横轴为超参数（如树深度、$\lambda$），找到验证误差最低点。
- 还应与**基准误差**（人类水平/贝叶斯误差）比较：训练误差与基准的差距 ≈ 可避免偏差，验证与训练误差之差 ≈ 方差。

Q4：***参数模型与非参数模型有什么区别？***

- **参数模型**：参数个数固定、与样本量无关，对函数形式有较强假设；例如线性回归、逻辑回归、朴素贝叶斯、固定结构的神经网络。
    - 优点：训练/预测快，所需数据少，可解释；缺点：假设错误时偏差大。
- **非参数模型**：模型复杂度随数据量增长，对函数形式假设少；例如 KNN、决策树、核 SVM（支持向量数随数据增长）、高斯过程、核密度估计。
    - 优点：灵活、可拟合复杂函数；缺点：需要更多数据，预测可能慢（KNN 要存储全部数据），易过拟合，受维度灾难影响大。
- 注意："非参数"不是"没有参数"，而是参数数量不固定。

Q5：***生成模型和判别模型有什么区别？***

- **判别模型**：直接建模 $P(y\mid x)$ 或决策边界；逻辑回归、SVM、CRF、大多数神经网络分类器。
- **生成模型**：建模联合分布 $P(x,y)=P(x\mid y)P(y)$，再用贝叶斯公式得 $P(y\mid x)$；朴素贝叶斯、LDA（线性判别分析）、高斯混合模型、HMM；更广义的还有 VAE、GAN、扩散模型、自回归语言模型（建模 $P(x)$）。
- 对比：
    - 分类准确率：数据充足时判别模型通常更好（只解决需要的问题）；
    - 数据量少时生成模型可能收敛更快（Ng & Jordan 2001 对朴素贝叶斯与逻辑回归的比较）；
    - 生成模型能处理缺失特征、能生成样本、可做异常检测，但需要更强的分布假设。
- 经典配对：朴素贝叶斯 ↔ 逻辑回归；HMM ↔ CRF。

Q6：***什么是"没有免费的午餐"定理？***

- **NFL 定理**（Wolpert 1996）：在所有可能的问题（目标函数均匀分布）上取平均，任何学习算法的期望泛化性能都相同——没有一个算法在所有问题上都优于其他算法。
- 含义：
    - 算法的好坏取决于其**归纳偏置**是否与问题的真实结构匹配（如 CNN 的平移等变、线性模型的线性假设）；
    - 必须基于领域知识和数据特性选择模型，并通过验证集实验比较；
- 追问：现实问题并非均匀分布在"所有可能函数"上，而是具有平滑性、层级结构等规律，因此一些方法（GBDT 对表格数据、Transformer 对序列数据）在实践中普遍表现良好，这与 NFL 并不矛盾。

Q7：***MLE 和 MAP 有什么区别？它们与正则化有什么关系？***

- **MLE**：$\hat\theta_{MLE}=\arg\max_\theta \sum_i\log p(x_i\mid\theta)$，只依赖数据。
- **MAP**：$\hat\theta_{MAP}=\arg\max_\theta\left[\sum_i\log p(x_i\mid\theta)+\log p(\theta)\right]$，加入了先验，相当于在对数似然上加一个**正则项**。
- 与正则化的对应（以线性回归为例，高斯噪声下 MLE ⇔ 最小二乘）：
    - 高斯先验 $\theta\sim\mathcal N(0,\tau^2)$ ⇒ $-\log p(\theta)\propto\frac{1}{2\tau^2}\|\theta\|_2^2$ ⇒ **L2 / 岭回归**；
    - 拉普拉斯先验 $p(\theta)\propto e^{-|\theta|/b}$ ⇒ $-\log p(\theta)\propto\frac1b\|\theta\|_1$ ⇒ **L1 / Lasso**；
    - 正则强度 $\lambda$ 与先验方差成反比：先验越"窄"，正则越强。
- 数据量 → ∞ 时似然主导，MAP → MLE；均匀先验时 MAP = MLE。
- MAP 仍是**点估计**；完整的贝叶斯推断保留整个后验分布。

## 正则化

Q8：***L1 和 L2 正则化有什么区别？为什么 L1 会产生稀疏解？***

- 目标：$\min_w L(w)+\lambda\|w\|_1$（L1/Lasso）或 $\min_w L(w)+\lambda\|w\|_2^2$（L2/Ridge）。
- **几何视角**：等价于约束优化 $\min L(w)$ s.t. $\|w\|_1\le t$ 或 $\|w\|_2\le t$。L1 约束区域是菱形（高维中的"多面体"），有尖角位于坐标轴上，损失函数的等高线更容易首先在**尖角**处与之相切，使部分 $w_j=0$；L2 约束区域是圆，切点一般不在坐标轴上。
- **梯度/次梯度视角**：L2 的梯度 $2\lambda w$ 随 $w\to0$ 而趋于 0，只把权重缩小但不到 0；L1 的次梯度是常数 $\lambda\,\mathrm{sign}(w)$，在 0 附近仍有恒定的"推力"。在正交设计下解为**软阈值**：$w_j=\mathrm{sign}(z_j)\max(|z_j|-\lambda,0)$，而 L2 为按比例缩放 $w_j=z_j/(1+\lambda)$。
- **贝叶斯视角**：L1 ↔ 拉普拉斯先验（在 0 处有尖峰），L2 ↔ 高斯先验（在 0 附近平坦）。
- 其他对比：

| | L1 | L2 |
|---|---|---|
| 解 | 稀疏，可做特征选择 | 稠密，权重整体变小 |
| 相关特征 | 随机选一个 | 权重平均分配 |
| 优化 | 0 处不可导，需坐标下降/近端梯度 | 光滑，有闭式解 $(X^TX+\lambda I)^{-1}X^Ty$ |
| 鲁棒性 | 对特征选择不稳定 | 更稳定，缓解共线性 |

Q9：***什么是弹性网络（Elastic Net）？***

- 结合 L1 和 L2：$\min_w L(w)+\lambda\left[\alpha\|w\|_1+\frac{1-\alpha}{2}\|w\|_2^2\right]$（sklearn 中的 `l1_ratio` 即 $\alpha$）。
- 解决 Lasso 的两个问题：
    - **相关特征组**：Lasso 只会随机选一个，Elastic Net 由于 L2 部分具有"分组效应"，会同时选入或剔除相关特征；
    - **$p>n$**：Lasso 最多选出 $n$ 个特征，Elastic Net 没有这个限制。
- 同时保留稀疏性。需要调两个超参数（$\lambda$, $\alpha$），通常用交叉验证网格搜索。

## 模型评估与数据

Q10：***交叉验证有哪些变体？各适用于什么场景？***

- **k 折交叉验证**：数据分成 $k$ 份，轮流用 1 份做验证、$k-1$ 份训练，平均 $k$ 次结果；常用 $k=5$ 或 10。$k$ 越大偏差越小但方差和计算量越大；$k=n$ 为**留一法（LOOCV）**。
- **分层 k 折（Stratified）**：每折保持类别比例与整体一致；用于分类，尤其**类别不平衡**时。
- **分组 k 折（Group）**：同一组（同一用户、患者、会话）的样本只出现在训练或验证中的一个，防止"同一实体"泄漏导致高估。
- **时间序列交叉验证**：严格按时间顺序，训练集只包含验证集之前的数据（扩展窗口或滑动窗口，`TimeSeriesSplit`）；必要时在训练和验证之间留**间隔（gap/embargo）**避免标签重叠泄漏。绝不能随机打乱。
- **嵌套交叉验证**：内层调参、外层评估，避免在同一份验证数据上既选超参数又报告性能而导致的乐观偏差。
- 重复 k 折：多次随机划分取平均，降低划分带来的方差。

Q11：***什么是数据泄漏？有哪些常见形式？***

- **数据泄漏**：训练时用到了预测时无法获得的信息，导致离线指标虚高、线上表现差。
- 常见形式：
    - **目标泄漏**：特征中包含由标签派生或在标签之后才产生的信息（如预测是否流失时用"注销日期"，预测疾病时用"服药记录"）；
    - **训练/测试污染**：在划分**之前**对全量数据做标准化、填充缺失值、特征选择、PCA、过采样（SMOTE）；
    - **时间泄漏**：随机划分时间序列数据，用未来预测过去；
    - **实体重复**：同一用户/患者/近重复样本同时出现在训练集和测试集；
    - 目标编码（target encoding）未使用 out-of-fold 方式；
    - 大模型时代：测试集被包含在预训练语料中（**基准污染**）。
- 防范：先划分再预处理，用 `Pipeline` 把预处理放进交叉验证内部；按时间/分组划分；检查特征的产生时间；对"好得令人怀疑"的特征保持警惕。

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
pipe = make_pipeline(StandardScaler(), LogisticRegression())
scores = cross_val_score(pipe, X, y, cv=5)  # scaler is fit inside each training fold
```

Q12：***如何处理类别不平衡问题？***

- **评估指标**：不要用准确率；使用 Precision/Recall/F1、PR-AUC（正例稀少时比 ROC-AUC 更有信息量）、按类别的召回率。
- **数据层面**：
    - 随机欠采样多数类（丢失信息）、随机过采样少数类（易过拟合）；
    - **SMOTE**：在少数类样本与其近邻之间插值合成新样本；变体 Borderline-SMOTE、ADASYN；
    - 采样只能在**训练集**上做（在交叉验证折内部），否则泄漏。
- **算法层面**：
    - **类别权重/代价敏感学习**：损失中给少数类更大权重（`class_weight='balanced'`）；
    - **Focal Loss**：$-(1-p_t)^\gamma\log p_t$，降低易分类样本的权重；
    - 集成方法：EasyEnsemble、BalancedRandomForest。
- **决策层面**：**调整分类阈值**（往往最简单有效），根据业务代价在 PR 曲线上选择工作点。
- 注意：重采样或加权会改变预测概率的分布，若需要校准的概率，需要事后校准或修正先验。
- 极度不平衡时可以考虑转化为**异常检测**问题。

Q13：***哪些模型需要特征缩放？为什么？***

- **需要缩放**：
    - 基于**距离**的：KNN、K-means、SVM（RBF 核）——量纲大的特征会主导距离；
    - 基于**梯度下降**优化的：线性/逻辑回归、神经网络——特征尺度差异使损失曲面呈狭长椭圆，收敛慢；
    - **带正则化**的：Ridge/Lasso——惩罚对所有系数一视同仁，尺度不同会导致惩罚不公平；
    - 基于**方差**的：PCA——大方差特征会主导主成分。
- **不需要缩放**：**树模型**（决策树、随机森林、GBDT/XGBoost/LightGBM）——分裂只依赖特征值的排序，单调变换不改变结果；朴素贝叶斯通常也不需要。
- 方法：
    - **标准化**（Z-score）：$x'=\frac{x-\mu}{\sigma}$，最常用；
    - **归一化**（Min-Max）：$x'=\frac{x-x_{min}}{x_{max}-x_{min}}$，对离群点敏感；
    - **鲁棒缩放**：用中位数和 IQR，抗离群点；
    - 对数变换处理偏态分布。
- 缩放参数只能在训练集上拟合，再应用到验证/测试集。

Q14：***如何处理缺失值？***

- 先分析**缺失机制**：
    - **MCAR**（完全随机缺失）：缺失与任何变量无关，删除不会引入偏差；
    - **MAR**（随机缺失）：缺失依赖于其他观测到的变量，可用其他特征建模填充；
    - **MNAR**（非随机缺失）：缺失依赖于缺失值本身（如高收入者不填收入），最难处理，"是否缺失"本身就是信息。
- 方法：
    - **删除**：删除行（缺失少且 MCAR）或删除列（缺失比例极高）；
    - **简单填充**：均值/中位数（数值）、众数或"Unknown"类别（类别）；会低估方差；
    - **添加缺失指示变量**：配合填充使用，保留"缺失"这一信号，对 MNAR 尤其有用；
    - **模型填充**：KNN 填充、迭代回归填充（MICE / `IterativeImputer`）；
    - 时间序列：前向填充、插值；
    - **模型原生支持**：XGBoost/LightGBM 在分裂时学习缺失值的默认方向，无需填充。
- 填充统计量同样只能在训练集上计算。

Q15：***什么是模型校准？如何校准？***

- **校准**：预测概率与实际频率一致，即在预测为 0.8 的样本中约 80% 确实为正例。对需要概率的场景（风控决策、期望收益计算、广告出价、模型融合）至关重要。
- 评估：**可靠性图**（预测概率分桶 vs 实际正例比例）、**ECE**（期望校准误差）$=\sum_b\frac{|B_b|}{n}|\text{acc}(B_b)-\text{conf}(B_b)|$、Brier 分数、对数损失。
- 不同模型的校准特性：
    - 逻辑回归通常校准较好（直接优化对数损失）；
    - 朴素贝叶斯倾向于把概率推向 0/1（独立性假设）；
    - 随机森林倾向于远离 0/1；SVM 输出的是间隔而非概率；
    - 现代深度神经网络往往**过度自信**（Guo et al. 2017）。
- 校准方法（在独立的校准集上拟合）：
    - **Platt Scaling**：对模型分数拟合一个逻辑回归 $\sigma(As+B)$，适合数据少、S 形失真；
    - **Isotonic Regression**：非参数单调函数，更灵活但需要更多数据，易过拟合；
    - **Temperature Scaling**：神经网络中 $\text{softmax}(z/T)$，只学一个参数 $T$，不改变预测类别（准确率不变）。
- 注意：AUC 只衡量排序，校准不会改变 AUC（单调变换）。

## KNN

Q16：***KNN 的原理是什么？常用的距离度量有哪些？***

- **原理**：对于新样本，找到训练集中距离最近的 $K$ 个邻居，分类时**多数投票**、回归时取**平均**（可以按距离倒数加权）。属于**惰性学习**：没有训练过程，预测时才计算，预测复杂度 $O(nd)$。
- 距离度量：
    - **闵可夫斯基距离**：$d(x,y)=\left(\sum_i|x_i-y_i|^p\right)^{1/p}$；
    - $p=2$ **欧氏距离**（最常用）；$p=1$ **曼哈顿距离**（对离群更鲁棒，高维中比欧氏更有区分度）；$p\to\infty$ **切比雪夫距离** $\max_i|x_i-y_i|$；
    - **余弦距离** $1-\frac{x\cdot y}{\|x\|\|y\|}$：文本、嵌入向量，关注方向而非大小；
    - **马氏距离** $\sqrt{(x-y)^T\Sigma^{-1}(x-y)}$：考虑特征相关性和尺度；
    - **汉明距离**：类别/二值特征；**Jaccard 距离**：集合。
- 必须先做**特征缩放**，否则大尺度特征主导距离。

Q17：***如何选择 KNN 中的 K？***

- **K 太小**（如 $K=1$）：决策边界复杂，对噪声敏感，**低偏差高方差**，过拟合；
- **K 太大**：决策边界过于平滑，极端情况 $K=n$ 时总是预测多数类，**高偏差低方差**，欠拟合。
- 选择方法：**交叉验证**在一系列 K 值上选择验证误差最低的；经验起点 $K\approx\sqrt n$。
- 二分类时取**奇数** K 避免平票；类别不平衡时可用距离加权投票。
- 1-NN 的渐近错误率不超过贝叶斯错误率的 2 倍（Cover & Hart 1967）。

Q18：***什么是维度灾难？它为什么影响 KNN？***

- 在高维空间中：
    - **数据稀疏**：保持相同的采样密度所需样本量随维度指数增长；
    - **距离集中**：随机点之间最远和最近距离的比值趋于 1，$\frac{d_{max}-d_{min}}{d_{min}}\to0$，"最近邻"变得没有意义；
    - **"邻域"不再局部**：在单位超立方体中，要覆盖 10% 的数据，每个维度需要的边长为 $0.1^{1/d}$，$d=10$ 时约 0.8，几乎覆盖整个取值范围；
    - 超球体的体积集中在**表面附近**。
- 对 KNN 的影响：邻居不再"相近"，预测质量下降，并且无关特征会严重干扰距离。
- 缓解：**降维**（PCA、自编码器）、特征选择、度量学习、使用学习到的嵌入空间；真实数据通常位于低维**流形**上，这是 KNN 在嵌入空间中仍有效的原因。

Q19：***什么是 KD 树？如何加速 KNN 搜索？***

- **KD 树**：二叉空间划分树。每层选择一个维度（通常方差最大的维度或轮流），在**中位数**处将数据分成两半，递归构建；构建复杂度 $O(n\log n)$。
- **搜索**：
    1. 从根向下找到查询点所在的叶节点，作为当前最近邻候选；
    2. 回溯：若以查询点为球心、当前最近距离为半径的超球与另一个子节点的区域**相交**，则需要搜索该子树，否则**剪枝**；
    3. 低维时平均复杂度约 $O(\log n)$。
- 局限：维度较高（经验上 $d>20$ 左右）时剪枝失效，退化到接近暴力搜索。
- 其他方法：**Ball Tree**（用超球划分，高维与非欧距离下更好）；大规模/高维向量使用**近似最近邻（ANN）**：LSH（局部敏感哈希）、HNSW（分层可导航小世界图）、IVF + 乘积量化（PQ，如 FAISS）——这也是向量数据库和 RAG 检索的基础。

## 集成学习

Q20：***Bagging、Boosting 和 Stacking 有什么区别？***

| | Bagging | Boosting | Stacking |
|---|---|---|---|
| 训练方式 | **并行**，各基学习器独立 | **串行**，后一个修正前一个的错误 | 两层：基学习器 + 元学习器 |
| 样本 | Bootstrap 重采样 | 全量数据，调整样本权重或拟合残差/负梯度 | 基学习器的 out-of-fold 预测作为元特征 |
| 主要降低 | **方差** | **偏差**（也能降方差） | 两者，组合异质模型的优势 |
| 基学习器 | 强（低偏差高方差，如深树） | 弱（如浅树） | 通常异质（GBDT、NN、LR 等） |
| 代表 | 随机森林 | AdaBoost、GBDT、XGBoost、LightGBM、CatBoost | Kaggle 常用融合方案 |
| 过拟合 | 不易过拟合 | 对噪声敏感，需学习率/早停 | 元学习器需用 OOF 预测，否则泄漏 |

- Bagging 降低方差的原因：$B$ 个方差为 $\sigma^2$、两两相关系数为 $\rho$ 的模型取平均，方差为 $\rho\sigma^2+\frac{1-\rho}{B}\sigma^2$；随机森林通过**特征随机子采样**降低 $\rho$。
- Boosting：AdaBoost 提高错分样本的权重（等价于以指数损失做前向分步加法建模）；GBDT 每一轮拟合损失函数的**负梯度**。
- Stacking：必须用 K 折的 **out-of-fold** 预测训练元学习器；元学习器通常用简单模型（如逻辑回归）以免过拟合。**Blending** 是用一个留出集代替 K 折的简化版本。
