## 基础函数与损失

Q1：***手写数值稳定的 softmax 和 log-softmax***

- **先减去最大值再取指数：softmax 对平移不变，这样最大的指数是 1，不会上溢。log-softmax 用 log-sum-exp 直接算，不要对 softmax 结果取 log（下溢成 0 会得到 `-inf`）。**
- 坑：`keepdims=True` 才能正确广播；batch 输入要沿类别维取 max。

```python
def softmax(x, axis=-1):
    x = x - x.max(axis=axis, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def log_softmax(x, axis=-1):
    m = x.max(axis=axis, keepdims=True)
    return x - m - np.log(np.exp(x - m).sum(axis=axis, keepdims=True))
```

Q2：***手写基于 logits 的交叉熵损失及其梯度***

- **直接从 logits 算 log-softmax，取出正确类的值求负均值；梯度就是"softmax 概率减 one-hot"再除以 N。**
- 坑：用 `logp[np.arange(N), y]` 取正确类，写成 `logp[:, y]` 会得到 N×N 矩阵。
- 核心公式：$\frac{\partial L}{\partial z} = \frac{1}{N}(\mathrm{softmax}(z) - \mathrm{onehot}(y))$

```python
def cross_entropy(logits, y):
    """logits: (N, C)，y: (N,) 整数标签"""
    logp = log_softmax(logits, axis=1)
    return -logp[np.arange(len(y)), y].mean()

def cross_entropy_grad(logits, y):
    N = logits.shape[0]
    g = softmax(logits, axis=1)
    g[np.arange(N), y] -= 1
    return g / N
```

Q3：***手写数值稳定的 sigmoid 与 BCE（with logits）***

- **sigmoid 按符号分两支写，让指数的参数总是非正、不会上溢；BCE 化简成只含 $|z|$ 的形式，直接从 logits 计算。**
- 用 `np.log1p` 更精确。这就是 PyTorch 推荐 `BCEWithLogitsLoss` 而不是 `Sigmoid + BCELoss` 的原因。
- 核心公式：$\ell(z,y) = \max(z,0) - zy + \log(1+e^{-|z|})$

```python
def sigmoid(x):
    out = np.empty_like(x, dtype=float)
    pos = x >= 0
    out[pos] = 1 / (1 + np.exp(-x[pos]))
    ex = np.exp(x[~pos])
    out[~pos] = ex / (1 + ex)
    return out

def bce_with_logits(z, y):
    # max(z,0) - z*y + log(1+e^{-|z|})
    return np.mean(np.maximum(z, 0) - z * y + np.log1p(np.exp(-np.abs(z))))
```

## 经典机器学习

Q4：***手写线性回归（闭式解 + 梯度下降）***

- **闭式解直接解正规方程（加 λ 就是岭回归），适合维度小；梯度下降沿 MSE 梯度迭代，适合大规模。**
- 用 `np.linalg.solve`，不要显式求逆；偏置不加正则；梯度下降前要标准化特征。
- 核心公式：$w^*=(X^\top X+\lambda I)^{-1}X^\top y$

```python
def linreg_closed_form(X, y, lam=0.0):
    Xb = np.hstack([X, np.ones((X.shape[0], 1))])   # 追加偏置列
    d = Xb.shape[1]
    reg = lam * np.eye(d); reg[-1, -1] = 0           # 偏置不正则
    return np.linalg.solve(Xb.T @ Xb + reg, Xb.T @ y)

def linreg_gd(X, y, lr=0.1, epochs=1000):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        err = X @ w + b - y
        w -= lr * (X.T @ err) / n
        b -= lr * err.mean()
    return w, b
```

Q5：***手写逻辑回归（梯度下降）***

- **线性模型套 sigmoid 输出概率，对 BCE 做梯度下降；梯度和线性回归同形："预测减标签"乘特征。**
- 坑：线性可分数据不加正则时权重会无限增大，要加 L2 或早停。
- 追问：不用 MSE 是因为它和 sigmoid 组合后非凸、饱和区梯度消失。

```python
def logreg_fit(X, y, lr=0.1, epochs=1000, lam=0.0):
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        p = sigmoid(X @ w + b)
        g = p - y
        w -= lr * (X.T @ g / n + lam * w)   # L2 正则
        b -= lr * g.mean()
    return w, b

def logreg_predict(X, w, b, thr=0.5):
    return (sigmoid(X @ w + b) >= thr).astype(int)
```

Q6：***手写 K-means***

- **交替两步：每个点分给最近的中心，再把中心更新为簇内均值；目标单调不增，一定收敛到局部最优。**
- 距离用平方展开式向量化；要处理空簇；对初始化敏感，工程上用 k-means++ 加多次重启。

```python
def kmeans(X, k, n_iter=100, tol=1e-6, seed=0):
    rng = np.random.default_rng(seed)
    C = X[rng.choice(len(X), k, replace=False)].copy()
    for _ in range(n_iter):
        d2 = (X**2).sum(1, keepdims=True) - 2 * X @ C.T + (C**2).sum(1)   # (n, k)
        labels = d2.argmin(1)
        C_new = C.copy()
        for j in range(k):
            mask = labels == j
            if mask.any():                  # 空簇保持原中心
                C_new[j] = X[mask].mean(0)
        shift = np.linalg.norm(C_new - C)
        C = C_new
        if shift < tol:
            break
    labels = ((X**2).sum(1, keepdims=True) - 2 * X @ C.T + (C**2).sum(1)).argmin(1)
    return C, labels
```

Q7：***手写 KNN 分类***

- **没有训练过程；预测时算到所有训练点的距离，取最近 k 个做多数投票。**
- 用 `np.argpartition` 取前 k 小，比全排序快；数据大时分块或用近似最近邻（FAISS、HNSW）。
- 坑：展开式可能出现微小负距离，开根前截到 0；二分类 k 取奇数避免平票。

```python
def knn_predict(X_train, y_train, X_test, k=5):
    d2 = ((X_test**2).sum(1, keepdims=True) - 2 * X_test @ X_train.T
          + (X_train**2).sum(1))                                  # (m, n)
    idx = np.argpartition(d2, k - 1, axis=1)[:, :k]
    neigh = y_train[idx]                                          # (m, k)
    return np.array([np.bincount(row).argmax() for row in neigh])
```

Q8：***用 SVD 手写 PCA***

- **先中心化，再对数据矩阵做 SVD：右奇异向量是主成分方向，奇异值平方除以 n−1 是解释方差。**
- 不先算协方差，是因为那会把条件数平方、损失精度。
- 坑：忘记中心化；新数据要减训练集均值；SVD 符号不唯一。

```python
def pca(X, k):
    mu = X.mean(0)
    Xc = X - mu                                     # 必须中心化
    U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
    components = Vt[:k]                             # (k, d)
    explained_var = S[:k]**2 / (len(X) - 1)
    Z = Xc @ components.T                           # (n, k)，也等于 U[:, :k] * S[:k]
    return Z, components, explained_var, mu
```

## Transformer 组件

Q9：***手写带 mask 的缩放点积注意力***

- **Q、K 点积后除以 $\sqrt{d_k}$，不能看的位置填 `-inf`，softmax 成权重再对 V 加权求和。除以 $\sqrt{d_k}$ 是为了防止点积过大导致 softmax 饱和。**
- 这里 `True` 表示可以关注（同 `F.scaled_dot_product_attention`）；`nn.MultiheadAttention` 的布尔 mask 正好相反。
- 坑：fp16 下不要用 `-1e9`（超出范围）；整行被屏蔽时 softmax 是 nan，要置 0。

```python
def scaled_dot_product_attention(q, k, v, mask=None, dropout_p=0.0, training=False):
    """q: (..., Tq, d)，k/v: (..., Tk, d)，mask: 可广播到 (..., Tq, Tk) 的布尔张量"""
    d = q.size(-1)
    scores = q @ k.transpose(-2, -1) / math.sqrt(d)
    if mask is not None:
        scores = scores.masked_fill(~mask, float("-inf"))
    attn = torch.softmax(scores, dim=-1)
    attn = torch.nan_to_num(attn)          # 整行被屏蔽时 softmax 为 nan，置 0
    if dropout_p > 0:
        attn = F.dropout(attn, p=dropout_p, training=training)
    return attn @ v, attn
```

Q10：***如何构造因果（causal）mask？***

- **用下三角矩阵：位置 i 只能看 j ≤ i。和 padding mask 做逻辑与，扩成 (B, 1, T, T) 广播到所有头。**
- KV cache 逐个生成时新 query 能看全部历史，不需要因果 mask；左填充时位置编号要偏移。

```python
def causal_mask(T, device=None):
    return torch.tril(torch.ones(T, T, dtype=torch.bool, device=device))   # (T, T)

def causal_padding_mask(pad_mask):
    """pad_mask: (B, T)，True 表示真实 token -> (B, 1, T, T)，可广播到各个头"""
    T = pad_mask.size(1)
    return causal_mask(T, pad_mask.device) & pad_mask[:, None, None, :]
```

Q11：***手写多头注意力模块（Multi-Head Attention）***

- **一个线性层得到 Q/K/V，把隐藏维切成 h 个头分别做注意力，拼回来再过输出投影；计算量和单头相当，但各头能关注不同模式。**
- 坑：要先 `view` 成 (B, T, h, d_k) 再转置，直接 `view(B, h, T, d_k)` 会混淆 token；转置后 `view` 前要 `.contiguous()`。

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads, dropout=0.0):
        super().__init__()
        assert d_model % n_heads == 0
        self.h, self.d_k = n_heads, d_model // n_heads
        self.qkv = nn.Linear(d_model, 3 * d_model)    # 融合 Q/K/V 投影
        self.out = nn.Linear(d_model, d_model)
        self.dropout = dropout

    def forward(self, x, mask=None):
        B, T, C = x.shape
        q, k, v = self.qkv(x).split(C, dim=-1)
        # (B, T, C) -> (B, h, T, d_k)
        q, k, v = (t.view(B, T, self.h, self.d_k).transpose(1, 2) for t in (q, k, v))
        y, _ = scaled_dot_product_attention(q, k, v, mask, self.dropout, self.training)
        y = y.transpose(1, 2).contiguous().view(B, T, C)   # 合并各头
        return self.out(y)

# 用法：mha = MultiHeadAttention(512, 8); y = mha(x, causal_mask(x.size(1), x.device))
```

Q12：***手写 RoPE（旋转位置编码）的应用***

- **把 q、k 的维度两两配对，在位置 m 按角度 $m\theta_i$ 旋转，每对频率不同；这样 q·k 只依赖相对位置 m−n。只作用于 q、k，不作用于 v。**
- 坑：interleaved 和 half-split 两种配对布局不兼容，加载权重时必须一致；KV cache 推理时 cos/sin 要按绝对位置切片。

```python
def rope_cache(T, d, base=10000.0, device=None):
    inv_freq = 1.0 / (base ** (torch.arange(0, d, 2, device=device).float() / d))   # (d/2,)
    t = torch.arange(T, device=device).float()
    freqs = torch.outer(t, inv_freq)                                                # (T, d/2)
    return freqs.cos(), freqs.sin()

def apply_rope(x, cos, sin):
    """x: (B, H, T, d)；cos/sin: (T, d/2)。采用 half-split 布局（GPT-NeoX / HF LLaMA）"""
    x1, x2 = x[..., : x.size(-1) // 2], x[..., x.size(-1) // 2 :]
    return torch.cat([x1 * cos - x2 * sin, x1 * sin + x2 * cos], dim=-1)

# 只作用于 q、k，不作用于 v：q, k = apply_rope(q, cos, sin), apply_rope(k, cos, sin)
```

## 归一化与正则

Q13：***手写 LayerNorm***

- **每个样本在特征维上减均值、除标准差，再乘 γ 加 β；与 batch 无关，训练推理行为一致。**
- 坑：用有偏方差（`unbiased=False`），ε 放在根号里。

```python
class LayerNorm(nn.Module):
    def __init__(self, d, eps=1e-5):
        super().__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(d))
        self.beta = nn.Parameter(torch.zeros(d))

    def forward(self, x):
        mu = x.mean(-1, keepdim=True)
        var = x.var(-1, keepdim=True, unbiased=False)    # 有偏方差
        return self.gamma * (x - mu) / torch.sqrt(var + self.eps) + self.beta
```

Q14：***手写 BatchNorm（训练/推理两种模式，带 running stats）***

- **训练时用当前 batch 的均值方差归一化，并用滑动平均更新 running 统计量；推理时只用 running 统计量。**
- running stats 存成 buffer，在 `no_grad` 下更新，running_var 用无偏方差。
- 坑：推理忘记 `model.eval()` 会用 batch 统计；小 batch 时 BN 不稳，改用 GroupNorm/LayerNorm。

```python
class BatchNorm1d(nn.Module):
    def __init__(self, num_features, eps=1e-5, momentum=0.1):
        super().__init__()
        self.eps, self.momentum = eps, momentum
        self.gamma = nn.Parameter(torch.ones(num_features))
        self.beta = nn.Parameter(torch.zeros(num_features))
        # buffer：随 state_dict 保存、随 .to(device) 移动，但不参与优化
        self.register_buffer("running_mean", torch.zeros(num_features))
        self.register_buffer("running_var", torch.ones(num_features))

    def forward(self, x):  # x: (N, C)
        if self.training:
            mean = x.mean(0)
            var = x.var(0, unbiased=False)
            n = x.size(0)
            with torch.no_grad():
                self.running_mean.lerp_(mean, self.momentum)
                self.running_var.lerp_(var * n / (n - 1), self.momentum)
        else:
            mean, var = self.running_mean, self.running_var
        x_hat = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_hat + self.beta
```

Q15：***手写 RMSNorm***

- **去掉 LayerNorm 的减均值和 β，只除以均方根再乘 γ；更省计算、效果相当，LLaMA 等 LLM 默认使用。**
- 坑：低精度下平方和易丢精度或溢出，先转 fp32 计算再转回。

```python
class RMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(d))

    def forward(self, x):
        rms = torch.rsqrt(x.float().pow(2).mean(-1, keepdim=True) + self.eps)   # 在 fp32 中计算
        return (x.float() * rms).type_as(x) * self.weight
```

Q16：***手写 Dropout（inverted dropout）***

- **训练时以概率 p 置零，保留的值除以 1−p 让期望不变；推理时直接返回输入。**
- 坑：p 是丢弃概率不是保留概率；反向要用同一个 mask。

```python
def dropout(x, p=0.5, training=True, rng=np.random.default_rng()):
    if not training or p == 0:
        return x
    mask = rng.random(x.shape) >= p          # 以概率 1-p 保留
    return x * mask / (1 - p)
```

## 检测与评估

Q17：***手写 IoU（批量）***

- **交集面积除以并集面积；交集左上角取两框左上角的较大值，右下角取较小值。**
- 坑：不相交时宽高必须截到 0，否则两个负数相乘会得到正的"交集"。

```python
def box_iou(a, b):
    """a: (N,4)，b: (M,4)，格式 (x1,y1,x2,y2) -> (N,M)"""
    area_a = (a[:, 2] - a[:, 0]) * (a[:, 3] - a[:, 1])
    area_b = (b[:, 2] - b[:, 0]) * (b[:, 3] - b[:, 1])
    lt = np.maximum(a[:, None, :2], b[None, :, :2])    # 交集左上角 (N,M,2)
    rb = np.minimum(a[:, None, 2:], b[None, :, 2:])    # 交集右下角 (N,M,2)
    wh = np.clip(rb - lt, 0, None)                     # 不相交时为 0
    inter = wh[..., 0] * wh[..., 1]
    return inter / (area_a[:, None] + area_b[None, :] - inter + 1e-9)
```

Q18：***手写 NMS（非极大值抑制）***

- **按分数从高到低，每次保留最高分的框，删掉和它 IoU 超过阈值的框，重复到没有框为止。**
- 多类别要按类别分别做；追问：Soft-NMS 用降分代替删除，适合密集遮挡。

```python
def nms(boxes, scores, iou_thr=0.5):
    order = scores.argsort()[::-1]
    keep = []
    while order.size > 0:
        i = order[0]
        keep.append(i)
        if order.size == 1:
            break
        ious = box_iou(boxes[i:i + 1], boxes[order[1:]])[0]
        order = order[1:][ious <= iou_thr]
    return np.array(keep)
```

Q19：***手写 AUC 计算***

- **AUC 是随机一个正样本得分高于随机一个负样本的概率。用排名算：正样本排名之和减去最小可能值，再除以正负样本对数。**
- 坑：平局取平均排名；只有一个类别时 AUC 无定义。
- 核心公式：$\mathrm{AUC}=\frac{\sum_{i\in pos}\mathrm{rank}_i-\frac{n_+(n_++1)}{2}}{n_+n_-}$

```python
def average_ranks(s):
    order = np.argsort(s, kind="mergesort")
    s_sorted = s[order]
    _, first, counts = np.unique(s_sorted, return_index=True, return_counts=True)
    avg = first + (counts + 1) / 2              # 每组平局的平均秩（1 起始）
    ranks = np.empty(len(s))
    ranks[order] = np.repeat(avg, counts)
    return ranks

def roc_auc(y_true, scores):
    pos = y_true == 1
    n_pos, n_neg = pos.sum(), (~pos).sum()
    ranks = average_ranks(scores)
    return (ranks[pos].sum() - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)
```

## 训练与优化

Q20：***用 NumPy 手写两层 MLP 的训练循环（手动反向传播）***

- **前向：线性、ReLU、线性、交叉熵；反向：从 Q2 的 logits 梯度出发，按链式法则逐层往回传，再做梯度下降。**
- 检查：每个梯度形状和参数一致，偏置梯度在 batch 维求和，可用数值梯度验证。
- 坑：全 0 初始化无法打破对称；`p -= ...` 才是原地更新。

```python
def train_mlp(X, y, hidden=64, n_classes=3, lr=0.1, epochs=500, seed=0):
    rng = np.random.default_rng(seed)
    n, d = X.shape
    W1 = rng.normal(0, np.sqrt(2 / d), (d, hidden)); b1 = np.zeros(hidden)          # He 初始化
    W2 = rng.normal(0, np.sqrt(2 / hidden), (hidden, n_classes)); b2 = np.zeros(n_classes)
    for ep in range(epochs):
        # 前向
        h_pre = X @ W1 + b1
        h = np.maximum(h_pre, 0)
        logits = h @ W2 + b2
        loss = cross_entropy(logits, y)
        # 反向
        dlogits = cross_entropy_grad(logits, y)        # (n, C)，已除以 n
        dW2 = h.T @ dlogits;  db2 = dlogits.sum(0)
        dh = dlogits @ W2.T
        dh_pre = dh * (h_pre > 0)                      # ReLU 的梯度
        dW1 = X.T @ dh_pre;   db1 = dh_pre.sum(0)
        # 更新（原地修改）
        for p, g in ((W1, dW1), (b1, db1), (W2, dW2), (b2, db2)):
            p -= lr * g
    return (W1, b1, W2, b2), loss
```

Q21：***手写 Adam / AdamW 的一步更新***

- **Adam 维护梯度的一阶动量 m 和二阶动量 v，偏差修正后用 m/√v 更新；AdamW 把权重衰减直接作用在参数上，而不是加进梯度（否则会被自适应分母缩放）。**
- 偏差修正抵消 m、v 从 0 开始造成的早期偏小；t 要从 1 开始。
- 核心公式：$\theta\leftarrow\theta-\eta\,\hat m_t/(\sqrt{\hat v_t}+\epsilon)$

```python
class AdamW:
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8, weight_decay=0.0):
        self.params, self.lr, self.eps, self.wd = params, lr, eps, weight_decay
        self.b1, self.b2 = betas
        self.m = [np.zeros_like(p) for p in params]
        self.v = [np.zeros_like(p) for p in params]
        self.t = 0

    def step(self, grads):
        self.t += 1
        for p, g, m, v in zip(self.params, grads, self.m, self.v):
            if self.wd:
                p -= self.lr * self.wd * p              # 解耦权重衰减
            m[:] = self.b1 * m + (1 - self.b1) * g
            v[:] = self.b2 * v + (1 - self.b2) * g * g
            m_hat = m / (1 - self.b1 ** self.t)
            v_hat = v / (1 - self.b2 ** self.t)
            p -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)
```

Q22：***手写 top-k / top-p（nucleus）采样***

- **先除以温度，再过滤：top-k 留概率最高的 k 个，top-p 留累计概率刚超过 p 的最小集合；其余设为 `-inf`，重新 softmax 后采样。**
- 坑：用"不含自身的累计概率 > p"判断删除，保证至少留一个；排序后要 `scatter` 回原顺序。

```python
def sample_top_k_top_p(logits, k=0, p=1.0, temperature=1.0):
    """logits: (B, V) -> (B,) token id"""
    logits = logits / max(temperature, 1e-5)
    if k > 0:
        kth = torch.topk(logits, k, dim=-1).values[..., -1, None]
        logits = logits.masked_fill(logits < kth, float("-inf"))
    if p < 1.0:
        sorted_logits, sorted_idx = torch.sort(logits, descending=True, dim=-1)
        probs = torch.softmax(sorted_logits, dim=-1)
        cum = probs.cumsum(-1)
        remove = cum - probs > p                # 移除前面累计已超过 p 的 token，至少保留 1 个
        sorted_logits = sorted_logits.masked_fill(remove, float("-inf"))
        logits = torch.full_like(logits, float("-inf")).scatter(-1, sorted_idx, sorted_logits)
    probs = torch.softmax(logits, dim=-1)
    return torch.multinomial(probs, 1).squeeze(-1)
```

Q23：***手写（简化版）beam search***

- **始终保留累计对数概率最高的 B 条候选；每步每条扩展 B 个 token，从 B×B 个里选前 B 条，遇到 EOS 的移入完成列表；最后按长度惩罚后的分数选最优。**
- 要在 log 空间累加；不加长度惩罚会偏向短句。
- 追问：适合翻译、摘要；开放式生成容易重复，通常改用采样。

```python
def beam_search(step_fn, bos, eos, beam_size=4, max_len=50, alpha=0.6):
    """step_fn(seq: list[int]) -> 下一个 token 的对数概率（一维 torch 张量）"""
    beams = [([bos], 0.0)]
    finished = []
    for _ in range(max_len):
        candidates = []
        for seq, score in beams:
            logp = step_fn(seq)
            top_lp, top_id = logp.topk(beam_size)
            for lp, tok in zip(top_lp.tolist(), top_id.tolist()):
                candidates.append((seq + [tok], score + lp))
        candidates.sort(key=lambda c: c[1], reverse=True)
        beams = []
        for seq, score in candidates:
            (finished if seq[-1] == eos else beams).append((seq, score))
            if len(beams) == beam_size:
                break
        if not beams:
            break
    finished.extend(beams)                                 # 到达 max_len 仍未结束的序列
    length_penalty = lambda L: ((5 + L) / 6) ** alpha      # GNMT 长度惩罚
    return max(finished, key=lambda c: c[1] / length_penalty(len(c[0])))
```
