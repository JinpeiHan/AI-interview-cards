# Optimisation

## Easy

Q1：**解释什么是贝叶斯优化方法？**

- **贝叶斯优化是一种黑盒优化方法：用少量采样点拟合一个代理模型（通常是高斯过程）来估计目标函数的分布，再用采集函数决定下一个最值得尝试的点，反复迭代，最后返回最好的采样点。**
- 代理模型给出每个点的预测均值和不确定性。
- 采集函数（如 EI、UCB）在"利用已知好区域"和"探索不确定区域"之间做权衡。
- 适合评估代价很高的函数，常用于 AutoML 超参数搜索，部分 NAS 方法也会用到。

Q2：**解释机器学习中的凸优化**

- **如果优化问题是凸的，任何局部最优就是全局最优，所以用梯度下降等简单方法就能可靠地找到最优解。**
- 凸问题求解更快、更简单、计算量更小，也有理论上的收敛保证。
- 线性回归、逻辑回归、SVM 都是凸问题；神经网络训练是非凸的。

Q3：你知道哪些超参数调整（Hyperparameters tuning）方法?

- **常用的有网格搜索、随机搜索和贝叶斯优化。**
- **网格搜索**：把每个超参数的候选值组成网格，逐一遍历，返回最好的组合；简单但维度一高就太贵。
- **随机搜索**：在搜索空间里随机采样组合；预算相同时通常比网格搜索更高效，因为重要的超参数能被试到更多取值。
- **贝叶斯优化**：把"超参数→验证损失"看作一个未知函数，用 SMBO 等方法建代理模型，有针对性地选下一组超参数，评估次数最少。

Q4：**解释Adam优化器**

- **Adam（Adaptive Moment Estimation）同时维护梯度的一阶矩（均值，相当于动量）和二阶矩（平方均值），用它们为每个参数自适应地调整步长。**
- 可以理解为 Momentum + RMSProp 的结合：动量让方向更稳，二阶矩让梯度大的参数步长变小。
- 收敛快、对学习率不太敏感，是很多任务的默认选择（公式见 Q16）。

Q5：**Adam算法有什么局限性？**

- **Adam 收敛快，但最终模型的泛化性能常常不如 SGD + Momentum。**
- 它虽然有自适应学习率，仍然需要好的学习率调度才能发挥最好效果。
- 训练初期权重随机、梯度不可靠，学习率太大容易发散，所以通常要先做 warmup，稳定后再提高学习率。
- 原版 Adam 中的 L2 正则与自适应步长耦合，效果差，一般改用 AdamW。

Q6：***Batch Size*如何影响梯度下降方法的收敛性？为什么？**

- **大 batch 的梯度噪声小，倾向于收敛到离初始点较近、更"尖锐"的极小值；小 batch 的梯度噪声大，能把参数推出尖锐的盆地，倾向于收敛到更平坦的极小值，泛化通常更好。**
- 平坦极小值对参数扰动不敏感，所以在测试数据上更稳健。
- 大 batch 每步更准、并行效率高，但通常需要相应调大学习率并配合 warmup。

Q7：**什么情况下，选择遗传算法作为优化算法？**

- **当目标函数多峰（很多局部最优）、不可导或是黑盒，并且有大量处理器可以并行评估时，遗传算法比较合适。**
- 它基于种群搜索，不依赖梯度，不容易困在单个局部最优。
- 每个个体的评估相互独立，天然适合并行。

Q8：**Adagrad算法是怎样调整学习率的？**

- **Adagrad 为每个参数累加历史梯度的平方，用学习率除以这个累加值的平方根，所以更新频繁、梯度大的参数步长变小，很少更新的参数步长较大。**
- 因此很适合稀疏数据（如稀疏特征、词向量）。
- 缺点是累加值只增不减，学习率会单调衰减到很小，训练后期可能停滞；RMSProp 用指数滑动平均解决了这个问题。
- 核心公式：$\theta_t=\theta_{t-1}-\dfrac{\eta}{\epsilon+\sqrt{r_t}}\odot g_t$，其中 $r_t=r_{t-1}+g_t\odot g_t$

Q9：**比较牛顿法和梯度下降**

- **梯度下降只用一阶导数，沿负梯度方向走；牛顿法用二阶导数（Hessian）做局部二次近似，直接跳到近似的极值点，收敛更快但每步代价大得多。**
- 收敛速度：牛顿法在最优点附近是二次收敛，通常比梯度下降快。
- 计算代价：牛顿法要计算并求逆 Hessian 矩阵，参数多时不可行，实际常用拟牛顿法（如 L-BFGS）。
- 非凸问题：牛顿法容易被吸引到鞍点，而梯度下降更容易逃离鞍点，所以神经网络训练一般用梯度下降。
- 梯度下降在最优点附近会震荡，需要调整步长，于是有了 Adagrad、RMSProp、Adam 等自适应方法。

Q10：**贝叶斯优化如何在超参数优化中使用？**

- **把"超参数组合→验证集性能"当作一个昂贵的黑盒函数：用高斯过程等代理模型根据已试过的结果预测其他组合的表现，用采集函数选出下一组最有希望的超参数去训练评估，再用新结果更新模型，循环直到预算用完。**
- 相比网格/随机搜索，用更少的训练次数就能找到好的超参数。
- 常见工具有 Hyperopt（TPE）、Optuna 等。

Q11：**剪枝方法是否适用于神经网络优化？**

- **适用。剪枝通过评估神经元或权重的重要性，删掉不重要的部分，从而减少计算量和模型大小，也能降低过拟合风险。**
- 可以在训练中加稀疏正则让部分权重趋于 0，也可以训练后按重要性剪枝再微调。
- 非结构化剪枝（单个权重）压缩率高但需要稀疏计算支持；结构化剪枝（整个通道/神经元）更容易真正加速。

Q12：**在随机森林模型中，如何优化森林中树的数量？**

- **用交叉验证（或袋外误差 OOB）评估不同树的数量，选择性能趋于饱和时的数量。**
- 树越多，结果越稳定，一般不会因为树多而过拟合，但计算成本线性增加。
- 实践中常在 10 到 1000 棵之间评估，选择效果不再明显提升的那个点。

Q13：****若CNN网络很庞大，在手机上运行效率不高，对应模型压缩方法有了解吗？****

- **主要有四类：低秩近似、剪枝与稀疏约束、参数量化、知识蒸馏。**
- **低秩近似**：卷积本质是矩阵运算，用若干个小矩阵（如 SVD 分解、Toeplitz 矩阵重构）近似原权重矩阵，减少计算和存储。
- **剪枝与稀疏约束**：去掉不重要的神经元后微调，反复进行；或在训练目标中加稀疏正则，让部分权重趋于 0，一遍训练即可完成剪枝。
- **参数量化**：用低比特或码本（codebook）里的少数代表值表示权重，原矩阵只存索引，大幅降低存储。
- **知识蒸馏**：用训练好的大 teacher 网络指导小 student 网络学习，得到更紧凑的模型。

Q14：**讲述模型蒸馏的原理与操作**

- **蒸馏让小的 student 模型去模仿大的 teacher 模型的输出分布（软标签），因为软标签里包含了类别之间的相似性信息，比只学硬标签更有效。**
- 操作：先训练好 teacher；对 teacher 和 student 的 logits 都用温度 $T$ 做 softmax 得到软化的概率分布。
- student 的总损失 = 与软标签的 KL 散度 + 与真实硬标签的交叉熵，两者加权求和。
- 温度越高，分布越平滑，类别间的"暗知识"越明显；除了输出，也可以让 student 模仿中间层的特征图。
- 核心公式：$p_i=\dfrac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$

Q15：**为什么梯度下降能够降低Loss？其数学原理是什么？**

- **梯度是函数在当前点上升最快的方向，所以沿负梯度方向走一小步，loss 一定会下降（只要梯度不为 0 且步长足够小）。**
- 原理是一阶泰勒展开：在局部，函数近似为线性，沿负梯度走时 loss 的变化量约等于负的"学习率 × 梯度范数平方"，一定小于 0。
- 在步长固定的所有方向中，负梯度方向下降最多，所以叫"最速下降"。
- 学习率太大，局部线性近似失效，会震荡甚至发散；太小则收敛很慢。
- 对凸函数能收敛到全局最优；对神经网络这类非凸函数，只能保证收敛到驻点（局部极小或鞍点）。
- 核心公式：$\theta_{t+1}=\theta_t-\eta\nabla_\theta L(\theta_t)$

Q16：**Adam与SGD优化器的原理及区别是什么？**

- **SGD 用 mini-batch 梯度乘一个全局学习率来更新参数，通常加动量来平滑方向；Adam 在动量（一阶矩）的基础上再用梯度平方的滑动平均（二阶矩）为每个参数单独缩放步长，并做偏差修正。**
- 学习率：SGD 所有参数共用一个学习率；Adam 对梯度大的参数步长小，对稀疏/梯度小的参数步长大。
- 收敛与调参：Adam 收敛快、对学习率不敏感，适合 NLP/Transformer；SGD 收敛慢，对学习率和调度更敏感。
- 泛化：SGD + Momentum 往往收敛到更平坦的极小值，在 CV 任务（如 ImageNet 上的 ResNet）中泛化通常更好（见 Q5）。
- 显存与权重衰减：Adam 每个参数要额外存 $m_t, v_t$ 两份状态，显存约为参数量的 3 倍；AdamW 把权重衰减从自适应步长中解耦，是大模型训练的常用选择。
- 核心公式（Adam）：$\theta_{t+1}=\theta_t-\dfrac{\eta\,\hat{m}_t}{\sqrt{\hat{v}_t}+\epsilon}$，其中 $\hat m_t,\hat v_t$ 是偏差修正后的一阶、二阶矩
