# BERT

Q1：***BERT 的模型结构与规模是怎样的？***

- **BERT 是只用 Transformer Encoder 堆叠起来的预训练语言模型，靠双向自注意力让每个 token 同时看到左右上下文。**
- BERT-Base：12 层、隐藏维度 768、12 个头，约 110M 参数；BERT-Large：24 层、1024 维、16 个头，约 340M 参数。
- FFN 维度是隐藏维度的 4 倍，激活用 GELU，Post-LN 结构。
- 在 BooksCorpus 和英文维基上用 MLM 和 NSP 两个任务预训练。

Q2：***BERT 的输入表示是如何构造的？WordPiece 有什么作用？***

- **输入格式是 `[CLS] 句子A [SEP] 句子B [SEP]`，每个位置的输入向量是词嵌入、句段嵌入和可学习的绝对位置嵌入（最多 512 个位置）三者相加。**
- WordPiece 是子词分词算法，把词拆成常见子词，如 "playing" → "play", "##ing"。
- 好处：词表规模可控（约 30k），几乎没有 OOV，罕见词和词形变化可以复用常见子词的表示。
- 做 NER 等 token 级任务时要处理子词与标签的对齐，通常只用第一个子词预测标签。

Q3：***MLM 为什么选择 15% 的掩码比例？80/10/10 规则的深层动机是什么？***

- **15% 是一个经验折中：太低则训练信号太稀疏，太高则上下文被破坏太多、和下游完整输入差距太大。**
- **80/10/10（80% 换成 [MASK]、10% 换成随机词、10% 不变）是为了缓解预训练和微调的不一致：下游没有 [MASK]，而模型又不知道哪些位置被改过，只能为每个 token 都学好上下文表示。**
- 随机替换只占全部 token 的 1.5%，引入的噪声很小。
- 后续研究发现大模型用更高的掩码比例也很好，15% 并非最优。

Q4：***NSP 任务是什么？为什么 RoBERTa 去掉了 NSP？***

- **NSP 让模型判断句子 B 是否是句子 A 的真实下一句（正负各 50%，负例随机采样），用 [CLS] 做二分类，希望学到句间关系。**
- RoBERTa 去掉它，是因为实验发现用连续的完整句子填满 512 长度训练，效果持平甚至更好。
- NSP 太简单：负例来自别的文档，只看主题是否一致就能判断，学不到真正的连贯性（ALBERT 改用 SOP）。
- 句对格式让每段输入变短，不利于学习长距离依赖。

Q5：***BERT 如何用于下游任务微调？***

- **在 BERT 上加一个很小的任务输出层，然后用小学习率把全部参数一起微调。**
- 分类/句对任务：取 [CLS] 的输出接 softmax 分类层。
- 序列标注（NER）：每个 token 的输出接分类层，可再加 CRF。
- 抽取式问答：学习一个起点向量和一个终点向量，分别与每个 token 输出做点积，选得分最高的合法片段。
- 常用学习率 2e-5 到 5e-5、训练几个 epoch，配合 warmup 和线性衰减。

Q6：***为什么可以用 [CLS] 做句子表示？它有什么局限？***

- **[CLS] 不对应任何真实词，经过多层自注意力能聚合整句信息，又在 NSP 上训练过，所以微调后很适合做分类特征。**
- 但不微调时它不是好的语义向量，做相似度往往不如 token 输出平均池化。
- BERT 表示空间有各向异性，向量挤在一个窄锥里，余弦相似度普遍偏高。
- 所以句向量一般用 Sentence-BERT、SimCSE 等专门训练的方法，或做白化等后处理。

Q7：***RoBERTa 对 BERT 做了哪些改进？***

- **RoBERTa 不改结构，只是证明 BERT 训练不充分，通过更好的训练策略提升效果。**
- 动态掩码：每次输入时重新生成掩码，而不是预处理时固定。
- 去掉 NSP，用连续完整句子填满输入。
- 更大的 batch、更多数据（约 160GB vs 16GB）、更长训练。
- 改用字节级 BPE（约 50k 词表），没有未知字符。

Q8：***ALBERT 是如何减少参数量的？***

- **ALBERT 主要靠两招减参：把词嵌入分解成"低维嵌入 + 投影"，以及所有 Transformer 层共享同一组参数。**
- 嵌入分解：词先映射到 128 维再投影到隐藏维度，因为上下文无关的词嵌入不需要那么大的容量。
- 跨层共享：参数量与层数无关。
- 另外用 SOP（判断两段是否被交换顺序）替代 NSP，迫使模型学连贯性而不是主题。
- 注意：减少的是参数和显存，计算量和推理速度并没有改善。

Q9：***DistilBERT 是如何进行知识蒸馏的？***

- **DistilBERT 在预训练阶段做任务无关的蒸馏：学生层数减半（6 层），让它模仿教师 BERT 的输出分布。**
- 用教师每隔一层的参数初始化学生。
- 损失由三部分组成：带温度的软标签蒸馏损失、标准 MLM 损失、对齐隐藏状态方向的余弦损失。
- 结果是模型更小、推理更快，保留了教师大部分能力；同类方法还有 TinyBERT、MobileBERT、剪枝和量化。

Q10：***ELECTRA 的替换 token 检测（RTD）是什么？为什么更高效？***

- **ELECTRA 用一个小生成器（小 MLM）把部分 token 替换成采样词，再训练一个判别器判断每个 token 是原词还是被替换过的；预训练后只保留判别器。**
- 更高效：MLM 只在 15% 的位置有损失，RTD 在所有 token 上都有学习信号。
- 判别器输入里没有 [MASK]，缓解了预训练-微调不一致。
- 生成器用最大似然训练而不是对抗训练，所以它不是 GAN；生成器不宜太强，约为判别器的 1/4–1/2 最好。

Q11：***DeBERTa 的解耦注意力（Disentangled Attention）是什么？***

- **DeBERTa 给每个 token 分别用内容向量和相对位置向量表示，注意力分数拆成"内容-内容、内容-位置、位置-内容"三项相加。**
- 位置-位置这一项信息很少，被省略。
- 由于主干只用相对位置，它在最后的预测层前才加入绝对位置信息（增强掩码解码器 EMD）。
- DeBERTa v3 改用 ELECTRA 式的 RTD 目标，并用梯度解耦的嵌入共享解决生成器和判别器的"拔河"问题。

Q12：***BERT 与 GPT 在设计上的核心区别是什么？***

- **BERT 是双向的 Encoder，用 MLM 做去噪预训练，擅长理解；GPT 是单向的 Decoder，用下一个词预测做自回归预训练，擅长生成。**
- BERT 每个 token 都融合了全局上下文，适合分类、抽取、匹配。
- MLM 只有约 15% 位置有损失，自回归 LM 每个位置都有损失。
- BERT 通常要按任务微调；GPT 规模变大后可以靠提示做零样本/少样本。
- 统一两者的尝试：XLNet、T5、UniLM。

Q13：***为什么 BERT 不擅长文本生成？***

- **BERT 学的是"已知其他所有词时预测某个词"，不是从左到右的联合概率分解，所以无法自然地逐词采样生成。**
- 同时遮盖多个词时，各位置的预测相互独立，容易生成不连贯的组合。
- 双向注意力下每加一个词所有表示都会变，不能用 KV cache，效率低。
- 它从没在"只看左侧上下文"的条件下训练过；迭代填充等变通方法效果一般。

Q14：***BERT 的最大长度为什么是 512？如何处理长文本？***

- **因为自注意力代价随长度平方增长，而且 BERT 用的是可学习的绝对位置嵌入，只训练了 512 个位置，超出部分没有嵌入可用。**
- 截断：保留开头、结尾或首尾拼接。
- 滑动窗口：分段重叠编码再融合结果。
- 层级模型：先编码段落，再用上层模型聚合。
- 换长文本模型：Longformer、BigBird（稀疏注意力），或用 RoPE 等易外推位置编码的新编码器（如 ModernBERT）。

Q15：***Sentence-BERT 是如何得到句子向量的？为什么不直接用 BERT？***

- **直接用 BERT 比较句子要把两句拼起来一起算（交叉编码器），每对都要推理一次，大规模检索算不起；而直接取 [CLS] 或平均池化的句向量质量又差。**
- Sentence-BERT 用共享参数的孪生 BERT 分别编码两句，平均池化得到句向量。
- 在 NLI 上用 $(u, v, |u-v|)$ 拼接做分类训练，或在 STS 上直接优化余弦相似度。
- 句向量可以预先算好建索引，用余弦相似度检索；实际常用"双编码器召回 + 交叉编码器重排"。
- 后续的 SimCSE 用对比学习进一步提升句向量质量。

Q16：***BERT 的各向异性问题是什么？如何缓解？***

- **各向异性是指 BERT 的向量挤在一个狭窄的锥形区域里，任意两句的余弦相似度都很高，语义区分度很差。**
- 原因与词频有关：高频词和低频词的嵌入分布不均匀，训练目标也会导致表示退化。
- 后处理：BERT-flow（映射成各向同性高斯）、BERT-whitening（白化）。
- 训练方法：SimCSE 等对比学习提升均匀性，或 Sentence-BERT 有监督训练。

Q17：***微调 BERT 时有哪些常见问题与技巧？***

- **常见问题是小数据上过拟合和训练不稳定，主要靠小学习率、少 epoch、warmup 和分层学习率来缓解。**
- 分层学习率衰减：底层学的是通用特征，学习率更小。
- BERT-Large 小数据微调对随机种子敏感，可用带偏差校正的 Adam、更多步数、重新初始化顶部几层。
- 领域差异大时先在领域语料上继续预训练（如 BioBERT、SciBERT）。
- 多任务部署可用 Adapter、LoRA 等参数高效微调；类别不平衡用加权损失或 Focal Loss。
