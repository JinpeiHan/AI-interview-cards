# MAE

Q1：***简述 MAE（Masked Autoencoder）的基本思想***

- **MAE 是一种掩码图像建模的自监督方法：随机遮住图像大部分 patch（默认 75%），让 ViT 编码器只看剩下的 patch，再由轻量解码器重建被遮住部分的像素。**
- 解码器输入是编码结果加上 mask token 和位置编码。
- 损失只在被遮住的 patch 上计算。
- 预训练后丢掉解码器，只用编码器做下游任务。

Q2：***MAE 为什么使用 75% 这么高的掩码率？***

- **因为图像冗余度很高，遮得少时模型靠邻近 patch 简单插值就能补全，学不到语义；遮掉 75% 才逼着模型理解物体和场景的整体结构。**
- 实验中线性探测和微调都在 75% 左右最好，而 BERT 只遮 15%。
- 额外好处：编码器只处理 25% 的 token，预训练计算量和显存大幅下降，大模型和长训练变得可行。

Q3：***MAE 的非对称编码器-解码器设计是什么？为什么这样设计？***

- **编码器只处理可见 patch、不碰 mask token；解码器很轻（默认 8 层、512 维），负责处理完整序列并重建像素。**
- 效率：编码器计算量随可见 token 减少大幅下降，预训练快 3 倍以上。
- 一致性：编码器预训练时从没见过 mask token，和下游输入一致（BEiT/SimMIM 则会让编码器看到 mask token）。
- 分工：像素细节交给解码器，编码器专注学语义表示；解码器深一些对线性探测更有利。

Q4：***MAE 的损失函数是什么？为什么只在被遮盖的 patch 上计算？***

- **损失是重建像素与原始像素的均方误差，只在被遮盖的 patch 上计算，因为可见 patch 只需"复制"输入，计入损失只会稀释学习信号。**
- 论文实验也表明只算掩码 patch 精度更高，这和 BERT 只预测被遮盖的词是一个道理。
- 核心公式：$\mathcal{L}=\frac{1}{|\mathcal{M}|}\sum_{i\in\mathcal{M}}\|\hat{x}_i-x_i\|_2^2$

Q5：***什么是归一化像素目标（normalized pixel targets）？为什么有用？***

- **就是先用每个 patch 自己的均值和标准差把该 patch 归一化，再当作重建目标。**
- 这样去掉了整体亮度、对比度等低频信息，让模型关注纹理、边缘和形状，而不是平均颜色。
- 实验中能稳定提升表示质量，而且比 BEiT 的 dVAE token 目标简单，不需要额外训练分词器。

Q6：***为什么掩码建模在图像上起步比 NLP 晚？图像与文本有何不同？***

- **MAE 论文给出三点原因：早期视觉以 CNN 为主不方便加 mask token；图像信息密度低、冗余大，必须高掩码率才有意义；重建像素是低语义任务，需要专门设计解码器。**
- 架构：ViT 出现后，加入 mask token 和位置编码的障碍才消除。
- 信息密度：语言是高度语义化的信号，预测少量缺词就够难了。
- 解码器：BERT 预测词，一个 MLP 就够；MAE 重建像素，解码器设计会影响表示的语义层级。

Q7：***MAE 的掩码策略有哪些？哪种更好？***

- **随机掩码最好，是默认选择，在高掩码率下效果最佳，而且没有规律可钻。**
- 块状掩码（BEiT 使用）：遮住大块连续区域，高掩码率下任务太难，重建模糊。
- 网格掩码：规律地保留 patch，太容易插值，表示质量差。

Q8：***MAE 对数据增强的依赖如何？***

- **MAE 几乎不依赖数据增强，只用随机裁剪缩放加水平翻转就很好，颜色抖动等强增强反而可能有害。**
- 原因是随机掩码本身就是强增强，每轮掩码不同，同一张图能产生大量不同样本。
- 这与 SimCLR、BYOL 等对比学习形成对比，它们严重依赖精心设计的增强来构造正样本对。

Q9：***MAE 的线性探测（linear probe）和微调（fine-tune）结果有何特点？***

- **MAE 微调很强、线性探测偏弱：微调在分类、检测、分割上都很突出且随规模持续提升，但冻结特征的线性可分性不如 MoCo v3、DINO。**
- 原因是 MAE 的特征非线性程度更高，语义分布在多层中，最后一层还保留不少像素细节。
- 只微调最后一两个块（部分微调）精度就远超线性探测，说明线性探测不能全面反映表示质量。

Q10：***MAE 与 BEiT 有什么区别？***

- **BEiT 先用 dVAE 把图像变成离散视觉 token，再预测被遮位置的 token 类别；MAE 直接回归像素，不需要分词器，更简单也更高效。**
- 掩码：BEiT 用约 40% 的块状掩码，MAE 用 75% 的随机掩码。
- 编码器：BEiT 处理全部 token（含 mask token），MAE 只处理可见 patch。
- 结论：像素目标配合高掩码率和归一化像素就足够；BEiT v2 后来改用 CLIP 等教师蒸馏出的语义 tokenizer。

Q11：***MAE 与 SimMIM 有什么区别？***

- **SimMIM 也直接回归像素，但它让编码器处理包含 mask token 的完整序列，所以能直接用在 Swin 这类层级结构上，代价是计算量比 MAE 大。**
- 没有独立解码器，预测头只是一个线性层。
- 用 L1 损失。
- 用较大的掩码 patch（如 32×32）做随机掩码。

Q12：***MAE 与对比学习方法相比有哪些优缺点？***

- **MAE 简单高效、易扩展到大模型、微调和密集预测强；但冻结特征的线性探测、kNN、少样本表现比对比学习弱。**
- 优点：不需要负样本、大 batch 或强增强，保留丰富的空间细节。
- 缺点：像素目标让模型花容量建模低层细节；预训练只见 25% 的 patch，与推理输入分布不同。
- 对比学习（SimCLR、MoCo、DINO）全局特征语义性和线性可分性更强，但依赖增强设计，在密集任务上不一定占优。
- 两者可以结合，如 iBOT、CMAE。

Q13：***VideoMAE 如何将 MAE 扩展到视频？***

- **视频在时间上冗余更高，所以 VideoMAE 用 90%–95% 的极高掩码率，并采用管道掩码：同一空间位置在所有帧上一起遮住，防止模型从相邻帧直接复制。**
- token 是时空立方体（如 2×16×16），配合时空联合注意力。
- 掩码率极高使编码器计算量很小，在中等规模视频数据上也能有效预训练。

Q14：***MAE 如何扩展到音频等其他模态？***

- **Audio-MAE 把音频转成梅尔频谱图，当图像一样切 patch、高比例掩码后重建；解码器用局部窗口注意力，因为频谱在时间和频率上局部相关性强。**
- MultiMAE 同时掩码 RGB、深度、分割等多种模态做跨模态重建。
- 还有用于点云（Point-MAE）、图（GraphMAE）的版本。
- 共同规律：模态越冗余，能承受的掩码率越高。

Q15：***MAE 的预训练目标有哪些改进变体？***

- **总趋势是从重建低层像素走向预测更高层的特征或语义目标。**
- MaskFeat：重建 HOG 特征，对光照更不敏感。
- data2vec：预测 EMA 教师在完整输入上的多层平均特征，统一视觉、语音和文本。
- iBOT：在掩码 token 上做自蒸馏；I-JEPA：在表示空间预测目标块嵌入而不是重建像素。
- EVA、BEiT v2：用 CLIP 特征做重建目标，引入语言对齐的语义。

Q16：***为什么说 MAE 是"可扩展的（scalable）"？***

- **因为它训练便宜、效果随模型变大持续提升、方法又简单。**
- 计算：编码器只处理 25% 的 token，训练 ViT-L、ViT-H 的成本大大降低。
- 性能：模型越大微调精度越高，ViT-H 仅用 ImageNet-1k 也能有效训练，不容易过拟合。
- 简单：不需要负样本、动量编码器、分词器或复杂增强，容易大规模复现。
