# MAE

Q1：***简述 MAE（Masked Autoencoder）的基本思想***

- MAE（He et al., 2021，"Masked Autoencoders Are Scalable Vision Learners"）是一种基于 **掩码图像建模（Masked Image Modeling, MIM）** 的自监督预训练方法。
- 流程：
    1. 将图像切成 patch，**随机遮盖大部分 patch**（默认 75%）；
    2. **编码器**（ViT）只处理可见的 patch；
    3. 在编码结果中插入 **mask token**，加上位置编码后送入轻量 **解码器**；
    4. 解码器 **重建被遮盖 patch 的像素**，损失只在被遮盖的 patch 上计算。
- 预训练结束后丢弃解码器，只用编码器做下游任务的特征提取或微调。

Q2：***MAE 为什么使用 75% 这么高的掩码率？***

- **图像信息冗余度高**：相邻像素/patch 高度相关，遮盖比例低时，模型只需从邻近 patch 做简单插值就能恢复，学不到高层语义。
- 高掩码率让任务 **足够难**，迫使模型理解物体与场景的整体结构，才能补全大面积缺失区域。
- 论文实验中，线性探测和微调精度都在约 75% 掩码率附近表现良好，而 BERT 只用 15%。
- 额外收益：编码器只处理 25% 的 token，**预训练计算量与显存大幅降低**，使得训练大模型和更长的训练周期变得可行。

Q3：***MAE 的非对称编码器-解码器设计是什么？为什么这样设计？***

- **非对称** 体现在两方面：
    - 编码器 **只看可见 patch**，不处理 mask token；解码器处理完整序列（可见 token 的编码 + mask token）；
    - 解码器 **轻量**（默认 8 层、512 维），比编码器窄且浅，计算量只占很小一部分。
- 好处：
    - **效率**：编码器的计算量随可见 token 数减少而大幅下降，预训练加速约 3 倍以上；
    - **消除训练-测试不一致**：编码器预训练时从未见过 mask token，下游任务中输入也都是真实 patch，两者一致（对比 BEiT/SimMIM 在编码器中引入 mask token）；
    - **分工**：像素重建这种低层细节交给解码器，编码器可以专注学习语义表示。
- 论文发现解码器的 **深度** 对线性探测影响较大（深一些更好），而对微调影响较小。

Q4：***MAE 的损失函数是什么？为什么只在被遮盖的 patch 上计算？***

- 损失为重建像素与原始像素之间的 **均方误差（MSE）**，只在被遮盖的 patch 上计算：

$$\mathcal{L}=\frac{1}{|\mathcal{M}|}\sum_{i\in\mathcal{M}}\|\hat{x}_i-x_i\|_2^2$$

- 原因：可见 patch 的重建只需"复制"输入，任务过于简单，计入损失会稀释学习信号；论文中只在掩码 patch 上计算损失时精度更高（与 BERT 只预测被 mask 的词一致）。

Q5：***什么是归一化像素目标（normalized pixel targets）？为什么有用？***

- 以每个 patch 自身的像素 **均值和标准差** 对该 patch 做归一化，再作为重建目标：$\tilde{x}_i=\frac{x_i-\mu_i}{\sigma_i+\epsilon}$。
- 作用：去除 patch 的整体亮度、对比度等低频信息，**增强局部对比度与高频结构**，让模型关注纹理、边缘与形状，而不是平均颜色。
- 论文实验中使用归一化像素目标能稳定提升表示质量；它比 BEiT 的 dVAE token 目标更简单，且不需要额外训练分词器。

Q6：***为什么掩码建模在图像上起步比 NLP 晚？图像与文本有何不同？***

- MAE 论文从三个方面讨论了视觉与语言的差异：
    - **架构差异**：早期视觉以 CNN 为主，难以直接加入 mask token 和位置编码；ViT 出现后这一障碍消除。
    - **信息密度差异**：语言是人类创造的高度语义化、信息密集的信号，预测少量缺失词已是困难任务；图像是自然信号，空间冗余大，必须使用 **高掩码率** 才能构成有意义的任务。
    - **解码器角色差异**：BERT 预测的是语义级别的词，解码器可以是简单的 MLP；MAE 重建的是像素，属于低语义层级，因此需要一个独立的解码器，其设计会影响表示的语义层级。
- 此外，BERT 编码器会处理 [MASK] token，而 MAE 编码器完全丢弃被遮盖的 patch。

Q7：***MAE 的掩码策略有哪些？哪种更好？***

- **随机掩码**（random）：均匀随机采样被遮盖的 patch，是默认选择，在高掩码率下效果最好。
- **块状掩码**（block-wise，BEiT 使用）：遮盖大块连续区域，掩码率高时任务过难，重建模糊。
- **网格掩码**（grid）：规则地每隔几个 patch 保留一个，任务过于简单（易插值），表示质量较差。
- 随机掩码的另一个好处是无规律，避免模型利用掩码模式中的捷径。

Q8：***MAE 对数据增强的依赖如何？***

- MAE 只需要简单的 **随机裁剪缩放 + 水平翻转** 即可取得很好效果，颜色抖动等强增强反而可能降低表现。
- 原因：**随机掩码本身就是一种强数据增强**，每轮迭代掩码都不同，为同一张图产生了大量不同的训练样本。
- 这与对比学习形成鲜明对比：SimCLR、BYOL 等方法 **严重依赖** 精心设计的增强（尤其是颜色失真与裁剪）来定义正样本对。

Q9：***MAE 的线性探测（linear probe）和微调（fine-tune）结果有何特点？***

- **微调表现很强**：MAE 预训练的 ViT 在 ImageNet 微调、COCO 检测、ADE20K 分割等任务中表现突出，并且随模型规模扩大持续提升（可扩展性好）。
- **线性探测相对较弱**：与 MoCo v3、DINO 等对比/蒸馏类方法相比，MAE 特征的线性可分性更差。
- 原因分析：MAE 学到的特征 **非线性程度更高**，语义信息分布在多层中，需要非线性层才能充分利用；像素重建目标也会让最后一层特征保留不少低层细节。
- 论文提出 **部分微调**（partial fine-tuning）：只微调最后一两个 Transformer 块，精度就能大幅超过线性探测，说明线性探测并不能全面反映表示质量。

Q10：***MAE 与 BEiT 有什么区别？***

- **BEiT**（Bao et al., 2021）：
    - 先用 DALL-E 的 **dVAE** 将图像离散化为视觉 token，预训练目标是预测被遮盖位置的 **视觉 token 类别**（分类任务）；
    - 使用 **块状掩码**，掩码率约 40%；
    - 编码器处理全部 token（被遮盖位置替换为 mask token）。
- **MAE**：
    - 直接重建 **像素**（MSE 回归），无需预训练分词器；
    - 随机掩码 75%；
    - 编码器只处理可见 patch，计算更高效。
- 结论：MAE 更简单、更高效，说明像素目标配合合适的设计（高掩码率、归一化像素）就足够了。BEiT v2 后来改用 CLIP 等教师蒸馏出的语义 tokenizer 来提升目标的语义性。

Q11：***MAE 与 SimMIM 有什么区别？***

- SimMIM（Xie et al., 2021）与 MAE 几乎同时提出，同样直接回归原始像素，但：
    - **编码器处理 mask token**，即完整序列都进入编码器，因此可以直接用于 Swin 等层级结构（MAE 的丢 token 方式与窗口注意力不易兼容）；
    - 预测头是 **一个线性层**，没有独立的解码器；
    - 使用 **L1 损失**；
    - 使用较大的掩码 patch（如 32×32）配合随机掩码，以适当的掩码率取得好效果。
- 代价：编码器需处理全部 token，预训练计算量比 MAE 大。

Q12：***MAE 与对比学习方法相比有哪些优缺点？***

- **MAE 的优点**：
    - 不需要负样本、不需要大 batch、不依赖强数据增强；
    - 编码器只处理部分 token，训练高效，**可扩展到超大模型**；
    - 微调与密集预测任务（检测、分割）表现好，保留了丰富的空间细节。
- **MAE 的缺点**：
    - 线性探测与少样本、kNN 等直接使用冻结特征的场景较弱；
    - 像素重建目标会让模型花容量建模低层细节；
    - 预训练与推理时输入分布不同（预训练只见 25% 的 patch）。
- **对比学习**（SimCLR、MoCo、DINO）学到的全局特征语义性和线性可分性更强，但依赖增强设计，偏向图像级的不变性，在密集任务上不一定占优。
- 两者可以结合：iBOT、CMAE 等结合了掩码建模与对比/自蒸馏目标。

Q13：***VideoMAE 如何将 MAE 扩展到视频？***

- 视频在 **时间维度上冗余更高**（相邻帧几乎相同），因此 VideoMAE（Tong et al., 2022）使用 **更高的掩码率（90%–95%）**。
- 采用 **管道掩码（tube masking）**：同一空间位置在所有帧上一起被遮盖，防止模型从相邻帧的同一位置直接"复制"信息，避免信息泄漏。
- 将视频切为时空立方体（如 2×16×16）作为 token，配合时空联合注意力。
- 由于掩码率极高，编码器计算量大幅降低，在中等规模的视频数据集上也能有效预训练，数据效率较高。

Q14：***MAE 如何扩展到音频等其他模态？***

- **Audio-MAE**（Huang et al., 2022）：将音频转为 **梅尔频谱图**，把频谱图当作图像切 patch，高比例掩码后重建；解码器使用局部窗口注意力，因为频谱图的时间/频率局部相关性很强。
- 多模态版本：**MultiMAE** 同时掩码 RGB、深度、语义分割等多种模态，进行跨模态重建；还有将掩码建模用于点云（Point-MAE）、图（GraphMAE）等的工作。
- 共同点：模态冗余越高，可承受的掩码率越高。

Q15：***MAE 的预训练目标有哪些改进变体？***

- **MaskFeat**：重建被遮盖区域的 **HOG 特征**，HOG 对光照变化更不敏感；
- **data2vec**：预测 EMA 教师网络在 **完整输入** 上的多层平均特征，统一了视觉、语音与文本；
- **iBOT**：在掩码 token 上做在线 tokenizer 的自蒸馏，结合 DINO 式的全局目标；
- **I-JEPA**：在表示空间中预测目标块的嵌入，而不是重建像素，使学到的特征更具语义性；
- **EVA、BEiT v2**：以 CLIP 特征作为重建目标，引入语言对齐的语义。
- 趋势：从低层 **像素目标** 走向更高层的 **特征/语义目标**。

Q16：***为什么说 MAE 是"可扩展的（scalable）"？***

- **计算可扩展**：编码器只处理 25% 的 token，训练大模型（ViT-L、ViT-H）的成本显著降低；
- **性能可扩展**：随着模型变大，MAE 的微调精度持续提升，较少出现小数据集上大模型过拟合的问题，使 ViT-H 这类大模型仅用 ImageNet-1k 数据即可有效训练；
- **方法简单**：无需负样本、动量编码器、分词器或复杂增强，易于在大规模场景中复现与扩展。
