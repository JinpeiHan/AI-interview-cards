# Q-learning

# 初级:

Q1：**怎样定义强化学习中的状态？**

- **状态是对环境当前情况的描述，要包含做决策所需的信息；定义状态本质上和监督学习里的特征工程是同一个问题。**
- 简单问题可以把状态离散化，但维度一高就会遇到维度灾难。
- 复杂问题通常用状态表示学习（SRL），把状态学成一个特征向量（如用神经网络从图像中提取）。

Q2：**Q Learning 中的*Alpha*和*Gamma*参数代表什么？**

- **Alpha 是学习率，决定新经验覆盖旧 Q 值的程度；Gamma 是折扣因子，决定智能体多看重未来奖励。**
- Alpha 取 0–1：越大越快接受新估计但越不稳定，通常随着学习推进逐渐减小。
- Gamma 取 0–1：接近 0 时只看即时奖励，很短视；接近 1 时远期奖励和眼前一样重要，但在无终止任务中回报可能发散、学习更难。

Q3：**怎么判断 Q-Learning 算法何时收敛？**

- **实践中看学习曲线（回报或 Q 值变化）是否变平；理论上，表格 Q-learning 要保证收敛到最优，需要满足两个条件。**
- 学习率要逐渐趋于 0 但不能太快：学习率之和发散、平方和收敛，例如 1, 1/2, 1/3, …。
- 每个状态-动作对都要被无限次访问，即策略对每个动作都有非零概率，实践中用 ε > 0 的 ε-greedy 保证。
- 如果探索不够，曲线变平也可能只是过早收敛到次优策略。

引用：[https://stats.stackexchange.com/](https://stats.stackexchange.com/)

Q4：**如何理解epsilon greedy 算法？**

- **ε-greedy 以概率 ε 随机选动作（探索），以概率 1−ε 选当前 Q 值最大的动作（利用），用来平衡探索与利用。**
- 刚开始 Q 表几乎是空的，完全按它走容易出错或绕圈，所以要多随机走走、接触更多状态。
- 随着学习推进，用衰减函数逐渐降低 ε，越来越多地按学到的策略执行。

引用：[https://blog.csdn.net/Gin07](https://blog.csdn.net/Gin07)

Q5：**解释Q-learning算法**

- **Q-learning 学习一个动作价值函数 Q(s,a)：在状态 s 做动作 a、之后一直按最优方式行动所能得到的期望折扣回报；有了它，每个状态下选 Q 值最大的动作就是最优策略。**
- 它基于贝尔曼最优方程：当前的最优价值等于即时奖励加上下一状态最优价值的折扣。
- 每走一步，就用"即时奖励 + 折扣后的下一状态最大 Q 值"作为目标，把当前 Q 值往这个目标挪一点。
- 它是无模型、off-policy 的：目标里取的是 max，与实际执行的动作无关。
- 核心公式：$Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right]$

Q6：**分别写出基于状态值函数的贝尔曼方程以及基于状态-动作值函数的贝尔曼方程。**

- **两个方程都在说：当前价值 = 即时奖励 + 折扣后的下一步价值的期望；区别在于 V 要对当前动作按策略求期望，Q 已经给定了当前动作，只对下一个动作按策略求期望。**
- 状态值函数：$V^{\pi}(s)=\mathbb{E}_{a\sim\pi}\mathbb{E}_{s'}\left[r+\gamma V^{\pi}(s')\right]$
- 状态-动作值函数：$Q^{\pi}(s,a)=\mathbb{E}_{s'}\left[r+\gamma\,\mathbb{E}_{a'\sim\pi}Q^{\pi}(s',a')\right]$

Q7：**讲一下SARSA，最好可以写出其Q(s,a)的更新公式。另外，它是on-policy还是off-policy，为什么？**

- **SARSA 和 Q-learning 很像，但更新目标用的是下一步实际要执行的动作 a′ 的 Q 值，而不是最大 Q 值，所以它是 on-policy 的。**
- 每次更新需要一个五元组 (s, a, r, s′, a′)，名字就是这么来的。
- a′ 由当前策略（如 ε-greedy）选出，估计的是当前策略自身的 Q 值，产生数据和被评估的是同一个策略。
- 因此 SARSA 更"保守"，会把探索带来的风险算进去。
- 核心公式：$Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma Q(s',a')-Q(s,a)\right]$

Q8：**请问value-based和policy-based方法的区别是什么？**

- **基于价值的方法先学价值函数，再间接导出策略（如取 Q 最大的动作）；基于策略的方法直接把策略参数化，用策略梯度等方法优化回报。**
- 策略形式：价值方法通常得到确定性策略；策略方法可以学随机策略。
- 动作空间：价值方法要对动作取 max，适合离散动作，连续动作离散化后难选粒度；策略方法可直接输出连续动作（如高斯分布）。
- 收敛性：价值方法在函数近似加自举时可能不收敛；策略梯度收敛性更好，但方差大。
- 顺带：策略迭代是"策略评估 + 策略改进"两层循环，价值迭代直接迭代最优价值函数，没有单独的策略改进步。

引用：《Easy RL》

# 中级:

Q9：**能否简单说下动态规划、蒙特卡洛和时序差分的异同点？**

- **三者都是把价值估计往某个目标值上更新；区别在于目标怎么来：DP 用已知模型对所有后继状态求期望，MC 用整个回合的真实回报，TD 用一步奖励加下一状态的估计值。**
- DP：需要环境模型，自举，不采样。
- MC：无模型，不自举，必须等回合结束，估计无偏但方差大。
- TD：无模型，采样加自举，可单步在线更新，有偏但方差小，通常收敛更快。
- n 步 TD 和 TD(λ) 介于 MC 和一步 TD 之间，用来权衡偏差和方差。

Q10：**简述DQN？**

- **DQN 用深度神经网络来近似 Q 函数：输入状态（如 Atari 的 4 帧画面），输出每个离散动作的 Q 值，用 TD 误差的均方作为损失训练，在很多 Atari 游戏上达到人类水平。**
- 两个关键技巧：经验回放（从缓冲区随机采样小批量）和目标网络（每隔若干步从主网络复制参数）。
- 用 ε-greedy 探索，ε 逐渐衰减；实践中还用奖励裁剪、Huber 损失、跳帧等技巧。
- 核心公式：$L(\theta)=\mathbb{E}\left[\left(r+\gamma\max_{a'}Q(s',a';\theta^-)-Q(s,a;\theta)\right)^2\right]$

Q11：**DQN中的两个技巧：目标网络(target network)和经验回放(experience replay)的具体作用是什么呢？**

- **目标网络让回归目标在一段时间内固定不动，避免"追逐移动的目标"导致振荡发散；经验回放打乱样本的时间相关性并重复利用数据，让训练更稳定、更省样本。**
- 目标网络：每隔 C 步硬拷贝，或每步软更新一点，把 RL 近似成一系列监督回归问题。
- 经验回放：随机采样让数据更接近独立同分布，满足 SGD 假设，也平滑了策略变化带来的分布波动。
- 经验回放要求算法是 off-policy 的（缓冲区数据来自旧策略），Q-learning 正好满足。
- 改进版优先经验回放（PER）按 TD 误差大小采样，并用重要性采样权重纠偏。

Q12：**DQN（Deep Q-learning）和Q-learning有什么异同点？**

- **两者都是基于价值、无模型、off-policy 的 TD 方法，用同样的"奖励 + 折扣最大 Q"目标；区别在于 Q-learning 用表格存 Q 值，DQN 用神经网络近似 Q 函数。**
- 表格只能处理小规模离散状态；神经网络能处理图像等高维状态，并在相似状态间泛化。
- Q-learning 逐个表项更新；DQN 对 TD 损失做梯度下降，更新全部参数。
- 函数近似 + 自举 + off-policy 是"致命三元组"，容易发散，所以 DQN 要加经验回放和目标网络；表格版有收敛保证，DQN 没有。
- 两者都要对动作取 max，只适用于离散动作。

Q13：**DQN都有哪些变种？**

- **主要变种分别针对高估、结构、采样、探索和回报建模，Rainbow 把其中六种组合在一起。**
- Double DQN：解耦动作选择和评估，缓解高估；Dueling DQN：把 Q 拆成状态价值和优势。
- 优先经验回放：按 TD 误差优先采样；多步 DQN：用 n 步回报加快奖励传播。
- Noisy DQN：在权重里加可学习噪声代替 ε-greedy；分布式 DQN（C51、QR-DQN、IQN）：学习回报的完整分布。
- 其他：DRQN（加 LSTM 处理部分可观测）、Ape-X / R2D2（大规模分布式训练）。

Q14：**简述Double DQN(双深度Q网络)原理？**

- **DQN 用同一组带噪声的估计既选动作又评估动作，取 max 会系统性地高估 Q 值；Double DQN 把两者解耦：用在线网络选动作，用目标网络评估这个动作的价值。**
- 高估的原因是"噪声估计的最大值"的期望大于"真实值的最大值"，而且会通过自举不断累积。
- 思想来自 Double Q-learning（两个 Q 表互相评估），Double DQN 直接复用已有的目标网络，几乎没有额外开销。
- 核心公式：$y=r+\gamma\,Q\left(s',\arg\max_{a'}Q(s',a';\theta);\theta^-\right)$

Q15：**请问Dueling DQN(竞争深度Q网络)模型有什么优势？**

- **Dueling DQN 把网络后端拆成两支，一支估计状态价值 V(s)，一支估计每个动作的优势 A(s,a)，再合成 Q；这样在动作影响不大的状态下也能高效地学到状态本身好不好。**
- 比如赛车游戏前方没车时选什么动作都差不多，网络可以直接学 V，而不必为每个动作单独学。
- 每次更新都会更新 V，相当于所有动作共享信息，样本效率更高，动作多且价值相近时尤其明显。
- 为了让 V 和 A 可辨识，合成时把优势减去其均值。
- 只改网络结构，可以直接和 Double DQN、PER 等组合。

# 高级:

Q16：**请问Actor - Critic有何优点？**

- **Actor-Critic 用 Actor（策略网络）选动作、Critic（价值网络）评估动作好坏并指导 Actor 更新，兼具策略梯度和价值方法的优点。**
- 相比 REINFORCE：用 Critic 估计的优势/TD 误差代替蒙特卡洛回报，方差大大降低，还能单步更新，学得更快。
- 相比 DQN：直接优化参数化策略，能处理连续动作、学随机策略，策略随参数平滑变化。
- 代价是 Critic 有偏差、两个网络耦合，训练对超参敏感；常见算法有 A2C/A3C、PPO、DDPG、TD3、SAC。
- 核心公式：$\nabla_\theta J\approx\mathbb{E}\left[\nabla_\theta\log\pi_\theta(a|s)\,A(s,a)\right]$

Q17：**简述一下DDPG算法？**

- **DDPG 是面向连续动作的 Actor-Critic 算法，可以看成"DQN + 确定性策略梯度"：Actor 直接输出一个确定性动作，Critic 估计这个动作的 Q 值，Actor 沿着让 Q 变大的方向更新。**
- Critic 像 DQN 一样最小化 TD 误差，目标值由目标 Actor 和目标 Critic 计算。
- 借用了 DQN 的经验回放和目标网络，目标网络用软更新（τ 约 0.005）。
- 探索靠在确定性动作上加噪声（原文用 OU 噪声，高斯噪声也行）。
- DDPG 也有 Q 值高估、对超参敏感的问题，TD3 用双 Critic 取最小、延迟更新 Actor、目标策略平滑来改进。

Q18：**请问DDPG是on-policy还是off-policy，为什么？**

- **DDPG 是 off-policy 的：收集数据用的是加了噪声的行为策略，而学习和评估的是不带噪声的确定性目标策略，两者不同。**
- Critic 目标里的下一动作由目标策略给出，而不是数据里实际执行的动作，所以更新不依赖数据由谁产生（和 Q-learning 取 max 是一个道理）。
- 确定性策略梯度不需要对动作积分，也就不需要重要性采样，可以直接用经验回放里旧策略的数据训练，这正是 off-policy 的标志。
