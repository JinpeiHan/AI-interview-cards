# CNN

Q1：***CNN和RNN有什么区别？什么时候使用它们？***

- **CNN 擅长处理有空间局部结构的数据（如图像），利用平移不变性：目标出现在哪里都能检测到同样的特征；RNN 带有记忆状态，适合顺序很重要的序列数据。**
- CNN 典型场景：图像分类、检测、分割。
- RNN 典型场景：语音、文本、视频帧、各类时间序列。

Q2：***CNN怎样被用到时间序列预测中？***

- **把一段时间序列看成一维"图像"，用一维卷积沿时间轴自动提取局部模式，得到序列的特征表示再做预测。**
- 典型模型：TCN、WaveNet（因果卷积 + 空洞卷积，感受野随层数快速扩大）。
- 优点是可并行、对噪声较鲁棒，能提取信息丰富的深层特征。

Q3：***在CNN中，Max Pooling与Average Pooling的优缺点是什么？***

- **Max pooling 保留最强响应，更擅长提取纹理和显著特征；average pooling 保留整体信息，对背景保留更好。**
- 误差角度：max pooling 能减小卷积参数误差带来的均值偏移；average pooling 能减小邻域有限带来的估计方差。
- 识别类任务（如数字识别）一般用 max pooling。

Q4：***比较CNN和多层感知机MLP***

- **CNN 用局部连接和权重共享，参数远少于全连接的 MLP，并且保留了像素间的空间关系，更适合图像。**
- MLP 每个神经元连接上一层所有节点，参数冗余，难以做深。
- MLP 需要把输入拉平成向量，会丢失空间信息。
- MLP 可以看成 CNN 的特例：卷积核大小等于输入大小时，计算等价于全连接。

*Q5*： *****CNN*中的*全连接层*有什么作用？**  

- **全连接层相当于"分类器"：卷积和池化把数据映射到特征空间，全连接层把这些特征整合起来，映射到标签空间，交给最后的分类或回归。**

*Q6*：*****解释RELU激活函数在卷积神经网络中的意义*****

- **卷积本身是线性运算，叠多少层仍是线性的；ReLU 引入非线性，让网络能拟合复杂的图像特征。**
- 做法是逐像素把负值置零，通常接在每个卷积之后。
- 计算简单，正区间梯度为 1，缓解梯度消失。

Q7：***对于给定的图像输入尺寸、Filter Size、  Stride 和 Padding大小，feature map 的尺寸是多少？***

- **输出边长 = (输入边长 − 卷积核大小 + 2×padding) / stride + 1，向下取整。**
- 核心公式：$\lfloor (n-f+2p)/s \rfloor + 1$（n 为输入大小，f 为卷积核大小，p 为 padding，s 为 stride）

Q8：***解释Valid Paddding和Same Padding***

- **Valid padding 不补边，卷积核只在完全落在图像内时计算，输出会变小；same padding 在边缘补零，使输出尺寸与输入相同（stride=1 时）。**

Q9：****Pooling有哪些不同类型？说明他们的特点。****

- **常见的有 max、average 和 sum pooling，最常用的是 max pooling，因为它保留了最显著的特征。**
- Max pooling：取窗口内最大值，能抑制噪声。
- Average pooling：取窗口内平均值，更平滑。
- Sum pooling：取窗口内元素之和。

Q12：**解释flatten层在CNN中的角色和作用**

- **Flatten 把最后一层卷积/池化输出的多维特征图拉平成一个向量，作为后面全连接层的输入，用来学习特征中的非线性关系做分类。**

Q13：****列出池化层的超参数****

- **池化层的超参数是窗口大小 f、步长 s 和池化类型（max/average），没有可学习参数。**
- 核心公式：输入 $n_h\times n_w\times n_c$ 时，输出为 $((n_h-f)/s+1)\times((n_w-f)/s+1)\times n_c$

Q14：****解释CNN中“参数共享”和“稀疏连接”的意义****

- **两者都是为了大幅减少参数并利用图像的局部性：参数共享指同一个卷积核在整张图上滑动使用；稀疏连接指每个输出只依赖输入的一小块区域。**
- 参数共享的直觉：在图像某处有用的特征检测器（如边缘检测）在别处也有用，同时带来平移等变性。
- 稀疏连接的直觉：图像特征大多是局部的，不需要每个输出看全部输入。

Q15：**可以使用CNN执行降维操作吗？如果可以，CNN中哪个相关子层执行了降维操作？**

- **可以。主要由池化层做空间降维：通过窗口下采样缩小特征图的高和宽。**
- 另外，stride 大于 1 的卷积也能降低空间尺寸，1×1 卷积能降低通道数。

Q16：***3×3卷积与1×1卷积分别有什么作用？二者有什么区别？***

- **3×3 卷积看 3×3 邻域，负责提取空间局部特征（边缘、纹理）；1×1 卷积不看邻域，只在每个像素位置对通道做线性组合，负责改变通道数和融合通道信息。**
- 3×3：现代 CNN 最常用的核。VGG 指出两个 3×3 叠加的感受野等于一个 5×5，三个等于一个 7×7，但参数更少、非线性更多。
- 1×1：用于升降维（Inception、ResNet bottleneck 先降维再做 3×3，大幅省计算），后接激活还能在不改变感受野的情况下增加非线性（Network in Network），也是深度可分离卷积里的 pointwise 卷积。
- 参数量：3×3 是 $9C_{in}C_{out}$，1×1 是 $C_{in}C_{out}$，只有前者的 1/9。
- 参见：[深度学习基础](深度学习基础.md) Q15；[计算机视觉](计算机视觉.md) Q34

Q17：***Group Convolution（分组卷积）如何计算参数量？与普通卷积有什么区别？***

- **分组卷积把输入和输出通道各分成 g 组，每组独立卷积再拼接，参数量和计算量都降为普通卷积的 1/g。**
- 例子：k=3、输入输出都是 256 通道、g=8 时，普通卷积约 59 万参数，分组卷积约 7.4 万。
- 特例：g=1 就是普通卷积；g 等于通道数就是深度卷积（depthwise），再配 1×1 卷积就是 MobileNet 的深度可分离卷积。
- 应用：AlexNet 最早用于多 GPU 并行；ResNeXt 用它在相同计算量下增加宽度提升精度。
- 缺点：组间没有信息交流（ShuffleNet 用 channel shuffle 解决）；硬件上访存效率低，FLOPs 降了不一定同比例变快。
- 核心公式：$\text{参数量} = k\times k\times\frac{C_{in}}{g}\times C_{out}$
