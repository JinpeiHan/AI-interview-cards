# 图神经网络（GNN）

## 图基础

Q1：***图数据有哪些表示方式？邻接矩阵、度矩阵和拉普拉斯矩阵分别是什么？***

- **图通常用节点特征矩阵加一种连接结构来表示：邻接矩阵记录"谁和谁相连"，度矩阵记录每个节点有几条边，拉普拉斯矩阵由二者相减得到，用来衡量信号在图上是否平滑。**
- 邻接矩阵 $A$：有边为 1（带权图为边权），无向图对称。
- 度矩阵 $D$：对角阵，对角元是每个节点的度。
- 拉普拉斯矩阵 $L=D-A$ 半正定，常用对称归一化版本 $I-D^{-1/2}AD^{-1/2}$；0 特征值的个数等于连通分量数。
- 工程上大图几乎都用稀疏存储（边列表 `edge_index`、CSR），因为稠密邻接矩阵需要 $O(N^2)$ 内存。

Q2：***图学习有哪些任务层级？图级任务的 readout 怎么做？***

- **图任务分三层：节点级（如节点分类）、边级（如链接预测）和图级（如分子性质预测）。图级任务需要一个 readout 把所有节点表示汇总成一个图向量，而且它必须与节点顺序无关。**
- 节点级：直接拿最后一层节点表示接分类头。
- 边级：用两端节点表示打分，如内积、Hadamard 积或拼接后接 MLP。
- 图级 readout：常用 sum / mean / max 池化，sum 表达能力最强；也可以拼接每一层的 readout（GIN 做法），或用注意力池化、层次化池化（DiffPool、SAGPool）。

## 消息传递与经典模型

Q3：***什么是消息传递（Message Passing）框架？***

- **消息传递是大多数空域 GNN 的统一框架：每一层里，每个节点从邻居收集"消息"，用一个与顺序无关的函数聚合起来，再结合自己原来的表示更新成新表示。**
- 三个组件：消息函数、置换不变的聚合函数（sum/mean/max/attention）、更新函数（MLP、GRU 等）。
- 堆叠 $L$ 层，每个节点就能看到 $L$ 跳以内的邻居。
- 参数在所有节点间共享，与图大小无关；节点级输出对节点重排等变，加 readout 后图级输出不变。

```python
# PyG 风格的最简消息传递层
import torch
from torch_geometric.nn import MessagePassing

class SimpleConv(MessagePassing):
    def __init__(self, in_dim, out_dim):
        super().__init__(aggr="add")
        self.lin = torch.nn.Linear(in_dim, out_dim)

    def forward(self, x, edge_index):
        return self.propagate(edge_index, x=self.lin(x))

    def message(self, x_j):        # x_j: 源节点特征
        return x_j
```

Q4：***谱域 GNN 和空域 GNN 有什么区别？***

- **谱域 GNN 借助拉普拉斯矩阵的特征分解，在"图频域"上定义卷积；空域 GNN 直接在节点邻域上做聚合。GCN 是连接两者的桥梁，如今工业界和大多数新研究都用空域视角。**
- 早期谱方法需要特征分解（$O(N^3)$），滤波器不局部，且绑定在某一张图上，无法迁移到新图。
- ChebNet 用多项式近似滤波器，免去特征分解并且只作用于 $K$ 跳邻居；GCN 是它的一阶简化。
- 空域方法（GraphSAGE、GAT、GIN）天然局部、可采样做 mini-batch、支持归纳式学习，也更容易处理有向、异构和带边特征的图。
- 谱视角仍然有用：它解释了 GCN 为什么是低通滤波，以及为什么会过平滑。

Q5：***推导/解释 GCN 的传播公式 $H'=\sigma(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}HW)$***

- **GCN 的每一层先做线性变换，再按度归一化地把邻居和自身的特征加权平均，最后过一个非线性。它来自 ChebNet 的一阶近似，再加上"加自环 + 重归一化"让多层堆叠数值稳定。**
- 加自环（$\tilde A=A+I$）：聚合时保留节点自身信息。
- 对称归一化：防止高度节点的特征尺度爆炸，同时兼顾源和目标两端的度。
- 本质是低通滤波，让相邻节点特征越来越像，这也是过平滑的根源。
- 局限：直推式、全图训练占用内存大、邻居权重由度固定而不是学出来的。

Q6：***GraphSAGE 的核心思想是什么？为什么它是归纳式的？***

- **GraphSAGE 的核心是"采样 + 聚合"：每层只采样固定数量的邻居，用聚合函数汇总，再与节点自身表示拼接后变换。它学的是一个"怎么从邻居聚合"的函数，而不是每个节点一个嵌入，所以能直接用到新节点、新图上，这就是归纳式。**
- 固定扇出（如 25、10）让计算量与图规模无关，支持 mini-batch 训练。
- 聚合器可选 Mean、LSTM、Pooling（MLP 后逐元素取 max）。
- 自身与邻居拼接而不是相加，相当于跳跃连接，能缓解过平滑。
- 适合用户、商品不断新增的工业场景；也支持基于随机游走共现和负采样的无监督训练。

Q7：***GAT 如何计算注意力系数？多头注意力有什么作用？***

- **GAT 对每条边，把两端节点变换后的特征拼起来，用一个小的打分向量加 LeakyReLU 算出分数，再只在该节点的邻居之间做 softmax 得到注意力权重，最后按权重聚合邻居。多头注意力用多个独立的头，让训练更稳定、表达更丰富。**
- 只在邻居上做 softmax（masked attention），复杂度与边数成正比。
- 多头：中间层把各头拼接，输出层取平均。
- 相比 GCN，邻居权重由特征自适应学出（而不是由度决定），更有解释性，也天然归纳式。
- 追问点：GATv2 指出原 GAT 是"静态注意力"（所有节点对邻居的排序都一样），把 LeakyReLU 移到打分向量之前，变成动态注意力。

Q8：***GIN 是什么？GNN 的表达能力与 WL 测试有什么关系？***

- **消息传递 GNN 区分不同图的能力最多和 1-WL 图同构测试一样强；只有当聚合和更新都是单射时才能达到这个上限。GIN 就是按这个要求设计的：用 sum 聚合加 MLP 更新，因此达到了 1-WL 的上限。**
- 1-WL 测试：反复把每个节点的颜色更新为"自身颜色 + 邻居颜色多重集"的哈希，最终颜色直方图不同则两图不同构。
- mean 和 max 不是单射（例如区分不了 $\{a,b\}$ 和 $\{a,a,b,b\}$），sum 可以。
- 1-WL 的局限：区分不了某些正则图，也数不了三角形或环；可以用高阶 GNN、子图 GNN、位置编码或随机特征、结构特征来突破。
- 表达能力强不等于泛化好，实际节点分类里 GCN/SAGE 常和 GIN 差不多。
- 核心公式：$h_v'=\mathrm{MLP}\big((1+\epsilon)h_v+\sum_{u\in\mathcal N(v)}h_u\big)$

## 深层 GNN 的问题

Q9：***什么是过平滑（over-smoothing）？如何缓解？***

- **过平滑是指层数加深后，所有节点的表示越来越像，最终无法区分，性能下降。原因是 GCN 类模型本质是低通滤波，反复对邻居求平均会把差异抹平，所以 GCN 通常 2–3 层最好。**
- 残差和跳跃连接：ResGCN、JKNet（组合各层输出）、GCNII（初始残差，每层都混入一部分初始特征）。
- 把传播和变换解耦：APPNP（个性化 PageRank 传播）、SGC。
- 归一化与正则：PairNorm、DropEdge。
- 自身与邻居拼接（GraphSAGE）或门控更新；可以用 Dirichlet 能量等指标度量平滑程度。

Q10：***什么是过挤压（over-squashing）？和过平滑有什么区别？***

- **过挤压是指远处节点的信息很难传过来：随着层数增加，感受野内的节点数指数增长，却要被压进一个固定维度的向量，图拓扑中的瓶颈（如桥边、树状结构）尤其严重。过平滑是"所有表示变得一样"的深度问题，过挤压是"远处信息过不来"的拓扑问题。**
- 后果：需要长程依赖的任务效果差。
- 缓解：图重连（加边、基于曲率的重连、最后一层全连接）、加连接所有节点的虚拟节点、用 Graph Transformer 做全局注意力。
- 增大隐藏维度能缓解但不能根治；两者之间存在一定权衡。

Q11：***训练深层 GNN 还有哪些常用技巧？***

- **主要靠残差/稠密连接、归一化、随机删边等正则化，以及"传播与变换解耦"；但很多时候根本不需要很深，2–3 层加预计算的多跳特征就够了。**
- 结构：残差、初始残差、稠密连接（DeepGCN 可训练到 56 层以上），JK 连接让每个节点自适应选择感受野。
- 归一化与正则：BatchNorm、LayerNorm、PairNorm；DropEdge、DropNode、Dropout。
- 解耦：先用 MLP 做特征变换，再做多步无参数传播（APPNP、SGC、SIGN），既深又快。
- 训练习惯：较小学习率、weight decay、早停；小图数据集方差大，要报告多随机种子的均值和标准差。

## 任务与训练

Q12：***链接预测怎么做？负采样有哪些策略？***

- **链接预测先用 GNN 得到节点表示，再用解码器（内积或 MLP）给节点对打分，用真实边作正样本、采样的非边作负样本，以二分类或排序损失训练。关键是负样本要选得好，同时消息传递用的图里不能包含要预测的边。**
- 损失：BCE、BPR、InfoNCE；评估用 AUC、Hits@K、MRR、Recall@K/NDCG@K。
- 防泄露：把边切成消息边和监督边，时序图按时间切分。
- 负采样：均匀随机（简单但大多太容易）、按度/流行度采样、批内负样本（需做流行度偏差校正）、困难负样本（高分但未交互的物品，可由易到难课程式加入）。
- 追问：SEAL 等基于子图的方法能捕捉公共邻居等结构，弥补纯节点嵌入的不足。

Q13：***DeepWalk 和 node2vec 是怎么工作的？与 GNN 有何区别？***

- **DeepWalk 在图上做随机游走得到节点序列，把它当作"句子"，用 Skip-gram 学嵌入，让经常共现的节点嵌入相近；node2vec 把游走改成有偏的，用两个参数控制更偏 BFS 还是 DFS。和 GNN 的根本区别是：它们是每个节点一个查表向量的浅层嵌入。**
- node2vec：偏 DFS 时捕捉社区（同质性），偏 BFS 时捕捉结构角色相似性。
- 这类方法理论上等价于隐式的矩阵分解。
- 与 GNN 对比：随机游走嵌入是直推式的、参数量随节点数增长、不用节点特征；GNN 共享参数、能利用特征、可以归纳。
- 工业用途：做预训练嵌入或召回特征，例如 EGES 在此基础上加入商品侧信息来解决冷启动。

Q14：***什么是异构图？如何处理？***

- **异构图有多种节点类型和边类型（如用户–商品–店铺）。处理思路是让模型区分类型：要么沿元路径建模，要么给每种关系单独的参数，再用注意力组合。**
- 元路径：如 U-I-U，metapath2vec 沿元路径做随机游走。
- R-GCN：每种关系一个权重矩阵；关系多时用基分解共享参数，防止过参数化。
- HAN：元路径内的节点级注意力 + 元路径之间的语义级注意力。
- HGT：按节点/边类型参数化的 Transformer 式注意力；工程上可用 PyG 的 `HeteroData`、DGL 的 `HeteroGraphConv`。

## 规模化与工业应用

Q15：***GNN 如何扩展到亿级节点的大图？***

- **核心问题是全图训练放不进显存，而 mini-batch 时多层邻居会指数爆炸。解决办法是采样（采邻居、按层采样或采子图）、把传播预先离线算好，再配合分布式系统和特征缓存。**
- 节点级采样：GraphSAGE 固定扇出；PinSage 用随机游走选重要邻居。层级采样：FastGCN、LADIES。
- 子图采样：ClusterGCN 先划分成簇，每个 batch 只训练几个簇的子图；GraphSAINT 随机采样子图并做无偏归一化。
- 预计算/解耦：SGC、SIGN 离线算好多跳特征，训练时只是 MLP；GNNAutoScale 复用历史嵌入。
- 系统层面：图分区 + 分布式采样、热点特征缓存、CPU/GPU 协同，推理时逐层全图计算避免重复。

Q16：***PinSage 有哪些关键设计？***

- **PinSage 是 Pinterest 在 30 亿节点图上落地的 GraphSAGE 变体，关键设计是：用随机游走选重要邻居并加权聚合、CPU 采样与 GPU 计算流水线并行、由易到难的困难负样本训练，以及用 MapReduce 批量生成嵌入供 ANN 召回。**
- 邻域：从节点出发做短随机游走，取访问次数最多的 Top-T 节点作邻居，访问计数作为聚合权重。
- 训练：生产者–消费者式 mini-batch，CPU 负责采样和取特征，GPU 负责计算。
- 负样本：取 PageRank 排名中段的物品作为困难负样本，逐轮增加比例，配合 max-margin 排序损失。
- 推理：MapReduce 避免重复计算，全量嵌入放进 ANN 索引。

Q17：***GNN 在推荐系统中如何应用？LightGCN 为什么去掉了特征变换和非线性？***

- **推荐可以建模成用户–物品二部图，多跳连接（用户→物品→相似用户→物品）就是协同过滤信号，GNN 用消息传递把它编码进嵌入。LightGCN 发现在只有 ID 嵌入、没有语义特征的协同过滤里，特征变换和非线性不但没用还让训练更难，所以只保留归一化的邻居聚合，再把各层嵌入加权求和。**
- NGCF 是带特征变换和非线性的前身；LightGCN 唯一可训练的参数是第 0 层的 ID 嵌入，用 BPR 损失训练。
- 各层嵌入组合起到类似残差的作用，缓解过平滑。
- 后续：SGL、SimGCL 加对比学习改善长尾，UltraGCN 用约束损失近似无限层。
- 落地：多用于召回（ANN 检索 GNN 嵌入）或给精排提供特征；难点是动态更新、冷启动和延迟，常离线算嵌入、天级/小时级更新。

Q18：***GNN 在金融风控/反欺诈中如何应用？有哪些难点？***

- **把用户、设备、IP、银行卡、商户作为节点，把交易、登录、共用设备作为边，构成异构图。欺诈者往往成团伙、共享设备和 IP，图结构能暴露单看个体特征发现不了的关联，可用于识别欺诈账户、欺诈交易和团伙。**
- 代表方法：GEM（异构设备图）、CARE-GNN / PC-GNN（处理伪装和类别不平衡）、时序 GNN（TGN、TGAT）。
- 异质性：欺诈者会故意连接正常用户伪装，需要邻居筛选或高通滤波（H2GCN、FAGCN）。
- 极度类别不平衡与对抗演化：用重采样、focal loss，持续训练并按时间切分验证。
- 实时性与可解释性：常用离线图嵌入 + 实时特征；监管要求解释，可用 GNNExplainer 展示子图证据。

Q19：***什么是 Graph Transformer？与消息传递 GNN 相比有什么优缺点？***

- **Graph Transformer 把节点当作 token 做全局自注意力，一层就能连接任意两个节点，从而缓解过挤压并突破 1-WL 限制。但 Transformer 本身看不到边，所以关键是把图结构注入进去；代价是 $O(N^2)$ 的计算量。**
- 注入结构：拉普拉斯或随机游走位置编码；Graphormer 用度、最短路距离和边信息做注意力偏置。
- 混合架构：GraphGPS 每层 = 局部消息传递 + 全局注意力 + FFN，是常用框架。
- 缺点：大图需要线性或稀疏注意力（Performer、Exphormer、SGFormer）；小数据容易过拟合，依赖好的位置编码。
- 适用：分子等小图的图级任务、长程依赖任务；大规模节点分类中，调好的经典 GNN 仍是强基线。

Q20：***同质性（homophily）假设是什么？在异质图上 GNN 怎么改？***

- **同质性是指相连的节点往往标签相同、特征相似，GCN 这类低通模型默认了这一点。在异质图（如反欺诈、约会网络）上，对邻居求平均会把信号搅混，效果甚至不如 MLP，所以要让模型能区分自身和邻居、看更远的邻居，或学会"高通"地看差异。**
- 分离自身与邻居表示（拼接而不是相加），如 H2GCN。
- 多跳聚合：2 跳邻居可能反而更同质。
- 自适应滤波：FAGCN、GPR-GNN 学习可以为负的滤波系数；或用带符号/门控的消息。
- 重新构图（如基于特征相似度的 kNN 图）；实操上先测同质率，并始终拿 MLP 作基线。
- 核心公式（边同质率）：$h=\frac{|\{(u,v)\in E:y_u=y_v\}|}{|E|}$

Q21：***GNN 常用的框架和工程实践有哪些？***

- **主流框架是 PyTorch Geometric（PyG）和 DGL，大规模分布式有 GraphLearn、GraphScope、DGL Distributed。工程上最重要的是先做强基线、严格防数据泄露，再决定 GNN 是否值得上。**
- 用稀疏算子（`scatter`、SpMM）和 CSR 加速邻居采样。
- 先做 MLP / LightGBM + 图统计特征的基线，再看 GNN 的增益。
- 数据切分防泄露：按时间切分，链接预测分开消息边和监督边；小数据集多种子重复实验。
- 上线：离线批量生成嵌入 + ANN 检索，或实时子图采样 + 低延迟推理服务。
