# 图神经网络（GNN）

## 图基础

Q1：***图数据有哪些表示方式？邻接矩阵、度矩阵和拉普拉斯矩阵分别是什么？***

- 图 $G=(V,E)$，$|V|=N$ 个节点，节点特征矩阵 $X\in\mathbb{R}^{N\times d}$。
- **邻接矩阵** $A\in\{0,1\}^{N\times N}$：$A_{ij}=1$ 表示存在边 $(i,j)$；带权图中为边权。无向图 $A$ 对称。
- **度矩阵** $D=\mathrm{diag}(d_1,\dots,d_N)$，$d_i=\sum_j A_{ij}$。
- **拉普拉斯矩阵**：
    - 组合拉普拉斯 $L=D-A$
    - 对称归一化 $L_{sym}=I-D^{-1/2}AD^{-1/2}$，特征值位于 $[0,2]$
    - 随机游走归一化 $L_{rw}=I-D^{-1}A$
- $L$ 半正定，$x^\top Lx=\frac{1}{2}\sum_{i,j}A_{ij}(x_i-x_j)^2$，衡量信号在图上的**平滑度**；0 特征值的重数 = 连通分量数。
- 工程上大图几乎都用**稀疏存储**（COO 边列表 `edge_index`、CSR），因为 $A$ 极其稀疏，稠密存储 $O(N^2)$ 不可行。

Q2：***图学习有哪些任务层级？图级任务的 readout 怎么做？***

- **节点级**：节点分类/回归（如论文分类、用户风险识别），直接用最后一层节点表示 $h_v^{(L)}$ 接分类头。
- **边级**：链接预测、边分类（如推荐中用户-物品是否交互、交易是否欺诈），用 $f(h_u,h_v)$，如内积、拼接后 MLP、Hadamard 积。
- **图级**：图分类/回归（如分子性质预测），需要 **readout（池化）** 把节点集合聚合为图向量：
    - 简单置换不变池化：$h_G=\sum_v h_v$ / mean / max；sum 表达能力最强（能区分多重集大小）
    - 每层 readout 拼接（如 GIN 做法）：$h_G=\Vert_{l}\,\mathrm{SUM}(\{h_v^{(l)}\})$
    - 注意力池化、Set2Set、层次化池化（DiffPool、SAGPool、TopK pooling）
- **readout 必须是置换不变的**，因为节点编号是任意的。

## 消息传递与经典模型

Q3：***什么是消息传递（Message Passing）框架？***

- 绝大多数空域 GNN 可统一为 **MPNN**（Gilmer et al., 2017）：
$$m_v^{(l)}=\bigoplus_{u\in\mathcal{N}(v)}\phi^{(l)}\big(h_v^{(l-1)},h_u^{(l-1)},e_{uv}\big)$$
$$h_v^{(l)}=\psi^{(l)}\big(h_v^{(l-1)},m_v^{(l)}\big)$$
- 三要素：**消息函数** $\phi$、**置换不变的聚合函数** $\bigoplus$（sum/mean/max/attention）、**更新函数** $\psi$（MLP、GRU 等）。
- $L$ 层 GNN 的感受野是 **$L$ 跳邻居**。
- 性质：对节点重排**置换等变**（节点级输出），加 readout 后**置换不变**（图级输出）；参数在所有节点间共享，与图大小无关。

```python
# PyG 风格的最简消息传递层
import torch
from torch_geometric.nn import MessagePassing

class SimpleConv(MessagePassing):
    def __init__(self, in_dim, out_dim):
        super().__init__(aggr="add")
        self.lin = torch.nn.Linear(in_dim, out_dim)

    def forward(self, x, edge_index):
        return self.propagate(edge_index, x=self.lin(x))

    def message(self, x_j):        # x_j: 源节点特征
        return x_j
```

Q4：***谱域 GNN 和空域 GNN 有什么区别？***

- **谱域**：基于图信号处理。对 $L_{sym}=U\Lambda U^\top$ 做特征分解，图傅里叶变换 $\hat x=U^\top x$，图卷积定义为 $g_\theta * x=U g_\theta(\Lambda)U^\top x$。
    - Spectral CNN（Bruna 2014）：直接学习 $g_\theta(\Lambda)$，需特征分解 $O(N^3)$，非局部化，且依赖特定图结构，无法迁移到新图。
    - **ChebNet**：用 $K$ 阶切比雪夫多项式近似 $g_\theta(\Lambda)\approx\sum_{k=0}^{K}\theta_k T_k(\tilde\Lambda)$，避免特征分解，滤波器是 $K$ 跳**局部化**的。
    - **GCN**：ChebNet 取 $K=1$ 并进一步简化得到。
- **空域**：直接在节点邻域上定义聚合（GraphSAGE、GAT、GIN、MPNN）。
    - 优点：天然局部、可批处理/采样、支持**归纳式**学习和有向/异构/带边特征图，更易扩展。
- 结论：GCN 是两者的桥梁；工业界与新研究几乎都用空域视角；谱域视角在分析低通滤波、过平滑时依然有用。

Q5：***推导/解释 GCN 的传播公式 $H'=\sigma(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}HW)$***

- 来源：ChebNet 一阶近似，设 $\lambda_{max}\approx2$，$K=1$：$g_\theta * x\approx\theta_0x+\theta_1(L-I)x=\theta_0x-\theta_1D^{-1/2}AD^{-1/2}x$；令 $\theta=\theta_0=-\theta_1$ 得 $\theta(I+D^{-1/2}AD^{-1/2})x$。
- **重归一化技巧**：$I+D^{-1/2}AD^{-1/2}$ 特征值在 $[0,2]$，多层堆叠会数值不稳定，于是改用 $\tilde A=A+I$（加自环）、$\tilde D_{ii}=\sum_j\tilde A_{ij}$：
$$H^{(l+1)}=\sigma\big(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}H^{(l)}W^{(l)}\big)$$
- 节点视角：$h_v'=\sigma\Big(\sum_{u\in\mathcal{N}(v)\cup\{v\}}\frac{1}{\sqrt{\tilde d_u\tilde d_v}}W h_u\Big)$
- 为什么加**自环**：保留节点自身信息。为什么**对称归一化**：防止高度节点特征尺度爆炸，同时兼顾源/目标两端的度（相比 $\tilde D^{-1}\tilde A$ 的行归一化即均值聚合）。
- 本质是**低通滤波器**：平滑相邻节点的特征，这也是过平滑的根源。
- 局限：**直推式（transductive）**、全图训练内存大、聚合权重由度固定、各向同性。

Q6：***GraphSAGE 的核心思想是什么？为什么它是归纳式的？***

- **采样 + 聚合（SAmple and aggreGatE）**（Hamilton et al., 2017）：
$$h_{\mathcal N(v)}^{(l)}=\mathrm{AGG}\big(\{h_u^{(l-1)},u\in\mathcal{S}(v)\}\big),\quad h_v^{(l)}=\sigma\big(W^{(l)}[h_v^{(l-1)}\,\Vert\,h_{\mathcal N(v)}^{(l)}]\big)$$
  之后通常做 $\ell_2$ 归一化。
- **邻居采样**：每层固定采样 $S_l$ 个邻居（如 25、10），计算量 $O(\prod_l S_l)$，与图规模无关，支持 mini-batch。
- **聚合器**：Mean、LSTM（对随机排列的邻居，非严格置换不变）、Pooling（逐元素 max of MLP），GCN 风格聚合。
- **归纳式**：学的是"如何从邻居聚合"的函数而不是每个节点的嵌入，因此对**新节点/新图**可以直接推理（只需它的特征和邻居），适合用户、商品不断新增的工业场景。
- 自身表示与邻居表示**拼接**（而非相加），相当于一种跳跃连接，缓解过平滑。
- 支持无监督损失：基于随机游走共现的正样本 + 负采样。

Q7：***GAT 如何计算注意力系数？多头注意力有什么作用？***

- 对每条边 $(i,j)$（Veličković et al., 2018）：
$$e_{ij}=\mathrm{LeakyReLU}\big(\mathbf a^\top[Wh_i\,\Vert\,Wh_j]\big),\quad \alpha_{ij}=\frac{\exp(e_{ij})}{\sum_{k\in\mathcal N(i)\cup\{i\}}\exp(e_{ik})}$$
$$h_i'=\sigma\Big(\sum_{j\in\mathcal N(i)\cup\{i\}}\alpha_{ij}Wh_j\Big)$$
- 只在邻居上做 softmax（**masked attention**），复杂度 $O(|E|)$。
- **多头**：$K$ 个独立头，中间层拼接、输出层取平均，稳定训练、增强表达。
- 相对 GCN：邻居权重**由特征自适应学习**而非由度决定（各向异性），可解释性更好，天然归纳式。
- 追问点：**GATv2**（Brody et al., 2022）指出原 GAT 是"静态注意力"——由于 $\mathbf a$ 线性作用后才过 LeakyReLU，所有查询节点对邻居的排序相同；GATv2 改为 $\mathbf a^\top\mathrm{LeakyReLU}(W[h_i\Vert h_j])$ 实现动态注意力。

Q8：***GIN 是什么？GNN 的表达能力与 WL 测试有什么关系？***

- **1-WL 测试**：迭代地把每个节点的颜色更新为 hash(自身颜色, 邻居颜色多重集)，若两图最终颜色直方图不同则不同构。
- Xu et al.（2019，"How Powerful are GNNs?"）证明：**消息传递 GNN 的区分能力上界是 1-WL**；当聚合与更新函数都是**单射**时可达到该上界。
- mean / max 聚合不是单射：mean 无法区分 $\{a,b\}$ 与 $\{a,a,b,b\}$，max 无法区分 $\{a,b\}$ 与 $\{a,a,b\}$；**sum 可以**。
- **GIN**：
$$h_v^{(l)}=\mathrm{MLP}^{(l)}\Big((1+\epsilon^{(l)})h_v^{(l-1)}+\sum_{u\in\mathcal N(v)}h_u^{(l-1)}\Big)$$
  sum 聚合 + MLP（万能逼近保证单射），图级 readout 用各层 sum 拼接。
- 1-WL 的局限：无法区分某些正则图，不能数三角形/环；突破手段：**k-WL / 高阶 GNN**、**子图 GNN**、加**随机特征或位置编码**（Laplacian PE、随机游走 PE）、结构特征（节点度、环计数）。
- 注意：表达能力强 ≠ 泛化好，实际节点分类中 GCN/SAGE 常与 GIN 相当。

## 深层 GNN 的问题

Q9：***什么是过平滑（over-smoothing）？如何缓解？***

- 现象：层数加深后，所有节点表示趋于相同，节点不可区分，性能下降。GCN 通常 2–3 层最佳。
- 原因：GCN 是低通滤波，反复乘以 $\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$，$\hat A^k x$ 随 $k\to\infty$ 收敛到主特征向量（仅与度相关）的子空间，信息被抹平；可用 **Dirichlet 能量**或 MAD 度量。
- 缓解：
    - **残差/跳跃连接**：ResGCN、**JKNet**（拼接/最大池化各层输出）、GCNII（**初始残差** $(1-\alpha)\hat AH+\alpha H^{(0)}$ + 恒等映射）
    - **解耦传播与变换**：**APPNP**（个性化 PageRank 传播 $Z^{(k+1)}=(1-\alpha)\hat AZ^{(k)}+\alpha H$）、SGC
    - **归一化**：PairNorm、DiffGroupNorm
    - **随机删边**：DropEdge
    - 自身与邻居拼接（GraphSAGE）、门控更新

Q10：***什么是过挤压（over-squashing）？和过平滑有什么区别？***

- 现象：$L$ 跳内邻居数随 $L$ 指数增长，但要被压缩进**固定维度向量**中，导致远距离信息无法有效传递，长程依赖任务效果差（Alon & Yahav, 2021）。
- 根源在**图拓扑的瓶颈**（如树状结构、桥边、负曲率区域），可用 Jacobian $\partial h_v^{(L)}/\partial x_u$ 的敏感度衡量。
- 区别：过平滑是"所有表示变得一样"（深度问题）；过挤压是"远处信息过不来"（拓扑瓶颈问题），两者存在一定的权衡。
- 缓解：
    - **图重连（rewiring）**：在最后一层加全连接层（FA layer）、基于曲率的重连（SDRF）、扩展图
    - 加虚拟节点（virtual node）连接所有节点
    - **Graph Transformer** 全局注意力
    - 增加隐藏维度（缓解但不根治）

Q11：***训练深层 GNN 还有哪些常用技巧？***

- **残差 / 初始残差 / 稠密连接**（DeepGCN 将 ResNet、DenseNet、空洞卷积思想引入，训练到 56 层以上）。
- **归一化**：BatchNorm、LayerNorm、GraphNorm、PairNorm。
- **正则化**：DropEdge、DropNode、Dropout、DropMessage。
- **解耦**：先用 MLP 做特征变换，再做多步无参数传播（APPNP、SGC、SIGN 预计算 $\hat A^kX$），既深又快。
- **JK 连接**：让每个节点自适应选择感受野大小。
- **深度 vs 感受野**：很多时候不需要深，用 2–3 层 + 预计算多跳特征就足够。
- 训练稳定性：较小学习率、weight decay、早停（小图数据集方差大，需多次随机种子报告均值和标准差）。

## 任务与训练

Q12：***链接预测怎么做？负采样有哪些策略？***

- 流程：GNN 编码得到节点表示 $z_u,z_v$ → 解码器打分 $s(u,v)=z_u^\top z_v$ 或 $\mathrm{MLP}(z_u\odot z_v)$ → 二分类或排序损失。
- 损失：BCE（正边 vs 负边）、**BPR** $-\log\sigma(s(u,i)-s(u,j))$、InfoNCE。
- **数据泄露陷阱**：训练时消息传递的图中不能包含要预测的监督边（需切分为 message edges 与 supervision edges），否则模型"看到答案"。时序图要按时间切分。
- **负采样策略**：
    - 均匀随机采样（简单，但大多太容易）
    - 按度/流行度采样（$\propto \deg^{0.75}$，类似 word2vec）
    - **批内负采样**（in-batch negatives），需做流行度偏差校正（logQ correction）
    - **困难负样本**：同类目、高分但未交互、PinSage 用 PageRank 排名靠中段的节点；课程式由易到难
- 评估：AUC、Hits@K、MRR、Recall@K/NDCG@K。
- 追问：SEAL 等基于子图的方法能捕捉公共邻居等结构，弥补纯节点嵌入（如 GCN）在链接预测上"无法区分自同构节点"的不足。

Q13：***DeepWalk 和 node2vec 是怎么工作的？与 GNN 有何区别？***

- **DeepWalk**（2014）：在图上做截断**随机游走**生成节点序列，视作"句子"，用 **Skip-gram + 负采样/层次 softmax** 学嵌入，相邻共现的节点嵌入相近。
- **node2vec**（2016）：**有偏二阶随机游走**，参数 $p$（返回参数）和 $q$（进出参数）：
    - 从 $t$ 走到 $v$ 后，下一步到 $x$ 的未归一化概率：回到 $t$ 为 $1/p$；$x$ 与 $t$ 相邻为 $1$；否则为 $1/q$
    - $q<1$ 偏 **DFS**，捕捉**同质性（社区）**；$q>1$ 偏 **BFS**，捕捉**结构等价性**
- 理论上 DeepWalk/LINE/node2vec 等价于隐式**矩阵分解**（NetMF）。
- 与 GNN 区别：
    - 随机游走方法是**浅层嵌入**（每个节点一个查表向量），参数量 $O(Nd)$，**直推式**，不使用节点特征
    - GNN 共享参数、可利用特征、可归纳
- 工业用途：做预训练嵌入/召回特征（如 EGES 在 node2vec 基础上加入商品侧信息解决冷启动）。

Q14：***什么是异构图？如何处理？***

- 异构图（HIN）：多种**节点类型**和**边类型**，如 用户–商品–店铺、作者–论文–会议。
- 方法：
    - **元路径（meta-path）**：如 U-I-U、A-P-A，metapath2vec 沿元路径随机游走
    - **R-GCN**：每种关系一个权重矩阵 $h_i'=\sigma\big(W_0h_i+\sum_r\sum_{j\in\mathcal N_i^r}\frac{1}{c_{i,r}}W_rh_j\big)$；关系多时用**基分解** $W_r=\sum_b a_{rb}V_b$ 或块对角分解防止过参数化
    - **HAN**：节点级注意力（元路径内）+ 语义级注意力（元路径间）
    - **HGT**：按节点/边类型参数化的 Transformer 式注意力，支持动态异构图
- 工程上 PyG 的 `HeteroData` + `to_hetero`，DGL 的 `HeteroGraphConv` 可以按关系分别聚合再合并。

## 规模化与工业应用

Q15：***GNN 如何扩展到亿级节点的大图？***

- 全图 GCN 的瓶颈：需要整张图和所有层激活放进显存；mini-batch 下 $L$ 层邻居**指数爆炸**。
- **节点级采样**：GraphSAGE 每层固定扇出；PinSage 用随机游走的访问计数选 Top-K 重要邻居。
- **层级采样**：FastGCN、LADIES，按层独立采样，控制每层节点数。
- **子图采样**：
    - **ClusterGCN**：用 METIS 把图划分为多个簇，每个 batch 取若干簇的诱导子图训练，簇内边多、簇间边少，内存只与子图相关；随机合并多个簇以减少偏差
    - GraphSAINT：随机节点/边/游走采样子图，并做归一化以保证无偏
- **预计算/解耦**：SGC、SIGN 离线计算 $\hat A^kX$，训练只是 MLP，极易扩展。
- **历史嵌入**：GNNAutoScale 等复用过期邻居表示。
- **系统层面**：图分区 + 分布式采样（DGL distributed、GraphLearn、PyG + 特征存储），**特征缓存**热点节点、CPU/GPU 协同、推理时**逐层全图推理**（layer-wise inference）避免重复计算。

Q16：***PinSage 有哪些关键设计？***

- Pinterest 的工业级 GraphSAGE 变体（2018），在 30 亿节点 pin–board 二部图上训练。
- **基于随机游走的邻域**：从节点出发做短随机游走，按访问次数取 Top-T 邻居，访问计数归一化作为**重要性权重**进行加权聚合（importance pooling）。
- **生产者–消费者 mini-batch**：CPU 负责采样和特征抓取，GPU 负责计算，流水线并行。
- **课程学习 + 困难负样本**：在 PageRank 排序中第 2000–5000 名的物品作为困难负样本，逐轮增加困难负样本比例。
- **max-margin 排序损失**：$\max(0,\,z_q^\top z_{n}-z_q^\top z_{i}+\Delta)$。
- **MapReduce 推理**：避免重复计算，全量生成嵌入后放入 ANN 索引用于召回。

Q17：***GNN 在推荐系统中如何应用？LightGCN 为什么去掉了特征变换和非线性？***

- 推荐可建模为**用户–物品二部图**，高阶连通性（$u\to i\to u'\to i'$）即协同信号。
- **NGCF**（2019）：在二部图上做带特征变换、非线性和 $e_i\odot e_u$ 交互项的消息传递。
- **LightGCN**（He et al., 2020）发现在只有 ID 嵌入（无语义特征）的协同过滤里，特征变换和非线性**无益反而有害**（增加训练难度），简化为：
$$e_u^{(k+1)}=\sum_{i\in\mathcal N_u}\frac{1}{\sqrt{|\mathcal N_u|}\sqrt{|\mathcal N_i|}}e_i^{(k)},\quad e_u=\sum_{k=0}^{K}\alpha_ke_u^{(k)}$$
  唯一可训练参数是第 0 层的 ID 嵌入，$\alpha_k$ 一般取 $1/(K+1)$；层组合起到类似残差的作用、缓解过平滑；用 **BPR 损失**训练。
- 后续：SGL、SimGCL（加对比学习/噪声扰动缓解流行度偏差、提升长尾）、UltraGCN（用约束损失近似无限层）。
- 工业落地：多用于**召回**（双塔/ANN 检索 GNN 嵌入）或给精排提供图嵌入特征；难点是动态图更新、冷启动和线上延迟，常离线计算嵌入 + 天级/小时级更新。

Q18：***GNN 在金融风控/反欺诈中如何应用？有哪些难点？***

- 构图：用户、设备、IP、手机号、银行卡、商户为节点，交易/登录/共用设备为边，形成异构图。欺诈者常形成**团伙**，共享设备/IP，图结构能暴露单点特征看不出的关联。
- 任务：节点分类（欺诈账户识别）、边分类（欺诈交易）、子图/社区检测（团伙挖掘）、时序链接预测。
- 代表方法：GEM（阿里，异构设备图）、CARE-GNN / PC-GNN（处理**伪装**问题和类别不平衡）、时序 GNN（TGN、TGAT）。
- 难点：
    - **异质性（heterophily）**：欺诈者会刻意连接正常用户伪装，同质性假设失效 → 需要邻居筛选、区分同类/异类邻居、高通滤波（如 H2GCN、FAGCN）
    - **极度类别不平衡**：重采样、focal loss、邻居过采样
    - **标签延迟与对抗演化**：欺诈手法变化快，需持续训练和时序切分验证
    - **实时性**：在线推理要求低延迟，常用离线图嵌入 + 实时特征，或实时子图采样
    - **可解释性**：监管要求解释（GNNExplainer、子图证据展示）

Q19：***什么是 Graph Transformer？与消息传递 GNN 相比有什么优缺点？***

- 将节点作为 token，做**全局自注意力**，从而一层即可建模任意节点对，缓解过挤压和 1-WL 限制。
- 关键是**注入图结构**（否则 Transformer 看不到边）：
    - **位置编码**：Laplacian 特征向量 PE（需处理符号/基的不确定性，如 SignNet）、随机游走 PE（RWSE）
    - **结构编码 / 注意力偏置**：**Graphormer**（2021）加入中心性编码（度）、空间编码（最短路距离偏置）、边编码
    - **混合架构**：**GraphGPS**（2022）每层 = 局部 MPNN + 全局注意力 + FFN，是常用的通用框架
- 缺点：全局注意力 $O(N^2)$，大图需线性注意力（Performer、Exphormer 等稀疏/扩展图注意力、NodeFormer、SGFormer）；小数据易过拟合，依赖好的 PE。
- 适用：分子/小图图级任务（OGB-LSC 等表现突出）、长程依赖任务；大规模节点分类中，调好的经典 GNN 仍是强基线。

Q20：***同质性（homophily）假设是什么？在异质图上 GNN 怎么改？***

- **同质性**：相连节点倾向于有相同标签/相似特征，边同质率 $h=\frac{|\{(u,v)\in E:y_u=y_v\}|}{|E|}$。GCN 等低通滤波模型隐含此假设。
- **异质图**（如反欺诈、蛋白质交互、约会网络）上，邻居平均会混淆信号，甚至不如 MLP。
- 改进：
    - **分离自身与邻居表示**（拼接而非求和），H2GCN
    - **高阶邻居 / 多跳聚合**：2 跳邻居可能更同质
    - **高通/自适应滤波**：FAGCN、GPR-GNN（学习多项式滤波系数，可为负）
    - 符号/门控消息：允许负权重
    - 重新构图：基于特征相似度的 kNN 图
- 面试实操：先测 $h$，并始终把 **MLP 作为基线**比较。

Q21：***GNN 常用的框架和工程实践有哪些？***

- 框架：**PyTorch Geometric（PyG）**、**DGL**；大规模分布式有 GraphLearn、GraphScope、DGL Distributed。
- 实践要点：
    - 稀疏操作（`scatter`、`SpMM`），使用 CSR 加速邻居采样
    - 先做好 **MLP / LightGBM + 图统计特征**基线，再判断 GNN 的收益
    - 数据切分要防泄露：按时间切分、链接预测分离消息边与监督边
    - 小数据集上多种子重复实验
    - 上线时嵌入离线批量生成 + ANN 检索，或实时子图采样 + 低延迟推理服务
