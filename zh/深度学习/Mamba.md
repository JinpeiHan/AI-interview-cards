# Mamba

Q1：***什么是状态空间模型（SSM）？***

- 状态空间模型来自控制理论，用一个隐状态 $h(t)\in\mathbb{R}^N$ 把一维输入信号 $x(t)$ 映射到输出 $y(t)$：

$$h'(t)=Ah(t)+Bx(t),\qquad y(t)=Ch(t)+Dx(t)$$

- 其中 $A\in\mathbb{R}^{N\times N}$ 是 **状态转移矩阵**，决定隐状态如何随时间演化与"遗忘"；$B$ 决定输入如何写入状态；$C$ 决定如何从状态读出输出；$D$ 相当于跳跃连接（常被省略或视为残差）。
- 深度学习中的 SSM 对每个输入通道独立地应用一个 SSM（或共享结构），再通过线性层混合通道，作为序列模型的 **序列混合层**，可以替代 RNN 或注意力。

Q2：***SSM 如何离散化？什么是零阶保持（ZOH）？***

- 实际序列是离散的，需要引入 **步长** $\Delta$ 将连续参数 $(\Delta,A,B)$ 转换为离散参数 $(\bar{A},\bar{B})$：

$$h_t=\bar{A}h_{t-1}+\bar{B}x_t,\qquad y_t=Ch_t$$

- **零阶保持（Zero-Order Hold, ZOH）**：假设输入在每个采样区间 $\Delta$ 内保持不变，对微分方程精确积分可得：

$$\bar{A}=\exp(\Delta A),\qquad\bar{B}=(\Delta A)^{-1}(\exp(\Delta A)-I)\cdot\Delta B$$

- 其他离散化方法还有双线性变换（S4 早期使用）等。Mamba 中 $\bar{A}$ 用 ZOH，$\bar{B}$ 常用更简单的近似 $\bar{B}\approx\Delta B$。
- $\Delta$ 可理解为 **时间分辨率**：$\Delta$ 越大，状态越多地被当前输入"刷新"；$\Delta$ 越小，状态越倾向于保持原样。

Q3：***SSM 的循环视角与卷积视角是什么？各有什么用途？***

- **循环视角**：按 $h_t=\bar{A}h_{t-1}+\bar{B}x_t$ 逐步更新，每步计算量恒定、只需保存固定大小的状态，适合 **自回归推理**，但训练时无法沿序列并行。
- **卷积视角**：当参数 **不随时间变化**（线性时不变，LTI）时，把递推展开得：

$$y_t=\sum_{k=0}^{t}C\bar{A}^k\bar{B}x_{t-k}\quad\Rightarrow\quad y=x*\bar{K},\quad\bar{K}=(C\bar{B},C\bar{A}\bar{B},\dots,C\bar{A}^{L-1}\bar{B})$$

- 即输出是输入与一个长度为 $L$ 的 **SSM 卷积核** 的卷积，可以用 FFT 在 $O(L\log L)$ 内 **并行训练**。
- 结论：LTI SSM 可以"卷积训练、循环推理"，兼顾两种优势；但 Mamba 的选择性 SSM 不再是 LTI，无法使用卷积视角，需要改用并行扫描。

Q4：***S4 的主要贡献是什么？HiPPO 初始化有什么作用？***

- 朴素 SSM 存在两个问题：随机初始化的 $A$ 难以记住长程历史（梯度消失/爆炸）；计算卷积核 $\bar{K}$ 需要反复计算矩阵幂，代价很高。
- **HiPPO**（Gu et al., 2020）：从"用正交多项式（如 Legendre 多项式）在线逼近输入的全部历史"的角度推导出一类特殊的 $A$ 矩阵；用它初始化，隐状态就能对历史信号进行最优压缩，显著提升 **长程依赖** 建模能力。
- **S4**（Gu et al., 2021，"Efficiently Modeling Long Sequences with Structured State Spaces"）：
    - 将 $A$ 参数化为 **正规矩阵加低秩（NPLR）** 的结构化形式，使卷积核可以高效、数值稳定地计算；
    - 在 Long Range Arena 等长序列基准上表现突出，包括此前所有模型都难以解决的 Path-X 任务。
- 后续简化：**S4D** 证明对角化的 $A$（配合合适的初始化）就能取得接近效果；**S5** 使用 MIMO SSM 与并行扫描。

Q5：***Mamba 的选择性 SSM 是什么？与 S4 有何不同？***

- Mamba（Gu & Dao, 2023，"Mamba: Linear-Time Sequence Modeling with Selective State Spaces"）的核心是 **选择机制（selection mechanism）**：让 SSM 参数 **依赖于当前输入**：

$$B_t=\text{Linear}_B(x_t),\quad C_t=\text{Linear}_C(x_t),\quad\Delta_t=\text{softplus}(\text{Linear}_\Delta(x_t)+b)$$

- $A$ 仍是与输入无关的参数（对角矩阵），但由于 $\bar{A}_t=\exp(\Delta_tA)$，状态转移也随输入变化。
- 与 S4 的区别：S4 的参数 **对所有时间步相同**（LTI），无论输入内容如何都以相同方式处理；Mamba 是 **时变（输入依赖）** 的，模型可以根据内容 **选择性地记住或忽略** 信息。
- 与门控 RNN 的联系：论文指出当 $N=1$、$A=-1$、$B=1$ 时，选择性 SSM 退化为 $h_t=(1-g_t)h_{t-1}+g_tx_t$ 的门控形式，其中 $g_t=\sigma(\text{Linear}(x_t))$，因此 $\Delta$ 的作用类似 RNN 的门。

Q6：***为什么选择性很重要？选择性复制和归纳头任务说明了什么？***

- **LTI 模型的局限**：卷积核固定，只能根据 **相对位置** 而不是 **内容** 处理信息，无法做到"遇到重要 token 就记住、遇到无关 token 就跳过"。
- **选择性复制（Selective Copying）**：需要记住的 token 分布在随机位置，中间夹杂无关的噪声 token。由于间隔不固定，LTI 模型无法用固定卷积核解决，而选择性 SSM 可以根据内容决定是否写入状态。
- **归纳头（Induction Heads）**：看到 "... A B ... A" 时输出 "B"，即基于内容的联想回忆，是大语言模型上下文学习的重要机制之一。论文中 Mamba 能够解决该任务并且能 **外推到比训练长得多的序列**。
- **$\Delta$ 的直观含义**：$\Delta_t$ 大 → 状态被重置、聚焦当前输入；$\Delta_t$ 小 → 忽略当前输入、保持原有状态。$B_t$、$C_t$ 则控制信息写入与读出的内容。
- 本质：**选择性 = 根据内容压缩上下文**，这是注意力具备而 LTI SSM 缺乏的能力。

Q7：***Mamba 的硬件感知并行扫描是如何实现的？***

- 选择性 SSM 不再是 LTI，无法用卷积/FFT 并行；直接循环计算又慢，而且展开后的状态大小为 $(B,L,D,N)$，比输入大 $N$ 倍，写入显存代价很高。
- Mamba 的 **硬件感知算法**：
    - **并行扫描（parallel scan）**：线性递推 $h_t=\bar{A}_th_{t-1}+\bar{B}_tx_t$ 满足结合律，可以用 work-efficient 的 **并行前缀和（Blelloch scan）** 在 $O(\log L)$ 的并行深度内完成；
    - **算子融合（kernel fusion）**：只把参数 $(\Delta,A,B,C)$ 从慢速的 **HBM** 读入快速的 **SRAM**，在 SRAM 中完成离散化、扫描与和 $C$ 的乘法，只把最终输出 $y$ 写回 HBM，**不在 HBM 中实例化完整的隐状态**，大幅减少显存读写；
    - **重计算（recomputation）**：反向传播时不保存中间状态，而是重新计算它们，以计算换显存，使显存占用与使用 FlashAttention 的 Transformer 相当。
- 思路与 FlashAttention 类似：瓶颈在于 **显存带宽** 而非计算量。

Q8：***Mamba 与 Transformer 在复杂度上有何差异？***

- **训练**：
    - Transformer 自注意力的计算量为 $O(L^2d)$；
    - Mamba 通过扫描实现，计算量随序列长度 **线性增长**：$O(LdN)$。
- **推理（自回归生成）**：
    - Transformer 需要维护 **KV cache**，其大小随已生成长度 $L$ 线性增长，每生成一个 token 需要与所有历史 token 计算注意力，单步代价 $O(L)$；
    - Mamba 只需维护 **固定大小的状态** $(D\times N)$，每步计算量和显存都是 **常数** $O(1)$，与上下文长度无关，因此推理吞吐更高，长序列生成更省显存。
- 代价：固定大小的状态意味着必须 **有损压缩** 历史信息，而注意力可以无损地访问全部历史（见 Q11）。

Q9：***Mamba block 的结构是怎样的？***

- Mamba block 融合了 H3 block 与门控 MLP（类似 GLU），整个网络由 **同构的 Mamba block** 堆叠而成，**不再需要单独的 MLP/FFN 层**：
    1. 输入经 LayerNorm/RMSNorm 后，用线性层 **扩展** 维度（扩展因子通常为 2），分成两条分支；
    2. **主分支**：短的 **因果一维卷积**（causal conv1d）→ SiLU 激活 → **选择性 SSM**；
    3. **门控分支**：SiLU 激活；
    4. 两条分支 **逐元素相乘**（门控），再经线性层投影回原维度；
    5. 外加残差连接。
- $A$ 采用对角实数参数化，常取 $A=-\exp(A_{\log})$ 以保证稳定（特征值为负、状态衰减），初始化参考 S4D-Real。
- 短卷积提供局部的 token 混合，SSM 负责长程依赖，门控增强表达能力。

Q10：***Mamba-2 和 SSD（结构化状态空间对偶）是什么？***

- Mamba-2（Dao & Gu, 2024，"Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality"）提出 **SSD 框架**：
    - 将 $A_t$ 限制为 **标量乘单位矩阵**（$A_t=a_tI$），此时整个序列变换可写成矩阵乘法 $y=Mx$，其中

$$M_{ji}=C_j^\top\left(\prod_{k=i+1}^{j}a_k\right)B_i,\quad j\ge i$$

- $M$ 是一个 **半可分（semiseparable）矩阵**。
- **对偶性**：
    - **线性（循环）形式**：按 SSM 递推计算，复杂度对 $L$ 线性；
    - **二次（注意力）形式**：令 $Q=C$、$K=B$、$V=x$，则 $y=(L\circ QK^\top)V$，其中 $L$ 是由累积衰减 $\prod a_k$ 构成的下三角掩码矩阵——这正是 **带衰减掩码的线性注意力**。
- **SSD 算法**：把序列分块，块内用二次的矩阵乘法形式（充分利用 GPU 的 **Tensor Core**），块间用循环形式传递状态，比 Mamba-1 的扫描实现快很多，并允许使用 **更大的状态维度** $N$。
- 架构改动：$B$、$C$、$\Delta$ 与输入 $x$ 在 block 开头 **并行** 生成（类似注意力中的 $Q$、$K$、$V$），引入多头结构，并在输出前增加一个归一化层，更易进行张量并行。

Q11：***Mamba 等 SSM 的主要弱点是什么？***

- **上下文召回与复制能力较弱**：固定大小的状态必须压缩全部历史，当任务需要 **精确检索** 上下文中的任意信息时（如长文本中查找电话号码、复制长字符串、大量键值对的联想回忆），SSM 往往不如注意力。
- 理论与实验工作（如 Jelassi et al., 2024，"Repeat After Me: Transformers are Better than State Space Models at Copying"）表明，Transformer 只需较少层就能复制任意长度的字符串，而固定状态的模型复制能力受状态大小限制。
- **上下文学习**：在需要从提示中精确提取格式或示例信息的少样本任务上，纯 SSM 模型可能落后于同规模 Transformer。
- **生态与工具链**：注意力的优化、并行与推理框架更成熟；SSM 需要专门的 kernel。
- 根本原因：**注意力 = 无损的 KV 缓存检索；SSM = 有损的定长状态压缩**，这是效率与召回能力之间的基本权衡。

Q12：***什么是 Attention-Mamba 混合模型？为什么有效？***

- **思路**：在以 Mamba 层为主的网络中 **插入少量注意力层**，结合两者的优势：
    - Mamba 层负责高效的序列建模，保持较低的计算和显存开销；
    - 少量注意力层提供精确的上下文检索与复制能力，弥补 SSM 的弱点。
- 代表工作：
    - **Jamba**（AI21, 2024）：Transformer 层与 Mamba 层交替排列，并结合 MoE 扩大容量；
    - **Zamba**：Mamba 主干加上共享的注意力块；
    - **Samba**：Mamba 层与滑动窗口注意力结合；
    - NVIDIA 对 Mamba、Mamba-2 与混合模型的系统性对比研究表明，混合模型能弥补纯 SSM 在召回类任务上的不足。
- 收益：KV cache 只存在于少量注意力层中，显存和长上下文推理代价远低于纯 Transformer，同时保持较强的召回与上下文学习能力。

Q13：***Mamba 如何应用于视觉等其他模态？***

- 挑战：图像是二维、非因果的，而 SSM 是一维因果序列模型。
- **Vision Mamba（Vim）**：将图像切为 patch 序列，使用 **双向 SSM**（正向和反向各扫描一次）获取全局上下文，并加入位置编码。
- **VMamba**：提出 **二维选择性扫描（SS2D / cross-scan）**，沿四个方向展开 patch 序列分别扫描后合并，以更好地建模二维空间关系。
- 其他模态：
    - **音频与语音**：长序列波形或频谱建模；
    - **基因组**：DNA 序列极长，线性复杂度优势明显（如 Caduceus 使用双向、反向互补等变的设计）；
    - **视频、点云、图、时间序列** 等。
- 反思：**MambaOut**（Yu & Wang, 2024）认为图像分类这类短序列、非因果任务并不需要 SSM，SSM 更适合 **长序列、自回归** 的任务。

Q14：***Mamba 与线性注意力、RetNet、RWKV 有何异同？***

- 它们都属于 **线性 RNN / 次二次复杂度的序列模型**，可以写成统一形式：带矩阵（或扩展）状态的递推 $S_t=G_t\odot S_{t-1}+k_tv_t^\top$，输出 $o_t=S_t^\top q_t$，训练可并行、推理状态恒定。区别主要在于 **衰减/门控 $G_t$ 的形式**：
    - **线性注意力**（Katharopoulos et al., 2020）：用核函数特征映射替代 softmax，$S_t=S_{t-1}+\phi(k_t)v_t^\top$，**没有衰减**，历史信息不断累积，难以遗忘；
    - **RetNet**（Sun et al., 2023）：引入 **固定的指数衰减** $\gamma$（每个头一个常数），支持并行、循环与分块三种计算形式；衰减与输入无关；
    - **RWKV**：通过 token shift 与 WKV 机制实现带 **可学习逐通道衰减** 的线性注意力，早期版本的衰减与输入无关，RWKV-6 起引入了 **数据依赖** 的衰减；
    - **Mamba / Mamba-2**：衰减由输入依赖的 $\Delta_t$ 决定，是 **数据依赖（选择性）** 的；Mamba-2 可视为带标量数据依赖门控的线性注意力，与 GLA（Gated Linear Attention）非常接近。
- 趋势：**数据依赖的门控/衰减** 是提升线性模型表达能力的关键；进一步的改进如 DeltaNet、Gated DeltaNet 采用 **delta 规则** 更新状态，改善了联想回忆能力。

Q15：***Mamba 的 $\Delta$、$A$、$B$、$C$ 各起什么作用？如何初始化？***

- **$\Delta$（步长）**：控制当前输入与历史状态之间的权衡，类似遗忘门/输入门；通过 softplus 保证为正，偏置初始化使 $\Delta$ 落在一个合适的范围内（如 $[0.001,0.1]$ 量级）。
- **$A$（状态矩阵）**：对角、取负值以保证稳定；与 $\Delta$ 共同决定衰减速率 $\exp(\Delta A)$。不同状态维度对应不同的衰减速率，相当于多时间尺度的记忆。
- **$B$（输入矩阵）**：输入依赖，决定 **哪些信息写入状态**；
- **$C$（输出矩阵）**：输入依赖，决定 **从状态中读出哪些信息**；
- 与注意力类比：$C$ 类似 query，$B$ 类似 key，$x$ 类似 value，$\exp(\Delta A)$ 类似随时间衰减的位置掩码。

Q16：***Mamba 有哪些优势场景？在实际选型时应如何考虑？***

- **优势场景**：
    - **超长序列**：基因组、音频、长时间序列、长文档等，线性复杂度与恒定推理显存优势明显；
    - **高吞吐推理**：无 KV cache，适合大批量、长输出的生成；
    - **流式/在线处理**：天然的循环形式，适合实时、边缘设备场景。
- **选型考虑**：
    - 若任务高度依赖 **精确检索与复制**（如长上下文问答、RAG、代码补全中的精确引用），纯 SSM 可能不如 Transformer，可考虑混合架构；
    - 短序列任务中注意力的二次代价并不是瓶颈，Mamba 的优势有限；
    - 需要考虑生态成熟度、专用 kernel 支持以及部署框架是否支持。
