# Mamba

Q1：***什么是状态空间模型（SSM）？***

- **SSM 来自控制理论，用一个隐状态把输入序列映射到输出：每一步用矩阵 A 决定旧状态如何演化和遗忘，用 B 把输入写入状态，用 C 从状态读出输出。在深度学习中它作为序列混合层，可以替代 RNN 或注意力。**
- 通常对每个通道独立应用 SSM，再用线性层混合通道。
- D 相当于跳跃连接，常被省略或视为残差。
- 核心公式：$h'(t)=Ah(t)+Bx(t),\quad y(t)=Ch(t)$

Q2：***SSM 如何离散化？什么是零阶保持（ZOH）？***

- **实际序列是离散的，需要用步长 Δ 把连续参数转成离散参数，得到 $h_t=\bar{A}h_{t-1}+\bar{B}x_t$ 这样的递推。零阶保持假设输入在每个步长区间内保持不变，据此对微分方程精确积分得到离散参数。**
- Mamba 中 $\bar{A}$ 用 ZOH，$\bar{B}$ 常用简化近似 $\Delta B$；其他方法还有双线性变换。
- Δ 可理解为时间分辨率：Δ 大时状态更多被当前输入刷新，Δ 小时状态更倾向保持原样。
- 核心公式：$\bar{A}=\exp(\Delta A)$

Q3：***SSM 的循环视角与卷积视角是什么？各有什么用途？***

- **循环视角是逐步更新状态，每步代价恒定，适合自回归推理；卷积视角是在参数不随时间变化（LTI）时，把递推展开成输入与一个固定卷积核的卷积，可以用 FFT 并行训练。LTI SSM 因此能"卷积训练、循环推理"。**
- 循环形式训练时无法沿序列并行。
- 卷积形式用 FFT 复杂度为 $O(L\log L)$。
- Mamba 的选择性 SSM 不再是 LTI，用不了卷积视角，只能改用并行扫描。

Q4：***S4 的主要贡献是什么？HiPPO 初始化有什么作用？***

- **S4 解决了朴素 SSM 的两个问题：难以记住长程历史，以及卷积核计算代价高。它用 HiPPO 矩阵初始化 A 来记住长历史，并把 A 参数化为"正规加低秩"结构，使卷积核可以高效、稳定地计算。**
- HiPPO 从"用正交多项式在线逼近输入的全部历史"推导出特殊的 A，让隐状态能最优压缩历史信号。
- S4 在 Long Range Arena 上表现突出，包括此前没人能解决的 Path-X。
- 后续简化：S4D 证明对角 A 配合好的初始化就够了；S5 用 MIMO SSM 加并行扫描。

Q5：***Mamba 的选择性 SSM 是什么？与 S4 有何不同？***

- **选择性 SSM 让参数 B、C 和步长 Δ 都由当前输入计算出来，于是模型能根据内容决定记住还是忽略信息。S4 的参数对所有时间步都相同，不管输入是什么都以同样方式处理。**
- A 本身与输入无关，但离散化后的 $\exp(\Delta_t A)$ 随 Δ 变化，所以状态转移也随输入变化。
- 与门控 RNN 的联系：特定简化下选择性 SSM 退化为 $h_t=(1-g_t)h_{t-1}+g_tx_t$，Δ 的作用就像 RNN 的门。
- 核心公式：$\Delta_t=\text{softplus}(\text{Linear}(x_t))$，$B_t$、$C_t$ 同样是 $x_t$ 的线性函数。

Q6：***为什么选择性很重要？选择性复制和归纳头任务说明了什么？***

- **LTI 模型的卷积核固定，只能按相对位置而不能按内容处理信息。选择性让模型能"遇到重要 token 就记住、遇到无关 token 就跳过"，也就是按内容压缩上下文，这是注意力具备而 LTI SSM 缺乏的能力。**
- 选择性复制：要记住的 token 位置随机、中间夹噪声，固定卷积核解决不了，选择性 SSM 可以。
- 归纳头：看到"A B … A"时输出"B"，是上下文学习的重要机制；Mamba 能解决并外推到比训练长得多的序列。
- 直观理解：Δ 大时重置状态、聚焦当前输入，Δ 小时忽略当前输入；B、C 控制写入和读出什么。

Q7：***Mamba 的硬件感知并行扫描是如何实现的？***

- **选择性 SSM 无法用卷积并行，而展开的隐状态又太大，写进显存代价很高。Mamba 用并行扫描沿序列并行计算，并把离散化、扫描等融合成一个 kernel 在快速的 SRAM 里完成，只把输出写回显存，反向时再重算中间状态。**
- 并行扫描：线性递推满足结合律，可以用并行前缀和在对数深度内完成。
- 算子融合：不在 HBM 中实例化完整隐状态，大幅减少显存读写。
- 重计算：用计算换显存，使显存占用与使用 FlashAttention 的 Transformer 相当。
- 思路与 FlashAttention 一样：瓶颈在显存带宽而非计算量。

Q8：***Mamba 与 Transformer 在复杂度上有何差异？***

- **训练时注意力的计算量随序列长度平方增长，Mamba 是线性增长；推理时 Transformer 的 KV cache 随上下文变长、每步要看所有历史，Mamba 只维护固定大小的状态，每步计算和显存都是常数。**
- 因此 Mamba 推理吞吐更高，长序列生成更省显存。
- 代价：固定状态必须有损压缩历史，而注意力可以无损访问全部历史（见 Q11）。

| | 训练 | 推理每步 |
|---|---|---|
| Transformer | $O(L^2d)$ | $O(L)$，KV cache 随 L 增长 |
| Mamba | $O(LdN)$ | $O(1)$，状态大小固定 |

Q9：***Mamba block 的结构是怎样的？***

- **Mamba block 融合了 H3 和门控 MLP：输入先扩展维度分成两路，主路经过短因果卷积、SiLU 和选择性 SSM，另一路经过 SiLU 作为门，两路逐元素相乘后投影回原维度，再加残差。整个网络就是这种 block 的堆叠，不需要单独的 FFN。**
- 扩展因子通常为 2，输入前有 LayerNorm/RMSNorm。
- A 取对角负实数（如 $A=-\exp(A_{\log})$），保证状态衰减、训练稳定。
- 分工：短卷积负责局部混合，SSM 负责长程依赖，门控增强表达能力。

Q10：***Mamba-2 和 SSD（结构化状态空间对偶）是什么？***

- **Mamba-2 把状态矩阵 A 限制为标量乘单位阵，此时 SSM 可以等价地写成一种带衰减掩码的线性注意力，这就是"结构化状态空间对偶"（SSD）：同一个模型既能按循环方式线性计算，也能按注意力方式用矩阵乘法计算。**
- SSD 算法把序列分块：块内用矩阵乘法形式，充分利用 Tensor Core；块间用循环形式传递状态。比 Mamba-1 快很多，并能用更大的状态维度。
- 对应关系：C 相当于 Q，B 相当于 K，输入 x 相当于 V。
- 架构改动：B、C、Δ 在 block 开头与 x 并行生成，引入多头，输出前加归一化，更易做张量并行。

Q11：***Mamba 等 SSM 的主要弱点是什么？***

- **主要弱点是精确召回和复制能力弱：固定大小的状态必须有损压缩全部历史，当任务需要精确检索上下文里的任意信息（查电话号码、复制长字符串、大量键值联想）时，SSM 往往不如注意力。**
- 研究（如 "Repeat After Me"）表明 Transformer 能复制任意长度的字符串，而固定状态模型受状态大小限制。
- 在需要从提示中精确提取格式或示例的少样本任务上，纯 SSM 可能落后于同规模 Transformer。
- 工程上注意力的生态更成熟，SSM 需要专门的 kernel。
- 本质权衡：注意力是无损的 KV 检索，SSM 是有损的定长压缩。

Q12：***什么是 Attention-Mamba 混合模型？为什么有效？***

- **混合模型以 Mamba 层为主、插入少量注意力层：Mamba 层负责高效的序列建模，少量注意力层提供精确检索和复制能力，弥补 SSM 的短板。KV cache 只存在于少数注意力层，长上下文推理代价远低于纯 Transformer。**
- 代表工作：Jamba（Transformer 与 Mamba 层交替，加 MoE）、Zamba（共享注意力块）、Samba（结合滑动窗口注意力）。
- NVIDIA 的系统对比表明，混合模型能补上纯 SSM 在召回类任务上的不足。

Q13：***Mamba 如何应用于视觉等其他模态？***

- **难点是图像是二维、非因果的，而 SSM 是一维因果模型。常见做法是把图像切成 patch 序列，再用多个方向扫描来获取全局上下文：Vision Mamba 用正反双向扫描，VMamba 沿四个方向扫描后合并。**
- 其他模态：音频语音、基因组（序列极长，如 Caduceus）、视频、点云、时间序列等。
- 反思：MambaOut 认为图像分类这类短序列、非因果任务并不需要 SSM，SSM 更适合长序列、自回归任务。

Q14：***Mamba 与线性注意力、RetNet、RWKV 有何异同？***

- **它们都是线性复杂度的"线性 RNN"，训练可并行、推理状态大小恒定，可以写成"状态 = 衰减 × 旧状态 + 新的 key-value"这一统一形式。区别主要在衰减方式：线性注意力没有衰减，RetNet 是固定衰减，RWKV 是可学习的逐通道衰减，Mamba 的衰减由输入决定。**
- 线性注意力历史不断累积、难以遗忘。
- RWKV-6 起也引入了数据依赖的衰减；Mamba-2 与 GLA（门控线性注意力）非常接近。
- 趋势：数据依赖的门控是提升表达力的关键；DeltaNet、Gated DeltaNet 用 delta 规则更新状态，进一步改善联想回忆。
- 核心公式：$S_t=G_t\odot S_{t-1}+k_tv_t^\top,\quad o_t=S_t^\top q_t$

Q15：***Mamba 的 $\Delta$、$A$、$B$、$C$ 各起什么作用？如何初始化？***

- **Δ 控制当前输入与历史状态的权衡，类似遗忘门；A 和 Δ 一起决定衰减速度；B 决定把什么写入状态；C 决定从状态读出什么。**
- Δ 用 softplus 保证为正，偏置初始化让它落在约 0.001–0.1 的范围。
- A 是对角负值以保证稳定，不同维度衰减速率不同，相当于多时间尺度记忆。
- 类比注意力：C 像 query，B 像 key，x 像 value，$\exp(\Delta A)$ 像随时间衰减的位置掩码。

Q16：***Mamba 有哪些优势场景？在实际选型时应如何考虑？***

- **Mamba 适合超长序列、高吞吐生成和流式处理这类场景，因为它计算线性、推理显存恒定、没有 KV cache。但如果任务依赖精确检索和复制，纯 SSM 可能不如 Transformer，可考虑混合架构。**
- 优势场景：基因组、音频、长时间序列、长文档；大批量长输出生成；实时、边缘设备。
- 短序列任务中注意力的二次代价不是瓶颈，Mamba 优势有限。
- 还要考虑生态成熟度、专用 kernel 和部署框架支持。
