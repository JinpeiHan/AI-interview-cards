# Deep Learning Fundamental

# 初级

Q1：***深度学习和机器学习本质的区别在哪里？***

- **本质区别在于特征从哪里来：传统机器学习依赖人工设计和组合特征，深度学习通过多层非线性网络端到端地自动学习特征（表示学习）。**
- 深度学习的各层参数由反向传播根据最终任务的 loss 联合学习：浅层学边缘、纹理等低级特征，深层组合成部件、物体等高级语义特征。
- 深度学习需要大量数据才能发挥优势；传统机器学习对数据量的依赖低。

Q2：***深度学习的性能为什么会随着数据增多而提高？***

- **数据越多，模型见到的情况和边缘样本越多，就越能学到真实的规律而不是记住噪声，所以泛化更好；而深度网络容量大，不像简单模型那样很快饱和，能持续从更多数据中获益。**

Q3：***什么是ensemble learning，在深度学习中有何运用？***

- **集成学习是训练多个模型，再按某种规则（投票、平均等）把它们的结果组合起来，以提高整体的泛化能力。**
- 深度学习中的典型例子是 dropout、zoneout 和 drop-connect，它们相当于在一个网络里隐式地集成了大量子网络（更多见 Q38）。

Q4：**深度学习中，如何选择激活函数**？

- **隐藏层一般默认用 ReLU（或其变体），因为计算简单、不易梯度消失；输出层根据任务选：二分类用 Sigmoid 输出概率，多分类用 Softmax，回归一般用线性输出。**

Q5：***相比机器学习，深度学习有什么优势？***

- **深度学习是端到端的，不需要大量人工特征工程；在数据量大、问题复杂（图像、语音、文本）时，准确率明显更高。**

Q7：***如何判断深度学习模型中存在梯度消失问题？***

- **主要看训练 loss 和浅层的梯度：loss 下降非常缓慢、训练很久后 loss 仍然很大，同时靠近输入的层梯度极小、权重几乎不更新（甚至趋于 0），就说明存在梯度消失。**

Q8：***如何判断深度学习模型是否存在梯度爆炸问题？怎么确定？***

- **怀疑信号是：loss 一直很高、训练很不稳定（每次更新 loss 剧烈波动），或者 loss 直接变成 NaN。确认的方法是检查梯度和权重：权重变成 NaN，或者各层梯度范数持续很大（例如始终大于 1.0 且不断增长）。**

Q9：***Embedding Layer的作用是什么？***

- **Embedding 层把高维、稀疏的 one-hot 输入（如词 ID）映射成低维稠密的向量，既大大减少计算量，又能让语义相近的东西在向量空间里距离更近。**

Q10：***什么是早停策略？***

- **早停是一种正则化方法：训练时持续监控验证集误差，当验证误差不再下降（甚至开始上升）时就停止训练，因为再继续只会让模型更拟合训练集、泛化变差。**

Q11：***什么是增量学习？***

- **增量学习是指模型在已有数据上训练好之后，还能不断用新到的数据继续学习、扩展知识，同时不忘记已经学会的内容。**

引用：[https://link.springer.com/](https://link.springer.com/)

Q12：***解释感知机的原理***

- **感知机是一个用于二分类的线性模型：对输入特征加权求和再加偏置，经过符号函数输出 +1 或 -1，目标是找到一个能把正负样本分开的超平面（即参数 $w, b$）。**
- 训练方式：遇到分错的样本就沿着减少误分类的方向更新 $w, b$；数据线性可分时保证收敛。

Q13：***什么是计算图？哪些算法属于计算图模型？***

- **计算图是用有向图表示数学表达式的方法：节点表示变量或运算，边表示数据流向。深度学习框架用它来做前向计算和自动求导（反向传播沿着图反向传梯度）。**
- 感知机、深层神经网络、线性回归等都可以表示为计算图模型。

Q14：***线性激活函数和非线性激活函数之间有什么区别？***

- **线性激活函数的输出是输入的线性函数，多层叠加后仍然等价于一层线性变换；非线性激活函数（如 ReLU、tanh、sigmoid）让网络能表示复杂的非线性关系，这是深度网络有强表达能力的关键。**

Q15：***解释1*1卷积操作的意义？***

- **1x1 卷积不改变特征图的空间尺寸，只在通道维上做线性组合，主要用来改变通道数（降维或升维）。**
- 参见：[CNN](CNN.md) Q16；[计算机视觉](计算机视觉.md) Q34

Q16：***在设计神经网络时，神经网络的广度和深度哪个更重要？***

- **对标准前馈网络来说，深度通常比宽度更有价值：加深能引入更多层次的非线性和特征组合，用更少的参数表示更复杂的函数；但网络越深越难训练，也更容易过拟合。**
- 理论上存在一些函数，深网络很容易表示，而浅网络需要指数级宽度才能表示（相关研究论文：[http://proceedings.mlr.press/v49/eldan16.pdf](http://proceedings.mlr.press/v49/eldan16.pdf)）。

引用：[https://www.quora.com/What-are-the-tradeoffs-of-increasing-the-depth-of-a-neural-network](https://www.quora.com/What-are-the-tradeoffs-of-increasing-the-depth-of-a-neural-network)

Q17：***神经网络中的隐藏层计算的内容是什么？***

- **隐藏层对输入做"线性变换 + 非线性激活"，逐层把原始输入转换成对任务更有用的特征表示，并把维度调整成输出层需要的形式。**

引用：[https://stats.stackexchange.com/](https://stats.stackexchange.com/)

Q18：***神经网络中，可以将非线性激活函数替换为线性激活函数吗？为什么？***

- **不可以。全用线性激活的话，无论叠多少层，整个网络都等价于一个线性模型，就学不到复杂的函数了；非线性正是神经网络和线性回归的本质区别。**

Q19：***在深度学习模型中，如何选择损失函数？***

- **损失函数要和任务类型匹配，输出层的配置也要与之对应：回归用 MSE / MAE 一类，二分类用二元交叉熵，多分类用多类交叉熵（配 Softmax）。**
- 回归：MSE（对大误差敏感）、MAE（对异常值更鲁棒）、均方对数误差（目标跨度大时）。
- 二分类：交叉熵（Sigmoid 输出）、Hinge loss。
- 多分类：多类交叉熵；需要拟合整个分布时用 KL 散度（如自编码器、知识蒸馏）。

引用：[https://machinelearningmastery.com/](https://machinelearningmastery.com/)

Q20：***介绍GAN的原理***

- **GAN（生成对抗网络）由生成器 G 和判别器 D 组成：G 从随机噪声生成假样本，尽量以假乱真；D 判断输入是真实样本还是生成样本。两者对抗训练，最终达到平衡时 D 分辨不出真假，G 就学会了真实数据的分布。**

Q21：***什么是迁移学习？***

- **迁移学习就是把在一个任务（源域）上学到的知识用到另一个相关任务（目标域）上，核心是找到两者之间的相似性；深度学习中最常见的形式是"预训练 + 微调"。**
- 按迁移方式分四类：基于样本（对源域样本重新加权）、基于特征（把两域映射到同一空间并缩小分布差异）、基于模型（共享源域模型参数再微调）、基于关系（把源域中概念间的关系类比到目标域）。

![Untitled](%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0%E5%9F%BA%E7%A1%80/Untitled%204.png)

Q22：***卷积层什么时候与全连接层等价？***

- **当卷积核大小与输入特征图的空间尺寸完全相同（不做 padding），且卷积核个数等于全连接层的输出神经元数时，卷积层就等价于全连接层。**

Q23：***GAN和自动编码器有什么区别和联系？***

- **两者都能学习数据的分布或表示，但目标不同：自编码器用编码器压缩输入、解码器重建输入，优化的是重建误差，常用于降维、特征提取和异常检测；GAN 通过生成器和判别器的对抗博弈学习生成逼真样本，主要用于图像生成。**

引用：[https://stackoverflow.com](https://stackoverflow.com/)

Q24：***预训练对神经网络有什么好处？***

- **预训练让模型先在海量（往往无标注）数据上学到通用知识和特征，再在少量标注数据上微调，所以下游任务收敛更快、效果更好，也大大减少了对人工标注数据的需求。**

Q25：***在深度神经网络中使用Batch-Norm会有什么问题吗？***

- **有。BN 依赖 batch 内的统计量，所以 batch 小时统计不准、效果变差，训练和推理行为不一致，也不适合序列模型；因此在小 batch 或序列任务中常改用 LayerNorm、GroupNorm 等。**
- 对 batch size 敏感：batch 太小时均值方差估计噪声大，性能下降。
- 训练用 batch 统计量、推理用滑动平均，两者存在差异。
- 序列长度不一时难以统计，且需要额外的内存和计算保存统计量。

Q26：***什么是multitask learning？什么时候使用它较为合适？***

- **多任务学习是让一个模型同时学习多个任务，通常是共享底层网络和参数、每个任务各有一个输出头；共享的信息能让模型学到更通用、更紧凑的表示，从而提高泛化。**
- 当任务之间相关、或共享底层规律时最合适；任务冲突太大时反而可能互相拖累。

Q27：***AE与VAE的区别是什么？***

- **AE 把输入编码成一个确定的向量再解码；VAE 把输入编码成一个高斯分布（均值和方差），从中采样后再解码，并用 KL 项把隐空间约束成接近标准正态。因此 VAE 的隐空间是规整连续的，可以随机采样生成新数据，而 AE 不行。**

Q29：***什么是玻尔兹曼机？***

- **玻尔兹曼机是一种由对称连接的二值随机节点组成的神经网络，每个节点以一定概率决定是否激活，整个网络用能量函数描述状态的概率分布，是一种生成式模型。**
- 常用的是受限玻尔兹曼机（RBM），多个 RBM 堆叠可构成深度信念网络。
- 也可用于优化 / 搜索问题：固定连接权重来表示代价函数。

Q30：***你会选择那种神经网络完成视频分类任务？***

- **视频既有每帧内的空间信息，又有帧之间的时间信息，所以要选能同时建模两者的网络：例如 CNN 提取每帧特征 + RNN/LSTM 建模时序（CRNN），或者直接用 3D 卷积网络（如 C3D、I3D）。**

Q31：***dropout对神经网络训练有什么影响？***

- **Dropout 在训练时随机让一部分神经元失活，迫使网络不依赖个别神经元，相当于用一个模型隐式地集成了大量不同的子网络；它是一种代价很低又很有效的正则化方法，能减少过拟合、提高泛化。**

Q32：***AE模型可以用于特征生成吗？如果可以，怎么做？***

- **可以。先训练自编码器重建输入，训练完后丢掉解码器，把编码器在瓶颈层的输出作为输入数据的特征；这个特征维度固定，并保留了输入的大部分信息。**

Q33：***Batch Normalization、Instance Normalization、Layer Normalization、Group Normalization之间有什么区别？***

- **四者的区别只在于在哪些维度上算均值和方差：BN 在每个通道内跨整个 batch 统计；LN 在每个样本内跨所有通道统计；IN 在每个样本的每个通道内单独统计；GN 在每个样本内把通道分组，在组内统计。**
- BN 依赖 batch 大小，适合大 batch 的 CNN；LN 与 batch 无关，适合 RNN / Transformer。
- IN 常用于风格迁移；GN 适合小 batch 的检测、分割任务。

Q34：***同等参数量情况下，深层神经网络比浅层神经网络效果好的原理是什么？***

- **深层网络是很多简单函数的逐层组合，后面的层可以复用前面层学到的特征，所以同样的参数量能表示更复杂的函数，参数利用效率更高。**
- 它天然契合数据的层次结构：例如语音识别中，浅层学发音方式等低级特征，深层组合成音素等高级特征；浅层网络很难学到这种层级特征。

Q35：***比较svm和deep learning***

- **SVM 是在固定特征上找最大间隔的边界，凸优化、有全局最优解、理论清晰；深度学习通过多层网络自动学习分层特征表示，表达能力强但需要大量数据，且优化非凸。**
- 可解释性：SVM 有完整的数学推导支撑，深度网络更像黑箱。
- 优化：神经网络用梯度下降，对初始化敏感，可能陷入局部最优；SVM 无论初始值如何都收敛到全局最优。
- 多分类：神经网络一个模型即可；SVM 需要组合多个二分类器。
- 特征：特征数大于样本数时 SVM 表现不佳，且需要更多人工特征工程。

Q36：***Relu激活函数比sigmoid函数好的地方在哪里？***

- **ReLU 在正区间梯度恒为 1，不会饱和，所以深层网络中不容易梯度消失、收敛更快；同时它计算简单（没有指数运算），还能产生稀疏激活。Sigmoid 两端饱和、导数最大只有 0.25，层数一多梯度就消失了。**
- ReLU 的缺点：负区间梯度为 0，可能出现 Dead ReLU（神经元永久不激活），可用 Leaky ReLU、PReLU、ELU、GELU 缓解。
- 分工：Sigmoid 常用于输出层（二分类概率）和门控（如 LSTM 的门），ReLU 常用于隐藏层。
- 核心公式：$\sigma'(x)=\sigma(x)(1-\sigma(x))\le 0.25$，而 ReLU 在 $x>0$ 时导数为 1

Q37：***傅里叶变换在深度学习中有什么运用？***

- **最典型的是加速卷积：根据卷积定理，时域（空间域）的卷积等于频域的逐元素相乘，所以可以用 FFT 把输入和卷积核变到频域相乘，再用逆 FFT 变回来，对大卷积核能显著减少计算量。**

Q38：***集成学习在深度学习中有什么运用？***

- **集成学习是训练多个模型并组合它们的预测，以降低方差、提高准确率；在深度学习中可以从训练数据、模型本身和结果组合三个层面来做。**
- 训练数据：k 折交叉验证训练 k 个模型、对数据重采样（bagging）后分别训练。
- 模型本身：dropout、drop-connect 等在一个网络内隐式集成。
- 结果组合：按验证集优化权重的加权平均集成；对多个网络的权重做平均（模型权重平均）得到一个更好的单一模型。

引用：[https://machinelearningmastery.com/](https://machinelearningmastery.com/)

Q39：***深度学习怎么减轻/避免维度诅咒？***

- **维度诅咒常常来自大量冗余和无关（噪声）特征。深度网络能从高维数据中学到低维、有用的表示，在学习过程中自动削弱无关特征、强化相关特征，所以能缓解维度诅咒。**

引用：[https://www.quora.com/](https://www.quora.com/)

Q40：***你了解多少种跳转链接（skip-connection）方法？***

- **常见的有三种：ResNet 的残差连接（逐元素相加）、DenseNet 的密集连接（通道拼接）、U-Net 的长跳跃连接（把编码器特征拼到对应的解码器层）。**
- ResNet：浅层信息直接加到深层，不引入额外参数，让梯度能直接回传。
- DenseNet：每层的输出与后续所有层拼接，而不是求和，促进特征复用。

- U-Net：长跳跃连接把编码器的高分辨率细节送到解码器，有利于精细分割。

Q41：什么是***Deep Recurrent Q-Network*?**

- **DRQN 是把 DQN 中卷积层之后的第一个全连接层换成 LSTM 的网络，用来处理部分可观测的环境：即使每个时间步只看到一帧，它也能通过 LSTM 整合时间信息。**

引用：[https://arxiv.org/abs/1507.06527](https://arxiv.org/abs/1507.06527)

Q42：*****基于区域的目标检测神经网络*(R-CNN)、*Fast R-CNN*和*Faster R-CNN*之间有什么区别？**

- **三者是逐步加速的演进：R-CNN 对每个候选区域单独跑一次 CNN，非常慢；Fast R-CNN 整图只跑一次 CNN，再用 RoI 池化从特征图上取各区域特征；Faster R-CNN 进一步用区域建议网络（RPN）代替选择性搜索来生成候选框，实现了几乎端到端的检测。**
- R-CNN 用选择性搜索提取约 2000 个候选区域，无法实时；Fast R-CNN 的 RoI 池化把不同大小的区域变成固定尺寸再分类和回归；Faster R-CNN 的 RPN 与检测网络共享特征。

Q43：***在处理序列问题上，比较HMM模型和RNN模型***

- **HMM 是生成模型，基于很强的马尔可夫假设（下一个状态只依赖当前状态），结构简单，适合小数据集；RNN 是判别模型，不需要这类假设，能建模更长的依赖，在大数据集上效果更好。**

Q44：***知道哪些关于目标检测的网络结构？***

- **目标检测网络大致分为两类：单阶段检测器（YOLO、SSD、RetinaNet、CenterNet），直接一次性预测边界框和类别，速度快；两阶段检测器（R-CNN、Fast R-CNN、Faster R-CNN、Mask R-CNN、Cascade R-CNN），先提取候选区域（RoI）再分类和回归，精度通常更高。**

Q45：***GAN网络在训练时的难点是什么？***

- **GAN 训练主要有三个难点：不收敛（参数振荡、不稳定）、模式崩溃（生成器只会生成少数几种样本）和梯度消失（判别器太强，生成器学不到东西）。其中模式崩溃最难解决。**
- 模式崩溃举例：在 MNIST 上理想情况应该生成全部 10 个数字，却只生成其中几个。
- 一种理论解释：神经网络只能表示连续映射，而真实的数据传输映射可能是不连续的；当目标分布有多个分离的区域时，连续映射的输出可能只集中在其中一个区域，就出现了模式崩溃。
- 解法：经验上有 unrolled GAN（生成器更新时考虑判别器未来 K 步的反应）、DRAGAN（避免坏的局部纳什均衡）；理论上可根据 Brenier 理论计算最优传输势能函数、找出奇异点集来避免模式崩溃。

Q46：***假设你想训练一个分类器，你有大量未标记的训练数据，但只有几千个标记实例。你将如何进行？***

Q47：***怎样使用遗传算法优化神经网络？***

- **思路是用遗传算法来搜索神经网络的初始权重和阈值：把一个网络的全部权重编码成一个个体，以网络的预测误差作为适应度，通过选择、交叉、变异不断进化种群，得到最优个体后用它初始化网络，再用反向传播训练。**
- 分三步：根据输入输出确定网络结构（从而确定个体编码长度）、遗传算法优化权重、用最优权重初始化并训练网络后预测。

Q48：***为什么神经网络可以拟合任意函数？以sin、cos函数为例解释非线性激活函数的作用；Loss如何计算，与样本数量和特征维度有什么关系？***

- **依据是万能逼近定理：只要隐藏层神经元足够多，一个带非线性激活的单隐藏层网络就能以任意精度逼近任意连续函数。直观上，每个 ReLU 提供一个"折点"，足够多的折线段拼起来就能逼近任意曲线。**
- 以 sin、cos 为例：没有非线性激活时，多层网络合起来仍是一个线性函数，只能拟合直线，无论多深都拟合不了正弦波；加了 ReLU 后输出是分段线性函数，神经元越多分段越细，就越接近 sin、cos 的波形。
- 注意：定理只保证这样的网络存在，不保证梯度下降能找到，也不保证泛化。
- Loss 计算：对所有样本的单样本损失取平均，回归常用 MSE，分类常用交叉熵；样本数不改变 loss 的量级，但样本越多计算量越大、对真实风险的估计越准。
- 特征维度决定输入层参数量和计算量；维度高而样本少时更容易过拟合，需要更多数据或正则化。
- 核心公式：$L=\frac{1}{N}\sum_{i=1}^{N}\ell(f(x_i;\theta),y_i)$

Q49：***什么是过拟合？为什么训练可能停留在局部最优解？***

- **过拟合是模型在训练集上表现很好、在验证集和测试集上表现差，原因是模型容量相对数据太大，记住了训练数据中的噪声。典型现象是训练 loss 一直下降，验证 loss 却开始上升。**
- **停在局部最优是因为神经网络的 loss 曲面高度非凸，有大量局部极小值、鞍点和平坦区域；梯度下降只看局部梯度，梯度接近 0 时就停滞了。**
- 实际上高维空间里鞍点比局部极小值更常见，而且多数局部极小值的 loss 和全局最优相差不大。
- 缓解办法：动量、Adam 等优化器；SGD 的小批量噪声帮助跳出鞍点；合理初始化和学习率调度（warm-up、cosine）；BN 和残差连接让 loss 曲面更平滑。

Q50：***如何降低过拟合、提高网络的泛化能力？***

- **最有效的是增加数据（包括数据增强），其次是控制模型复杂度和加正则化，再配合早停、集成等训练策略。**
- 数据：更多数据、数据增强（翻转、裁剪、Mixup、CutMix，文本回译等）、清洗噪声标签。
- 模型：减小模型、使用合适的结构先验（如 CNN）、预训练 + 微调。
- 正则化：L2（权重衰减）、L1（稀疏权重）、Dropout、Label Smoothing、BN。
- 训练策略与评估：早停、模型集成；用交叉验证或独立验证集监控泛化、选择超参数。

Q51：***Batch Normalization的作用是什么？反向传播如何进行？训练与推理时有什么区别？***

- **BN 对每个通道用当前 mini-batch 的均值和方差做标准化，再用可学习的缩放 $\gamma$ 和平移 $\beta$ 恢复表达能力。它让各层输入分布更稳定、loss 曲面更平滑，从而可以用更大学习率、加速收敛、缓解梯度消失/爆炸，并带有一定正则化效果。**
- 反向传播：$\gamma, \beta$ 的梯度直接按链式法则求；由于均值和方差依赖 batch 内所有样本，对输入的梯度还要经过均值和方差这两条路径回传，所以每个样本的梯度会受同 batch 其他样本影响。
- 训练时：用当前 batch 的统计量归一化，同时用滑动平均累积全局均值和方差（PyTorch 中 momentum 默认 0.1）。
- 推理时：不再计算 batch 统计量，而是用训练累积的固定均值和方差，BN 变成一个线性变换，可以融合进前面的卷积层；PyTorch 中要调用 `model.eval()` 切换。
- 核心公式：$y=\gamma\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}+\beta$；相关问题见 Q25（BN 的缺点）、Q33（各种 Normalization 的区别）

Q52：***什么是Mini-batch？为什么使用它？***

- **Mini-batch 是每次迭代只取一小批样本（如 32、64、256 个），用它们的平均 loss 计算梯度并更新参数。它介于全量梯度下降和单样本 SGD 之间，兼顾了计算效率和训练稳定性。**
- 效率：全量数据放不进显存，小批量能充分利用 GPU 并行，而且一个 epoch 内能多次更新。
- 稳定性：比单样本 SGD 的梯度方差小，训练更稳。
- 泛化：保留适量梯度噪声，有助于跳出鞍点、收敛到泛化更好的平坦极小值。
- batch size 选择：太小不稳定、硬件利用率低、BN 统计不准；太大可能泛化变差，需要按比例调大学习率并配合 warm-up。

Q53：***CNN、RNN、LSTM的基本原理是什么？各自适用于什么任务？***

- **CNN 用局部连接、权重共享的卷积核提取空间局部特征，适合图像这类网格数据；RNN 按时间步处理序列，用隐状态记住历史信息，适合短序列；LSTM 在 RNN 上加了细胞状态和门控，能捕获长期依赖，适合长序列任务。**
- CNN：卷积 + 激活 + 池化逐层提取由低到高的特征，参数少、具有平移不变性；用于分类、检测、分割，也可用 1D 卷积处理语音、文本、时序。
- RNN：各时间步共享参数，用 BPTT 训练；长序列中梯度连乘导致梯度消失/爆炸，且不能并行。
- LSTM：遗忘门、输入门、输出门控制信息的保留和写入，细胞状态的加法更新让梯度能稳定地长距离传播；用于机器翻译、语音识别、文本生成、时序预测。GRU 是只有两个门的简化版。
- 核心公式：$c_t=f_t\odot c_{t-1}+i_t\odot\tilde{c}_t$
