# JEPA

Q1：***什么是 JEPA（Joint-Embedding Predictive Architecture）？***

- **JEPA 是 LeCun 提出的世界模型核心模块：用两个编码器分别把相关的输入 x（如上下文）和 y（如被遮挡部分或未来）编码成表示，再用一个预测器从 x 的表示去预测 y 的表示。**
- 预测器还可以接收一个隐变量 z，用来表达 y 中无法由 x 确定的部分。
- 核心理念：在抽象的表示空间里做预测，而不是在像素空间里重建，从而忽略不可预测的细节，只建模有语义、可预测的部分。

Q2：***JEPA 与生成式方法（如 MAE）在"预测什么"上有何根本区别？***

- **MAE 这类生成式方法在像素空间里预测 y，而 JEPA 在表示空间里预测 y 的表示。**
- 像素预测的问题：很多细节（树叶纹理、噪声）本身就不可预测，模型要浪费容量去建模；面对多种可能的未来，像素回归会给出模糊的平均。
- 表示空间里，目标编码器可以学会丢掉无关信息，预测器只需预测语义内容，所以特征更有语义、线性探测更好。
- 一句话：MAE 是"补全图像"，JEPA 是"补全对图像的理解"。

Q3：***JEPA 与对比学习（联合嵌入方法）有何区别？***

- **SimCLR、BYOL、DINO 这类联合嵌入方法要求同一图像不同增强视图的嵌入相同；JEPA 则是用一个以位置或动作为条件的预测器，从 x 的表示去预测 y 的表示。**
- 联合嵌入方法依赖手工数据增强定义"什么该不变"，这个先验很强，可能丢掉颜色、位置等有用信息；对比方法还需要大量负样本。
- JEPA 不需要负样本，也不依赖手工增强（I-JEPA 只用掩码），能表达 x 和 y 之间的变换关系。
- 学习信号来自"预测缺失部分"，而不是"对增强保持不变"。

Q4：***如何从能量模型（EBM）的角度理解 JEPA？***

- **能量模型用一个能量函数衡量 x 和 y 是否兼容（兼容则能量低）；JEPA 的能量就是表示空间里的预测误差，有隐变量时对 z 取最小。**
- 隐变量 z 表达 y 的多种可能（比如未来的多种走向），但要限制它的信息量，防止它直接泄露答案。
- 训练的关键是防止能量面变平，也就是表示坍塌。
- 对比方法显式抬高负样本能量，高维下效率低；正则化方法限制低能量区域的体积（如 VICReg 式方差/协方差正则、EMA 加 stop-gradient），LeCun 更推崇后者。
- 核心公式：$F(x,y)=\min_z D\big(s_y,\text{Pred}(s_x,z)\big)$

Q5：***简述 I-JEPA 的结构与训练流程***

- **I-JEPA 由三个 ViT 组成：上下文编码器只看上下文块里的 patch；目标编码器看完整图像，从输出里取出目标块的表示作为目标；预测器根据上下文表示和目标块的位置预测目标表示，损失是两者的 L2 距离。**
- 目标编码器是上下文编码器的 EMA，不接收梯度。
- 预测器是一个较窄的 ViT，输入带目标位置编码的 mask token。
- 掩码作用在目标编码器的输出上而不是输入上，所以目标表示带有完整图像的上下文，语义层次更高。
- 整个方法不用任何手工数据增强。

Q6：***I-JEPA 的多块掩码（multi-block masking）策略是怎样的？为什么重要？***

- **采样多个（默认 4 个）较大的目标块，再采样一个覆盖大部分图像的上下文块并去掉与目标块重叠的部分；这样预测目标是语义层面的，而不是能靠邻近像素插值的纹理。**
- 目标块要足够大，才能逼模型理解物体部件。
- 上下文要足够丰富、分布够广，才能支撑预测；去掉重叠是为了防止信息泄漏。
- 消融实验表明，相比随机 patch 掩码或单个目标块，多块掩码对学到语义表示至关重要。

Q7：***JEPA 如何避免表示坍塌？与 BYOL、data2vec 有什么联系？***

- **没有负样本时，编码器输出常数就能让误差为 0；I-JEPA 和 BYOL 一样靠非对称结构防坍塌：目标编码器用 EMA 更新、不回传梯度（stop-gradient），再加一个预测器。**
- 与 BYOL 的区别：BYOL 预测另一个增强视图的全局嵌入，I-JEPA 预测同一图像其他区域的 patch 级嵌入，并以位置为条件。
- 与 data2vec 的联系：都是学生在掩码输入上预测 EMA 教师在完整输入上的表示；I-JEPA 更强调多块掩码、独立预测器和只编码上下文块。
- 局限：EMA 防坍塌主要是经验设计，理论保证较弱。

Q8：***为什么 I-JEPA 学到的特征更具语义性？***

- **因为它预测的是抽象表示而不是像素，而且目标块很大，必须理解物体和场景结构才能预测，靠局部纹理插值做不到。**
- 不用手工增强，所以不会被迫丢掉颜色、位置信息，也不会被低层细节主导。
- 预测器分担了部分低层工作，让编码器专注于抽象表示（类似 MAE 的解码器）。
- 用额外训练的解码器可视化发现，预测结果能反映物体部件的位置和姿态，但不还原细节。

Q9：***为什么说 I-JEPA 计算高效？***

- **因为它每张图只需一个视图、上下文编码器只处理部分 patch、也没有像素解码器，所以达到相近效果所需的 GPU 时间比 MAE、iBOT 等更少。**
- 不像 DINO 那样要生成多个增强视图（multi-crop）。
- 预测发生在表示空间，不用重建高维像素。
- 代价是多一次目标编码器的前向传播（不需要反向）。

Q10：***如何评估 I-JEPA 等 JEPA 模型？效果有何特点？***

- **主要在冻结特征下评估，这正是 JEPA 的强项：线性探测明显好于 MAE，和依赖手工增强的方法相比也有竞争力。**
- 少标签（如 1% ImageNet）分类表现也较好。
- 在物体计数、深度预测等需要空间信息的任务上优于 DINO、iBOT，因为没有被迫丢掉位置信息。
- V-JEPA 用冻结骨干加注意力探针评估：用带可学习 query 的交叉注意力聚合 token 后分类，比线性探测更能反映 patch 级特征质量。

Q11：***V-JEPA 如何将 JEPA 扩展到视频？***

- **V-JEPA 只靠特征预测目标从视频中学习：把视频切成时空 patch，遮住大部分时空区域，让预测器预测被遮区域在 EMA 目标编码器下的表示。**
- 不用文本监督、负样本、像素重建或预训练图像编码器。
- 掩码在空间上采样多个块并沿时间延伸成管道，防止从相邻帧直接复制，损失用 L1。
- 学到的表示在冻结评估下对运动和外观理解都有效，且比像素重建更高效。

Q12：***V-JEPA 2 有什么进展？如何用于规划与机器人？***

- **V-JEPA 2 把视频 JEPA 预训练扩展到更大规模的视频和模型，并在冻结编码器上用少量机器人数据训练一个以动作为条件的预测器，作为世界模型用于规划。**
- 动作条件预测器学的是"在当前状态执行某动作后，未来的表示是什么"。
- 规划时给定目标图像的表示，用模型预测控制（MPC）在表示空间里搜索让预测未来最接近目标的动作序列，执行第一步后重新规划。
- 这样机器人能在新环境中零样本完成抓取、放置等简单任务，不需要任务奖励或大量演示。
- 它的编码器还能与语言模型对齐做视频问答；意义在于验证了"在表示空间预测未来并用于规划"的世界模型构想。

Q13：***JEPA 中的预测器起什么作用？为什么不直接让编码器输出对齐？***

- **预测器让模型能以位置或动作为条件做预测，回答"在这个位置/动作下表示是什么"，而不是简单要求所有视图表示相同。**
- 它是非对称结构的一部分，和 BYOL/SimSiam 一样有助于防坍塌。
- 它承担部分"推理"，让编码器专注于通用表示；预测器深度会影响表示质量。
- 去掉预测器直接对齐，就退化成基于不变性的联合嵌入方法，无法表达空间或时间上的变化。

Q14：***JEPA 中的隐变量 $z$ 在实践中如何体现？***

- **理论上 z 表示 y 中无法从 x 推断的不确定性，但在 I-JEPA、V-JEPA 的实际实现里，预测器是确定性的，只以目标位置为条件，并没有显式隐变量。**
- 不确定性靠"只预测可预测部分、忽略不可预测细节"来部分处理。
- 如何高效引入并正则化隐变量、实现多种可能未来的预测，仍是开放问题。

Q15：***JEPA 与 LeCun 的分层世界模型（H-JEPA）构想有什么关系？***

- **H-JEPA 是把 JEPA 叠成多层：低层在短时间尺度上预测细节较多的表示，高层在更抽象的表示上做更长时间尺度的预测，共同支持分层规划。**
- 在 LeCun 的构想里，世界模型与感知、代价、行动者、短期记忆和配置器模块一起组成自主智能体。
- 目前 I-JEPA、V-JEPA 只实现了单层的表示学习与预测，完整的分层世界模型还没实现。

Q16：***JEPA 的局限性与开放问题有哪些？***

- **主要问题是防坍塌靠经验设计、掩码策略要手工设计、无法直接生成像素，以及不确定性建模和长时程规划还不成熟。**
- 训练稳定性：依赖 EMA 和 stop-gradient，对 EMA 系数、掩码等超参敏感。
- 评估：冻结特征很强，但需要全局不变性的任务上可能落后于强增强方法，微调下的优势也不如线性探测明显。
- 可解释性：表示无法直接输出像素，可视化需要额外训练解码器。
- 应用：规划目前只在短时程简单任务上验证，与大语言模型如何结合也是活跃方向。
