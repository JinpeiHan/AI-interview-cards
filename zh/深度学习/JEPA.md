# JEPA

Q1：***什么是 JEPA（Joint-Embedding Predictive Architecture）？***

- JEPA 由 Yann LeCun 在立场论文 "A Path Towards Autonomous Machine Intelligence"（2022）中提出，是其 **世界模型（world model）** 构想中的核心模块。
- 结构：给定两个相关的输入 $x$（如上下文、当前状态）和 $y$（如被遮挡部分、未来状态）：
    1. 两个 **编码器** 分别得到表示 $s_x=\text{Enc}_x(x)$、$s_y=\text{Enc}_y(y)$；
    2. 一个 **预测器** 根据 $s_x$（以及可选的隐变量 $z$）预测 $y$ 的表示：$\hat{s}_y=\text{Pred}(s_x,z)$；
    3. 训练目标是让 $\hat{s}_y$ 与 $s_y$ 接近。
- 核心理念：**在抽象的表示空间中做预测，而不是在像素/输入空间中重建**，从而忽略不可预测的细节，只建模可预测的、有语义的部分。

Q2：***JEPA 与生成式方法（如 MAE）在"预测什么"上有何根本区别？***

- **生成式/重建式方法**（MAE、自回归像素生成）：在 **输入空间（像素）** 中预测 $y$，损失如 $\|\hat{y}-y\|^2$。
    - 问题：世界中大量细节本质上是 **不可预测** 的（如树叶的精确纹理、噪声），模型要花大量容量去建模这些无关细节；对于多种可能的未来，像素级回归会得到模糊的平均结果。
- **JEPA**：在 **表示空间** 中预测 $s_y$，损失如 $\|\hat{s}_y-s_y\|^2$。
    - 目标编码器可以学会 **丢弃不可预测或无关的信息**，预测器只需预测抽象的、语义层面的内容；
    - 因此学到的特征往往 **语义性更强**，线性探测效果优于基于像素重建的方法。
- 简言之：MAE 是"补全图像"，JEPA 是"补全对图像的理解"。

Q3：***JEPA 与对比学习（联合嵌入方法）有何区别？***

- **联合嵌入架构（JEA）**，如 SimCLR、BYOL、DINO：让同一图像不同增强视图的嵌入 **相同**（不变性），一般 **没有显式的条件预测器**（BYOL 的预测头不以位置等信息为条件）。
    - 依赖 **手工设计的数据增强** 来定义"什么应该不变"，引入了很强的先验，可能丢失对下游任务有用的信息（如颜色、位置）；
    - 对比方法还需要 **负样本**，在高维空间中需要大量负样本才能有效。
- **JEPA**：
    - 不要求两个嵌入相同，而是通过 **预测器**，在条件信息（如目标块的位置、动作）的帮助下，从 $s_x$ **预测** $s_y$，能够表达 $x$ 与 $y$ 之间的变换关系；
    - **不需要负样本**，也不依赖手工增强（I-JEPA 只用掩码）；
    - 学习信号来自"预测缺失部分"，而不是"对增强保持不变"。

Q4：***如何从能量模型（EBM）的角度理解 JEPA？***

- **能量模型** 用标量能量函数 $F(x,y)$ 衡量 $x$ 与 $y$ 的 **兼容性**：兼容的配对能量低，不兼容的配对能量高；推理即寻找使能量最小的 $y$。
- JEPA 的能量定义为表示空间中的预测误差（含隐变量时对 $z$ 取最小）：

$$F(x,y)=\min_z D\big(s_y,\text{Pred}(s_x,z)\big)$$

- **隐变量 $z$** 用于表达 $y$ 中无法由 $x$ 确定的多种可能性（例如未来的多种走向），使模型能够处理多模态不确定性；需要对其信息容量进行正则化，防止 $z$ 直接"泄露"答案。
- 训练能量模型的关键是 **防止能量面变平**（即对所有输入都给出低能量——对应 **表示坍塌**）：
    - **对比方法**：显式抬高负样本的能量，需要大量负样本，在高维空间中效率低；
    - **正则化方法（非对比）**：通过限制低能量区域的"体积"来防坍塌，如 VICReg 风格的方差/协方差正则、EMA 与 stop-gradient 等架构手段。LeCun 主张优先使用正则化方法。

Q5：***简述 I-JEPA 的结构与训练流程***

- I-JEPA（Assran et al., 2023，"Self-Supervised Learning from Images with a Joint-Embedding Predictive Architecture"）是 JEPA 在图像上的实例化，由三个 ViT 组成：
    - **上下文编码器（context encoder）**：只处理图像中 **上下文块** 内的可见 patch；
    - **目标编码器（target encoder）**：处理 **完整图像**，再从其输出中取出 **目标块** 对应位置的表示作为预测目标；参数为上下文编码器的 **EMA**，不接收梯度；
    - **预测器（predictor）**：一个较窄的 ViT，输入上下文编码器的输出，以及带有目标块 **位置编码** 的 mask token，输出对目标块表示的预测。
- 损失：预测表示与目标表示之间的 **L2 距离**，对所有目标块的所有 patch 取平均：

$$\mathcal{L}=\frac{1}{M}\sum_{i=1}^{M}\sum_{j\in B_i}\|\hat{s}_{y_j}-s_{y_j}\|_2^2$$

- 关键细节：掩码作用于目标编码器的 **输出** 而非输入，使目标表示具有完整图像的上下文、语义层级更高；整个方法 **不使用手工设计的数据增强**。

Q6：***I-JEPA 的多块掩码（multi-block masking）策略是怎样的？为什么重要？***

- **目标块**：采样 **多个**（论文默认 4 个）矩形块，每块覆盖图像中 **较大比例** 的区域，长宽比在一定范围内随机；
- **上下文块**：采样一个 **大的** 块（覆盖大部分图像），然后 **移除与目标块重叠的部分**，避免信息泄漏；
- 设计原则：
    - 目标块要 **足够大**，使预测目标是语义层面的（如物体的一部分），而不是可以从邻近像素插值的局部纹理；
    - 上下文要 **足够丰富且空间分布广**，提供足够信息支撑预测；
    - 论文消融实验显示，相比随机 patch 掩码或单个目标块，多块掩码对学到语义表示至关重要。
- 预测器通过位置编码知道"要预测哪里"，因此可以针对不同位置做条件预测。

Q7：***JEPA 如何避免表示坍塌？与 BYOL、data2vec 有什么联系？***

- 由于没有负样本，平凡解是让编码器输出常数，此时预测误差为 0。I-JEPA 采用与 BYOL 类似的 **非对称架构**：
    - **目标编码器使用 EMA 更新**：$\bar{\theta}\leftarrow m\bar{\theta}+(1-m)\theta$，$m$ 接近 1；
    - **stop-gradient**：损失不对目标编码器回传梯度；
    - **预测器** 作为额外的非对称组件。
- **与 BYOL 的联系**：都是 EMA 教师 + 预测器 + stop-gradient 的非对称结构；区别在于 BYOL 预测的是另一个 **增强视图** 的全局嵌入，I-JEPA 预测的是同一图像中 **其他空间区域** 的 patch 级嵌入，并以位置为条件。
- **与 data2vec 的联系**：data2vec 也让学生在掩码输入上预测 EMA 教师在完整输入上的表示（取多层平均），本质上同属表示空间中的掩码预测；I-JEPA 强调多块掩码策略、单独的预测器，以及学生编码器只处理上下文块。
- 局限：EMA 防坍塌主要依赖优化动态的经验性设计，理论保证较弱；LeCun 的立场论文中也讨论了 VICReg 等显式正则化方案。

Q8：***为什么 I-JEPA 学到的特征更具语义性？***

- **表示空间目标**：目标编码器的输出已经过滤掉部分像素细节，预测目标本身是抽象的；
- **大目标块**：预测大面积区域的表示，需要理解物体与场景结构，无法靠局部纹理插值完成；
- **没有手工增强**：不会因为增强而被迫丢弃颜色、位置等信息，同时也不会像像素重建那样被低层细节主导；
- **预测器吸收部分低层工作**：预测器作为编码器与目标之间的"缓冲"，使上下文编码器可以专注于抽象表示（类似 MAE 中解码器的作用）。
- 论文用一个独立训练的生成模型将预测的表示解码回像素进行可视化：预测结果能正确反映物体部件的位置与姿态等高层信息，而不精确还原低层细节。

Q9：***为什么说 I-JEPA 计算高效？***

- **单视图**：不需要像对比学习那样为每张图生成多个增强视图（如 DINO 的 multi-crop），每张图只需一次目标编码器前向传播；
- **上下文编码器只处理部分 patch**：与 MAE 类似，计算量显著降低；
- **没有像素解码器**：预测发生在表示空间，不需要重建高维像素；
- **收敛快**：论文报告在达到相近表现时，所需的预训练 GPU 时间少于 MAE、iBOT 等方法，并能较好地扩展到 ViT-H 等大模型。
- 代价：需要额外的目标编码器前向传播（但不需要反向传播）。

Q10：***如何评估 I-JEPA 等 JEPA 模型？效果有何特点？***

- **线性探测**：冻结编码器，训练线性分类器（通常对最后一层 patch 表示做平均池化）。I-JEPA 的线性探测明显优于 MAE 等像素重建方法，与使用手工增强的方法相比也具有竞争力。
- **低样本（少量标签）分类**：如只用 1% ImageNet 标签，I-JEPA 表现较好。
- **低层/密集任务**：在物体计数、深度预测等需要局部空间信息的任务上，I-JEPA 优于 DINO、iBOT 等依赖增强不变性的方法，因为它没有被迫丢弃位置等信息。
- **V-JEPA** 主要使用 **冻结骨干 + 注意力探针（attentive probe）** 评估：用一个带可学习 query 的交叉注意力层聚合 token，再分类，比简单的线性探测更能反映 patch 级特征的质量。
- 一般结论：JEPA 在 **冻结特征** 设定下表现出色，这正是它相对 MAE 的主要优势。

Q11：***V-JEPA 如何将 JEPA 扩展到视频？***

- V-JEPA（Bardes et al., 2024，"Revisiting Feature Prediction for Learning Visual Representations from Video"）完全依靠 **特征预测** 目标从视频中学习，不使用文本监督、负样本、像素重建或预训练图像编码器。
- 关键设计：
    - 视频被切分为 **时空 patch（tubelet）** 作为 token；
    - **时空多块掩码**：在空间上采样多个块，并沿时间维度延伸成"管道"，遮盖大部分时空区域，防止从相邻帧直接复制信息；
    - 预测器根据可见时空 token 和 mask token 的位置，预测被遮盖区域在 EMA 目标编码器下的表示，使用 L1 损失。
- 学到的表示在冻结评估下对 **运动理解** 与外观理解都有效，说明表示空间预测在视频上同样可行，且比像素重建更高效。

Q12：***V-JEPA 2 有什么进展？如何用于规划与机器人？***

- V-JEPA 2（Meta，2025）将视频 JEPA 预训练扩展到 **更大规模的互联网视频与更大模型**，学到更通用的视觉理解与预测能力。
- **动作条件世界模型（V-JEPA 2-AC）**：
    - 冻结预训练的视频编码器，在 **少量机器人交互数据** 上训练一个 **以动作为条件的预测器**，学习"在当前状态表示下执行某动作后，未来的表示会是什么"；
    - 规划时，给定 **目标图像** 的表示，通过 **模型预测控制（MPC）**，在表示空间中搜索使预测未来表示最接近目标表示的动作序列，执行第一个动作后重新规划；
    - 这使得机器人可以在未见过的环境中零样本完成抓取、放置等简单操作任务，而无需任务特定的奖励或大量演示。
- V-JEPA 2 的编码器还可以与语言模型对齐，用于视频问答等任务。
- 意义：这是 LeCun 世界模型构想的一个具体验证——在 **表示空间而非像素空间** 中预测未来，并用于规划。

Q13：***JEPA 中的预测器起什么作用？为什么不直接让编码器输出对齐？***

- **条件预测**：预测器以目标位置（I-JEPA）、时空位置（V-JEPA）或动作（V-JEPA 2-AC）为条件，使模型能回答"在某个位置/动作下，表示是什么"，而不是简单地要求所有视图的表示相同；
- **打破对称、防止坍塌**：与 BYOL/SimSiam 类似，预测器是非对称结构的一部分，有助于避免平凡解；
- **分离抽象层次**：预测器承担部分"推理"工作，使编码器专注于产生通用表示；论文发现预测器的深度会影响表示质量。
- 若去掉预测器、直接对齐编码器输出，就退化为基于不变性的联合嵌入方法，无法表达空间/时间上的变化关系。

Q14：***JEPA 中的隐变量 $z$ 在实践中如何体现？***

- 理论上，$z$ 用于表示 $y$ 中无法从 $x$ 推断的不确定性（例如被遮挡区域的多种可能内容），推理时通过最小化能量或采样来确定 $z$。
- 在 I-JEPA、V-JEPA 的实现中，预测器通常是 **确定性** 的，条件信息只有目标位置，没有显式的隐变量；不确定性通过在表示空间中"预测可预测部分、忽略不可预测细节"来部分处理。
- 如何高效地引入并正则化隐变量、实现多模态（多种可能未来）的预测，仍是开放问题。

Q15：***JEPA 与 LeCun 的分层世界模型（H-JEPA）构想有什么关系？***

- 立场论文提出 **分层 JEPA（H-JEPA）**：
    - 低层 JEPA 在短时间尺度上预测细节较多的表示；
    - 高层 JEPA 在更抽象的表示上做 **更长时间尺度** 的预测；
    - 不同层次的预测共同支持 **分层规划**。
- 该构想中，世界模型与感知模块、代价模块、行动者、短期记忆以及配置器（configurator）共同组成自主智能体架构。
- 目前的 I-JEPA、V-JEPA 主要实现了单层的表示学习与预测，完整的分层世界模型尚未实现。

Q16：***JEPA 的局限性与开放问题有哪些？***

- **坍塌与训练稳定性**：依赖 EMA、stop-gradient 等经验性设计，缺乏严格的理论保证，对 EMA 系数、掩码策略等超参数较敏感。
- **掩码策略依赖人工设计**：块的大小、数量、长宽比仍是手工选择，本质上是另一种归纳偏置。
- **评估方式**：冻结特征评估效果好，但在某些需要全局不变性的任务上，仍可能落后于使用强增强的方法；微调场景下的优势不如线性探测明显。
- **无法直接生成**：表示空间预测无法直接输出像素，难以解释和可视化（需要额外训练解码器）。
- **不确定性建模**：确定性预测器难以表达多种可能的未来，隐变量的实践方案尚不成熟。
- **规划能力有限**：基于世界模型的规划目前主要在较短时间跨度和较简单的任务上得到验证，长时程、分层规划仍待探索。
- **与语言的结合**：如何将 JEPA 式的世界模型与大语言模型有效结合，也是一个活跃的研究方向。
