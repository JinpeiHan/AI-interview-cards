Q3：***讲述标准的计算机视觉处理系统的主要处理步骤***

- **标准流程是：获取图像 → 预处理 → 特征提取 → 用机器学习模型做分类等任务。**
- 输入图像：由相机等成像设备获取单张图像或视频帧序列。
- 预处理：缩放、去噪、旋转、颜色空间转换等，把图像标准化，便于统一比较和分析。
- 特征提取：提取形状、颜色等描述物体的信息，输出特征向量。
- 模型：把特征送入分类器等 ML 模型得到结果。

Q4：***目标检测领域，如何判断一个特征是好特征？***

- **好特征要能在各种条件下稳定地识别同一物体，具体看三点：可重复、独特、可定位。**
- 可重复检测：同一场景的两张图中能检测到大致相同的特征，对尺度、光照、视角和噪声鲁棒。
- 独特性：特征周围的邻域足够有区分度，能和其他特征可靠地匹配。
- 可定位：特征有唯一确定的位置，不随观察条件变化。

Q5：**CNN在图像处理上表现好的原因：**

- **因为 CNN 的结构契合图像的特点：图像有局部相关性，CNN 用局部卷积去捕捉；同时 CNN 通过层层组合，从低层的边缘、曲线逐步得到高层语义，并保持空间不变性。**
- 局部相关性：每个像素和周围像素关系紧密，打乱像素图像就面目全非。
- 层次化特征：浅层提取边缘等低级特征，深层组合成高级特征。

Q6：**BatchNorm层的具体计算及作用**

- **BN 对每个通道用当前 batch 的均值和方差做标准化，再用可学习的缩放 γ 和平移 β 恢复表达能力；作用是稳定各层输入分布，让训练更快更稳定。**
- 避免参数更新和网络加深导致数据分布大幅漂移。
- γ、β 保证网络仍能保留学到的东西和非线性表达能力，必要时甚至可以还原原始分布。
- 核心公式：$y=\gamma\cdot \frac{x-\mu }{\sqrt{\sigma ^2+\varepsilon }}+\beta$

Q7：**目标检测里如何有效解决常见的前景少背景多的问题**

- **核心思路是让模型少关注大量简单背景，多关注困难样本。**
- 用 Focal Loss 或 OHEM（在线难例挖掘），提高难样本的损失权重。
- 训练时只采样 GT 周围的 prior box，忽略大部分背景，只保留困难的背景区域。

Q8：**ROIPool和ROIAlign的区别，以及ROIAlign的简单实现**

- **ROIPool 有两次取整（框坐标取整、bin 边界取整），会造成特征错位；ROIAlign 不取整，用双线性插值在浮点坐标上采样，保留了精确的空间位置。**
- 简单实现：把 ROI 均分成 k×k 个 bin，每个 bin 取几个采样点，用周围 4 个特征点双线性插值得到采样值，再做池化。
- 大目标上两者差别不大；小目标多时 ROIAlign 明显更准。

Q9：***Batch Norm在训练和推理的时候有什么区别？***

- **训练时用当前 batch 的均值和方差，并更新一个全局的移动平均；推理时不再依赖 batch，而是用训练中累积的固定均值和方差。**
- 推理时均值用各 batch 均值的平均，方差用各 batch 方差的无偏估计。
- 这样推理结果对单个样本是确定的，不受 batch 组成影响。

Q10：***为什么Relu激活函数逐渐取代了sigmoid函数？它的优势在哪里？***

- **ReLU 正区间梯度恒为 1，解决了 sigmoid 饱和导致的梯度消失；同时计算极简单，速度快。**
- 形式为 max(0, x)，两段线性拼成的非线性函数，组合起来能逼近任意函数。
- 单侧抑制让一部分神经元输出 0，带来稀疏性，减少参数依赖、缓解过拟合，也更接近生物神经元。

Q11：***ReLU函数在0处不可导，实际应用时如何解决这个问题？***

- **人为规定一个次梯度，通常直接定义 ReLU 在 0 处的导数为 0（TensorFlow 等框架就是这么实现的）；而且输入恰好等于 0 的概率极小，影响可以忽略。**

Q12：***图像处理中加入Pooling层的目的；以及Pooling层是如何反向传播的？***

- **Pooling 的目的是降维减少计算量、保留主要特征、提供对小平移/形变的不变性，从而抑制过拟合；反向传播时没有参数，只是把梯度按前向的规则分回去。**
- Average pooling 反向：把输出像素的梯度平均分成 n 份，分给对应窗口里的 n 个像素。
- Max pooling 反向：梯度只传给前向时取到最大值的那个像素，窗口内其他像素梯度为 0。

Q13：***列举几种常见的深度学习优化器，以及各自的优缺点***

- **常见优化器沿两条线改进 SGD：Momentum 用历史梯度加速并帮助冲出局部极小，Adagrad/RMSProp 给每个参数自适应学习率，Adam 把两者结合起来。**
- SGD：只用当前一阶梯度，简单但慢，容易卡在局部最优。
- Momentum：在梯度上叠加上一步的更新方向，收敛更快、更能逃离局部极小。
- Adagrad：按历史梯度平方和缩放学习率，梯度大的参数学习率降得快；缺点是累积量只增不减，后期更新过慢。
- RMSProp：给 Adagrad 的累积加衰减，解决后期太慢的问题；Adam = Momentum + RMSProp，是最常用的默认选择。

引用：[https://medium.com/towards-data-science/a-visual-explanation-of-gradient-descent-methods-momentum-adagrad-rmsprop-adam-f898b102325c](https://medium.com/towards-data-science/a-visual-explanation-of-gradient-descent-methods-momentum-adagrad-rmsprop-adam-f898b102325c)

Q14：***卷积层的FLOPs和参数量***

- **FLOPs 指浮点运算次数，用来衡量模型复杂度。卷积层参数量 = 每个卷积核的权重数（k²·C_in）加偏置，再乘以卷积核个数 C_out；FLOPs 则是每个输出点的乘加次数乘以输出点总数。**
- 参数量即 (k²·C_in + 1)·C_out，其中 +1 是偏置。
- 核心公式（FLOPs，乘加各算一次）：$2C_{in}k^2\cdot C_{out}HW$，其中 H、W 为输出特征图的高宽。

Q15：***使用F1-Score评价模型性能好坏有哪些好处？***

- **F1 是精确率和召回率的调和平均，同时兼顾两者，而且结果偏向两者中较小的那个，所以只有 P 和 R 都高时 F1 才高。**
- 用调和平均而不是算术平均，是为了避免一个指标很高掩盖另一个很低。
- 在类别不平衡时比准确率更能反映模型真实表现。
- 核心公式：$F1 = \frac{2PR}{P+R}$

Q16：***ROI Pooling 和 ROI Align 的区别是什么***

- **两者都是把大小不一的候选框变成固定尺寸特征（如 7×7）送入检测头；最大区别是 ROI Pooling 做了两次取整量化，ROI Align 不量化，而是用双线性插值。**
- ROI Pooling 步骤：ROI 坐标除以 stride 映射到特征图并取整（第一次量化）→ 均分成 k×k 个 bin 并对边界取整（第二次量化）→ 每个 bin 内 max pooling。
- ROI Pooling 的意义：所有 ROI 共享整张图的卷积特征，不用像 R-CNN 那样对每个框重复卷积，速度大幅提升。
- ROI Align 做法：保留浮点坐标，每个 bin 取若干（通常 4 个）采样点，用双线性插值求值再池化；反向时梯度按插值权重回传。
- 量化带来的错位：特征图上偏 1 个像素对应原图约 16 个像素，对分类影响小，但对 mask 预测和小目标影响大，所以 Mask R-CNN 改用 ROI Align。

Q17：***特征融合时，concat和add操作的区别是什么？***

- **add 是对应位置相加，通道数不变，相当于每个特征里的信息变多；concat 是在通道维拼接，通道数变多，相当于特征的个数变多但每个特征的信息不变。**
- add 计算量更小，要求两路形状完全一致（如 ResNet）。
- concat 保留了各路的原始信息，由后续层决定如何融合（如 DenseNet、U-Net）。

Q18：***阐述深度可分离卷积***

- **深度可分离卷积把普通卷积拆成两步：先逐通道做空间卷积（depthwise），再用 1×1 卷积做通道融合（pointwise），大幅减少参数量和计算量。**
- 深度卷积：每个输入通道单独用一个 k×k 卷积核，输出通道数等于输入通道数，各通道结果不相加。
- 逐点卷积：在此基础上用 1×1 卷积组合通道、改变通道数。
- 是 MobileNet 等轻量网络的核心组件。

Q19：***计算深度可分离卷积的FLOPs***

- **总 FLOPs 等于深度卷积和 1×1 逐点卷积两部分之和，相比普通卷积约降为 1/C_out + 1/k²。**
- 深度卷积部分：每个通道一个 k×k 卷积，约 2k²·HW·C_in。
- 逐点卷积部分：每个位置做一次 C_in → C_out 的线性变换，约 2·C_in·HW·C_out。
- 核心公式（总计）：$2HWC_{in}(k^2 + C_{out})$

Q20：***简述LBP算法原理***

- **LBP 是一种局部纹理描述子：在 3×3 窗口中，把周围 8 个像素和中心像素比较，大于中心记 1、否则记 0，得到的 8 位二进制数（共 256 种）就是中心像素的 LBP 值。**
- 优点：具有旋转不变性（改进版本）、对光照变化鲁棒、特征维度低、计算快。

Q21：***简述HOG算法原理***

- **HOG 通过统计图像局部区域的梯度方向直方图来描述物体形状，常用于行人检测。**
- 把图像分成小的 cell，计算每个像素的梯度大小和方向，统计每个 cell 的方向直方图。
- 把若干 cell 组成 block，在 block 内做对比度归一化，提升对光照和阴影的不变性。
- 把所有 block 的描述子串起来，就是整幅图的 HOG 特征。

Q22：***边缘检测算子有哪些以及它们之间的对比***

- **边缘检测算子主要分三类：基于一阶导数找梯度极值的（Roberts、Prewitt、Sobel），基于二阶导数找过零点的（Laplacian），以及综合性的 Canny 算子。**
- 一阶导数类：简单快速，边缘较粗，对噪声较敏感。
- 二阶导数类：定位准确，但对噪声更敏感。
- Canny：高斯平滑 + 梯度 + 非极大值抑制 + 双阈值，边缘细而连续，效果最好但计算更复杂。

Q23：***常见的图像插值方式***

- **常见的有三种：最近邻、双线性和双三次插值，效果依次变好，计算量依次变大。**
- 最近邻：直接取距离最近像素的值，最快但有锯齿。
- 双线性：用周围 4 个像素在两个方向上各做一次线性插值，效果平滑。
- 双三次：用周围 16 个像素按三次多项式加权，细节保留最好但最慢。

Q24：***FAST算法的原理***

- **FAST 是一种快速角点检测算法：看候选点 p 周围圆环上的 16 个像素，如果有连续 n 个像素都比 p 明显更亮或都明显更暗，就认为 p 是角点。**

![Untitled](%E8%AE%A1%E7%AE%97%E6%9C%BA%E8%A7%86%E8%A7%89/Untitled%202.png)

- 优点是速度很快；缺点是受噪声影响大，没有尺度不变性和旋转不变性。

Q25：**简述BRIEF算法原理**

- **BRIEF 是一种二进制特征描述子：在特征点周围的 s×s 邻域内随机选 n 个点对，比较每对点的灰度大小得到 0/1，拼成一个 n 位二进制串作为描述子。**
- 先对图像做高斯滤波，因为随机点对比较对噪声很敏感。
- n 一般取 128、256 或 512；匹配时用汉明距离，速度很快。
- 缺点是没有旋转不变性。

Q26：***简述ORB算法原理***

- **ORB = FAST 检测特征点 + BRIEF 描述特征，并解决了 BRIEF 没有旋转不变性的问题。**
- 方法是灰度质心法：计算特征点邻域的灰度质心，特征点指向质心的向量作为主方向。
- 描述时先按主方向旋转再做 BRIEF，图像旋转后描述子保持一致，从而实现旋转不变性。

Q27：**简述SIFT特征；SIFT特征和SURF特征有什么区别？**

- **SIFT 是一种局部特征，在不同尺度空间里找关键点并计算方向，对旋转、尺度、亮度变化不变，对视角变化、仿射变换和噪声也比较稳定；SURF 是 SIFT 的加速版，用盒子滤波和积分图近似，速度快得多，鲁棒性相当。**
- SIFT 四步：尺度空间极值检测、关键点定位、方向确定、关键点描述。
- 主要区别：

|  | SIFT | SURF |
| --- | --- | --- |
| 尺度空间 | 用 DoG 与不同尺度图像卷积 | 用不同尺度的 box filter 与原图卷积 |
| 关键点检测 | 非极大值抑制 + 去低对比度点 + Hessian 去边缘点 | 先用 Hessian 矩阵找候选点，再非极大值抑制 |
| 方向 | 统计方形区域的梯度直方图，取峰值方向 | 统计圆形区域内扇形的 Haar 小波响应，取最大方向 |
| 描述子 | 4×4 子区域 × 8 方向 = 128 维 | 4×4 子区域 × 4 个 Haar 统计量 = 64 维 |

引用：[Sift与Surf的区别_eternity1118_的博客-CSDN博客_surf和sift区别](https://blog.csdn.net/eternity1118_/article/details/51152162)

Q28：**你了解哪些图像语义分割任务的loss？**

- **最常用的是逐像素交叉熵；为应对类别不平衡和难样本，有加权交叉熵和 Focal Loss；为直接优化重叠度，有 Dice Loss 和 IoU Loss。**
- 交叉熵：对每个像素的预测分布和 one-hot 标签算交叉熵，再对全图取平均。
- 加权交叉熵：给像素少的类别更大权重，缓解类别不平衡。
- Focal Loss：自动降低易分样本的权重，专注训练难样本。
- Dice / IoU Loss：直接以预测和标签的重叠程度为目标，对小目标和不平衡更友好。
- 核心公式（单像素交叉熵）：$-\sum_{c} y_c\log \hat{y}_c$

Q29：**在边缘检测任务中，比较Sobel算子和Canny算子**

- **Sobel 简单快速，但边缘较粗；Canny 加入了非极大值抑制和双阈值，边缘更细、更平滑、更连续，代价是更复杂、更慢。**

Q30：**为什么图像在输入网络前要对图像做归一化？**

- **归一化把输入拉到统一的尺度，消除量纲差异，让梯度下降收敛更快、更稳定，有时还能提高精度。**
- 消除量纲：不同特征之间可比。
- 加快收敛：损失曲面更"圆"，梯度下降不容易来回震荡。
- 提高精度：对 KNN 等基于距离的方法，避免值域大的特征主导距离计算。

Q31：***在使用Yolo网络做目标检测时，可能会碰到什么问题？***

- **早期 YOLO 每个网格只能预测很少的物体，所以对成群的小目标（如一排蚂蚁）检测效果差；此外它对光照等环境变化较敏感，模型计算量也让边缘端部署有难度。**
- 小目标与密集目标：一个网格内多个物体时容易漏检。
- 环境变化：光照条件变化大的实际场景中表现不稳定。
- 部署：计算资源消耗较大，边缘设备上需要剪枝、量化或轻量版本。

## 深度学习在图像领域的优势

Q32：***为什么深度学习在图像处理和计算机视觉领域表现如此出色？***

- **因为深度网络能端到端地从像素中自动学习层次化特征，远强于手工设计的 SIFT、HOG；再加上 CNN 契合图像的结构、大规模数据和 GPU 算力的支撑，使得训练很深的网络成为可能。**
- 层次化特征：浅层学边缘纹理，中层学部件，深层学物体语义。
- 归纳偏置：局部连接和权值共享契合图像的局部相关性，参数少、易训练，并带来一定平移不变性（见 Q5）。
- 端到端优化：特征提取和下游任务联合训练，避免多阶段误差累积。
- 数据、算力与技巧：ImageNet/COCO、数据增强、GPU，以及 ReLU、BN、残差连接等；预训练模型还能很好地迁移到下游任务。

## CNN 基础结构

Q33：***CNN 中卷积层、池化层、全连接层分别有什么作用？***

- **卷积层负责提取局部特征，池化层负责下采样降维并提供一定不变性，全连接层负责把特征映射到类别上做分类。**
- 卷积层：卷积核在输入上滑动做局部加权求和，局部连接 + 权值共享让参数很少；堆叠多层后感受野变大，从低级特征组合出高级语义。
- 池化层（详见 Q12）：max/average 下采样，减少计算量、增大感受野，提供对小平移/形变的不变性。
- 全连接层：整合全局信息起"分类器"作用；缺点是参数多（VGG 的大部分参数都在这里）且要求固定输入尺寸，所以现代网络常用全局平均池化（GAP）替代。

Q34：***1×1 卷积为什么可以降低或改变通道数？如何引入非线性？***

- **1×1 卷积在每个像素位置上对通道向量做一次线性变换（相当于逐像素的全连接），输出通道数等于卷积核个数，所以设成比输入少就是降维、多就是升维，空间尺寸不变；它本身是线性的，非线性来自其后接的 BN + ReLU。**
- 减少计算：Inception/ResNet bottleneck 先把 256 通道降到 64 再做 3×3，最后再升回 256，计算量和参数量大幅下降。
- 增加非线性：在不改变感受野的前提下加深网络（Network in Network 的思想）。
- 跨通道融合：对不同通道的特征做线性组合，实现通道间的信息交互。
- 核心公式：$y_{i,j} = W x_{i,j} + b,\ W \in \mathbb{R}^{C_{out}\times C_{in}}$
- 参见：[深度学习基础](深度学习基础.md) Q15；[CNN](CNN.md) Q16

## 图像分类模型（VGG、ResNet、Inception）

Q35：***简述图像分类经典网络 VGG、ResNet 及其变种、Inception V2/V3***

- **VGG 用堆叠的 3×3 小卷积把网络做深；ResNet 用残差连接解决深层网络的退化问题，可以训练上百层；Inception 用并行的多尺度卷积分支提取特征，V2/V3 主要在加 BN 和卷积分解上做改进。**
- VGG：全部 3×3 卷积 + 2×2 池化，结构规整；两个 3×3 等效一个 5×5 但参数更少；缺点是参数量大（约 1.38 亿，主要在全连接层）。
- ResNet：学习残差，ResNet50 以上用 1×1 降维 → 3×3 → 1×1 升维的 bottleneck。变种有：Pre-activation ResNet（BN、ReLU 前移）、ResNeXt（分组卷积）、Wide ResNet（更宽）、DenseNet（与前面所有层 concat）、SE-ResNet（通道注意力）。
- Inception V1（GoogLeNet）：并行 1×1、3×3、5×5 卷积和池化后在通道上 concat，用 1×1 降维省计算。
- Inception V2：引入 BN 加快收敛，用两个 3×3 替代 5×5。
- Inception V3：非对称分解（如 7×7 → 1×7 + 7×1）、改进下采样模块避免表达瓶颈、使用 Label Smoothing，输入 299×299。

Q36：***ResNet 的主要创新是什么？残差模块的结构与原理？为什么残差连接能改善深层网络训练、缓解梯度消失和深度增加时的性能退化？***

- **ResNet 的核心创新是残差学习加恒等快捷连接：每个模块只学习"在输入基础上的改动"，学不到东西时就退化为恒等映射，因此加深网络至少不会变差，上百层的网络也能训练。**
- 结构：残差分支是两个 3×3 卷积（basic block）或 1×1-3×3-1×1（bottleneck），每个卷积后接 BN，相加后再 ReLU；维度不一致时 shortcut 用带 stride 的 1×1 卷积做投影。
- 缓解梯度消失：反向传播时梯度可以沿 shortcut 直接无衰减地传回浅层，不再是很多小于 1 的项连乘。
- 缓解退化：退化指网络加深后训练误差反而上升，是优化困难而不是过拟合；普通深层网络很难学出恒等映射，而残差结构把恒等映射变成默认解（残差为 0），新增层只需学小扰动。
- 另一种理解：残差网络相当于许多不同深度子网络的集成，信息和梯度都有短路径，优化曲面更平滑。
- 核心公式：$y = F(x) + x$

## 目标检测（Faster R-CNN、Mask R-CNN）

Q37：***Faster R-CNN 和 Mask R-CNN 的工作原理以及区别是什么？***

- **Faster R-CNN 是两阶段检测器：backbone 提特征，RPN 生成候选框，ROI Pooling 把每个框变成固定尺寸特征，再由检测头做分类和边框回归。Mask R-CNN 在此基础上加了一个并行的 mask 分支做实例分割，并把 ROI Pooling 换成更精确的 ROI Align。**
- Faster R-CNN：RPN 基于 anchor 生成候选框并经 NMS 筛选；检测头做 K+1 类分类和类别相关的框回归，最后再 NMS。
- Mask R-CNN：通常用 ResNet + FPN 输出多尺度特征；mask 分支是一个小 FCN，为每个 ROI 输出每类一个 28×28 的二值 mask。
- 主要区别：

|  | Faster R-CNN | Mask R-CNN |
| --- | --- | --- |
| 任务 | 目标检测（类别 + 边框） | 检测 + 实例分割（再加像素级 mask） |
| ROI 特征提取 | ROI Pooling（两次量化） | ROI Align（双线性插值，无量化） |
| 头部分支 | 分类 + 回归 | 分类 + 回归 + mask（并行） |
| 损失 | $L_{cls}+L_{box}$ | $L_{cls}+L_{box}+L_{mask}$ |

Q38：***RPN 是什么？详细说明其网络结构***

- **RPN 是 Faster R-CNN 提出的一个小型全卷积网络，在共享的特征图上用 anchor 快速生成候选框，取代了耗时的 Selective Search，并能端到端训练。**
- Anchor：特征图每个位置预设 k 个参考框，原论文为 3 种尺度 × 3 种长宽比，k=9。
- 结构：特征图先过一个 3×3 卷积（512 通道 + ReLU），再接两个并行的 1×1 卷积：分类分支输出 2k 个通道（每个 anchor 前景/背景得分），回归分支输出 4k 个通道（每个 anchor 4 个偏移量）。
- 生成候选框：偏移量作用到 anchor 上 → 裁剪越界、去掉过小框 → 按得分取 top-N → NMS（IoU 0.7）→ 训练时约 2000、测试时约 300 个 proposal。
- 样本分配：与 GT 的 IoU > 0.7 为正样本，< 0.3 为负样本，其余忽略；每张图采 256 个 anchor，正负尽量 1:1。在 FPN 中每层共享 RPN 头，每层只用一种尺度。
- 核心公式（偏移量参数化）：$t_x=\frac{x-x_a}{w_a},\ t_y=\frac{y-y_a}{h_a},\ t_w=\log\frac{w}{w_a},\ t_h=\log\frac{h}{h_a}$

Q39：***RPN 的 Loss 由什么组成，如何计算？分类 Loss 是二分类还是多分类？***

- **RPN 的损失由分类损失和边框回归损失两部分组成；分类是二分类（前景 vs 背景），只判断 anchor 里有没有物体，具体的多类别分类在第二阶段的检测头完成。**
- 分类损失：二分类交叉熵，对采样的正负 anchor 都计算。
- 回归损失：smooth L1，只对正样本计算（负样本没有对应 GT）。smooth L1 在误差小时像平方损失、梯度平滑，误差大时是线性的，对离群点不敏感。
- 归一化与权重：分类项除以 mini-batch 大小（256），回归项除以 anchor 位置数（约 2400），λ=10 让两项量级相当；实践中也常用正样本数归一化、λ=1。
- 核心公式：$L = \frac{1}{N_{cls}}\sum_i L_{cls}(p_i, p_i^*) + \lambda \frac{1}{N_{reg}}\sum_i p_i^* L_{reg}(t_i, t_i^*)$

Q40：***Faster R-CNN 的 Loss 由哪些部分组成，分别有什么含义？***

- **Faster R-CNN 的总损失是 RPN 和检测头两阶段损失之和，共四项：RPN 的前景/背景分类和框回归，检测头的 K+1 类分类和框回归。**
- RPN 分类：二分类交叉熵，学会判断 anchor 里有没有物体。
- RPN 回归：正样本 anchor 到 GT 偏移量的 smooth L1，让候选框更接近真实物体（见 Q39）。
- 检测头分类：对每个 ROI 做 K+1 类（含背景）softmax 交叉熵；检测头回归：只对前景 ROI、只用其 GT 类别那组偏移量算 smooth L1，对候选框进一步精修。
- 训练细节：每张图采样 128 或 512 个 ROI，IoU ≥ 0.5 为正、[0.1, 0.5) 为负，正样本约 25%；原论文四步交替训练，现在通常把四项直接相加端到端训练。
- 核心公式：$L = L_{cls}^{rpn} + L_{reg}^{rpn} + L_{cls}^{det} + L_{reg}^{det}$

Q41：***Mask R-CNN 相比 Faster R-CNN 增加了哪些组件？为什么？Mask R-CNN 的基本结构是什么？***

- **Mask R-CNN 的结构是：ResNet + FPN 主干 → RPN 生成候选框 → ROI Align 提取特征 → 分类、框回归、mask 三个并行头。相比 Faster R-CNN，主要增加了 mask 分支、用 ROI Align 替代 ROI Pooling，并常配 FPN，目的都是实现精确的像素级实例分割。**
- Mask 分支：小型全卷积网络，为每个 ROI 输出每类一个 28×28 的 mask；用卷积而不是全连接，是为了保留空间结构。
- ROI Align：去掉量化带来的错位，mask 精度显著提升，尤其是小目标。
- FPN：融合高层语义和低层细节，提升多尺度和小目标效果（不是 Mask R-CNN 独有，但是常用配置）。
- 分类与 mask 解耦：每类独立预测二值 mask（逐像素 sigmoid + 二值交叉熵，只算 GT 类别那一个通道），类别之间不竞争，由分类分支决定类别，效果明显好于逐像素 softmax。
- 推理时先得到检测框，再在框上跑 mask 分支，取预测类别的 mask，缩放到框大小并以 0.5 为阈值二值化。
