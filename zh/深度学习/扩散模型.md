# 扩散模型

Q1：***什么是扩散模型？核心思想是什么？***

- **扩散模型先把真实数据一步步加噪直到变成纯高斯噪声，再训练一个网络把这个过程反过来，从噪声一步步去噪生成数据。**
- 前向加噪过程是固定的，没有可学习参数；反向去噪过程由神经网络学习。
- 核心思想：把“从噪声直接生成数据”这个难题，拆成许多个“只去掉一点噪声”的简单小问题。
- 代表工作：DDPM、Score-based SDE、DDIM、Latent Diffusion（Stable Diffusion）、DiT。

Q2：***写出前向过程的定义，以及 $q(x_t|x_0)$ 的闭式解***

- **每一步把上一步的数据稍微缩小、再加一点高斯噪声；由于高斯可以叠加，任意时刻的 $x_t$ 都能从 $x_0$ 一步直接算出来。**
- 噪声大小由预设的噪声调度 $\beta_t$ 控制，记 $\alpha_t=1-\beta_t$，$\bar\alpha_t=\prod_{s\le t}\alpha_s$。
- 意义：训练时不用逐步模拟加噪，随机采一个 $t$ 就能直接构造 $x_t$，训练很高效。
- 缩放系数 $\sqrt{1-\beta_t}$ 保证方差不发散（variance preserving）；$T$ 足够大时 $x_T$ 近似标准高斯。
- 核心公式：$x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\ \epsilon\sim\mathcal{N}(0,I)$

Q3：***反向过程是怎样建模的？***

- **真实的反向分布 $q(x_{t-1}|x_t)$ 算不出来，但每步噪声很小时它近似是高斯，所以用一个网络输出高斯的均值（和方差）来近似它。**
- 在已知 $x_0$ 的条件下，反向后验 $q(x_{t-1}|x_t,x_0)$ 是可以解析计算的高斯，训练就是让网络去拟合它。
- DDPM 把方差固定（取 $\beta_t$ 或 $\tilde\beta_t$），只学均值；Improved DDPM 让模型也学习方差。
- 核心公式：$p_\theta(x_{t-1}|x_t)=\mathcal{N}\big(\mu_\theta(x_t,t),\Sigma_\theta(x_t,t)\big)$

Q4：***DDPM的训练目标是什么？为什么预测噪声？***

- **理论目标是最大化似然的变分下界（ELBO），化简后变成一个很简单的回归任务：给加噪后的图像，让网络预测当初加进去的噪声，用 MSE 训练。**
- 训练流程：采样 $x_0$、时间步 $t$ 和噪声 $\epsilon$ → 构造 $x_t$ → 网络预测 $\epsilon$ → 算 MSE。
- 预测噪声的好处：目标始终是标准高斯，尺度统一，优化稳定。
- 简化损失去掉了 ELBO 中的加权系数，相当于降低了简单的小噪声步的权重，实验中样本质量更好。
- 网络通常是带时间步嵌入的 U-Net（或 Transformer）。
- 核心公式：$L_{simple}=\mathbb{E}\big[\|\epsilon-\epsilon_\theta(x_t,t)\|^2\big]$

Q5：***DDPM如何采样？有什么缺点？***

- **从纯高斯噪声 $x_T$ 出发，每一步用网络预测的噪声算出去噪后的均值，再加一点随机噪声，重复 $T$ 步得到样本。**
- 最后一步不再加噪声；整个过程类似朗之万动力学：沿学到的方向走一步，再加点扰动。
- 缺点：每一步都要一次网络前向，原始 DDPM 用 $T=1000$ 步，采样比 GAN 的单步生成慢得多。

Q6：***噪声调度有哪些？余弦调度为什么比线性调度好？***

- **常见的有线性调度和余弦调度；余弦调度让信息被破坏得更均匀，不像线性调度那样过早变成纯噪声，所以样本质量和似然都更好。**
- 线性调度：$\beta_t$ 从 $10^{-4}$ 线性增加到 $0.02$；在低分辨率图像上信息破坏过快，后面很多步几乎是纯噪声，对训练帮助很小。
- 余弦调度（Improved DDPM）：直接按余弦曲线定义 $\bar\alpha_t$，中间段近似线性下降，两端平缓。
- 更一般地可以用信噪比 SNR 描述调度；高分辨率图像像素冗余大，需要把调度往更高噪声方向偏移。
- 注意终端 SNR 不为零会导致训练和推理（从纯噪声开始）不一致，可重新缩放调度使其为零（常配合 v-prediction）。
- 核心公式：$\text{SNR}(t)=\frac{\bar\alpha_t}{1-\bar\alpha_t}$

Q7：***扩散模型与分数匹配（score matching）有什么关系？***

- **预测噪声和估计分数（对数密度的梯度）本质上是一回事，只差一个缩放系数；DDPM 的损失就是在多个噪声尺度上做的去噪分数匹配。**
- 分数 $\nabla_x\log p(x)$ 指向数据密度增大的方向，有了它就能用朗之万动力学采样。
- 对加噪数据，条件分数正好是 $-\epsilon/\sqrt{1-\bar\alpha_t}$，所以学会预测噪声就学会了分数。
- NCSN（噪声条件分数网络）和 DDPM 是同一思想的两种表述。
- 核心公式：$s_\theta(x_t,t)\approx-\frac{\epsilon_\theta(x_t,t)}{\sqrt{1-\bar\alpha_t}}$

Q8：***如何从SDE的角度理解扩散模型？***

- **当步数趋于无穷时，加噪过程变成一个随机微分方程（SDE）；它有一个只依赖分数函数的反向 SDE 用于生成，还有一个边缘分布相同的确定性概率流 ODE。**
- DDPM 对应 VP-SDE（方差保持），NCSN 对应 VE-SDE（方差爆炸），SDE 框架把两者统一起来。
- 概率流 ODE 采样是确定性的，可以用高阶 ODE 求解器加速（DPM-Solver 等的理论基础）。
- 通过 ODE 能在噪声和数据之间做可逆映射（编码/反演），并能精确计算似然。
- 核心公式（前向 SDE）：$dx=f(x,t)\,dt+g(t)\,dw$

Q9：***DDIM相比DDPM有什么改进？***

- **DDIM 构造了与 DDPM 边缘分布相同的非马尔可夫过程，因此可以直接用训练好的 DDPM 模型，但能跳步采样、并且可以做到完全确定性。**
- 采样时先由预测噪声估计 $\hat x_0$，再直接跳到更早的时间步；只用几十步质量下降也不大。
- 噪声项 $\sigma_t=0$ 时完全确定（相当于概率流 ODE 的离散化），取特定 $\sigma_t$ 时退化为 DDPM。
- 确定性使同一初始噪声对应同一输出，支持语义插值和 DDIM 反演（inversion），常用于图像编辑。

Q10：***什么是分类器引导（classifier guidance）？***

- **额外训练一个能在加噪图像上判断类别的分类器，采样时把它对目标类别的梯度加到分数上，把样本往“更像这个类别”的方向推。**
- 原理是贝叶斯公式：条件分数 = 无条件分数 + 分类器的对数概率梯度。
- 引导强度 $w$ 越大，样本越符合类别、保真度越高，但多样性越低。
- 缺点：要额外训练能处理各种噪声水平的分类器；梯度可能有对抗性的“欺骗”效果；难以扩展到文本等复杂条件。
- 核心公式：$\nabla\log p(x_t|y)=\nabla\log p(x_t)+\nabla\log p(y|x_t)$

Q11：***什么是无分类器引导（classifier-free guidance, CFG）？与分类器引导有何区别？***

- **用同一个模型同时学有条件和无条件的预测（训练时随机丢掉条件），采样时把两者的差值放大，从而在不需要额外分类器的情况下增强条件的作用。**
- 训练时以约 10% 的概率把条件替换为空条件（条件 dropout）；两者之差相当于一个“隐式分类器”的梯度。
- 相比分类器引导：无需额外分类器、实现简单、适用于文本等任意条件，效果通常更好，是文生图的标准做法。
- 代价是每步需要两次前向（可合并为一个 batch）；系数过大会过饱和、颜色失真、多样性下降。负向提示词可替代空条件。
- 核心公式：$\tilde\epsilon=\epsilon_\theta(x_t,\varnothing)+w\big(\epsilon_\theta(x_t,c)-\epsilon_\theta(x_t,\varnothing)\big)$

Q12：***潜在扩散模型（Latent Diffusion / Stable Diffusion）的结构是怎样的？***

- **先用 VAE 把图像压缩到低维潜空间，在潜空间里用 U-Net 做扩散去噪，文本通过交叉注意力注入，最后用 VAE 解码器还原成图像。**
- VAE：空间下采样约 8 倍，负责感知压缩和还原。
- U-Net 去噪网络：带时间步嵌入、残差和注意力模块，在潜空间中迭代去噪。
- 文本编码器（如 CLIP）：把提示词编码为 token 嵌入；交叉注意力中图像特征做 Query，文本嵌入做 Key/Value。
- 优点：在潜空间而非像素空间扩散，计算量和显存大幅降低，高分辨率文生图能跑在消费级 GPU 上。

Q13：***DiT（Diffusion Transformer）是什么？相比U-Net有什么优势？***

- **DiT 用 Transformer 替代 U-Net 作为去噪骨干：把潜变量切成 patch 当作 token，条件通过自适应 LayerNorm 注入；它最大的优势是随规模增大效果稳定提升。**
- 时间步和类别等条件通过 adaLN 注入，最好的变体是 adaLN-Zero（调制参数零初始化，每个残差块初始为恒等映射）。
- 可扩展性好：计算量（GFLOPs）越大，FID 越低，规模化趋势清晰。
- 结构统一简单，能复用 Transformer 的工程优化，也便于处理多模态条件和可变长度/分辨率输入。
- 后续的 SD3（MMDiT）、Sora 等图像和视频模型都采用 Transformer 骨干。

Q14：***ControlNet是如何给扩散模型加入额外条件控制的？***

- **冻结原始 U-Net，复制一份它的编码器作为可训练分支来接收边缘图、深度图、姿态等空间条件，再通过初始化为零的卷积把输出加回原网络。**
- 零卷积（权重和偏置都初始化为 0 的 1×1 卷积）保证训练开始时对原模型没有任何影响。
- 因此不会破坏预训练的生成能力，在小数据集上也能稳定训练。
- 类似的轻量控制方法还有 T2I-Adapter、IP-Adapter（图像提示）等。

Q15：***如何用LoRA微调扩散模型？与DreamBooth、Textual Inversion有什么区别？***

- **LoRA 冻结原权重，只在注意力层上学一个低秩增量；DreamBooth 是对整个模型微调来绑定一个主体；Textual Inversion 则只学一个新的词嵌入。三者参数量和表达能力依次是：中、大、小。**
- LoRA：可训练参数少、文件小、训练快，多个 LoRA 能按权重叠加，常用来学风格、人物或概念。
- DreamBooth：用少量主体图像把主体绑定到罕见标识符上，用先验保持损失防止过拟合和语言漂移；效果好但开销大，常与 LoRA 结合。
- Textual Inversion：模型完全冻结，参数最少，但表达能力有限。
- 核心公式：$W'=W+BA,\ r\ll\min(d,k)$

Q16：***有哪些加速扩散模型采样的方法？***

- **主要有两大类：不用重新训练、换更好的 ODE 求解器来减少步数；或者通过蒸馏训练一个少步甚至一步生成的模型。**
- 更好的求解器：DDIM 跳步；DPM-Solver/DPM-Solver++ 利用概率流 ODE 的半线性结构，十几到二十步即可；还有 PNDM、UniPC、Heun/EDM 等。
- 蒸馏：渐进式蒸馏（学生一步模拟教师两步，每轮步数减半）；对抗蒸馏（如 SDXL-Turbo 的 ADD）；分布匹配蒸馏（DMD）。
- 一致性模型：直接学一步映射到数据（见下一题）。
- 其他：潜空间扩散降低每步开销、缓存中间特征、用更直的轨迹（rectified flow）。

Q17：***什么是一致性模型（Consistency Models）？***

- **一致性模型学习一个函数，把概率流 ODE 同一条轨迹上的任意一点都直接映射到轨迹起点（干净数据），因此可以一步生成。**
- 自一致性约束：同一轨迹上的点输出相同；边界条件（最小噪声时输出等于输入）通过跳跃连接参数化保证。
- 训练方式：一致性蒸馏（CD，用预训练扩散模型的 ODE 求解器得到相邻点对）或一致性训练（CT，不依赖预训练模型）。
- 也可以多步采样：生成后再加噪、再映射，用计算换质量。
- 潜在一致性模型（LCM）把它用到 Stable Diffusion 潜空间，实现几步出图。

Q18：***什么是流匹配（Flow Matching）和整流（Rectified Flow）？***

- **流匹配直接学习一个速度场，用 ODE 把噪声“流”到数据；整流（Rectified Flow）选用噪声和数据之间的直线路径，轨迹越直，用越少的步数就能生成。**
- 最常用的是线性插值路径，训练目标就是让网络预测这条直线的速度（噪声减数据）；不同文献的时间方向约定可能相反。
- Reflow：用当前模型生成噪声-数据配对再重新训练，把轨迹进一步拉直，甚至可以一步生成。
- 扩散模型的概率流 ODE 可以看作一种特殊的流匹配路径；流匹配更简洁，不需要 SDE 理论，路径设计更灵活。
- Stable Diffusion 3、FLUX 等采用 rectified flow 目标。
- 核心公式：$x_t=(1-t)x_0+t\epsilon,\quad L=\mathbb{E}\big[\|v_\theta(x_t,t)-(\epsilon-x_0)\|^2\big]$

Q19：***什么是v-prediction？为什么要使用它？***

- **v-prediction 让网络预测噪声和干净数据的一种加权组合（“速度” $v$），它在高噪声和低噪声两端都数值稳定，避免了预测噪声或预测 $x_0$ 各自在某一端的问题。**
- 预测 $\epsilon$ 的问题：高噪声端 $x_t$ 几乎全是噪声，从预测的噪声反推 $x_0$ 会放大误差；终端 SNR 为零时甚至得不到有意义的 $x_0$。
- 预测 $x_0$ 的问题：低噪声端模型容易学成恒等映射。
- 三种参数化可以互相转换；v-prediction 适合渐进式蒸馏和零终端 SNR 调度，SD 2.x 部分模型采用了它。
- 核心公式：$v=\sqrt{\bar\alpha_t}\,\epsilon-\sqrt{1-\bar\alpha_t}\,x_0$

Q20：***如何评估扩散模型（特别是文生图模型）？***

- **最常用的是 FID 衡量图像质量和多样性、CLIP Score 衡量图文一致性，再配合人类偏好分数和人工评估。**
- FID：生成分布与真实分布在 Inception 特征空间的距离，越低越好。
- CLIP Score：图像与提示词的 CLIP 嵌入相似度，越高越好；增大 CFG 通常提高 CLIP Score 但让 FID 变差，常画 FID-CLIP 曲线比较。
- 其他：IS、Precision/Recall、KID、基于 DINOv2 特征的 FD；组合性基准（GenEval、T2I-CompBench）；偏好模型（ImageReward、PickScore、HPS）。
- 人工评估仍重要，自动指标对美学和手、文字等细节不敏感；似然指标（bits-per-dim）与视觉质量相关性不高。

Q21：***扩散模型与GAN各有什么优缺点？***

- **扩散模型训练稳定、多样性好、容易扩展和控制，但采样慢；GAN 一步生成很快，但训练不稳定、容易模式崩溃，难以扩展到开放域文生图。**
- 扩散模型的目标是简单的 MSE 回归，没有对抗博弈；基于似然的训练不易模式崩溃。
- 扩散模型便于引入文本等条件，支持编辑、修复、引导；但没有 GAN 那样紧凑语义化的单步隐空间（DDIM 反演可部分弥补）。
- GAN 在人脸等窄领域质量很高，StyleGAN 隐空间编辑能力强。
- 趋势：二者融合，例如用对抗损失做扩散蒸馏，实现少步高质量生成。

Q22：***视频扩散模型的一般思路是什么？有哪些主要挑战？***

- **思路是把图像扩散扩展到时空数据：用视频 VAE 压缩出时空潜变量，再用加了时间注意力的网络或时空 Transformer 对整段视频联合去噪；最大挑战是时间一致性和计算开销。**
- 骨干：在图像模型上加时间维度的注意力/卷积（空间+时间分解），或把视频切成时空 patch 做全时空注意力（DiT 式）。
- 常从预训练图像扩散模型初始化以复用图像先验；条件可以是文本、首帧图像、运动或相机控制。
- 挑战：保持物体身份和运动连贯、避免闪烁；token 数随时长和分辨率快速增长；长视频需要分段或自回归扩展。
- 高质量带描述的视频数据难获取，物理规律和因果合理性也难建模。
