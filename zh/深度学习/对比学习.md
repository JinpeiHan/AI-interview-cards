# 对比学习

Q1：***什么是对比学习？核心思想是什么？***

- 对比学习（Contrastive Learning）是一种 **自监督表示学习** 方法：不需要人工标签，通过构造 **正样本对**（语义相同，如同一张图的两种增强）和 **负样本对**（语义不同，如不同图片），学习一个编码器，使得：
    - 正样本在表示空间中 **相互靠近**；
    - 负样本 **相互远离**。
- 学到的表示对数据增强等无关变化 **不变**，同时保留区分不同样本的信息，可用于下游分类、检索、检测等任务。

Q2：***写出 InfoNCE 损失，并解释其含义***

- 对于锚点 $q$、正样本 $k^+$ 和 $K$ 个负样本 $\{k_i^-\}$，InfoNCE 损失为：

$$\mathcal{L}=-\log\frac{\exp(\text{sim}(q,k^+)/\tau)}{\exp(\text{sim}(q,k^+)/\tau)+\sum_{i=1}^{K}\exp(\text{sim}(q,k_i^-)/\tau)}$$

- $\text{sim}$ 通常为 **余弦相似度**（向量先做 L2 归一化再点积），$\tau$ 为 **温度系数**。
- 理解方式：
    - 本质是一个 **$(K+1)$ 类的 softmax 交叉熵**，要求模型从 $K+1$ 个候选中"认出"正样本；
    - 从信息论角度，它是互信息的下界：$I(q;k^+)\ge\log(K+1)-\mathcal{L}$，**负样本越多，下界越紧**，这也是对比学习偏好大量负样本的理论动机之一。
- SimCLR 中的 **NT-Xent**（归一化温度交叉熵）就是 InfoNCE 的一种形式，同一 batch 中其他 $2(N-1)$ 个增强样本都作为负样本。

Q3：***温度系数 $\tau$ 起什么作用？***

- $\tau$ 控制 softmax 分布的 **尖锐程度**：
    - **$\tau$ 小**：分布更尖锐，损失主要由与锚点最相似的 **困难负样本** 主导，梯度集中在它们上面，表示更具区分度，但过小会导致训练不稳定，且可能把语义相似的样本（"假负样本"）也强行推开；
    - **$\tau$ 大**：分布平滑，所有负样本被一视同仁，惩罚较温和，对困难负样本的关注度下降。
- Wang & Liu（2021）分析指出，温度控制着 **均匀性与容忍度** 之间的权衡。
- 实践中 $\tau$ 通常取 0.05–0.5 左右；CLIP 将 $\tau$ 作为 **可学习参数**（以对数形式参数化并设置上限）。

Q4：***对比学习中如何构造正负样本？***

- **正样本**：
    - 同一图像的两种不同数据增强（SimCLR、MoCo）；
    - 同一视频的不同帧/片段，同一对象的不同模态（图像-文本配对，CLIP）；
    - 有标签时同类样本（监督对比学习 SupCon）；
    - NLP 中同一句子两次不同的 dropout（SimCSE）。
- **负样本**：
    - 同一 batch 中的其他样本（SimCLR、CLIP）；
    - 维护的历史特征队列（MoCo）；
    - memory bank（InstDisc）。
- 问题：随机负样本中可能含有与锚点同类的 **假负样本（false negatives）**，会损害语义结构；可通过去偏对比损失（Debiased Contrastive Loss）或剔除可疑负样本缓解。

Q5：***SimCLR 的关键设计有哪些？***

- SimCLR（Chen et al., 2020）是一个简洁的端到端框架：同一图像做两次随机增强 → 编码器（ResNet）→ **投影头**（MLP）→ NT-Xent 损失。关键发现：
    - **数据增强的组合至关重要**：**随机裁剪 + 颜色失真** 的组合最为关键；只用裁剪时，模型可以靠颜色直方图"作弊"区分正负样本；此外还使用高斯模糊；
    - **非线性投影头**：在表示 $h$ 之后加一个 MLP 得到 $z=g(h)$，损失在 $z$ 上计算，但下游使用 $h$。投影头会丢弃对增强敏感的信息（如颜色、方向），使 $h$ 保留更多通用信息；
    - **大 batch 与长时间训练**：负样本来自 batch 内，batch 越大负样本越多，效果越好，需要 LARS 优化器以支持大 batch 训练；
    - 对比学习比监督学习更能从 **更大模型** 中获益。
- 缺点：依赖非常大的 batch，计算资源要求高。

Q6：***MoCo 是如何解决负样本数量问题的？***

- MoCo（He et al., 2019）将对比学习看作 **字典查找**：query 编码器编码锚点，key 编码器编码正负样本，希望字典 **大** 且 **一致**。
- **队列（queue）**：将过去若干 batch 的 key 特征存入一个先进先出队列作为负样本，字典大小与 batch 大小 **解耦**，小 batch 也能使用大量负样本。
- **动量编码器**：key 编码器的参数不通过反向传播更新，而是 query 编码器参数的 **指数移动平均（EMA）**：

$$\theta_k\leftarrow m\theta_k+(1-m)\theta_q$$

- $m$ 取值接近 1（如 0.999），使 key 编码器缓慢变化，队列中不同时间产生的 key **保持一致**；若直接复制 query 编码器（$m=0$），训练会失败。
- 后续：MoCo v2 引入 SimCLR 的 MLP 投影头与更强增强；MoCo v3 将其用于 ViT，去掉队列改用大 batch，并发现冻结随机初始化的 patch 投影层可以提升训练稳定性。

Q7：***BYOL 为什么不需要负样本也不会坍塌？***

- **坍塌（collapse）**：如果只拉近正样本对，最简单的解是让所有输入输出同一个常数向量，损失为零但表示毫无用处。负样本的作用之一就是防止坍塌。
- BYOL（Grill et al., 2020）结构：
    - **online 网络**：编码器 + 投影头 + **预测头（predictor）**；
    - **target 网络**：编码器 + 投影头，参数为 online 网络的 **EMA**，不接收梯度；
    - 损失：online 的预测输出与 target 的投影输出（均做 L2 归一化）之间的 MSE，并对两个视图交换计算。
- 避免坍塌的关键在于 **非对称结构**：
    - **预测头** 与 **stop-gradient**（target 分支不回传梯度）共同打破对称性，使常数解不再是优化动态容易到达的平衡点；
    - EMA 目标网络提供缓慢变化、稳定的回归目标。
- 理论上常数解仍是损失的全局最小值，BYOL 依靠的是 **优化动态** 而不是损失函数本身来避免坍塌。

Q8：***SimSiam 的发现是什么？stop-gradient 有什么作用？***

- SimSiam（Chen & He, 2020）对 BYOL 做了极简化：**去掉 EMA**，两个分支 **共享同一编码器**，不使用负样本、不需要大 batch，仅保留预测头与 **stop-gradient**：

$$\mathcal{L}=\frac{1}{2}D(p_1,\text{sg}(z_2))+\frac{1}{2}D(p_2,\text{sg}(z_1))$$

- 其中 $D$ 是负余弦相似度，$\text{sg}$ 表示停止梯度。
- 实验表明 **去掉 stop-gradient 会立即坍塌**，而 EMA 并不是必需的。
- 作者给出的解释：SimSiam 类似于一个 **EM 式的交替优化**——stop-gradient 相当于固定一组变量（每张图的目标表示），优化另一组（网络参数），预测头则近似完成对多种增强的期望。

Q9：***DINO 的原理是什么？如何防止坍塌？***

- DINO（Caron et al., 2021）是 **无标签的自蒸馏**：学生网络和教师网络结构相同，教师参数为学生的 **EMA**。
- 教师输出经 softmax 得到概率分布，学生用 **交叉熵** 拟合教师分布：$\mathcal{L}=-\sum P_t(x)\log P_s(x')$。
- **multi-crop**：教师只看 2 个全局视图，学生看全部的全局与局部小视图，鼓励"局部到全局"的对应。
- 防坍塌依靠两种互补操作：
    - **centering**：教师输出减去一个滑动平均的中心 $c$，防止某一维主导，但会让输出趋向均匀分布；
    - **sharpening**：教师使用较低的温度，使分布尖锐，防止均匀分布坍塌。
- 特点：用于 ViT 时，[CLS] token 的自注意力图能呈现清晰的 **物体分割**；特征适合 kNN 分类与检索。后续 DINOv2 结合 iBOT 的掩码目标与大规模精选数据，得到通用视觉特征。

Q10：***Barlow Twins 和 VICReg 的思路是什么？***

- 这类方法通过 **约束表示的统计特性** 来避免坍塌，而不是依赖负样本或非对称结构。
- **Barlow Twins**（Zbontar et al., 2021）：计算两个视图的嵌入（沿 batch 标准化）之间的 **互相关矩阵** $\mathcal{C}$，使其接近单位矩阵：

$$\mathcal{L}=\sum_i(1-\mathcal{C}_{ii})^2+\lambda\sum_i\sum_{j\ne i}\mathcal{C}_{ij}^2$$

- 对角线项：同一维度在两个视图之间高度相关（**不变性**）；
- 非对角线项：不同维度之间去相关（**减少冗余**）。
- **VICReg**（Bardes et al., 2021）：三项损失：
    - **Variance**：每个维度在 batch 内的标准差不低于阈值（铰链损失），直接防止坍塌为常数；
    - **Invariance**：两个视图嵌入的 MSE；
    - **Covariance**：协方差矩阵的非对角元素趋于 0，去相关。
- 优点：不需要负样本、大 batch、EMA 或预测头；缺点是通常需要较高的嵌入维度。

Q11：***CLIP 是如何进行图像-文本对比学习的？***

- CLIP（Radford et al., 2021）在大规模网络图文对上联合训练 **图像编码器** 和 **文本编码器**。
- 对于一个 batch 的 $N$ 个图文对，计算 $N\times N$ 的相似度矩阵，对角线为正样本对，其余 $N^2-N$ 个为负样本。
- 损失为 **对称交叉熵**：图像→文本方向和文本→图像方向各做一次 InfoNCE，取平均：

$$\mathcal{L}=\frac{1}{2}\left(\mathcal{L}_{i\to t}+\mathcal{L}_{t\to i}\right)$$

- 温度为可学习参数；需要非常大的 batch 提供足够负样本。
- 能力：**零样本分类**（用类别名构造文本提示，选择相似度最高的文本）、跨模态检索，并成为众多多模态模型的视觉编码器。
- 改进：**SigLIP** 用逐对的 sigmoid 损失替代 softmax，不需要在全 batch 上做归一化，对 batch 大小更友好。

Q12：***什么是困难负样本？如何利用？***

- **困难负样本（hard negatives）**：与锚点在表示空间中相似但语义不同的负样本，提供的梯度信息最多；简单负样本很快就产生接近零的梯度。
- 利用方式：
    - 降低温度 $\tau$，隐式提高困难负样本权重；
    - **困难负样本挖掘**：从队列或检索结果中选取相似度高的负样本；
    - 根据相似度对负样本 **重新加权**（如 Robinson et al., 2021 的 hard negative sampling）；
    - 特征空间中 **合成** 困难负样本（如 MoCHi 对负样本做混合）。
- 风险：越困难的负样本越可能是 **假负样本**，过度强调会损害表示；检索任务（如 DPR）中常用 BM25 检索到的非答案段落作为困难负样本。

Q13：***什么是对齐性（alignment）和均匀性（uniformity）？***

- Wang & Isola（2020）把对比损失分解为两个性质（表示位于单位超球面上）。
- **对齐性**：正样本对的表示应接近：

$$\mathcal{L}_{align}=\mathbb{E}_{(x,y)\sim p_{pos}}\|f(x)-f(y)\|_2^2$$

- **均匀性**：所有表示应在超球面上尽可能均匀分布，以保留最多信息：

$$\mathcal{L}_{uniform}=\log\mathbb{E}_{x,y\sim p_{data}}e^{-t\|f(x)-f(y)\|_2^2}$$

- InfoNCE 的分子项主要优化对齐性，分母项（负样本）主要优化均匀性。
- 两个指标可直接用于诊断表示质量：只有对齐没有均匀性就会坍塌；只有均匀性没有对齐则表示对增强不具不变性。

Q14：***什么是维度坍塌（dimensional collapse）？***

- **完全坍塌**：所有表示收敛到同一点。
- **维度坍塌**：表示没有坍缩为一个点，但只占据嵌入空间的一个 **低维子空间**，很多维度没有被利用，嵌入协方差矩阵的奇异值谱中大量奇异值接近 0。
- Jing et al.（2021，"Understanding Dimensional Collapse in Contrastive Self-supervised Learning"）指出，即使是使用负样本的对比学习也会发生维度坍塌，原因包括强数据增强以及多层网络中的隐式正则化。
- 诊断：观察嵌入协方差矩阵的 **奇异值谱** 或有效秩。
- 缓解：Barlow Twins/VICReg 的去相关项、投影头设计（如 DirectCLR）、白化（W-MSE）等。

Q15：***如何评估自监督/对比学习得到的表示？***

- **线性探测（linear probe）**：冻结编码器，只在其特征上训练一个线性分类器，衡量特征的 **线性可分性**，是最常用的标准评估协议。
- **kNN 分类**：冻结特征，直接用最近邻投票分类，无需训练，DINO 常报告此指标。
- **微调（fine-tuning）**：解冻全部参数在下游任务上训练，衡量作为初始化的价值。
- **半监督 / 少样本**：只用 1% 或 10% 标签微调。
- **迁移学习**：迁移到检测、分割等其他任务和数据集上。
- 注意：不同评估协议的结论可能不一致——对比学习方法通常线性探测强，而 MAE 等掩码建模方法微调强、线性探测较弱。

Q16：***为什么 SimCLR 下游使用投影头之前的特征？***

- 对比损失要求表示对数据增强 **不变**，因此投影头输出 $z$ 会丢弃颜色、方向等被增强改变的信息。
- 而这些信息可能对下游任务有用；投影头之前的 $h$ 保留了更多信息。
- SimCLR 实验显示，在 $h$ 上训练的线性分类器显著优于在 $z$ 上训练的；同时用 $z$ 预测所施加的增强类型准确率较低，而用 $h$ 准确率较高，支持了上述解释。
- 另一种解释：投影头吸收了损失带来的维度坍塌，使骨干特征保持较高的有效秩。

Q17：***对比学习与监督学习、掩码建模相比各有什么特点？***

- **与监督学习相比**：
    - 不需要标签，可以利用海量无标注数据；
    - 学习的是实例级的判别（每个样本自成一类），而非预定义类别；
    - 迁移到检测等下游任务时，往往能达到甚至超过监督预训练的效果。
- **与掩码建模（MAE、BEiT）相比**：
    - 对比学习学到的是 **全局、不变** 的语义特征，线性可分性强；
    - 依赖精心设计的数据增强和负样本/防坍塌机制；
    - 掩码建模保留更多 **空间细节**，更适合微调与密集预测，训练也更容易扩展。
- 两类方法正在融合，如 iBOT、DINOv2 同时使用自蒸馏与掩码目标。
