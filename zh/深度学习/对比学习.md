# 对比学习

Q1：***什么是对比学习？核心思想是什么？***

- **对比学习是一种不需要标签的自监督表示学习：构造正样本对（如同一张图的两种增强）和负样本对（如不同图片），训练编码器让正样本在表示空间里靠近、负样本远离。**
- 这样学到的表示对增强等无关变化保持不变，同时保留区分不同样本的信息。
- 学到的编码器可用于下游分类、检索、检测等任务。

Q2：***写出 InfoNCE 损失，并解释其含义***

- **InfoNCE 本质上是一个 K+1 类的 softmax 交叉熵：让模型在一个正样本和 K 个负样本里"认出"正样本，相似度用归一化后的余弦相似度再除以温度。**
- 从信息论看，它是互信息的下界，负样本越多下界越紧，这是对比学习偏爱大量负样本的理论原因之一。
- SimCLR 的 NT-Xent 就是 InfoNCE 的一种形式，同一 batch 里其他增强样本都当作负样本。
- 核心公式：$\mathcal{L}=-\log\frac{\exp(\text{sim}(q,k^+)/\tau)}{\exp(\text{sim}(q,k^+)/\tau)+\sum_{i=1}^{K}\exp(\text{sim}(q,k_i^-)/\tau)}$

Q3：***温度系数 $\tau$ 起什么作用？***

- **温度控制 softmax 的尖锐程度，也就是模型对困难负样本的关注程度。**
- 温度小：分布尖锐，损失由最相似的困难负样本主导，表示更有区分度，但过小会不稳定，还可能把语义相似的"假负样本"强行推开。
- 温度大：分布平滑，所有负样本一视同仁，惩罚温和。
- 本质上是均匀性和容忍度之间的权衡；常取 0.05–0.5，CLIP 把它设成可学习参数。

Q4：***对比学习中如何构造正负样本？***

- **正样本通常是同一样本的不同"视图"，负样本通常就是 batch 内或队列里的其他样本。**
- 正样本：同一图像的两种增强（SimCLR、MoCo），配对的图像和文本（CLIP），有标签时的同类样本（SupCon），同一句子两次不同 dropout（SimCSE）。
- 负样本：batch 内其他样本（SimCLR、CLIP）、历史特征队列（MoCo）、memory bank。
- 随机负样本里可能混有同类的假负样本，可用去偏对比损失或剔除可疑负样本缓解。

Q5：***SimCLR 的关键设计有哪些？***

- **SimCLR 是一个简洁的端到端框架：同一图像做两次随机增强，经编码器和 MLP 投影头后用 NT-Xent 损失训练；关键在于强增强组合、非线性投影头和大 batch。**
- 增强组合至关重要，尤其是随机裁剪加颜色失真；只用裁剪时模型会靠颜色直方图"作弊"。
- 损失在投影头输出上计算，但下游用投影头之前的特征，因为投影头会丢掉对增强敏感的信息。
- 负样本来自 batch 内，batch 越大越好，需要 LARS 优化器；缺点是计算资源要求很高。

Q6：***MoCo 是如何解决负样本数量问题的？***

- **MoCo 用一个先进先出的队列保存过去多个 batch 的 key 特征作为负样本，让负样本数量与 batch 大小解耦；再用动量编码器保证队列里的 key 保持一致。**
- 动量编码器：key 编码器不靠反向传播，而是 query 编码器参数的 EMA，动量取 0.999 左右，变化很慢。
- 如果直接复制 query 编码器，队列里不同时刻的 key 不一致，训练会失败。
- MoCo v2 加入了 MLP 投影头和更强增强；MoCo v3 用于 ViT，去掉队列改用大 batch。
- 核心公式：$\theta_k\leftarrow m\theta_k+(1-m)\theta_q$

Q7：***BYOL 为什么不需要负样本也不会坍塌？***

- **BYOL 靠非对称结构避免坍塌：online 分支多一个预测头，target 分支是 online 的 EMA 且不回传梯度，这种不对称让"所有输出都一样"的常数解在优化过程中很难到达。**
- 坍塌是指只拉近正样本时，最简单的解就是输出常数，损失为零但表示无用。
- 损失是 online 预测输出与 target 投影输出（L2 归一化后）的 MSE，两个视图交换再算一次。
- 常数解理论上仍是损失的全局最小值，BYOL 依靠的是优化动态而不是损失本身。

Q8：***SimSiam 的发现是什么？stop-gradient 有什么作用？***

- **SimSiam 发现 BYOL 的 EMA 不是必需的：两个分支共享同一个编码器、不用负样本和大 batch，只保留预测头和 stop-gradient 就能学好；但去掉 stop-gradient 会立刻坍塌。**
- 作者的解释：它类似一种 EM 式的交替优化，stop-gradient 相当于固定每张图的目标表示，只优化网络参数。
- 预测头则近似完成对多种增强求期望的作用。
- 核心公式：$\mathcal{L}=\frac{1}{2}D(p_1,\text{sg}(z_2))+\frac{1}{2}D(p_2,\text{sg}(z_1))$，$D$ 为负余弦相似度

Q9：***DINO 的原理是什么？如何防止坍塌？***

- **DINO 是无标签的自蒸馏：教师是学生的 EMA，学生用交叉熵去拟合教师输出的概率分布；防坍塌靠对教师输出做 centering 和 sharpening。**
- multi-crop：教师只看两个全局视图，学生看全部全局和局部小图，学习"局部到全局"的对应。
- centering 减去滑动平均中心，防止某一维主导，但会让分布趋于均匀。
- sharpening 用低温度让教师分布更尖锐，防止均匀分布坍塌，两者互补。
- 用在 ViT 上时 [CLS] 注意力图能清晰分割物体；DINOv2 进一步结合掩码目标和大规模精选数据。

Q10：***Barlow Twins 和 VICReg 的思路是什么？***

- **这类方法不靠负样本或非对称结构，而是直接约束表示的统计特性来防坍塌：让两个视图的嵌入在同一维度上相关、不同维度之间去相关。**
- Barlow Twins：让两个视图嵌入的互相关矩阵接近单位矩阵，对角线代表不变性，非对角线代表减少冗余。
- VICReg 有三项：方差项要求每维标准差不低于阈值（直接防坍塌），不变项是两视图的 MSE，协方差项让非对角元素趋于 0。
- 优点是不需要负样本、大 batch、EMA 或预测头；缺点是通常需要较高的嵌入维度。
- 核心公式：$\mathcal{L}_{BT}=\sum_i(1-\mathcal{C}_{ii})^2+\lambda\sum_i\sum_{j\ne i}\mathcal{C}_{ij}^2$

Q11：***CLIP 是如何进行图像-文本对比学习的？***

- **CLIP 在海量网络图文对上联合训练图像编码器和文本编码器：一个 batch 的 N 对图文算出 N×N 相似度矩阵，对角线是正样本，其余都是负样本，从图到文和从文到图各做一次 InfoNCE 再取平均。**
- 温度可学习；需要非常大的 batch 提供足够负样本。
- 能做零样本分类（用类别名构造文本提示，选最相似的）和跨模态检索，并成为很多多模态模型的视觉编码器。
- SigLIP 用逐对的 sigmoid 损失替代 softmax，不需要全 batch 归一化，对 batch 大小更友好。

Q12：***什么是困难负样本？如何利用？***

- **困难负样本是在表示空间里和锚点很像但语义不同的负样本，它们提供的梯度最多，而简单负样本的梯度很快趋近于零。**
- 利用方法：降低温度（隐式加权）、从队列或检索结果里挖掘高相似度负样本、按相似度重新加权、在特征空间里合成困难负样本（如 MoCHi）。
- 风险：越难的负样本越可能是假负样本，过度强调会损害表示。
- 检索任务（如 DPR）常用 BM25 检出的非答案段落作为困难负样本。

Q13：***什么是对齐性（alignment）和均匀性（uniformity）？***

- **对齐性是指正样本对的表示要彼此接近；均匀性是指所有表示要在单位超球面上尽量均匀分布，以保留尽可能多的信息。**
- InfoNCE 的分子主要优化对齐性，分母（负样本）主要优化均匀性。
- 两者都可以直接用来诊断表示：只有对齐没有均匀会坍塌，只有均匀没有对齐则对增强不具不变性。

Q14：***什么是维度坍塌（dimensional collapse）？***

- **维度坍塌是指表示没有缩成一个点，但只占据了嵌入空间的一个低维子空间，很多维度没被利用。**
- 区别于完全坍塌（所有表示收敛到同一点）。
- 即使使用负样本的对比学习也会发生，原因包括强数据增强和多层网络的隐式正则化。
- 诊断：看嵌入协方差矩阵的奇异值谱或有效秩，大量奇异值接近 0 就说明有维度坍塌。
- 缓解：Barlow Twins/VICReg 的去相关项、投影头设计（如 DirectCLR）、白化（W-MSE）。

Q15：***如何评估自监督/对比学习得到的表示？***

- **最常用的是线性探测：冻结编码器，只训练一个线性分类器，衡量特征的线性可分性。**
- kNN 分类：冻结特征直接做最近邻投票，不需要训练（DINO 常报告）。
- 微调：解冻全部参数，衡量它作为初始化的价值；还有只用 1% 或 10% 标签的半监督评估。
- 迁移到检测、分割等其他任务和数据集。
- 不同协议结论可能不同：对比学习通常线性探测强，MAE 等掩码建模则微调强、线性探测弱。

Q16：***为什么 SimCLR 下游使用投影头之前的特征？***

- **因为对比损失要求表示对增强不变，投影头输出会丢掉颜色、方向等被增强改变的信息，而这些信息可能对下游有用；投影头之前的特征保留得更多。**
- 实验中，在投影头之前的特征上做线性分类明显更好。
- 用投影头输出预测施加了哪种增强准确率低，用之前的特征准确率高，支持了这个解释。
- 另一种解释：投影头吸收了维度坍塌，让骨干特征保持较高的有效秩。

Q17：***对比学习与监督学习、掩码建模相比各有什么特点？***

- **相比监督学习，对比学习不需要标签、学的是实例级判别；相比掩码建模，它学到的是全局、不变的语义特征，线性可分性强，但依赖增强设计和防坍塌机制。**
- 迁移到检测等下游任务时，往往能达到甚至超过监督预训练。
- 掩码建模（MAE、BEiT）保留更多空间细节，更适合微调和密集预测，也更容易扩展。
- 两类方法正在融合，如 iBOT、DINOv2 同时使用自蒸馏和掩码目标。
