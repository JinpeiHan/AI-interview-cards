# BERT

Q1：***BERT 的模型结构与规模是怎样的？***

- BERT（Devlin et al., 2018，"Bidirectional Encoder Representations from Transformers"）是 **仅由 Transformer Encoder 堆叠** 而成的预训练语言模型，每个 token 都能通过自注意力 **同时看到左右两侧的上下文**。
- 两种标准规模（$L$ 为层数，$H$ 为隐藏维度，$A$ 为注意力头数）：
    - **BERT-Base**：$L=12,H=768,A=12$，约 110M 参数；
    - **BERT-Large**：$L=24,H=1024,A=16$，约 340M 参数。
- FFN 中间层维度为 $4H$，激活函数为 **GELU**，采用 Post-LN 结构。
- 预训练语料为 BooksCorpus 与英文维基百科，预训练任务为 **MLM** 和 **NSP**。

Q2：***BERT 的输入表示是如何构造的？WordPiece 有什么作用？***

- 输入序列格式：`[CLS] 句子A [SEP] 句子B [SEP]`，最终输入向量为三种嵌入之和：

$$E=E_{token}+E_{segment}+E_{position}$$

- **Token Embedding**：WordPiece 子词嵌入（英文词表约 30k）；
- **Segment Embedding**：区分句子 A/B，只有两个取值；
- **Position Embedding**：**可学习的绝对位置编码**，最大 512 个位置。
- **WordPiece** 是一种子词分词算法，按照最大化训练语料似然的准则合并子词；如 "playing" → "play", "##ing"（"##" 表示词内续接）。
- 作用：
    - 词表规模可控，同时基本消除 **OOV** 问题——任何词都可以拆成子词甚至字符；
    - 子词共享使罕见词、形态变化的词可以复用常见子词的表示。
- 下游做 token 级任务（如 NER）时，需要处理一个词被切成多个子词的标签对齐问题（通常只用第一个子词预测标签）。

Q3：***MLM 为什么选择 15% 的掩码比例？80/10/10 规则的深层动机是什么？***

- **15% 的权衡**：
    - 比例太低：每个序列只有很少的位置产生损失，训练信号稀疏，需要更多训练步数；
    - 比例太高：上下文被破坏过多，预测缺乏足够依据，且与下游完整输入的差距更大。
- **80/10/10 规则**（被选中的 15% 中，80% 替换为 [MASK]，10% 替换为随机词，10% 保持不变）的深层动机：
    - 解决 **预训练-微调不一致**：[MASK] 在下游从不出现，若始终使用 [MASK]，模型可能只在 [MASK] 位置学习好的预测表示，而对普通 token 的表示不够重视；
    - 由于模型 **无法得知哪些位置被篡改**，它必须为 **每一个 token** 都维护基于上下文的表示，而不能简单地复制输入嵌入；
    - 随机替换只占全部 token 的 $15\%\times10\%=1.5\%$，噪声很小，不会明显损害语言理解能力。
- BERT 论文的消融实验显示，混合策略在微调与基于特征的使用方式上都较为稳健；而纯 [MASK] 策略在基于特征（不微调）的 NER 上明显较差。
- 后续研究（如 Wettig et al., 2022，"Should You Mask 15% in Masked Language Modeling?"）发现在更大模型上更高的掩码比例也可以工作得很好，15% 并非最优而是一个经验选择。

Q4：***NSP 任务是什么？为什么 RoBERTa 去掉了 NSP？***

- **NSP（Next Sentence Prediction）**：给定句子 A 和 B，50% 的情况下 B 是 A 在原文中的真实下一句（IsNext），50% 是从语料中随机采样的句子（NotNext），用 [CLS] 的输出做二分类。目的是让模型学习句间关系，以服务问答、自然语言推理等任务。
- RoBERTa（Liu et al., 2019）去掉 NSP 的原因：
    - 消融实验表明，去掉 NSP 并使用 **连续的完整句子（FULL-SENTENCES / DOC-SENTENCES）** 填满 512 长度进行训练，下游效果持平或更好；
    - NSP 任务 **过于简单**：负样本来自不同文档，模型只需判断 **主题是否一致** 即可，学不到真正的句间连贯性（ALBERT 也指出了这一点，并用 SOP 替代）；
    - 句子对格式使单个输入片段变短，模型 **难以学习长距离依赖**。

Q5：***BERT 如何用于下游任务微调？***

- 在 BERT 之上加一个很小的任务相关输出层，**全部参数一起微调**：
    - **单句/句对分类**（情感分析、NLI）：取 [CLS] 的最终隐藏向量 $C\in\mathbb{R}^H$，接一个 softmax 分类层 $P=\text{softmax}(CW^T)$；
    - **序列标注**（NER、分词）：对每个 token 的输出向量接分类层，预测其标签（可以再加 CRF 层建模标签依赖）；
    - **抽取式问答**（SQuAD）：输入 `[CLS] 问题 [SEP] 段落 [SEP]`，引入可学习的起始向量 $S$ 和结束向量 $E$，第 $i$ 个 token 为答案起点的概率为 $P_i=\frac{e^{S\cdot T_i}}{\sum_j e^{S\cdot T_j}}$，终点同理，选取 $j\ge i$ 时 $S\cdot T_i+E\cdot T_j$ 最大的片段作为答案；
    - **多选题**（SWAG）：每个选项与题目拼接后分别编码，用 [CLS] 打分后做 softmax。
- 微调常用较小学习率（如 $2\times10^{-5}$ 到 $5\times10^{-5}$）、少量 epoch，配合 warmup 与线性衰减。

Q6：***为什么可以用 [CLS] 做句子表示？它有什么局限？***

- [CLS] 位于序列开头且不对应任何真实词，通过多层自注意力可以 **聚合整句信息**；BERT 在 [CLS] 输出后接一个带 tanh 的 **pooler 层**，在 NSP 任务上预训练，因此天然适合作为分类特征。
- 局限：
    - 不微调时，[CLS] 向量 **并不是好的句子语义表示**——它只在 NSP 上训练过，直接用于语义相似度往往不如对 token 输出做平均池化，甚至不如 GloVe 平均；
    - BERT 的表示空间存在 **各向异性（anisotropy）**：向量集中在一个狭窄的锥形区域，余弦相似度普遍偏高，区分度差；
- 因此句子嵌入任务一般采用 Sentence-BERT、SimCSE 等专门训练的方法，或者对表示做白化（BERT-whitening）、流变换（BERT-flow）。

Q7：***RoBERTa 对 BERT 做了哪些改进？***

- RoBERTa（"A Robustly Optimized BERT Pretraining Approach"）**不改变模型结构**，而是证明 BERT 训练不充分，通过改进训练策略提升效果：
    - **动态掩码**：每次把序列输入模型时重新生成掩码，而不是在数据预处理时固定掩码（BERT 将数据复制 10 份并用不同掩码，属于静态掩码）；
    - **去掉 NSP**，使用连续完整句子填满输入；
    - **更大的 batch**（如 8k）和更大的学习率；
    - **更多的数据**（约 160GB 文本，BERT 约 16GB）与 **更长的训练**；
    - **字节级 BPE**（byte-level BPE，约 50k 词表），无需预处理即可编码任意文本，无未知字符。
- 启示：预训练模型的效果很大程度取决于 **数据量、训练步数和超参数**，而不只是模型结构与预训练目标。

Q8：***ALBERT 是如何减少参数量的？***

- ALBERT（Lan et al., 2019）有三个主要改进：
    - **词嵌入矩阵分解（Factorized Embedding Parameterization）**：BERT 中嵌入维度 $E$ 等于隐藏层维度 $H$，嵌入参数量为 $V\times H$。ALBERT 先将词映射到低维空间 $E$（如 128），再投影到 $H$，参数量从 $O(V\times H)$ 降为 $O(V\times E+E\times H)$。理由：词嵌入学习的是 **上下文无关** 的表示，隐藏层学习的是 **上下文相关** 的表示，后者需要更大容量；
    - **跨层参数共享**：所有 Transformer 层共享同一组参数（注意力与 FFN 都共享），参数量与层数无关，同时使各层输入输出的变化更平滑；
    - **SOP（Sentence Order Prediction）**：替代 NSP，正样本为同一文档中的两个连续片段，负样本为 **交换顺序** 的同一对片段，迫使模型学习句间 **连贯性** 而非主题。
- 注意：ALBERT 减少的是 **参数量和显存**，而 **计算量并没有减少**（层数不变，每层都要计算），推理速度没有提升，ALBERT-xxlarge 的计算代价甚至大于 BERT-Large。

Q9：***DistilBERT 是如何进行知识蒸馏的？***

- DistilBERT（Sanh et al., 2019）在 **预训练阶段** 进行任务无关的蒸馏：
    - 学生网络 **层数减半**（6 层），隐藏维度不变，并去掉 token-type 嵌入与 pooler；
    - **用教师的层初始化学生**：每隔一层取一层教师参数作为学生的初始化；
    - 损失由三部分组成：
        1. **蒸馏损失**：学生与教师在 MLM 上的软目标分布之间的交叉熵，使用温度 $T$ 软化 softmax：$p_i=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}$；
        2. **MLM 损失**：标准的掩码语言模型损失；
        3. **余弦嵌入损失**：对齐学生与教师隐藏状态的方向。
- 效果：模型更小、推理更快，同时保留了教师模型的大部分语言理解能力。
- 其他 BERT 压缩方案：TinyBERT（中间层与注意力矩阵蒸馏，含预训练和任务两阶段蒸馏）、MobileBERT、剪枝、量化等。

Q10：***ELECTRA 的替换 token 检测（RTD）是什么？为什么更高效？***

- ELECTRA（Clark et al., 2020）包含两个网络：
    - **生成器（Generator）**：一个小型 MLM，对被遮盖的位置采样生成替换词；
    - **判别器（Discriminator）**：判断输入序列中 **每个 token** 是原始的还是被生成器替换过的（二分类），即 **Replaced Token Detection**。
- 总损失：$\mathcal{L}=\mathcal{L}_{MLM}(\theta_G)+\lambda\mathcal{L}_{Disc}(\theta_D)$，预训练后只保留判别器用于下游任务。
- 更高效的原因：
    - MLM 只在 15% 的被遮盖位置上计算损失，而 RTD 在 **所有 token** 上都有学习信号，样本效率更高；
    - 判别器的输入中没有 [MASK]，**缓解了预训练-微调不一致**。
- 细节：
    - 生成器用 **最大似然** 训练，而不是对抗训练（生成器采样离散 token，梯度无法从判别器回传），因此它并不是 GAN；
    - 生成器不宜太强，否则判别任务过难，论文发现生成器大小为判别器的 1/4–1/2 时效果最好；
    - 生成器与判别器共享词嵌入；如果生成器恰好生成了原词，该位置标记为"原始"。

Q11：***DeBERTa 的解耦注意力（Disentangled Attention）是什么？***

- DeBERTa（He et al., 2020）的核心改进之一是 **解耦注意力**：每个 token 用两个向量表示——**内容向量** $H_i$ 与 **相对位置向量** $P_{i|j}$。注意力分数分解为：

$$A_{i,j}=\underbrace{H_iH_j^T}_{\text{内容→内容}}+\underbrace{H_iP_{j|i}^T}_{\text{内容→位置}}+\underbrace{P_{i|j}H_j^T}_{\text{位置→内容}}$$

- 位置→位置项在相对位置下信息较少，被省略；注意力得分的缩放因子相应改为 $\frac{1}{\sqrt{3d}}$。
- **增强掩码解码器（Enhanced Mask Decoder, EMD）**：由于主干只用相对位置，DeBERTa 在最后的 softmax 预测层之前才引入 **绝对位置** 信息（例如区分 "a new **store** opened beside the new **mall**" 中 store 和 mall 的句法角色）；
- 微调时使用虚拟对抗训练（SiFT）提升鲁棒性。
- DeBERTa v3 将预训练目标改为 ELECTRA 式的 RTD，并提出 **梯度解耦的嵌入共享（GDES）**，解决生成器与判别器共享嵌入时的"拔河"问题。

Q12：***BERT 与 GPT 在设计上的核心区别是什么？***

- **结构**：BERT 是 Encoder-only，使用 **双向** 自注意力；GPT 是 Decoder-only，使用 **因果（单向）掩码** 自注意力。
- **预训练目标**：BERT 是 **去噪自编码**（MLM，预测被遮盖的词）；GPT 是 **自回归语言模型**（预测下一个词），$P(x)=\prod_tP(x_t|x_{<t})$。
- **优势任务**：BERT 擅长 **理解类任务**（分类、抽取、匹配），每个 token 的表示都融合了全局上下文；GPT 擅长 **生成类任务**，并且随着规模扩大展现出 in-context learning 等能力。
- **训练效率**：MLM 每个序列只有约 15% 的位置产生损失；自回归 LM 每个位置都有损失。
- **使用方式**：BERT 通常需要针对每个任务微调；GPT 系列可以通过提示（prompt）完成零样本/少样本任务。
- 统一尝试：XLNet（排列语言模型）、T5（Encoder-Decoder，Span Corruption）、UniLM（通过不同注意力掩码统一双向/单向/seq2seq）。

Q13：***为什么 BERT 不擅长文本生成？***

- **MLM 不是一个合法的自回归分解**：BERT 学习的是 $P(x_i|x_{\setminus i})$，即在已知其他所有词的条件下预测一个词，无法直接给出整个序列的联合概率 $P(x)$，也就无法从左到右逐词采样。
- **独立性假设**：同时遮盖多个词时，BERT 对每个被遮盖位置的预测是 **相互独立** 的，生成多个词时容易产生不连贯的组合（XLNet 论文指出了该问题）。
- **双向注意力无法缓存**：生成时每增加一个词，所有位置的表示都会改变，不能像因果模型那样使用 KV cache 增量计算，效率低。
- **预训练-生成不一致**：BERT 从未在"只有左侧上下文"的条件下训练过。
- 变通方法：Gibbs 采样式的迭代填充、非自回归生成（Mask-Predict）、用 BERT 初始化 seq2seq 的编码器，但效果一般不如原生的生成式模型。

Q14：***BERT 的最大长度为什么是 512？如何处理长文本？***

- **原因**：
    - 自注意力的计算与显存为 $O(n^2)$，长度越长代价越大；
    - 位置编码是 **可学习的绝对位置嵌入**，只训练了 512 个位置，超过 512 的位置没有对应的嵌入，无法直接外推；
    - 预训练时为了效率，前 90% 的步数使用长度 128 的序列，只有最后 10% 使用 512 长度。
- **处理长文本的方法**：
    - **截断**：保留开头、结尾或首尾拼接（如 head+tail）；
    - **滑动窗口**：分段编码并设置重叠，再融合各段结果（SQuAD 中使用 doc stride）；
    - **层级模型**：先对段落分别编码，再用一个上层模型聚合段落表示；
    - **长文本模型**：Longformer、BigBird（局部窗口 + 全局 + 随机稀疏注意力）；
    - **位置编码改进**：使用相对位置编码或 RoPE 等便于外推的方式，ModernBERT 等新一代编码器支持更长的上下文。

Q15：***Sentence-BERT 是如何得到句子向量的？为什么不直接用 BERT？***

- **直接用 BERT 的问题**：
    - BERT 做句对相似度是 **交叉编码器（cross-encoder）**：两个句子拼接后一起输入，精度高但每一对都要完整计算一次。在 $n=10000$ 个句子中找最相似的一对需要 $\frac{n(n-1)}{2}\approx5\times10^7$ 次推理，无法用于大规模检索；
    - 直接取 [CLS] 或平均池化得到的句向量质量较差（见 Q6）。
- **Sentence-BERT（Reimers & Gurevych, 2019）**：
    - 采用 **孪生网络（Siamese）/ 双编码器（bi-encoder）** 结构，两个句子分别经过 **共享参数** 的 BERT，再做 **平均池化** 得到句向量 $u$、$v$；
    - 在 NLI 数据上训练分类目标：将 $(u,v,|u-v|)$ 拼接后接 softmax 分类器；在 STS 回归任务上直接优化余弦相似度；也可使用三元组损失；
    - 推理时句向量可以 **预先计算并建立索引**，相似度用余弦距离计算，适合语义检索与聚类。
- 后续：**SimCSE** 使用对比学习（无监督版本中，同一句子两次不同 dropout 作为正样本），进一步提升句向量质量并缓解各向异性；在检索系统中常用"bi-encoder 召回 + cross-encoder 重排"的组合。

Q16：***BERT 的各向异性问题是什么？如何缓解？***

- **现象**：BERT 输出的词/句向量分布在一个狭窄的锥形空间中，任意两个句子的余弦相似度都很高，导致语义相似度计算的区分度很差。
- **原因分析**：与词频相关——高频词的嵌入靠近原点，低频词分布稀疏，词嵌入空间不均匀；softmax 训练目标与权重共享也会导致表示退化。
- **缓解方法**：
    - **后处理**：BERT-flow（将分布通过标准化流映射为各向同性高斯）、BERT-whitening（白化，使协方差矩阵为单位阵）；
    - **对比学习**：SimCSE 等方法通过拉开负样本提升 **均匀性**；
    - 有监督句向量训练（Sentence-BERT）。

Q17：***微调 BERT 时有哪些常见问题与技巧？***

- **灾难性遗忘与过拟合**：小数据集上全量微调容易过拟合，可使用较小学习率、少量 epoch、早停，或 **分层学习率衰减**（底层学习率更小，因为底层学到的是更通用的特征）。
- **训练不稳定**：BERT-Large 在小数据集上微调时，不同随机种子结果差异大，有时会失败；可通过 warmup、使用带偏差校正的 Adam、增加训练步数、重新初始化顶部几层来缓解。
- **领域适配**：在下游领域语料上 **继续预训练**（domain-adaptive pretraining），如 BioBERT、SciBERT、FinBERT。
- **参数高效微调**：Adapter、Prefix-Tuning、LoRA 等只训练少量参数，适合多任务部署。
- **类别不平衡**：使用加权交叉熵、Focal Loss 或重采样。
